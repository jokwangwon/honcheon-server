# 페이블 검토 대기열

## B-001~B-003

- 입력: `CODEX_B001_B003_COMPLETE.md`와 관련 diff
- 확인: ID 탐지력, domain 호출 사슬, 종료 코드 계약
- 조언 기록: `FABLE_REVIEW.md`

## B-009

- 입력: `CODEX_B009_COMPLETE.md`와 관련 diff
- 확인: 이벤트 로그 actor/target 계약, 등록부 단일 정본, 실제 이벤트 통합 테스트 필요성
- 조언 기록: `FABLE_REVIEW.md`
