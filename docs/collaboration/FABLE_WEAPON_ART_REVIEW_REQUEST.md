## 맥락 (여정)
사용자 목표: **겐신 무기팩(Teyvat Weapon Collection)류의 "이쁜" 무기** + 약간의 판타지 감각 +
**등급이 오를수록 부가 연출이 쌓여 직감적으로 "더 좋은 무기"로 읽힐 것.**
- 1~2차: 직육면체 리그 정교화 (원소 544→1138) → 사용자/조율자 판정 "여전히 상자 덩어리".
- 3차: **접근 전환** — 날/몸통 = 얇은 평판 1~2장 + 곡선 실루엣은 64px 텍스처 알파로 깎음(SDF 절차 페인팅) + 소형 입체 악센트. 크게 개선.
- 4차: 판타지 과장(날 폭·곡률·코등이 31건) + 등급 사다리(범철 무딘 쇠 → 정련 놋 → 보병 하몬+상감+드리개 → 신병 인선 빛무리+칼끝 기운 자락+겹수실 → 마병 어둠판: 검붉은 기운+톱니+혈조).

## 구현 사실 (분석에 필요한 만큼)
- 생성기: `tools/respack/weapons.py` (SDF 절차 페인팅 — 폴리라인/베지어/호 거리장, 난수 0, 씨앗=키 crc32) + `tools/respack/core.py` 3D 절(평판·display 유도).
- 텍스처: `weapon/paint/<이름>.png` 64x64 × 57장, 1장/자루. 아이콘 16px 57장은 별도(불변).
- 검수 계약 (texture_audit 축 ㉓): 평균 채도 ≤60 · 픽셀 채도>160 ≤1% · **색상 200°~330°(청·보라·마젠타) 금지** ≤1% · 적색 면적 상한(paint 0.12 / myeong 0.13 / 마병 0.24) · 알파 이분+가장자리 2px·중간알파 ≤25%.
- MC 모델 제약: 원소당 회전 한 축·{0,±22.5,±45}만 · 좌표 −16…32 · 평판 두께면은 얇음.
- 아트 디렉션 정본: 묵청(`docs/design/pack_art_direction.md`) — 애니메 원색 금지, 단 사용자가 "판타지스럽게"를 명시적으로 요청함 (긴장 관계 — 어디까지 허용할지도 비평 대상).

## 비평을 청하는 축
1. **조형**: 실루엣·비례(날:자루 비·코등이 크기)·곡률이 "이쁜 게임 무기"로 읽히는가. 계열별(특히 창·월아산·권갑) 약점은.
2. **색·명암**: 지금 강철+놋+먹 기조가 단조로운가. 등급 색 층(신병 청백·옥 / 마병 검붉음)의 설득력. 금지 대역(청보라) 없이 판타지 광채를 내는 방법.
3. **등급 사다리 가독성**: 범철→마병이 직감으로 읽히는가. 특히 **정련↔보병 격차가 좁다**(내부 판정) — 벌리는 방법 (보병 하몬 금빛? 다른 수?).
4. **기운 자락(에너지 이펙트)**: 칼끝 2가닥 베지어 형상 — 겐신류 대비 어색한 점·개선 (형상·배치·그라데이션).
5. **구도 외 요소**: 64px 해상도 배분·평판+악센트 구성에서 놓친 상투 기법 (림 라이트·투톤 날·그림자 앵커 등).
