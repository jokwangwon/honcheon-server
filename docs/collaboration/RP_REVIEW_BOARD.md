## 합의 (2026-07-14 · Fable 검토 서명 — Codex 실측 2건 재검증 일치 확인)

1. **RP-1**: 세 계열(획/봉우리·검/원환) 유지. 인접 XOR 하한 8px 신설, 최약쌍(초절정↔화경 2px)부터 수정.
2. **RP-2**: 시안 A 는 언어로 채택, 도트 원본은 보류 — 20x6 고정 폭 붓홈 + 선두 2열만 마른 붓, 9단 단조 증가·4틴트 감사.
3. **RP-3**: 격별 자산 증식 보류. 공용 기운 텍스처의 어두운 번짐 테 강화 (참격 3종 우선). 새 감사 축 ⑲(획 배경 합성 대비: 화선지·먹 양쪽 p25≥16 · 가시≥70%).
4. **RP-4**: 파일럿은 렌더러만 — 동일 horangi_v2.bbmodel + 5동작, A안 MobDisplay 확장 vs B안 ModelEngine 어댑터. MythicMobs 는 두 번째 복합 몹 수요 때 별도 ADR. 파트 예산(현행 global_cap 64 vs 7파트×20마리=140) 선설계 필수.
5. **RP-5**: 새 감사 축 ⑳(의미 적색 면적: 기본 ≤1% + 경로별 등록 예외 — 예외를 숨기지 않고 잰다).
6. **RP-6**: 신규 구조 작업 없음 — GUI 배율 2·3·4 실기동에서 최약 두 쌍(sword 범철→정련 등 9px) 판독 확인만.
7. 슬롯: RP-1(E020~27 교체)·RP-2(E010~18 교체)·시안 B(미래 E060~7F)·SJ-002(E0B0~BF) 충돌 없음 — 단 SJ-002 구현 전 config 정식 등록 + 빌더 중복 codepoint 실패 검사 추가.

**반영 순서**: RP-1 → RP-2 → RP-3(+축⑲) → RP-5(축⑳) → RP-4 파일럿. RP-6 은 실기동 때.
