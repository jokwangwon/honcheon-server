## 규칙

1. 평가는 **실물 근거**로 한다 (파일 경로·실측 수치·시안 이미지). 인상비평 금지.
2. 상대 문서를 반박해도 된다 — 반박은 상대 문서가 아니라 **자기 문서**에 적는다.
3. 합의된 것만 보드 §합의에 오른다. 반영(자산·config 수정)은 **Fable 검토 후 커밋**.
4. `config/resourcepack_design.yml` 동결(기존 미커밋 변경)은 합의 전까지 유지.
5. 사용자 확정이 필요한 것(취향·세계관)은 §사용자 결정 대기에 모은다.
