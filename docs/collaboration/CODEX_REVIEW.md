### 결론

조건부 승인이다. 지형 v4의 결정론, B-127과 `fill_below_raised`의 비인과성, 서장 차단의 재접속 경로, NPC 사망의 공통 해석기 진입, 사고 수리의 단일 표적 해석기는 확인됐다.

다만 B-119의 기존 NPC 이행과 B-116의 액션바 단일 소유권은 닫힘 조건을 충족하지 않는다. 아래 두 항목은 좋은 수리 커밋 전체를 되돌리라는 뜻이 아니다. 이미 맞게 고친 부분은 유지하고, 해당 결함의 **완료 판정만 되돌려** 보완한 뒤 다시 닫아야 한다.

### 위반 — 완료 판정을 되돌릴 것

1. **[P1] B-119 기존 NPC 이행이 서버 재시작을 완전히 덮지 못한다.**
   `TradeListener.onEntitiesLoad`만으로는 플러그인 리스너 등록 전에 이미 적재된 청크·엔티티에 이벤트가 재생되지 않는다. `plugin.yml`에 별도 조기 load 지정도 없고 리스너는 `HoncheonMvt.onEnable`에서 등록되므로, 예전 `invulnerable=true` NPC가 적재된 채 남아 정확히 같은 무적 상태를 보존할 수 있다. 서버 시작 시 이미 적재된 청크를 한 번 순회해 동일한 이행 함수에 태우거나, 동등하게 누락 불가능한 경로를 추가해야 한다. `126d7f2`의 신규 NPC 정책과 공통 `npc_death` 발신은 유지한다.

2. **[P2] B-116의 “액션바 한 손”은 전역 사실이 아니다.**
   `HudLine`은 `SkillHud` 내부 소유권만 중재한다. `SkillListener`의 등급 사다리, `HuntListener`, `Sparring`, `Incidents`, 그리고 뒤의 `SeojangBook` 대기 표시가 여전히 직접 `sendActionBar`를 호출해 4틱 HUD 갱신과 서로 덮어쓸 수 있다. `57ddf2a`·`4566228`·`5af2054`의 국소 수리는 유지하되 B-116은 다시 열고, 모든 직접 작성자를 공용 중재기로 보내거나 채널 우선순위 계약을 명시해야 한다.

### 요청 초점의 독립 판정

- **지형 v4 결정론:** 준수한다. `grain`/`grain2`는 정수 격자 좌표에 대한 고정 해시와 고정 옥타브만 사용한다. 동일 좌표 5,000건 재검사와 `TerrainGrainSelfTest` 23/23도 통과했다.
- **`fill_below_raised`와 B-127:** 직접 인과가 아니다. `feather`는 `innerY`, `outerY`, 보간값과 `target`을 먼저 확정한 뒤 그 열의 `oldGroundY+1..target-1`만 채운다. 표면 목표·이웃 표면·레이 높이를 바꾸지 않으며 하강 경계에서는 실행되지 않는다. B-127의 `y=89→88`은 기준 높이/앵커/재생성 기저 쪽을 추적해야 한다. 새 월드 A/B 없이는 모든 간접 가능성을 닫지는 않지만, 이 함수가 경계 높이를 직접 낮췄다는 가설은 기각한다.
- **B-118 서장 차단:** `seojang.json`의 pending body에 집필 상태를 포함하고, 횡단·접속·주기·자동 출항이 `WorldBridge.seojangHolds`를 공유한다. 재시작 후 신선한 heartbeat가 생긴 뒤 재접속도 차단된다. 60초 stale 시 fail-open은 “봇 장애로 영구 감금하지 않는다”는 의도된 절충이다.
- **B-119 사망 해석:** MVT는 등록 ID·직책·장소·목격·밤·시신·원인·가해자를 `npc_death`로 내보내며, 봇은 같은 registry/rules/rumor/지역 사건/명분/혈채 경로를 사용한다. 이 부분은 공통 해석기 계약을 만족한다.
- **사고 수리 표적 해석기:** `auditTerrain`과 `sweepUnderground` 모두 `MvtCommand.resolveTerrainTarget`을 호출하며 예전 `TerrainAudit.auditTown` 중복은 제거됐다.
- **안전핀 근거:** `cy < 0`과 `abs(surface-cy) < 40`은 현재 등록값이 아니라 코드 발명이다. `40`은 `TerrainAudit.surfaceY`의 고정 탐색 폭과 일치하지만 설정 계약은 아니며, `cy < 0`도 “조성 표면은 음수가 아니다”라는 암묵 불변식이다. 사고를 막는 fail-closed 방어는 유지하되 `terrain.yml`/등록 세계 경계에서 유도하거나 명시된 설정값으로 올리고 감사기가 같은 값을 검증하게 한다.

### 조언 — 향후 보강

1. 액션바는 플러그인 전역 중재 서비스 하나에 `combat`, `travel`, `waiting`, `notice` 같은 채널과 우선순위/TTL을 두는 편이 안전하다. 현재 남은 직접 작성자를 찾는 정적 감사도 추가한다.
2. NPC 이행은 “리스너 등록 뒤 이미 적재된 청크”를 재현하는 테스트를 더한다. 이름만 있는 임의의 무적 주민을 청하 NPC로 오인하지 않도록 등록 ID/정해진 NPC 이름 집합으로 범위를 제한한다.
3. 표적 안전핀은 중앙 한 열만 검사한다. 대규모 변형 전에는 대상 영역의 대표 경계점도 같은 등록 기반 범위 안인지 확인하면 잘못된 중심값 외의 오염도 막을 수 있다.
4. `bridge_audit.py --no-backup`은 `seojang_choice` 발신자가 없다고 경고하지만 실제 호출은 `MvtCommand`에 있다. 감사기의 소스 탐색 범위를 넓혀 이 거짓 경고를 제거한다.
