# 낭인의 강호와 기연(奇緣) — 밑바닥에서 시작하는 무협

> "삼류도 안 되는 일반인이 기연을 얻어 문파에 들어갈 수도 있지 않을까?"
> — 이 질문에 대한 시스템 답변. 무협 장르의 핵심 서사(범인 → 기연 → 입문)를
> 뽑기 운이 아니라 **행동 이력의 함수**로 구현한다.
>
> 기계 판독용: `config/fortune_encounters.yml`, `config/cultivation.yml`(범인 단계),
> `config/player_creation.yml`(일반인 신분)

---

## 1. 낭인 생태계 — 강호의 밑바닥

문파 제자가 아닌 무인의 세계. 플레이어 대다수가 거쳐 가는 층이므로 구체적으로 정의한다.

### 1.1 낭인의 위계

```text
잡일 낭인   경지: 범인~삼류. 짐꾼, 야경, 장터 경비. 하루 벌어 하루 산다.
호위 / 표사  경지: 삼류~이류. 상단 호위, 표국 일감. 목숨값이 곧 몸값.
이름 낭인   경지: 일류 이상 + 명성. 별호(別號)가 붙는 순간부터 —
           의뢰가 찾아오고, 세력들이 회유하러 온다. (별호 = 명성 임계 도달 시 소문망이 붙여줌)
```

### 1.2 의뢰 경제 (의뢰소 기준)

| 의뢰 등급 | 예 | 요구 수준 | 보수 감각 |
|-----------|-----|-----------|-----------|
| 잡(雜) | 짐 나르기, 야경, 전갈 심부름 | 범인 가능 | 하루 숙식비 |
| 호(護) | 상단 호위, 마을 경비 | 삼류 + 신원 보증 | 며칠 생활비 + 위험수당 |
| 토(討) | 도적 토벌, 맹수 사냥 | 이류 권장 | 목돈. 실패 시 목숨 |
| 수(搜) | 실종자 수색, 정보 수집 | 기술 요구 (조사/추적) | 성과급 |

- 의뢰 실패는 보수 몰수 + 의뢰소 평판 하락(소연의 기억 태그). 평판이 쌓이면 상위 의뢰가 열린다 — **PT-001의 곽진 채용이 이 표의 護급 의뢰였다.**
- 지역 상태 연동: 치안이 낮을수록 討급 의뢰가 늘고 보수가 오른다. 경제가 낮으면 보수가 깎인다.

### 1.3 낭인의 생존 감각

```text
숙식:  객잔 봉놋방(잡급 하루 보수) ~ 독방(護급 보수). 노숙은 피로 규칙 적용.
장비:  무기 관리 소홀 → 전투 판정에서 '자원 소모' 부수 리스크 대상이 된다.
정보:  낭인에게 소문은 밥줄이다 — 어느 지역 치안이 무너지는지가 곧 일감 지도.
보호:  낭인은 어느 세력의 장부에도 없다. 자유롭지만, 죽어도 아무도 찾지 않는다.
       (세력 반응 시스템에서 낭인은 항상 "미상의 낭인"으로 시작하는 이유)
```

## 2. 범인(凡人) — 삼류 아래의 세계

### 2.1 새 경지 단계

경지 사다리를 한 칸 아래로 연장한다:

```text
범인 → 삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경
```

- **범인**: 무공을 익히지 않은 보통 사람. 강호 인구의 절대다수.
  - 능력치 상한 3 / **내공 성장 불가** (심법을 얻기 전까지 내공은 1~2에 고정)
  - 무공 기술 없음. 생활 기술(흥정, 요리, 산길 지리, 손재주 등)만 보유
  - 삼류 승급: 기초 무공 1개 숙련 10 + 수련 기간 — 독학(느림, 부작용 위험) 또는 사사(빠름)
- 판정은 동일한 식을 쓴다. 범인이 약한 건 등급 페널티가 아니라 **수치가 낮아서**다.

### 2.2 일반인 시작 신분 (하드모드)

배분 5포인트(낭인 지망생은 6), 상한 3, 무공 기술 없음:

| 신분 | 생활 기술 (2/1/1) | 시작 위치 | 비고 |
|------|-------------------|-----------|------|
| 객잔 점소이 | 고객_파악2, 정보수집1, 흥정1 | 청하객잔 | 한백과 고용 관계. 소문의 한가운데서 산다 |
| 약초꾼 | 산길_지리2, 조사1, 의술1 | 북쪽 산길 방면 | 유문·약재상과 거래. 산에서 벌어지는 일을 본다 |
| 장터 잡부 | 흥정2, 손재주1, 정보수집1 | 장터 | 민간 소문망의 말단 |

### 2.3 백지(白紙)의 역설 — 왜 범인 시작이 가치 있는가

하드모드의 보상은 능력치가 아니라 **자격**이다:

```text
무공을 익힌 자는 그릇이 굳는다.
은거 기인은 이미 다른 문파의 색에 물든 자를 제자로 받지 않는다.
```

일부 기연(특히 사승 기연)은 **"무공 백지"를 조건으로 요구**한다. 삼류 무인은 낭인 지망생보다 강하지만, 그 기연의 문은 이미 닫혀 있다. 약함 자체가 자격인 설계 — 이것이 "강해지는 것만이 목표가 아닌 무협"의 수치적 표현이다.

## 3. 기연(奇緣) 시스템

### 3.1 철학 — 우연처럼 보이는 필연

기연을 순수 랜덤 이벤트로 만들면 이 프로젝트의 핵심("내 행동이 세계에 흔적을 남긴다")과 충돌한다. 그래서:

```text
기연은 세계에 미리 심어진 히든 사건이다.
발동 조건은 대부분 플레이어의 '행동 이력'이다 — 선행 태그, 방문 횟수,
NPC 인연, 특정 상태(빈사, 무공 백지), 장소+시간.
플레이어에게는 우연으로 보이지만, 로그를 열면 필연이다.
```

### 3.2 기연의 구조 (6요소)

```text
조건(trigger):   행동 이력 / 상태 / 장소+시간 / 소지품 / 명성·악명 — 복수 조건 AND
발견(discovery): 조건 충족 시 자동 노출 또는 감각/조사 판정 1회 (조건이 지배, 주사위는 양념)
시험(trial):     대부분의 기연은 사람을 시험한다 — 인의·담력·끈기.
                 판정보다 '선택'으로 처리하는 것을 권장 (수치가 아니라 인품을 본다)
보상(reward):    무공·심법·영약·인연·깨달음·단서
대가(price):     기연은 공짜가 아니다 (3.4)
소멸(consume):   1회성. 획득 즉시 세계에서 제거된다 — 공유 세계에서 선착순
```

### 3.3 기연 등급

| 등급 | 보상 규모 | 배치 밀도 | 예 |
|------|-----------|-----------|-----|
| 소기연 | 기술 +1, 단서, 소액 재물, 인연 태그 | 지역당 여럿 | 노인을 도왔더니 산길 지름길을 알려줌 |
| 중기연 | 무공 비급, 심법 입문, 영약(능력치 +1), 사승 인연 | 지역당 2~3개 | 폐사당의 은거 고수 |
| 대기연 | 경지 벽을 넘는 깨달음, 절세 비급, 신물 | **지역권당 0~1개**, 세계 공통 시간 연동 | 시즌 이벤트급 |

### 3.4 대가 — 기연은 공짜가 아니다

```text
비급에는 주인이 있다:   습득 무공을 공개 사용하면 무공 카탈로그의 public_use_rumor /
                      faction_reaction이 그대로 발동 — 원 소유 세력이 출처를 캐물으러 온다.
영약에는 명현이 있다:   복용 직후 며칠 무방비(판정 -2) — 어디서 앓아누울 것인가부터가 선택.
사승에는 은원이 있다:   스승의 원수는 제자의 원수다. 인연은 적도 함께 상속한다.
마공에는 유혹이 있다:   금기 계열 기연은 힘이 크고 대가는 영혼이다 (부작용 + 세력 반응 + 히든 루트).
```

### 3.5 5대 운영 규칙 (GM 절대 규칙에 추가)

```text
1. 등록제:    기연은 config/fortune_encounters.yml에 등록된 것만 존재한다.
             GM 즉석 발명 금지 — 공유 세계 일관성의 핵심.
2. 1회성:    획득 즉시 세계에서 소모된다. 다른 플레이어에게는 이미 사라진 기회다.
3. 시험 필수: 중기연 이상은 반드시 시험을 낸다. 조건 충족 = 자격이지 합격이 아니다.
4. 대가 필수: 중기연 이상은 반드시 대가·후폭풍을 갖는다.
5. 동시 1개:  플레이어당 진행 중인 중기연 이상은 1개. (기연 사냥꾼化 방지)
```

## 4. 문파 입문의 세 경로 — 통합

기존 두 경로에 기연 경로를 더해 완성한다:

```text
① 공적 경로 (정공법):   지역 사건 해결 → 공적·명성 → 추천(소연→진운) → 입문 심사
                        PT-001의 플레이어가 걷는 길.
② 시험 직행:            산문에 직접 찾아가 시험. 추천 없으면 심사가 엄격하다.
③ 기연 경로:            a) 은거 기인의 사사 → 그 문파의 방계 제자 or 추천장
                        b) 비급 습득 → 공개 사용 → 소문 → 문파가 찾아온다
                           — 출처 추궁이 될지, 파격 영입이 될지는 대응에 달렸다
```

**질문에 대한 답이 ③이다**: 범인(삼류 미만)도 기연을 통해 문파에 닿을 수 있다. 단, 이 세계의 기연은 하늘이 굽어살핀 우연이 아니라 — 폐사당에 세 번 발걸음한 것, 열병 환자 곁을 지킨 밤, 밥그릇을 나눈 사흘이 만든 **필연**이다. 그리고 ③-b는 기존 소문·세력 반응 시스템이 그대로 굴려준다: 남궁세가 검법을 쓰는 점소이를 세가가 가만둘 리 없다.

## 5. 청하현 배치 기연 (GM 전용 — 플레이어 스포일러 금지)

상세 데이터는 `config/fortune_encounters.yml`. 요약:

```text
[중] 폐사당의 취걸개   — 걸인 행세 은거 고수. 조건: 폐사당 3회 방문 + 선행 태그 2 + 무공 백지.
                        시험: 사흘간 제 밥을 나누는가 (선택 시험). 보상: 내공심법 입문 + 개방 인연.
                        대가: 발설하면 인연 단절 + 스승의 옛 원수 상속.
[중] 흑수나루 침몰선   — 조건: 나루 괴담 조사 + 잠수 시도 + 감각 판정. 보상: 수공 비급.
                        대가: 공개 사용 시 장강수로채가 출처를 캐묻는다.
[소] 열병 노인의 유품  — 조건: 유문을 도와 환자 간호 (열병 사건 비전투 루트).
                        보상: 화산파 고식 검결 절편 — 진운 접촉 시 강력한 입문 단서.
                        의미: 비전투 의원 루트에서도 화산파 목표에 닿는 다리.
```

폐사당이 기획서 13장에서 "장기 떡밥"으로 봉인해둔 장소였음을 상기 — 그 떡밥의 첫 회수가 이 기연이다.

## 6. 기존 시스템과의 접합 확인

```text
판정:      기연 발견/시험도 동일 판정식. 새 메커니즘 없음.
소문:      기연 보상 무공의 공개 사용 → public_use_rumor → 소문망 (기존 규칙 그대로)
세력 반응:  비급 원 소유 세력의 추적 = faction_reaction 입력 (거점_노출 계열)
NPC 영속성: 기연 NPC(취걸개)도 등급제 NPC — 죽을 수도, 떠날 수도 있다
공유 세계:  기연 소모의 선착순이 "다른 플레이어의 세계에 영향"의 가장 극적인 사례
성장:      영약·비급은 성장 4축의 지름길이지 우회로가 아니다 — 경지 승급 조건은 그대로
```
