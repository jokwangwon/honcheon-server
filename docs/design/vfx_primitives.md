# 혼천 VFX 공통 문법 + 무기군 원형 5종 (2026-07-21 채택)

> 검기 선호 학습(2026-07-19~21)과 외부 자문 2회를 거쳐 채택된 **이펙트 체계의 헌장**.
> 결론: 검압형 검기는 "모든 이펙트의 완성형"이 아니라 **"공통으로 깔릴 시각 문법의 첫 성공 사례"**다.
> 공통 문법은 공유하되, **공통 실루엣은 공유하지 않는다** (도끼가 검처럼 보이면 실패).

## 1. 공통 재질 문법 (모든 이펙트가 지킨다)

| 규칙 | 내용 |
|---|---|
| 명암 샌드위치 | 먹 테(밝은 배경 담당) / 반투명 몸체(볼륨) / 청백 첨두(어두운 배경 담당) — 배경 감지 없이 이중 가독 |
| 색 | 등록부 먹빛 + 그 사이 램프만 (먹→청회→청백…). 금지 대역 불가. 격 사다리 = 먹빛 인자 교체 |
| 위계 | 머리–몸통–꼬리의 에너지 분포. 첨두(서슬/심)는 **한쪽에만** — 병렬 다중선 금지 |
| 리듬 | 즉발 피크 → 잔상 → 빠른 소멸 (평타 기준 피크는 1~2틱). 그려지는 과정은 기술 전용 |
| 비대칭 | 통제된 비대칭 — 한두 군데에 불균형을 몰아준다. 규칙적 반복(톱니·빗살) 금지 |
| 번짐 | 전체 후광 금지 — 머리·충돌점 등 핵심 부위에만 국소 번짐 |
| 파편 | 장식적 파편(삼각 유리 조각) 대신 기능적 파편: 절단선·압력 고리·잔묵 안개·선 왜곡 |
| 상태 분화 | 빗나감 / 명중 / 치명타는 연출이 갈라져야 한다 (명중: 충돌음+청백 먹꽃 1틱+방향성 파편) |
| 연타 공백 | 이전 획이 거의 사라진 뒤 다음 획 — 지속 광원화 금지. 같은 방향 연속 사용 금지 |

## 2. 무기군 원형 5종 (실루엣은 여기서 갈린다)

| 원형 | 무기군 | 핵심 인상 | 상태 |
|---|---|---|---|
| **Slash** (검압형) | 검·도·낫 | 절단·곡선 궤적·통과감 | ★구현 — tools/kigi_press.py (A 내려·횡 / B 올려) |
| **Thrust** | 창·찌르기 | 직선 축·전방 집중·관통 콘 | 미구현 — 초승달 금지, 중심선+압력 리본 |
| **Impact** | 도끼·둔기·강타 | 짧고 넓은 압력면·충격 고리·균열 | 미구현 — cut 보다 impact 비중 |
| **Projectile** | 비도·침·표창·암기 | 작은 핵+긴 꼬리·속도·관통점 강조 | 미구현 — 몸체가 아니라 궤적을 보여준다 |
| **Spread/Fan** | 부채·풍계·파동 마법 | 부채꼴 분산·겹치는 얇은 면 | 미구현 — 절단이 아니라 확산 |

## 3. Slash 원형 확정 사양 (검압형 · 2026-07-21)

- 구조: 검압 몸체 면 하나(서슬 쪽 짙고 먹 테 쪽으로 급감) + 서슬 근처 좁은 압축대 + 흐름 결 1줄(희미)
- 실루엣: 꼬리 가늘게(최대의 ~12%) → 급팽창 → 최대 폭 t≈0.75 → 끝 12% 급수축, 끝은 비대칭
  (서슬 쪽이 더 길고 날카로움 · 먹 테 쪽 짧게 끊김)
- 서슬: 꼬리 15% 없음 → 가늘게 → 머리 직전 25% 최대 → 급수축. 미세 단절 1~2개 (네온 튜브 금지)
- 먹 테: 얇게, 몸체 밀착(안쪽 전이대), 꼬리에서 서서히 끊김. 머리에선 몸과 합쳐지며 두꺼워짐 허용
- 방향 체계: 궤적 진행 방향에 따라 서슬 면이 자동 결정 — 내려·횡=오목(A) / 올려·역횡=볼록(B)
- 평타 3프레임: ①압축 피크(몸 82%·잔상 없음) ②절단 통과(몸 62%·전방 이동·폭+7%·잔상 출현)
  ③붕괴(몸 소멸·서슬 토막·먹 테 머리만·절단선 3) → 삭제. 잔상은 피크에 두지 않는다
- 기술(오의)은 5프레임을 시전·피크·충돌·붕괴 서사로 재해석 (성장 애니 아님)
