## 목적

본 문서는 화산파 캠퍼스 **주변의 자연환경과 영역권**을 정의한다.

화산파는 하나의 건축물이 아니라 **산 전체를 사용하는 산악 문파**이다.

따라서 플레이어는 **산 입구 → 외곽 숲 → 등산로 → 문파 → 후산 → 정상** 이라는 경험을 하게 된다.

## 영역 구성 철학

화산파는 **"건물"보다 "산"이 중심**이다.

건축은 산을 점유하는 것이 아니라 **산에 스며드는 방식**으로 존재한다.
영역의 대부분은 자연 지형으로 유지한다.

**추천 비율**: 자연 지형 70% · 건축 20% · 인공 구조물 10%

## 영역 구조

추천 구조: **외곽 → 등산구역 → 문파 외문 → 생활구역 → 수련구역 → 본전 → 후산 → 정상**

높아질수록 **출입 제한 · 권위 · 수련 수준 · 위험도**가 함께 증가한다.

## 영역별 설계

### 1. 외곽 평원 — 플레이어가 처음 만나는 지역
- 추천 요소: 초원 · 작은 마을 · 농경지 · 마차길 · 우물 · 여행객
- 몬스터 낮음 · NPC 많음

### 2. 화산 입구 — 산의 시작
- 추천 요소: 거대한 패방 · 계단 · 안내비 · 석등 · 작은 사당
- 플레이어는 **여기서부터 "문파의 영역"이라는 느낌**을 받아야 한다.

### 3. 등산로 — 가장 긴 지역
- 추천: 계단 · 절벽길 · 목교 · 석교 · 폭포 · 쉼터 · 전망대
- 길은 직선보다 **곡선 · 지그재그** 형태를 추천한다.

### 4. 매화림 — 화산파를 상징하는 지역
- 추천: 매화나무 · 작은 정자 · 산책길 · 벤치 · 돌길
- 전투보다 **분위기 연출**이 목적이다.

### 5. 계곡
- 추천: 폭포 · 개울 · 작은 다리 · 바위 · 이끼
- 수련 장소로도 활용 가능하다.

### 6. 절벽 구역
- 추천: 암벽길 · 협곡 · 구름다리 · 낙석
- **난이도가 높은 이동 구간**

### 7. 연무 계곡 — 야외 수련장
- 추천: 목인 · 허수아비 · 검흔 · 훈련장
- NPC: 초급 제자 · 중급 제자 배치

### 8. 본산 — 문파의 중심
- 여기에 **본전 · 연무장 · 수련동 · 숙소** 등이 위치한다.

### 9. 장로 구역 — 일반 제자는 접근하지 않는다
- 추천: 작은 정원 · 차실 · 서고

### 10. 후산 — 비밀 지역
- 추천: 검총 · 동굴 · 암벽 · 폭포
- 고급 퀘스트 · 희귀 NPC 배치 가능

### 11. 정상 — 화산 최고봉
- 추천: 전망대 · 수행대 · 거대한 바위 · 운해
- **건축은 최소화한다.**

## 건축 배치 원칙 — 영역마다 건축 밀도가 달라야 한다

| 영역 | 건축 밀도 |
|---|---|
| 외곽 | 낮음 |
| 등산로 | 매우 낮음 |
| 매화림 | 낮음 |
| 계곡 | 매우 낮음 |
| 절벽 | 거의 없음 |
| 본산 | **매우 높음** |
| 장로구역 | 중간 |
| 후산 | 낮음 |
| 정상 | 거의 없음 |

## 지형 생성 규칙

**건축보다 먼저 지형을 생성한다.**

추천 순서: **능선 → 계곡 → 절벽 → 폭포 → 등산로 → 건축 → 식생 → NPC**

건축은 **이미 생성된 지형에 맞춰 배치**한다.

## 식생 설계 — 영역별 추천 식생

| 영역 | 식생 |
|---|---|
| 외곽 | 참나무 · 자작나무 · 풀 |
| 등산로 | 소나무 · 암석 · 관목 |
| 매화림 | 벚꽃(매화 대체) · 꽃 · 잔디 |
| 계곡 | 대나무 · 이끼 · 양치식물 |
| 후산 | 오래된 소나무 · 고목 · 희귀 약초 |
| 정상 | 작은 풀 · 바위 · 거의 나무 없음 |

## NPC 배치

| 영역 | NPC |
|---|---|
| 외곽 | 상인 · 여행객 |
| 등산로 | 순찰 제자 · 수행 중인 제자 |
| 매화림 | 명상하는 제자 |
| 연무장 | 훈련 중인 제자 · 교관 |
| 본전 | 장문인 · 장로 |
| 후산 | 고수 · 은둔 장로 |

## 플레이어 경험 설계

플레이어는 **평범한 마을 → 산 입구 → 등산 → 문파 → 더 높은 곳 → 후산 → 정상** 순으로 자연스럽게 진행한다.

높아질수록:
- 적이 강해지고
- NPC의 신분이 높아지며
- 건축은 줄어들고
- 자연환경은 더욱 거대해진다.

## 무협 분위기를 위한 권장 랜드마크

화산파의 정체성을 강화하기 위해 영역 곳곳에 랜드마크를 배치하는 것을 권장한다.

**자연 랜드마크**: 천연 폭포 · 운해가 보이는 전망대 · 기암괴석 · 천년송 · 매화 군락 · 깊은 협곡 · 산허리를 감싸는 운무

**인공 랜드마크**: 거대한 산문(패방) · 절벽을 잇는 현공교 · 암벽에 새겨진 검흔과 비문 · 선대 장문인의 석상 · 검총(역대 고수의 검을 모신 성역) · 수행 동굴과 석실 · 봉수대 또는 망루

**비밀 탐험 요소**: 숨겨진 암자 · 약초 채집지 · 고대 수련터 · 폐허가 된 옛 전각 · 비밀 동굴 · 절벽 뒤 숨겨진 통로

## 개발 AI를 위한 핵심 설계 원칙

화산파를 생성할 때는 '건물을 배치하는 것'이 아니라 **'하나의 산악 생태계를 설계한다'**는 관점을 유지한다.

생성 우선순위는 다음과 같다.

1. 산세와 능선
2. 계곡·절벽·수계
3. 주 등산로와 보조 동선
4. 영역 구분(외곽→본산→후산→정상)
5. 주요 건축물
6. 부속 건축물
7. 식생과 자연물
8. NPC 및 이벤트 배치

이 원칙을 따르면 플레이어는 단순히 문파를 방문하는 것이 아니라, **하나의 살아있는 화산파 영역을 탐험하는 경험**을 하게 된다.
