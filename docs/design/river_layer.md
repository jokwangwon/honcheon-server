# 강 — 지형 계층이 만드는 물 (2026-07-13)

> 사용자: "바다나 강의 건축이라면 특수 해당 범위만... (산위에 쪼그만한 물만 생성됨)"

## 왜 이것을 골랐는가

지도는 일곱 곳에 물을 주문한다 — `terrain: 강` 둘 · `수향` 셋 · `물가` 둘.
그런데 지형 계층의 윤곽표(`config/terrain.yml`)는 이렇게 적고 있었다:

```
그대로 — 강·수향·섬·밀림. 물과 숲은 자연이 준 대로가 옳다
```

그래서 **지형 계층은 물을 한 번도 만들지 않았다.** `terrain_layer.md` 가 스스로 그렇게 적는다
(§10: *"지금까지 TerrainForge 는 물을 만들지 않았다 — 오아시스가 그 첫 예외다"*).
**장강수로채는 바닐라가 물을 놓아 줬기를 바라며 섰다.**

### 세 겹의 파탄

1. **부지 판정이 강을 바다로 만든다.** `terrain_types.강` 은 `water_pct: [40,90] · max_depth_min: 6` 을
   요구했다. 그 조건은 **바다도 호수도 똑같이 만족한다** — 흐르지 않는 물은 강이 아니다.
   탐색 링(최대 4,096칸)이 총채를 물 많은 자리로 밀어 붙이니, "장강"이 **바다**가 됐다.
2. **물이 없으면 아무것도 서지 않는다.** `RemoteBuilder.waterStockade` 첫 줄:
   `if (!spec.waterfront()) { return List.of(); }` — 물 없는 수로채는 그냥 산채고, 그래서 **짓지 않는다.**
3. **★ 그리고 눈이 그것을 못 본다.** 아무것도 서지 않으면 `Zone` 이 없고, `Zone` 이 없으면
   `RegionAudit.audit(world, place, zone)` 이 **불리지 않는다.** 검수는 **위반 0건**을 보고한다.
   **짓지 않으면 위반이 없다** — 침묵이 성공으로 읽혔다. 이 눈의 **열여덟 번째 거짓말**이다.

## 원칙은 이미 정해져 있었다 — 굴·사막 때와 **같다**

```
끈다   — 통제 불가능한 무작위 배치는.
만든다 — 등록 좌표의 의도된 지형은.
```

자연 동굴을 끄고 굴을 우리가 팠다. 사막 바이옴을 끄고 사구를 우리가 빚었다.
**강도 같다.** 바닐라의 강이 거기 있기를 바라지 않는다 — **등록된 자리에 우리가 판다.**

## 무엇을 만들지 않는가 — **선을 여기 긋는다**

* **바다는 만들지 않는다** (`terrain_layer.md` §W6 — 섬은 자연에 맡긴다. 해남파의 선례).
* **대륙 수문(D8 유향·유량 누적)은 하지 않는다.** 이 세계는 **실지리 1:1** 이다 —
  장강수로채는 원점에서 **69만 블록** 떨어져 있다. 대륙의 유향을 풀려면 전 대륙의 고도장이 필요하고,
  그것은 **수십억 청크를 생성해야** 한다는 뜻이다. **그건 못 한다.** 못 하는 것을 한다고 말하지 않는다.
* 그래서 이것은 **국소 수문(局所水文)** 이다: 등록된 부지를 가로지르는 **한 굽이(reach)**.
  그 한 굽이 안에서 강은 **반드시 참이다.** 부지 밖의 장강은 **우리가 모른다.** 그렇다고 적는다.

## 계층 (2계층 계약을 넘지 않는다)

```
지도(world_map.yml) ──▶ TerrainForge.prepare() ──▶ RiverForge.carve() ──SiteSpec──▶ RemoteBuilder
                        (땅을 빚는다)              (물을 판다)                      (나루·뗏목을 놓는다)
```

**여기는 땅이다.** 물과 둔치까지가 지형 계층의 몫이고, **나루·뗏목·사슬관문은 집**이다
(`RemoteBuilder.waterStockade`). `RiverForge` 는 블록 하나도 건축하지 않는다.

| 파일 | 무엇 |
|---|---|
| `config/rivers.yml` | **물길의 등록부** — 어디에·어느 쪽으로·얼마나 넓고 깊게. 코드가 강을 발명하지 않는다 |
| `RiverPlan.java` | **산술.** Bukkit 이 없다 — 그래서 **서버 없이 시험할 수 있다** |
| `RiverForge.java` | 그 산술을 세계에 놓는다. `SiteSpec` 을 **다시 재서** 돌려준다 |
| `RiverAudit.java` | **눈.** 다섯 잣대. `Probe` 만 보므로 **가짜 세계로 시험할 수 있다** |

### 순서가 계약이다 — `prepare()` **다음**이다

`prepare()` 의 `tidyWater` 는 '공중의 물·산 위의 웅덩이'를 치운다. 그 **앞에서** 강을 파면
**우리가 판 강을 그것이 지운다.** 그리고 `feather` 가 지난 뒤라야 골짜기가 *이미 이어진* 지형을 가른다.

## 강의 다섯 가지 참 (= 검수의 다섯 잣대)

| | 잣대 | 왜 |
|---|---|---|
| ① | **있는가** | 등록된 물길에 물이 없으면 그것이 가장 큰 위반이다. **이 눈이 침묵을 깬다** |
| ② | **흐르는가** | 수면이 하류로 갈수록 **낮아지기만** 한다. 그리고 실제로 떨어진다 (낙차 0 = 못) |
| ③ | **끊기지 않는가** | 상류 끝에서 하류 끝까지 물로 이어진다. 끊긴 강은 못 두 개다 |
| ④ | **새지 않는가** | 하상 아래 6칸 단단(계약 ①) · 물가가 수면보다 높다 · 공중에 물이 없다 |
| ⑤ | **배가 다니는가** | 물길 한가운데가 등록된 만큼 깊다 — 뗏목이 말뚝을 박는다 |

### 산술 (`RiverPlan`)

* **수면은 층계로 내려간다** — 마인크래프트의 물은 한 켜 안에서 **평평하다**. 비스듬한 수면은 없다.
  `gradient` 칸마다 한 켜씩 떨어진다 (`waterY(s)` 는 s 에 대해 **단조 비증가** — 그것이 '흐른다'의 정의다).
* **단면은 반타원** — 한가운데가 깊고 물가로 가며 0으로 닿는다. 직사각 단면(수직 벽)은 강이 아니라 **수로**다.
* **굽이는 저주파 사인 둘** — 난수도, 좌표 해시도 쓰지 않는다.
  파장 한 칸짜리 요철은 결이 아니라 **노이즈**이고, 그것이 산을 '점무늬'로 만든 병이었다.
* **둔치가 자연으로 수렴한다** (smoothstep) — 이게 없으면 강가가 수직 절벽이 된다.
  주변 땅이 수면보다 낮으면 **둑을 쌓는다** — 강은 스스로 둑을 쌓는다. 안 쌓으면 옆으로 샌다.
* **자연이 이미 물이면 손대지 않는다** — 거기가 이 강의 **하구**다. 하구를 메우면 강이 막힌다.

### 수변 방위는 **강이 안다**

`TerrainForge.waterSides()` 는 물을 **사분면으로** 센다. 그 자[尺]는 **호수·바다**(한쪽에 있는 물)를
전제로 만들어졌다. 강은 부지를 **관통하므로** 상·하류 두 방위에서도 물이 잡힌다 — 동·남·서가 전부 수변이 된다.
`waterStockade` 는 `waterSides().get(0)` 을 보고 나루를 놓을 쪽을 정하는데, 그러면 **뭍을 향해 뗏목을 편다.**

그래서 `RiverForge.carve()` 는 다시 잰 `SiteSpec` 에서 **수변 방위만 덮어쓴다**:
**물은 흐름의 옆에 있다** (`axis_offset` 이 가리키는 쪽). 강이 아는 답이 사분면표보다 옳다.

## 거절 — 조용히 넘어가지 않는다

부지가 이미 바다·큰 호수 한복판이면 **강을 파지 않고 말한다** (`RiverForge.lastRefusal`).
우리 수면보다 높은 자연 수면이 곁에 있으면, 판 골짜기로 **그 물이 쏟아진다** — 강이 아니라 배수구가 된다.
`world_map.yml` 의 `terrain_types.강·수향` 을 **뭍을 요구하도록** 고친 이유가 이것이다.

## 검증

`RiverAudit.check()` 는 `World` 가 아니라 `Probe` 를 본다. 그래서 **서버 없이** 가짜 세계를 지어
눈을 시험했다 — 일부러 여섯 가지 규칙을 어기고 **눈이 정말 잡는지** 확인했다.
**시험하지 않은 눈은 눈이 아니라 장식이다.**

| 시험 | 눈이 잡았는가 |
|---|---|
| 0. 규칙대로 판 강 (대조군) | **위반 0건** — 참인 강을 참이라 한다 |
| 1. 하류 수면을 한 칸 올렸다 | ✓ 역류(1곳) |
| 2. 물길 한가운데 9칸을 지웠다 | ✓ 단절(9칸) |
| 3. 하상 아래 봉인을 뚫었다 | ✓ 하상 누수(71곳) |
| 4. 물가를 수면 높이에서 뚫었다 | ✓ 물가 누수(131곳) |
| 5. **물을 전부 지웠다** | ✓ 강 없음(0%) — **침묵이 깨진다** |
| 6. 강바닥을 여섯 칸 올렸다 | ✓ 수심 부족(100%) |

그리고 수로채가 실제로 이 강 위에 서는지 걸어 봤다 (`RemoteBuilder.waterStockade` 의 걸음 그대로):
중심은 뭍(나루가 선다) · 물가 +14칸(남) · 물길 폭 40칸 · 뗏목(shore+6~+33) 전부 물 위 ·
본채 자리 수심 9칸(말뚝이 강바닥에 닿는다).
