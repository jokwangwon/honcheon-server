# 세계 순도(純度) — 마크의 느낌을 어떻게 지우는가

> "바닐라의 그 지옥문과 주민마을, 바다 배, 바다 신전 등 이런 것도 다 제거.
> 기존의 마크의 느낌을 없애고 모든 공간이 무협처럼 느껴지게 변경"
> "사막 필드도 다 필요없음. 얼음 지역도 필요없음"

* 등록부(정본) — `config/world_purity.yml`
* 산출물 — `worldgen/honcheon_purity/` (등록부에서 **파생**된다. 손으로 고치지 마라)
* 검산 — `tools/world_purity_audit.py`
* 형제 — `worldgen/honcheon_no_caves/` (자연 동굴. 이미 껐다 — 10.08% → 0.04%)

---

## 1. 「마크의 느낌」은 정확히 무엇인가

지우려면 먼저 분해해야 한다. 이 프로젝트에서 「마크의 느낌」은 여섯 개의 축이다.

| 축 | 무엇이 마크를 마크로 만드는가 | 담당 | 상태 |
|---|---|---|---|
| **① 구조물** | 마을·사원·요새·**지옥문**. 세계에 박힌 「바닐라의 건축」 | 이 문서 | **완료** — 20/20 종 |
| **② 지형 피처** | 지하 감옥(이끼벽+스포너+상자)·화석·**지표 용암**. 구조물이 아니라 **피처**라 따로 안 끄면 남는다 | 이 문서 | **완료** — 9종 |
| **③ 바이옴** | 사막·설원·얼음가시·버섯섬. **매일** 걸어다니는 배경 그 자체 | 이 문서 | **완료** — 12종 재배치 |
| **④ 몹** | 좀비·크리퍼… 그리고 **야생의 젖소**. 적대 몹보다 젖소가 더 끈질기다 | 이 문서 | **완료** — 허용제 |
| **⑤ 블록 팔레트** | 오크 판자·조약돌의 색과 결 | 팩 담당 | 진행 중 (조성 팔레트 93.5%) |
| **⑥ UI · 소리** | 하트·배고픔 아이콘, 경험치 바, 「마크 소리」 | 팩 담당 | 진행 중 |

이 문서는 ①②③④ 를 맡는다.

### 왜 구조물보다 바이옴과 젖소가 중요한가

구조물은 **가끔** 만난다. 사막과 젖소는 **매 순간** 본다.

화산파(華山派)가 사막 한복판에 섰던 사고가 이 점을 정확히 보여준다.
지형 계층이 "없으면 산을 세운다"로 덮었지만, **애초에 그 자리가 사막이 아니었으면
자연이 준 산을 썼을 것이다.** 바이옴이 맞으면 지형을 덜 빚는다.

## 2. 방법론 — 레지스트리 실패 = 서버 사망

세 가지 편집만 한다. 셋 다 **바닐라 정본에서 필드 하나**를 건드린다.

| 대상 | 편집 | 왜 안전한가 |
|---|---|---|
| 구조물 | `structure_set` 의 `placement.frequency` → `0.0` | `StructurePlacement.isStructureChunk()` 이 `frequency < 1.0` 이면 확률 감쇠기를 태운다. `nextFloat() < 0.0` 은 **항상 거짓**. 한 청크도 안 선다. 동굴 카버를 `probability: 0` 으로 끈 것과 같은 수법 |
| 피처 | `placed_feature` 의 `placement` 에 `count: 0` | 배치 개수 0 → 스트림이 비어 아무것도 안 놓인다 |
| 바이옴 | 기후 상자의 **이름표만** 교체 | 아래 |

### 바이옴 — 기후 공간을 건드리지 않는다는 것

바닐라 오버월드는 **7,593개의 기후 상자**로 덮여 있다.
각 상자는 7축(온도·습도·대륙성·침식·깊이·기이함·오프셋)의 구간이고, 거기에 바이옴 이름표가 붙는다.

> 우리는 `parameters` 를 **한 글자도 건드리지 않는다. 붙은 이름표(`biome`)만 간다.**
>
> → 상자 수 불변(7,593). 기후 공간의 분할 불변.
> → **기후 공간에 구멍도 겹침도 원리적으로 생길 수 없다.**

이것이 이 방식의 안전성 증명이다. 「사막을 지웠더니 그 자리가 비어서 세계가 깨졌다」가 불가능하다 —
자리는 그대로 있고 거기 서는 것이 savanna 로 바뀔 뿐이다.
`world_purity_audit.py` 는 매 실행마다 바닐라 정본과 **바이트 비교**해 이 등식을 다시 증명한다.

기후 상자의 정본은 추측하지 않고 **바닐라 데이터 생성기**로 뽑는다:

```
java -DbundlerMainClass=net.minecraft.data.Main -jar run/mvt/cache/mojang_1.21.11.jar --server --reports
  → generated/reports/biome_parameters/minecraft/overworld.json     ← 7,593개 상자
```

이 파일의 모양(`{"biomes":[{"biome":…,"parameters":{…}}]}`)이 곧
`multi_noise` biome_source 의 **명시 목록 형식**이다. 그대로 박으면 된다.

> **왜 `multi_noise_biome_source_parameter_list/overworld.json` 을 덮지 않는가?**
> 덮어도 소용없기 때문이다. 그 레지스트리 항목은 **37바이트**이고 내용은 `{"preset":"minecraft:overworld"}`
> 뿐이다 — 프리셋의 **이름만** 담는다. 실제 구획은 Java(`OverworldBiomeBuilder`) 안에 있어
> 데이터팩으로 못 건드린다. 그래서 **`world_preset/normal.json`** 의 오버월드 `biome_source` 를
> 통째로 명시 목록으로 갈아끼운다. 서버는 `level-type` 으로 이 프리셋을 찾아 **월드를 만들 때** 읽는다.

### ⚠ 함정 — 스키마를 추측하면 죽는다 (실제 사례)

strongholds 를 끄면서 "concentric_rings 니까 `count: 0` 을 주면 고리 좌표 자체가 안 생기겠다"고 생각했다.
그럴듯했다. 그리고 **틀렸다.**

```
X  structure_set/strongholds.json  →  Value 0 outside of range [1:4095]
```

`count` 의 코덱은 `Codec.intRange(1, 4095)` 다. 0 은 레지스트리 로딩을 깨뜨린다 — **서버가 안 뜬다.**
월드를 깔고서야 알았을 일이다.

그래서 검산에 축을 하나 더 넣었다.

### 레지스트리 로딩 시험 — 서버를 띄우지 않고 코덱에 먹인다

```
python3 tools/world_purity_audit.py --load-test
```

`worldgen/loadtest/PurityLoadTest.java` 가 **진짜 마인크래프트 코덱**으로 데이터팩 30개 파일을 파싱한다.
Paper 의 jar 은 mojang 매핑이라 `net.minecraft.*` 를 이름 그대로 부를 수 있고,
`VanillaRegistries.createLookup()` 이 바닐라 동적 레지스트리를 통째로 세우므로
JSON 안의 `minecraft:savanna` 같은 **참조까지 실제로 해석된다**.

```
PASS — 25 개 파일이 바닐라 코덱으로 전부 파싱됐다. 레지스트리는 로딩된다.
```

`--build` 는 끝나면 자동으로 이 시험을 돌린다. **눈으로 읽어 맞다고 믿는 것은 검산이 아니다.**

## 3. 무엇을 껐는가

### ① 구조물 — 20/20 종. **남긴 것은 없다.**

폐허가 필요하면 **우리가 짓는다.** (청하현 폐사당·마교 은신처·성문·수로채가 이미 그렇게 섰다.)

| 껀 것 | 왜 |
|---|---|
| **villages** (평지·사막·사바나·설원·타이가) | 청하현 옆에 오크통 마을이 서면 세계가 두 개가 된다 |
| **ruined_portals** | ★ 사용자가 말한 **「지옥문」**. 흑요석 틀이 산야에 박혀 있으면 세계가 즉시 마크가 된다 |
| **ocean_monuments** | 해저 신전. 가디언·프리즈머린은 세계관 밖 |
| **shipwrecks** · **ocean_ruins** · **buried_treasures** | 바다 배·유적·보물지도. 대항해시대의 문법 |
| **pillager_outposts** | 산적은 녹림·산채다 — 회색 피부의 일리저가 아니다 |
| **woodland_mansions** | 대저택이 필요하면 **세가(世家)** 를 짓는다 |
| **desert_pyramids** · **jungle_temples** · **swamp_huts** · **igloos** | 사원·마녀 오두막·이글루. 함정 상자와 TNT 는 무협의 기연이 아니다 |
| **mineshafts** | 레일·광산 수레·거미줄 = 마크의 지하 |
| **strongholds** | 엔드 포탈의 집. 엔드로 가는 문을 세계에서 지운다 |
| **ancient_cities** · **trial_chambers** | 워든·스컬크·스포너 러시 = 게임 시스템이 세계를 뚫고 나온 자리 |
| **trail_ruins** | 고고학(솔·도자기 조각)은 통째로 마크의 신문법 |
| **nether_complexes** · **nether_fossils** · **end_cities** | 아래 |

**네더·엔드 — 갈 일이 없어도 끈다 (판단).**
지옥문과 요새를 껐으므로 「네더 요새 → 블레이즈 막대 → 엔더의 눈 → 엔드 포탈」의 사슬은 이미 끊겼다.
그 끝에 매달린 것도 함께 끊는다. 특히 **end_cities** 는 반드시 꺼야 한다 —
거기서 **겉날개(elytra)** 가 나오고, 그것 하나로 **경공(輕功) 설계가 통째로 무너진다.**

### ② 지형 피처 — 9종

구조물이 아니라 `placed_feature` 라서, structure_set 을 다 꺼도 **남는다.**

* `monster_room` · `monster_room_deep` — **지하 감옥.** 이끼낀 돌벽 + 몹 스포너 + 상자 = 마크의 원형질
* `fossil_upper` · `fossil_lower` — **화석.** 뼈 블록 골격은 지형이 아니라 **이스터에그**다
* `lake_lava_surface` · `spring_lava` · `spring_lava_frozen` · `underwater_magma` ·
  `lake_lava_underground` — **지표 용암.** §4 를 보라 (1차 판단을 뒤집었다)

### ③ 바이옴 — 12종 재배치 (7,593 상자 중 2,002개 이름표 교체)

**더운 곳은 사라지지 않는다. 더운 곳이 사막이 아니게 될 뿐이다.**

`desert` 는 온도 T4(0.55~1.0) — 세계에서 **가장 더운 띠 전체**를 차지한다(708 상자).
그 자리를 없애면 세계에서 더위가 사라진다. 그래서 자리는 두고 **채우는 것**을 바꾼다.

| 끈 것 | → 대신 | 근거 |
|---|---|---|
| `desert` (해안 176상자) | `beach` | 가장 더운 해안. 백사장은 남고 사막은 사라진다. 해남(열대)의 등록 바이옴이 `beach` |
| `desert` (내륙 532상자) | `savanna` | ★ **건조 초원.** 덥고 마른 땅은 남되 모래바다가 아니다. 산서의 등록 바이옴이 `savanna_plateau` — 이웃으로 자연스럽다 |
| `snowy_plains` | `plains` | 가장 넓은 눈 바이옴(388상자) |
| `ice_spikes` | `plains` | 파란 얼음탑은 마크의 서명 |
| `snowy_taiga` | `taiga` | 하북의 등록 바이옴이 `taiga` |
| `snowy_slopes` | `grove` | 산비탈의 눈 → 고산 침엽수림. **눈을 지우는 게 아니라 산으로 올린다** |
| `frozen_peaks` | `jagged_peaks` | 험봉. 관중·호북·사천·운남의 등록 바이옴 |
| `snowy_beach` | `beach` | |
| `frozen_river` | `river` | 얼어붙은 수면은 배와 나루를 막는다 |
| `frozen_ocean` / `deep_frozen_ocean` | `ocean` / `deep_ocean` | |
| `mushroom_fields` | `plains` | **판단.** 균사체 + 거대버섯 + 무시룸 = 마크의 서명 중 가장 진한 것. 먼바다의 섬은 **풀섬으로 남긴다**(섬 자체는 유지 — 세계가 비면 안 된다) |
| `pale_garden` | `dark_forest` | **판단.** 창백한 정원 + 삐걱이는 존재(Creaking) = 최신 마크의 서명. 같은 과(科)로 보내면 음습한 고목림은 남고 밈은 사라진다 |

## 4. 무엇을 **남겼는가** — 세계가 비면 안 된다

「끄기」는 쉽다. 어려운 것은 **무엇을 남길지 아는 것**이다.

### 광물 — 지형이다, 구조물이 아니다

* **광맥(ore)** — 남긴다. 철·석탄·구리는 무기 제련과 경제의 바닥이다(`economy.yml`).
  돌 속의 광물은 **지질**이지 건축이 아니다.
* **샘(`spring_water`)** — 남긴다. 산에서 물이 솟는 것은 중원의 자연이고, 계곡과 개울의 시작이다.

이것이 「지형」과 「구조물」을 가르는 선이다:
**자연이 놓은 것은 남기고, 누군가 지은 것은 우리가 다시 짓는다.**

### ★ 정정 — 용암은 「자연」이 아니었다 (1차 판단을 뒤집는다)

1차에서 나는 **용암 호수를 남겼다.** 근거는 위의 선이었다:
"지질 현상이고, 마크의 서명이 없다."

**그것이 틀렸다.** 사용자가 정확히 짚었다 — *"필드에 있는 용암 필드도 제거하여 필드 깨끗하게"*.

선을 「자연이 놓은 것 / 사람이 지은 것」에 그었는데, **그 선은 여기서 듣지 않는다.**
온대 활엽수림 한복판에 마그마가 노출된 웅덩이는 **지구에 없다.**
화산지대가 아닌 곳의 지표 용암은 지질이 아니라 **오직 마인크래프트에만 있는 현상**이다.
즉 이것은 「자연」이 아니라 **「마크의 자연」** 이었다. 내 선이 그 둘을 구분하지 못했다.

**새 선은 깊이로 긋는다:**

| 층 | 규칙 |
|---|---|
| **y ≥ −54** | 사람과 무인이 걷고 파는 층. **용암 0블록.** |
| **y < −54** | 땅의 배 속. 거기까지 파 내려간 자는 지심(地心)을 만날 자격이 있다. 남긴다 |

이 **−54** 는 우리가 고른 숫자가 아니다. **바닐라가 이미 거기에 그어 둔 선이다** —
`NoiseBasedChunkGenerator` 의 유체 선택기가 `y < -54` 면 용암, 아니면 물을 채운다.
우리의 규약과 바닐라의 상수가 같은 자리에서 만난다. (그래서 아래층은 **끄고 싶어도 못 끈다** —
placed_feature 가 아니라 Java 하드코딩이라 데이터팩의 손이 닿지 않는다. 마침 끌 이유도 없다.)

**끈 것 — 지표 용암 5종.** 오버월드에서 `y ≥ −54` 에 용암을 놓는 피처는 이것이 전부다:

| 피처 | 무엇을 하는가 |
|---|---|
| **`lake_lava_surface`** | ★ **핵심.** 지형 표면에 얹혀 **200청크마다 하나씩** 끓는 웅덩이를 뚫는다. 사용자가 말한 「필드의 용암」이 정확히 이것 |
| `spring_lava` | 용암 샘. **청크마다 20회** 시도한다. 산비탈에 용암 폭포를 걸고 절벽에서 흘러내린다 |
| `spring_lava_frozen` | ⚠ **함정.** 우리가 **`grove` 를 남겼기 때문에 살아 있다** — 눈 덮인 고산 침엽수림에 용암이 흐르는 그림. 반드시 함께 꺼야 한다 |
| `underwater_magma` | 바다 밑 마그마 블록(청크당 44~52회). 물기둥을 빨아들여 익사시키는 함정 = 마크의 서명. 수로채의 배가 다닐 물이다 |
| `lake_lava_underground` | **판단: 끈다.** 아래 |

**`lake_lava_underground` 를 왜 끄는가** — 「지하니까 안 보이지 않나」가 반론이다. 아니다:

1. 우리는 자연 동굴을 껐고 **굴은 우리가 판다**(은신처·기연굴·산적굴·제단굴).
   **우리가 파는 자리에 우리가 놓지 않은 용암이 묻혀 있으면 조성이 깨진다.**
   폐사당 벽을 뚫었더니 용암이 쏟아지는 것은 연출이 아니라 **사고**다.
2. 지하 용암을 만나는 유일한 경로는 채굴인데, 채굴 중의 용암 폭포는 **「마크의 죽음」** 그 자체다.
   무인의 죽음은 **칼에 의한 것**이어야 한다(`death_and_legacy.md`).
3. 끄는 비용이 **0** 이다. 깊은 용암 바다는 별개로 그대로 있다.

#### ⚠ 부작용 — 흑요석이 사실상 사라진다

흑요석은 「용암 원천 + 물」로만 생긴다. 지표 용암을 지우면 **`y < −54` 까지 파 내려가야** 용암을 만난다
(그마저 공동이 없어 희박하다 — 아래 참고). → **네더 포탈을 사실상 만들 수 없다.**

이것은 부작용이 아니라 **이득**이다. 우리는 이미 네더/엔드 구조물을 껐고
"이 세계에 다른 차원은 없다"고 선언했다. **그 선언이 이제 경제적으로도 강제된다.**
(다만 흑요석·용암 양동이를 제작/연료/경제에 쓰는 곳이 있으면 확인이 필요하다 —
`equipment.yml`·`economy.yml` 소유자에게 넘긴다. 내 소유가 아니다.)

#### ⚠ 예측 — 깊은 용암 바다는 실측에서 거의 0 일 것이다

우리는 `y < −54` 의 용암을 **남기기로** 했다. 그런데 실측하면 **0 에 가깝게 나올 것 같다.**
미리 적어 둔다 (맞든 틀리든):

> 용암 바다는 「액체로 찬 **공동**」이지 「돌을 녹인 것」이 아니다.
> 우리는 자연 동굴을 껐다(10.08% → **0.04%**). **용암이 들어앉을 자리 자체가 없다.**

그러니 거기서 0 이 나와도 **결함이 아니라 `no_caves` 의 당연한 귀결**이다.
실측값을 받으면 이 문단을 확정으로 바꾸겠다.

### 그 밖에 판단이 갈린 것들

* **`grove` (고산 침엽수림) — 남긴다.** 사용자가 「판단하라」고 지목한 바이옴.
  관중·호북·사천의 등록 바이옴이고, 침엽수 위에 눈이 얹힌 **고산 지대**다.
  화산·무당의 봉우리에 눈이 있는 것은 무협 그 자체다.
  **우리가 끄는 것은 「얼음 지역」이지 「높은 데의 눈」이 아니다.**
* **`badlands` (황토고원) — 남긴다.** 사용자가 「배드랜드?」라 물은 것.
  붉은 층상 대지는 **중원 서북의 실지리(黃土高原)** 이고 산서·청해의 등록 바이옴이다.
  사막을 끈 자리에 「덥고 마르고 척박한 땅」의 정체성이 하나는 필요하다.
* **`savanna` — 남긴다.** 사용자가 「사바나?」라 물은 것. 산서·새외북막의 등록 바이옴인 데다,
  이제 **사막의 후임**이다.
* **`cherry_grove` — 남긴다.** 무협에 이보다 맞는 바이옴이 없다.
* **자수정 정동 — 남긴다, 재해석한다.** 돌 속의 결정 공동 = **영맥(靈脈)**.
  동굴이 없으니 우연히 마주칠 일도 없고, 우리가 판 기연굴의 벽면 소재로 쓸 수 있다.
* **지하 바이옴(`deep_dark` 등) — 남긴다.** 자연 동굴이 0.04% 라 노출되지 않는다.
  우리가 판 굴의 팔레트로 재해석할 여지가 있다(마기 서린 굴 = 스컬크).
* **`desert_well` — 끌 것이 없다.** 사막을 껐으므로 **설 자리가 사라진다.**

## 5. 동물 — 무협의 산야에 젖소가 뛰노는가

**아니다.**

소·양·돼지·닭은 **가축(家畜)** 이다. **사람이 기르는 것**이지 산에 저절로 나는 것이 아니다.
야생에 젖소가 무리 지어 서 있는 것은 마크의 느낌 중에서도 **가장 조용하고 가장 끈질긴 것**이다.
구조물은 가끔 만나지만 **젖소는 매일 만난다.**

그러나 「가축을 지우자」가 아니다.

> **가축은 마을의 살림이다.** 청하현 마당의 닭과 외양간의 소는 **옳다.**
> 그건 조성기가 `CUSTOM` 으로 **놓는** 것이고(스폰 관문이 이미 통과시킨다), 번식·알로도 는다.
> 취소되는 것은 **야생에 저절로 솟는 것**뿐이다.

### 그래서 규칙은 금지 목록이 아니라 **허용 목록**이다

등록부 `config/world_purity.yml` → `wild_spawn.allow` → `HuntingGrounds.onSpawn()`.
**여기 적힌 것만 자연 스폰한다. 나머지는 전부 취소된다.**

허용 목록인 것이 핵심이다 — 바닐라가 다음 버전에서 몹을 새로 추가해도 **새지 않는다.**

* **허용(11종)** — 이리 `WOLF` · 여우 `FOX` · 산토끼 `RABBIT` · 박쥐 `BAT` ·
  물고기(`COD` `SALMON` `TROPICAL_FISH` `PUFFERFISH`) · `SQUID` · `DOLPHIN` · `TURTLE`
* **취소** — 젖소·양·돼지·닭(가축) · 말·나귀·라마·낙타(탈것은 사람의 것, 마방에서 나온다) ·
  주민·**떠돌이 상인**(그 라마 두 마리는 마크의 서명이다) · **철골렘**(향촌은 무사가 지킨다) ·
  무시룸·판다·아홀로틀·알레이·스니퍼·아르마딜로·개구리·앵무새(마크의 마스코트들)
* **염소 `GOAT` — 판단: 끈다.** 야생 산양 자체는 중원에 맞으나
  바닐라 염소의 들이받기·비명 염소는 **밈**이다. 고산 짐승이 필요하면 사냥터 등록부에
  **산양**을 올려 우리가 심는다.

**적대 몹은 이 목록 이전에 이미 전역 취소된다** (`entity instanceof Enemy` → cancel). 확인 완료 —
좀비·스켈레톤·크리퍼·엔더맨은 이미 안 뜬다.

그리고 마을과 사냥터에서는 **허용 목록의 것조차** 자연 스폰이 취소된다.
사냥터의 개체군은 **정원제(定員制)** 다 — 바닐라가 뿌린 이리가 섞이면 census 가 깨진다.
산야의 짐승(산늑대·멧돼지·호랑이·반달곰)은 **우리가 심는다.**

## 6. 검산

```
python3 tools/world_purity_audit.py --build       # 등록부 → 데이터팩 (+ 자동 load-test)
python3 tools/world_purity_audit.py               # 등록부 ↔ 데이터팩 대조
python3 tools/world_purity_audit.py --load-test   # ★ 바닐라 코덱 파싱 (서버 사망 예방)
python3 tools/world_purity_audit.py --emit-rcon   # 인게임 실측 명령 (525줄)
```

정적 검산이 보증하는 것:

* 등록한 20종 ↔ override 파일 20종이 **일치**하고, 바닐라의 20종 중 **빠뜨린 것이 없다**
* 모든 structure_set 의 `frequency == 0.0`, 모든 placed_feature 에 `count: 0`
* **지표 용암 5종이 전부 등록·차단**되었다 — `y ≥ −54` 에 용암을 놓을 수 있는 피처가 **하나도 없다**
* 기후 상자 7,593개의 **구획이 정본과 바이트 단위로 동일**하고, 금지 12종이 **0회 등장**
* 모든 바이옴 id 가 **실존**한다 (없는 id = 레지스트리 로딩 실패 = 서버 사망)
* 30개 파일이 **바닐라 코덱을 통과**한다

> 정적 검사는 「**생성될 수 없음**」까지 말한다 — 확률이 낮은 게 아니라 **불가능**하다.
> 기후 구획에 `desert` 이름표가 0개면 그 biome_source 는 desert 를 만들 방법이 없다.

### 인게임 실측 (RCON) — 무엇이 어떻게 나와야 통과인가

`--emit-rcon` 이 525줄을 뱉는다. 요약:

| # | 명령 | 통과 기준 |
|---|---|---|
| ⓪ | `datapack list` | `honcheon_purity` · `honcheon_no_caves` 가 **enabled** 에 보인다. **이게 아니면 아래는 전부 무의미** |
| ① | `locate structure minecraft:<31종>` | 전부 `Could not find a structure…`. 좌표가 나오면 그 구조물은 살아 있다 |
| ② | `locate biome minecraft:<금지 12종>` | 전부 `Could not find a biome…` |
| ③ | `locate biome minecraft:savanna` 등 12종 | ★ **전부 좌표가 나와야 한다.** 이게 없으면 「전부 못 찾음」이 순도가 아니라 **고장**이라는 뜻이다. 특히 `savanna` — 사막이 갔던 자리다 |
| ④ | `execute if entity @e[type=minecraft:cow]` 등 | **산야를 2,000블록쯤 돌아다닌 뒤** 전부 `Test failed`. (셀렉터는 로드된 청크만 본다.) **마을 안에서는 소·닭이 나오는 게 정상** — 가축은 마을의 살림이다 |
| ⑤ | `execute if entity @e[type=minecraft:wolf]` 등 | 최소한 몇은 `Test passed`. 전부 0 이면 산야가 **죽은 것**이다 |
| ⑥ | `execute positioned <x> 96 <z> if biome ~ ~ ~ minecraft:desert` × 441 | **passed 0 / 441.** `desert` 를 `savanna` 로 바꿔 다시 돌리면 여럿 passed 여야 한다 |

네더·엔드 구조물은 `execute in minecraft:the_nether run …` 으로 감싸 나온다.

### 지표 용암 — 전수 조사 (따로 뺐다: **파괴적**이다)

```
python3 tools/world_purity_audit.py --emit-lava-census --radius 256    # 3,264줄
```

**왜 전수 조사인가.** `/locate` 로는 블록을 못 세고, 표본 격자로도 안 된다 —
지표 용암 호수는 **200청크에 하나**라 격자 점이 그 위에 떨어질 확률이 사실상 0 이다.
블록 수를 돌려주는 명령은 `/fill … replace` 뿐이다("Successfully filled **N** blocks").

⚠ **용암을 공기로 바꾼다.** 버려도 되는 시험 월드에서, 위의 ①~⑥ 을 **전부 끝낸 뒤 마지막에** 돌려라.

| 구간 | 세는 것 | 통과 기준 |
|---|---|---|
| ⓪ **먼저** | 철광석 (y −64‥319, 타일 하나) | ★ **N > 0.** 우리는 광맥을 **남겼다** — 0 이면 순도가 아니라 **고장**이고, 그러면 아래의 「용암 0」은 아무것도 증명하지 못한다 |
| ① y **0‥319** | 용암 | ★ **합계 0.** **여기가 「필드」다.** 한 블록이라도 나오면 순도가 깨진 것 |
| ② y **−54‥−1** | 용암 | **합계 0.** 아쿠아퍼 규칙상 −54 위의 유체는 물이고, 용암을 놓던 `lake_lava_underground` 는 껐다 |
| ③ y **−64‥−55** | 용암 | **관측만. 통과/실패가 아니다.** 우리가 **남긴** 지심의 용암 바다. 다만 §4 의 예측대로 **0 에 가까울 것** — 동굴을 껐으니 용암이 들어앉을 공동이 없다. 수치를 알려 달라 |

**대조군(권장)** — 같은 시드로 `honcheon_no_caves` **만** 건 월드를 하나 더 깔고 그대로 돌려라.
(바닐라 생짜와 비교하면 **동굴 용암이 섞여 교란된다** — 동굴은 이미 no_caves 가 껐으니 그 차이가 아니다.)
두 월드의 차이가 정확히 `honcheon_purity` 가 지운 용암이어야 한다.
「대조 N / 우리 0」이 나오면 **「전부 0」이 순도의 증거지 측정 실패가 아님**이 확정된다.

> **하나 남은 불확실**: `locate structure minecraft:stronghold` 는 `concentric_rings` 라
> 고리 좌표를 미리 계산한다. `frequency: 0` 이 **생성**은 확실히 막지만(상위 클래스의 관문),
> `/locate` 가 유령 좌표를 뱉을 가능성은 실측으로 확인해야 한다.
> 뱉더라도 **거기엔 아무것도 없다** — 파 보면 안다. 그리고 엔드는 어차피 못 간다
> (요새 없음 → 블레이즈 없음 → 엔더의 눈 없음). 실측값을 알려주면 문서를 갱신한다.

## 7. ⚠ 기존 월드는 안 바뀐다 — 새 월드가 필요하다

이미 생성된 청크에는 **사막이 그대로 남는다.** 바이옴과 구조물은 청크가 **처음 만들어질 때** 결정된다.

`world_preset` 은 서버가 **월드를 만들 때** 딱 한 번 읽힌다. 그 뒤로는 `level.dat` 에 굳는다.

### 재조성 체크리스트

1. `worldgen/honcheon_purity/` 와 `worldgen/honcheon_no_caves/` 를 **새 월드 폴더의 `datapacks/`** 에 넣는다
2. `server.properties` 의 `level-type` 이 `minecraft:normal` 인지 확인 (그래야 우리가 덮은 프리셋을 탄다)
3. 서버를 띄운다. **로그에 레지스트리 오류가 없는지 먼저 본다** — 있으면 세계가 아니라 서버가 죽는다
4. `datapack list` → 둘 다 **enabled** 인지 확인 (⓪ 이 실패하면 나머지는 볼 필요도 없다)
5. `--emit-rcon` 의 ①~⑥ 을 돌린다
6. 조성기를 다시 돌린다 — **청하현이 이제 어떤 바이옴 위에 서는지** 확인하라.
   화산파가 사막에 서는 사고는 이제 구조적으로 불가능하지만, 좌표 점수는 다시 매겨질 수 있다

## 8. 끈 자리를 무엇으로 채우는가

**세계가 비면 안 된다.** 끈 것마다 채울 것을 등록해 둔다 (`world_purity.yml` → `refill_plan`).

| 껀 것 | 채울 것 | 상태 |
|---|---|---|
| 주민 마을 | **향촌·중촌·부촌** — `village_tiers.yml` 이 등급을 정의한다. 청하현이 그 표준 | 조성기 가동 중 |
| 약탈자 전초기지 | **산채(山寨)** — 녹림의 산적굴 | 부분 가동 (수로채·산채 조성됨) |
| 폐광 · 지하 감옥 | **우리가 판 굴** — `cave_archetypes.md` 의 4종(은신처·기연굴·산적굴·제단굴) | 설계 완료 · 조성 대기 |
| 사원 · 신전 | **폐사당 · 고묘 · 동천복지(洞天福地)** — 기연의 무대 | 청하현 폐사당 조성됨 |
| 산장 | **세가(世家)의 장원** — 남궁·팽가·제갈. `world_map.yml` 에 좌표가 있다 | 좌표만 |
| 난파선 · 바다 유적 | **장강수로채의 배** — 나루터·선단 | 수로채 조성됨 |
| 고대 도시 · 시련의 방 | **마교의 지하 제단 · 혈교의 혈굴** | 설계 대기 |
| 사막 | **건조 초원 + 황토고원** — 관중·산서의 서북 건조대 | 데이터팩 적용 시 즉시 |
| 빙설 | 평지·침엽수림·고산 침엽수림·험봉. **설산은 지형 계층이 짓는다** | 데이터팩 즉시 · 설산은 TerrainForge |
| **지표 용암** | **채우지 않는다 — 빼는 것이 곧 채우는 것이다.** 용암은 땅 위에 **덧칠된** 것이었다. 걷어내면 그 아래 숲과 초원이 이미 있다. 불과 열이 서사에 필요하면 그때 **놓는다**: 화산파의 대장간 화로 · 마교의 혈지(血池) · 기연굴의 지열. 조성기의 일이지 세계가 무작위로 뿌릴 일이 아니다 | 데이터팩 즉시 |
| 요새 · 지옥문 · 네더 · 엔드 | **채우지 않는다.** 이 세계에 다른 차원은 없다. 빈 자리가 아니라 **없는 자리**다 | 의도된 부재 |

### 설산은 어떻게 짓는가 — 눈은 **블록**이지 바이옴이 아니다

곤륜(崑崙)의 설산을 포기하는 것이 아니다.
`snowy_slopes` 바이옴을 껐다고 눈을 못 놓는 게 아니다 — **TerrainForge 가 산을 세우고 눈을 얹으면 된다.**
게다가 바닐라도 거들어 준다: 바이옴의 온도는 **고도로 보정**되므로, 충분히 높은 봉우리에는
`jagged_peaks` 든 `grove` 든 **알아서 눈이 얹힌다.**

같은 논리가 사막에도 적용된다. 서사가 요구하면 **사막 무대를 짓는다** — 모래는 블록이다.
우리가 끈 것은 「자연이 마음대로 뿌리는 사막」이지 「사막이라는 개념」이 아니다.

## 9. ⚠ 등록부 충돌 — `world_map.yml` (내 소유가 아니다)

`config/world_map.yml` 의 지역별 `biomes:` 목록에 **우리가 끄는 바이옴이 등록되어 있다.**
사용자의 지시가 등록부보다 우선이므로 끄는 쪽을 택했다. **소유자가 정리해야 한다.**

| 지역 | 등록된 금지 바이옴 | 해소 |
|---|---|---|
| 하북 | `snowy_plains` | → `plains`. 「겨울이 길다」는 서술은 유지 가능 (눈은 날씨·고도의 함수다) |
| 산서 | `badlands` | **충돌 없음** — 남긴다(황토고원) |
| 청해_서역 (곤륜) | `snowy_slopes` `frozen_peaks` `desert` | → `grove` `jagged_peaks` `savanna`. **설산은 지을 수 있다**(§8). center 가 1.38M 블록 밖 — 조성 대상도 아니다 |
| 새외_북막 (마교) | `snowy_plains` `snowy_taiga` `desert` | `hidden: true` 인 서사 지역. 마교의 땅이 필요해지면 그때 **짓는다** |

## 10. 남은 것

* **⑤ 블록 팔레트 · ⑥ UI·소리** — 팩 담당(진행 중). 특히 **소리**는 아직 아무도 안 건드렸다:
  마크의 「동굴 앰비언스」와 몹 소리는 눈을 감아도 마크다. 다음 사이클의 후보.
* **`/locate stronghold` 유령 좌표** — 실측 대기 (§6)
* **깊은 용암 바다의 실제 양** — 실측 대기. 0 에 가까울 것이라 **예측**해 두었다 (§4)
* **흑요석 경제** — 지표 용암을 지우면서 흑요석이 사실상 사라졌다.
  `equipment.yml`·`economy.yml` 이 흑요석/용암 양동이를 쓰는지 **소유자 확인 필요** (§4)
* **끈 자리 채우기** — §8 의 「설계 대기」 항목들

### 이 사이클에서 배운 것

1차에서 나는 「자연이 놓은 것 / 사람이 지은 것」이라는 선 하나로 모든 걸 가르려 했고,
그 선이 **용암을 놓쳤다.** 지표 용암은 「자연」의 얼굴을 하고 있지만 실은 **「마크의 자연」**이다.
지구에는 없고 마인크래프트에만 있다.

> **교훈:** 「이건 자연이니까 남긴다」는 판단은 **지구를 기준으로 다시 물어야 한다.**
> 중원의 산야에 실제로 있는가? 없으면 그것은 자연이 아니라 마크다.

이 잣대로 다시 볼 후보: 자수정 정동(지구엔 있다 — 남긴다) · 심층암의 색 · 대나무의 성장 속도.
