## 1. 디자인 원칙

```text
1. 수묵 3색 — 화면의 기본은 목골(짙은 나무)·백벽(흰 벽)·흑와(검은 기와) 세 값.
   채색은 아껴서: 차양·등롱·매화만 색을 갖는다. 색이 귀할수록 색이 말을 한다.
2. 맵도 컴파일한다 — 손건축 금지. 같은 입력 = 같은 마을 (결정론, 시드/난수 불사용 또는 고정).
3. 논리-공간 정합 — 앵커 계약(반환 Map 키)이 config 장소와 1:1. 건물은 장식이 아니라
   시스템의 무대다 (장터에서만 매각, 의뢰소 게시판 = 사건 소문의 물리적 표면).
4. 바닐라 안정 API만 — Paper/Bukkit 1.21.4 안정 API. BlockData는 검증된 인터페이스만
   (Stairs·Leaves·Lantern·Directional). 리소스팩 커스텀 블록은 차후 옵션.
5. 위계는 높이와 지붕으로 — 중요한 건물일수록 풋프린트가 크고 벽이 높고 지붕 층이 많다.
   (객잔 17x13·2층 > 관청류 13x11·벽4 > 민가 13x9~9x12·벽3~4 > 노점 3x2·차양뿐)
6. 생기는 민가에서 — 퀘스트 건물만 있는 마을은 무대 세트다. 앵커·NPC 없는
   일반 가옥(순수 풍경)이 골목길을 따라 서야 사람 사는 현이 된다.
7. 색만 바뀐 변형은 변형이 아니다 (v5) — 변주의 제1축은 골조(형태·규모), 자재 팔레트는
   유형에 종속시킨다. 같은 상자에 다른 칠을 하는 대신, 다른 집을 짓는다.
```

## 3. 건물 유형별 스펙

공통 문법: 4우 흑목 기둥 → 백벽(+격자창) → 상인방 → **계단식 팔작지붕**
(처마 1칸 내밀기 → 층마다 1칸씩 좁아지는 스테어 링, 모서리는 풀블록 층답, 꼭대기 용마루 슬래브).
입구는 도로를 바라본다: 광장 북쪽 건물은 남향, 남쪽 건물은 북향. 입구 옆 간판 + 골목길 연결.
민가는 간판·앵커·NPC 없는 순수 풍경으로, 북골목(z-21)·남골목(z+21) 두 줄을 따라 문이 골목을 본다.

구역(Zone) 계약: 조성기는 앵커 Map과 함께 구역 6개를 채운다 — 마을 전체("청하현 —
섬서의 작은 현"), 건물 4채(간판 문구 재활용 부제), 장터. 상자 y = 지면-2 ~ 지붕+3,
중첩 시 부피가 작은 쪽이 이긴다 (건물 > 마을). ZoneListener 가 입장 타이틀로 소비.

### 3.1 인테리어 규정 — 빈 상자 금지 + 필수 세트 (디자인 패스 2, v5 확대)

```text
1. 필수 세트 (v5) — 전 가옥(민가 포함) 예외 없이 다섯 요소를 갖춘다:
   침상(백색 깔개 2칸+곁깔개) · 수납(술통/궤) · 작업대(작업상/용광로/베틀 등 생업 도구)
   · 조명 높이 변화(바닥 등롱 y+1 + 선반등 y+2 또는 현수등 — 한 높이로 끝내지 않는다)
   · 바닥 패턴(귀틀+깔개) + 용도별 소품(국솥·가마솥·화분·모루·베 무더기 등).
2. 바닥 변화 — 본채급(w>=9)은 마루 가장자리 1칸 흑목 귀틀(DARK_OAK_PLANKS) — v5 민가
   본채는 전부 해당 — 여기에 깔개(카펫)를 얹는다. 카펫은 통행 가능이라 동선을 해치지 않는다.
3. 벽 장식 — 아이템 프레임(액자류) 금지 (엔티티 = 결정론·정리 비용). 대신
   간판(차림 팻말·게시판)·등롱(선반 위/현수)·화분(POTTED_BAMBOO/POTTED_POPPY)만 쓴다.
```
