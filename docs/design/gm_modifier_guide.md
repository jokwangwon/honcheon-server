# GM 보정 예시집 — 상황 보정 부여 가드레일

> 설계 검토 공백 G5 해결. LLM GM 프롬프트에 직접 포함할 자료.
> 판정식의 상황 보정(±5 캡)이 GM 재량이라서 세션 간 일관성이 흔들리는 문제를,
> "보정은 반드시 아래 표에서 근거를 찾아 부여한다"는 규칙으로 막는다.
> 기계 판독용: `config/gm_modifiers.yml`

## 0. 4대 원칙

```text
1. 근거 없는 보정 금지 — 모든 보정은 이 문서의 표 항목을 인용할 수 있어야 한다.
2. 중복 가산 금지 — 같은 사실은 한 번만 보정된다. ("어둡다"로 +2를 줬으면
   "달이 없다"로 또 줄 수 없다.)
3. 캡 준수 — 상황 보정 합계는 ±5를 넘지 않는다.
4. 내부 기록 — 부여한 보정과 근거를 내부 로그(JSON)에 남긴다.
   플레이어 출력에는 수치를 쓰지 않는다.
```

## 1. 준비도 (+1 ~ +2)

| 보정 | 기준 |
|------|------|
| +1 | 플레이어가 **구체적인 방법**을 선언 (그냥 "미행한다"가 아니라 "지붕을 타고 거리를 두고 따라간다") |
| +2 | 방법 + **사전 행동으로 만든 이점** (미리 답사한 지형, 준비한 변장, 매수한 내통자) |
| 0 | "잘 한다", "조심스럽게 한다" 같은 수식어만으로는 보정 없음 |

## 2. 정보량 (핵심 단서당 +1, 최대 +2)

**핵심 단서의 정의**: 세계 상태에 기록된 단서(clue) 태그를 플레이어가 대사나 행동에 **명시적으로 사용**한 것.

```text
인정:   "묵삼이 하오문과 접선하는 걸 봤소. 내일 해 질 무렵이 위험하오"
        → muksam_haomun_connection, tomorrow_sunset_timing 2개 사용 → +2
불인정: "위험한 일이 벌어질 것 같소" → 단서 인용 없음 → +0
불인정: 플레이어가 획득하지 않은 단서를 아는 척 → 오히려 상대 의심 +1
```

## 3. 환경 (행동에 따라 부호가 바뀐다)

같은 환경이 행동에 따라 다르게 작용한다. **한 판정에 환경 항목은 최대 2개까지만.**

| 환경 | 은신/잠복 | 미행 | 엿듣기 | 관찰/조사 | 기습 | 추적 |
|------|-----------|------|--------|-----------|------|------|
| 어둠 (밤, 무월) | +2 | +1 | 0 | −2 | +2 | −1 |
| 소음 (시장, 술집) | +1 | +1 | −2 | 0 | +1 | 0 |
| 군중 | +1 | +1 | −1 | −1 | −1 | −2 |
| 비/눈 | +1 | 0 | −1 | −1 | 0 | −2 (흔적은 +2) |
| 탁 트인 지형 | −2 | −2 | — | +1 | −2 | +1 |
| 엄폐물 풍부 (창고, 골목) | +2 | +1 | +2 | 0 | +1 | 0 |
| 관군 순찰 강화 (치안>70) | −1 | −1 | −1 | 0 | −1 | 0 |

## 4. 신체 상태 (고정값 — 재량 없음)

경상 −1 / 중상 −2 / 빈사 −3 / 피로 −1 / 내공 고갈 −2. `config/judgment.yml`의 값을 그대로 쓴다.

## 5. 경지 격차 (±2/단계 — 무공 개입 판정에만)

전투, 기습, 경공 추격, 기세 대결에만 적용한다. **설득·조사·정보 수집에는 적용하지 않는다** — 생사경 고수도 거짓말은 서툴 수 있다.

## 6. NPC 측 보정 상기

NPC 저항값의 경계도/의심도/목적 집중/심리 상태는 세계 상태에 **이미 기록된 값**을 쓴다. 판정 순간에 즉석으로 "왠지 경계할 것 같으니 +2" 같은 부여는 금지.

## 7. 좋은 보정 / 나쁜 보정 실례

```text
[좋음] 야간 창고 엿듣기: 어둠은 엿듣기에 무관(0), 엄폐물(술독) +2. 합계 +2.
       근거: 환경표 '엄폐물 풍부/엿듣기'.

[나쁨] "플레이어가 주인공이니 +1" — 근거 항목 없음. 금지.
[나쁨] 어둠 +2, 달 없음 +1, 야심한 시각 +1 — 같은 사실 삼중 가산. 어둠 +2 하나만.
[나쁨] "긴장감을 위해 이번엔 저항값을 올리자" — NPC 수치는 기록된 값만. 금지.
```

## 8. 내부 로그 형식

```json
{
  "judgment": "tail_npc",
  "player_side": { "base": "감각3+추적1", "modifiers": [ {"환경.어둠": 1}, {"환경.소음": 1} ] },
  "npc_side": { "base": "감각4+미행_감지4", "state": { "경계도": 0, "의심도": 0 } },
  "roll": 9, "margin": 0, "result": "narrow_success",
  "side_risk": "의심도 +1"
}
```
