# 전투 판정 재설계 v2 — 2d6 제거, 공방(攻防) 도입 (사용자 설계 2026-07-24)

> ★ 헌법 개정. 전투의 판정 축이 **"2d6 판정"에서 "공격력 vs 방어력 + 확률 치명타"** 로 바뀐다.
> 근거: 2d6 은 「한 장면 한 굴림」의 TRPG 물건인데 마크는 실시간(한 전투 = 수십 굴림)이라 안 맞았다
> (분석: 판정 엔진 3갭 — auto-resolution 미적용·분산 노이즈·극단 주사위 삼분열).
> ★ 성장 v3 와 직결: 원장 → 공격력 → 격차 압도 = **몸으로 느끼는 성장**(growth_v3_feel §2)의 실현.

---

## 1. 결정 (사용자 확정 2026-07-24)

| 축 | v1 (TRPG 판정) | ★v2 (액션 공방) |
|---|---|---|
| **명중** | 실행력+2d6 vs 저항 → 등급으로 명중 | **획(이펙트) 히트박스가 닿으면 무조건 타격** (band_hit) |
| **피해** | weaponPower + floorDiv(margin,2) + … | **공격력 − 방어력** (결정론 · 격차 곧 압도) |
| **치명타** | 쌍륙(2d6) | **확률 크리** — 기본 0 + 감각 가산 + 무기별 · 배수 (미결) |
| **방어** | 저항 = 태세 판정치 + 7 | **방어력** — 갑옷 + 체력 파생 (기존에서 유도) |
| **2d6 판정** | 전투에 있음 | ★**제거** (auto-resolution·극단 주사위도 함께 무의미) |

### 남는 것 (제거 아님)
- **TRPG 2d6 판정은 그대로** — 서장·퀘스트·사회 판정(genderStat → resolve). 「한 장면 한 굴림」의
  드라마가 사는 곳. 뱀눈/쌍륙·auto-resolution 도 여기서만 의미. (극단 주사위 삼분열 정리는 별건.)
- **격(格) 사다리** — 외공기→발경→검기→강기→어검→심검. "무엇을 쓸 수 있나"지 주사위가 아니라 무변경.
- **몸짓이 곧 선택** — 오히려 더 정합: 막기/흘리기 → **방어력↑(soak)** · 회피 → **획 회피(기하)** (주사위 아님).

## 2. 공식 (꼴 · 수치는 구현 시 config)

```
명중   = 획 히트박스 겹침 (band_hit) — 참/거짓. 닿으면 타격, 판정 없음.
공격력 = 무기 위력 + 기술 숙련 + 능력치(병기별 축 · combat.yml attacker_attribute) + 격 보정
          └ 능력치 항 = 원장 파생 (성장 v3) — 원장↑ ⇒ 공격력↑ = 몸 체감
방어력 = 갑옷 경감 + 체력 파생 (플레이어) / 경지 표준 + 갑옷 (NPC)   ← 기존에서 유도, 새 축 아님
피해   = max(1, 공격력 − 방어력) × 크리배수    ← 격차 곧 압도: 하한 1, 상한 없음 (잡졸 한 방 허용)
크리   = 확률(기본 0 + 감각 가산 + 무기별) 로 발동 → 피해 × 배수(미결)
몸짓   = 막기/흘리기 → 방어력 가산(soak) · 회피 → 획을 안 맞음(위치)
```

### 치명타 세부 (사용자 2026-07-24)
- 확률: **기본 0%** + **감각**(주축·2%/판정치) + **지혜**(급소를 안다·1%) + **무기별** + **장비**
- 배수: **기본 ×1.2** + **크리 피해 증강 시스템** (사용자 2026-07-24) — 무기·능력치가 크리 배수를
  더 올린다. ★축(2026-07-24): **감각**=주축(확률+피해) · **지혜**=급소를 안다(확률+피해) · **무기** · **장비**.
  배수 = 1.2 + 감각(0.02/판정치) + 지혜(0.03/판정치) + 무기(단검 0.3) + 장비 슬롯.

## 3. 무엇이 바뀌나 (구현 접점)

- `SkillEngine.strike(cast, execBase, roll2d6, resist)` → **roll2d6 인자 삭제**, tierOf 명중/실패 삭제.
  피해 = max(1, 공격력 − 방어력) × 크리. 획이 닿았으면(band_hit) 항상 타격.
- `SkillListener` 전투 루프: `roll2d6()` 제거 · resist(판정치+7) → **방어력**으로 교체 ·
  크리 확률 굴림(액션 RNG — 2d6 아님) 추가.
- `npcDefenseScore` → **방어력**(갑옷+경지 표준)으로 재해석.
- 등급표(6단)·auto-resolution·optional_extreme_dice 는 **전투 경로에서 안 읽는다** (TRPG 경로엔 남음).
- config: combat.yml 에 `crit`(base·감각계수·무기별·배수) + `defense`(갑옷·체력 파생) 신설.

## 4. 성장 v3 와의 접합
- growth_v3_feel §2 "몸으로 느끼는 성장"의 **전투 절반**이 이 모델이다: 원장↑ → 공격력↑ → 압도.
- growth_v3_impl_plan 단계 3(파생치)·단계 4(성장)와 겹친다 — 전투 피해가 원장 파생을 읽는다.
- ★판정치 범위(1~10) 불변이라 저울 전환(단계 2)은 이 재설계와 독립 — 하네스는 TRPG 판정만 지킨다.

## 5. 미결
- ~~크리 배수~~ → 기본 1.2 + 증강 시스템 확정.
- 방어력 파생 공식의 정확한 꼴 (갑옷 + 체력 √원장 계수 — 구현 시 combat.yml).
- 극단 주사위 삼분열(장식/기계/부재) 정리 — TRPG 경로 한정 별건.
- PvP(directOpposed)도 공방으로 갈지 (지금은 2d6 대립) — 별도 확인.
