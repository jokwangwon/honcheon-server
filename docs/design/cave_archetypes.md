# 동굴 원형 (cave archetypes) — 2026-07-12

사용자 판정:
> "자연동굴 제거 및 필요하면 그때 동굴의 형태로 생성하기 (**통제가 힘들기 때문**)"

## 왜 우리가 파는가

자연 동굴은 **어디에 뚫릴지 모른다**. 그래서 마을 바닥 밑이 뚫렸고(환경 검수 13%), 우리가 깐 길이
껍데기가 됐고, 협곡이 부지를 가로질러 잘려 열렸다. 통제할 수 없는 것은 자산이 아니라 사고다.

그래서 껐다 (`worldgen/honcheon_no_caves`). 지하 공동 **10.08% → 1.06% → ~0%**
(밀도함수 5종 + 카버 3종).

그런데 **등록부는 동굴을 요구한다**:
* `magyo_jinryeong` — architecture: "**동굴과 석실** — 사람이 사는 흔적을 지운다"
* `abandoned_shrine` (폐사당) — 취걸개 기연의 무대, 금기 사슬의 첫 고리
* `hyeolgyo_jedan` — 폐사에 남은 옛 제단
* 녹림 산채 셋 — 도적은 굴에 짐을 쟁인다

**그러면 우리가 판다.** 우리가 정한 자리에, 우리가 정한 형태로. 그것이 통제다.

## 공통 규약

| 규약 | 왜 |
|---|---|
| **광원이 없다** | 횃불 하나 놓지 않는다. **어둠이 동굴의 값이다** — 빛을 들고 들어가는 것이 사건이다 |
| **입구는 비탈에 뚫린다** | 평지 한복판의 구멍은 함정이지 동굴이 아니다. 부지 둘레를 훑어 *바깥으로 4켜 이상 내려가는* 마른 비탈을 찾고, 그 **살을 파고 들어간다** (위에 바위 지붕이 생긴다) |
| **물이 새지 않는다** | 자연 동굴은 껐지만 **대수층은 남아 있다**. 판 자리의 껍질(이웃 칸)에 물·용암이 닿으면 전부 돌로 막는다. 잠긴 굴은 굴이 아니라 우물이다 |
| **걸어 들어간다** | 통로의 하강은 한 걸음에 1켜를 넘지 않는다 (은신처 18켜 ÷ 44칸 = 0.41). 천장은 3~4칸 — 사람이 선다 |
| **결정론** | 난수가 없다. 입구 자리·통로의 굽이·방의 요철이 전부 좌표 해시(`Math.floorMod`)다. **두 번 파도 같은 굴이다** |
| **자로 그은 것이 없다** | 통로는 8칸마다 ±0.6rad 튼다(굽이). 벽은 해시로 1/3쯤 살을 남긴다. 매끈한 원통은 굴이 아니라 **갱도**다 |

## 원형 넷

```
        입구(비탈)  ──통로(굽이치며 내려간다)──▶  방  ──▶ (곁방)
```

| 원형 | 통로 | 깊이 | 방 | 곁방 | 파낸 부피 | 어디에 |
|---|---|---|---|---|---|---|
| **은신처** | 44칸 (반폭 2) | 18 | 7×4×7 | ✔ 석실 하나 더 | ~1,400칸 | 마교 전초 · 혈교 은거지 |
| **기연굴** | 24칸 (반폭 1) | 11 | 5×3×5 | — | ~700칸 | 폐사당 지하 · 고국 폐허 |
| **산적굴** | 18칸 (반폭 2) | 7 | 8×4×8 | — | ~1,300칸 | 녹림 산채 셋 |
| **제단굴** | 30칸 (반폭 2) | 22 | 9×5×9 | — | ~2,100칸 | 혈교 옛 제단 (복우산 폐사) |

### 원형이 성격이다

* **은신처** — 입구가 **좁고** 통로가 **길다**(44칸). 안쪽에 석실이 둘.
  "사람이 사는 흔적을 지운다"는 등록부의 말이 형태가 된 것: 밖에서는 굴인지도 모르고,
  들어가면 한참 걷는다. 그 길이가 곧 **비밀의 값**이다.
* **기연굴** — 짧다(24칸). 방 하나. **안쪽 끝에 무언가 있다** — 무엇을 놓을지는 건축 계층이 정한다
  (취걸개는 굴 안에서 술을 마시고 있을 것이다).
* **산적굴** — 입구가 **넓다**. 도적은 짐을 들여야 하고, 수레가 들어가야 한다.
  짧고 굵다 — 도적은 숨는 자가 아니라 **쟁이는 자**다.
* **제단굴** — **깊이 내려간다**(22켜). 방이 넓고 천장이 높다.
  내려가는 동안 조용해지는 것이 이 굴의 전부다.

## 자재

굴은 **자재를 놓지 않는다**. 파낼 뿐이다 — 벽은 그 산의 돌(화강암·안산암·심층암)이 그대로 드러난다.
땅이 놓는 것은 둘뿐:
* **바닥** — 파낸 칸 밑이 허공이면 돌로 받친다. 그 위에 6칸마다 **자갈**을 섞는다
  (사람이 다닌 굴의 바닥은 부슬부슬하다).
* **껍질** — 물·용암이 닿은 자리는 돌.

제단·궤·짚자리·시렁은 **집의 일**이다. 굴은 땅의 일이다.

## 환경 검수 ⑥ 과의 약속

검수 ⑥은 지면 아래 5~45칸의 공기 비율을 재고 **2%**를 문턱으로 잡는다.
우리가 판 굴은 이 문턱 **안**에 들어야 한다 — 안 그러면 검수가 "자연 동굴이 살아 있다"고 거짓말한다.

반경 40 부지의 표본 밀도(4칸 격자 × 41켜 = 18,081 표본)로 계산한 몫:

| 원형 | 파낸 부피 | 표본 기여 |
|---|---|---|
| 기연굴 | ~700 | **0.4%** |
| 산적굴 | ~1,300 | **0.7%** |
| 은신처 | ~1,400 | **0.8%** |
| 제단굴 | ~2,100 | **1.2%** |

전부 통과한다. **다만 한 부지에 굴을 둘 이상 파면 넘을 수 있다.**
그때는 검수 규칙을 고쳐야 한다 — 우리는 우리가 판 굴의 좌표(`CaveSpec`)를 알고 있으니,
검수가 그 구역을 빼고 세면 된다. (지형 계층이 요청할 일이다.)

## 부르는 법

```java
TerrainForge.SiteSpec site = TerrainForge.prepare(world, place, cx, cy, cz, radius);
TerrainForge.CaveKind kind = TerrainForge.caveKind(place);   // 등록부(terrain.yml) 또는 지도에서 읽어 낸다
if (kind != null) {
    TerrainForge.CaveSpec cave = TerrainForge.digCave(world, site, kind);
    // cave.mouthX/Y/Z — 입구 (여행의 도착점을 여기로 잡아도 된다)
    // cave.roomX/Y/Z  — 방의 중심 (건축 계층이 제단·궤를 놓는 자리)
    // site 의 입구 둘레 4칸은 이미 **보호구역**이다 — 집이 입구를 덮지 않는다
}
```
