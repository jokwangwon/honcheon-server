## 1. 무엇이 숙제였나 (진단)

현행 (training.yml curriculum): 하루 5구간을 **명령/발판으로 배분**한다
(`혼천 수련 외공 2` …). 병은 배분표가 아니라 **행위의 부재**다 — 수련이 "몸을 쓰는 것"이
아니라 "버튼을 누르는 것"이고, 매일 같은 버튼이라 숙제가 된다.

**바꾸지 않는 것** (이 등록부들은 정본 그대로):
- 하루 5구간 상한 (`time.yml segments_per_day` — 시간의 값)
- 과목 5종 → 기존 원장 매핑 (`training.yml curriculum.subjects` — 외공·내공·초식·신법·심안)
- 환산표 (`attribute_progression.cost` — 능력치 +1 = 1년)
- 사사 효율 (`party.yml 사제` — 1.0 · 경지 2단 우위 1.2)

**바꾸는 것**: 구간을 채우는 손 — 명령·발판 → **행위**.

## 2. 행위 → 과목 (기존 판정의 재사용 — 새 감지기를 만들지 않는다)

한 구간이 흐르는 동안 몸이 한 일을 **이미 있는 판정 지점**에서 센다:

| 과목 | 행위 | 이미 있는 지점 (발명 아님) |
|---|---|---|
| 외공 | 때리고 맞는다 — 유효 타격을 주고받음 | `basicJudged` 착지 · 피격 생존 (SkillListener) |
| 초식 | 무공을 실전에서 낸다 — 시전·판정 승리 | `swing`/`admit` 착지 (SkillListener) |
| 신법 | 달리고 · 허공을 딛고 · 몸을 뺀다 | 경공 사용 (Gyeonggong) · 회피 승리 (`lastDodge`) |
| 내공 | 운기 | `/혼천 운기` — **이미 구간 단위다. 그대로 둔다** |
| 심안 | 【미결 §5-①】 | — |

**적립 규칙 (결정론 · 난수 없음)**:
- 구간이 닫힐 때, 그 구간에 **문턱 이상** 행한 과목이 그 구간의 수련이 된다.
- 문턱 【제안】: 유효 행위 **N회** (과목별 단일 수치 — §5-② 사용자 승인 필요).
- 두 과목이 같이 문턱을 넘으면 **더 많이 한 쪽** (동률이면 원장 표기 순).
- 아무 문턱도 못 넘은 구간 = 자유 구간 — 수련 적립 0 (현행 `free_segments` 문구 그대로:
  *"그 구간의 수련 적립은 0 — 그것이 시간의 값이다"*).
- **상한은 그대로 하루 5구간** — 몰아서 그라인드해도 시간이 막는다 (수확 체감 불필요).

## 3. 디제시스 층 — 스승과 일과 (새 시스템 없음 · 접합 2건)

1. **사사 = 지도**: 스승과 같은 자리에서 수련(§2 행위)하면 그 구간의 적립에 사사 효율
   (party.yml — 1.0/1.2)이 탄다. 스승은 이미 있다 (표사 곽진: *"배울 생각이면 /혼천 사사 로
   정식으로 청하게"*).
2. **일과 = 의뢰의 옷**: 문파·스승이 "오늘의 일과"를 낸다 — 내용은 §2의 행위 (예: "산길을
   달려라" = 신법 구간). **의뢰 파이프 재사용** — 새 명령·새 표 없음. 일과를 하면 행위가
   쌓이니 따로 보상 로직이 필요 없다 (완수 명분·소문은 의뢰의 기존 몫).

## 4. 뜯는 것

- 발판 `수련_외공`·`수련_초식` (antechamber.yml stations) — 철거 【§5-③ 범위 확인】
- `/혼천 수련 <과목> <n>` 명령 — 뒷문으로 남길지 철거할지 【§5-③】
- 입도진 '수련' 과제 문구 — "발판을 밟아라" → "몸을 쓰면 자란다" (등록부 문구 개정)

## 5. 미결 — 사람이 정한다 (이것이 닫혀야 구현)

1. **심안의 행위는 무엇인가** — 관찰·흘리기 승리·조사? 등록부에 근거가 없다. 지어내지 않는다.
2. **문턱 N** — 과목별 "한 구간의 행위량". 제안 기준: 한 구간의 실시간 길이 동안 자연스러운
   전투/이동에서 나오는 양의 중앙값 (실측 후 제안치 제출).
3. **철거 범위** — 발판·명령을 완전히 걷는가, 뒷문(콘솔·관리자)으로 남기는가.
4. **입도진 수련 과제** — 새 문법을 나루에서 무엇으로 가르치는가 (행위 1구간 체험?).

## 6. 구현 순서 (미결 닫힌 뒤)

① 구간 마감 훅에 행위 계수기 (SkillListener·Gyeonggong 판정 지점에 계수 한 줄씩)
② 사사 근접 판정 + 효율 적용 ③ 일과 = 의뢰 접합 ④ 발판·명령·문구 정리
⑤ 눈: training_audit — 행위 없는 적립·상한 초과·이중 과금을 잡는다 (+ selftest)
