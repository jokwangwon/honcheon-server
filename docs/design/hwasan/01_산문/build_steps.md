## 재현 명령 (테스트 서버 · 25566 · RCON 25576)

    혼천 산세시험 hwasan          # ① 지형 — 골격·주상절리
    혼천 산군시험 hwasan          # ② 산군 — 대(臺) 실루엣
    혼천 캠퍼스시험 hwasan        # ③ 패드·계단·다리·구역 건물
    혼천 도면시험 hwasan_gate hwasan   # ④ 산문 — 이 도면

★**jar 과 도면 yml 은 짝으로 배포한다.** yml 만 넣으면 옛 jar 가 새 필드를 조용히
무시하고 틀린 것을 세운다.

★조성 순서가 곧 계약이다. 캠퍼스시험이 통짜 건물을 세우고 도면시험이 그 자리를
덮는다 — `BlueprintBuilder` 가 평면의 빈 칸(`.`)을 **비워야** 앞 건물이 안 남는다.
2026-08-05 에 이걸 안 비워서 세 회차를 오진했다 (「비운 켜」가 그 증거다:
산문 3,013 · 본전 6,353).

## 건물 한 채의 순서 (사용자 확정)

    기단 → 기둥 → 벽체 → 보 → 처마 → 지붕 → 문·창 → 난간 → 장식

도면 문법에서는 이 순서가 **`columns` 의 y 단면 순서**로 나타난다. 예를 들어 적주:

    "P": [smooth_stone,                 # 기단
          stripped_mangrove_log*6,      # 기둥
          stripped_mangrove_log,        # 보(도리)
          cut_sandstone]                # 단청 패널

한 칸의 아래→위가 곧 세우는 순서다. 지붕만 압출로 못 만들어 `roof` 절이
코드 문법(`sweepRoof`·`eaveRing`)을 부른다.
