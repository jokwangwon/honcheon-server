## ★왜 이 폴더가 여태 안 쓰였나

앞선 세션의 요약이 정본을 `mainhall_ref.png` 라는 <b>이름</b>으로 물려주었고,
나는 그 이름을 찾다가 「디스크에 없다」고 결론지었다. 정작 이 폴더는
<b>저장소 루트에 그대로 있었고 한 번도 열리지 않았다</b>.

그 결과 모든 회차의 측정이 「우리 렌더 <b>전 vs 후</b>」였다 —
<b>방향이 아니라 변화량</b>만 재고 있었던 것이다.
