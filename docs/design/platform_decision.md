# 플랫폼 결정 — 서버 버전 · 플러그인 vs 모드

> 질문: 서버 버전은 몇으로? 모드를 추가할 것인가, 혹은 모드를 직접 만들어 표현할 것인가?
> 결론 요약: **Paper 플러그인 + 서버 리소스팩 (바닐라 클라이언트 접속 가능), 대상 버전 1.21.4.**
> 자체 모드는 배제가 아니라 **후순위 '선택 설치 강화 옵션'**으로 남긴다.

---

## 1. 세 갈래 비교

| | ① 플러그인 (Paper) + 서버 리소스팩 | ② 기존 모드팩 조합 | ③ 자체 모드 제작 (Fabric/NeoForge) |
|---|---|---|---|
| 클라이언트 요구 | **없음 — 바닐라 정품 런처로 접속** (리소스팩은 접속 시 자동 적용) | 모드 설치 필수 | 모드 설치 필수 |
| 표현력 | 커스텀 아이템 모델·GUI 폰트·사운드·파티클 스킬 연출 (1.21.4 아이템 모델 컴포넌트로 크게 확장) | 남의 모드 기능에 종속 — 무협 전용 표현은 어차피 없음 | 최대 — 신규 블록(기와·처마), 커스텀 애니메이션, 자유 UI |
| 우리 시스템과의 궁합 | **핵심 시스템이 전부 서버 사이드** (방금 포팅한 룰 엔진) — 클라이언트 개조가 필요 없다 | 세계 반응 루프와 무관한 기능 뭉치 | 서버 로직은 동일하게 필요 — 모드는 표현 계층만 더해줌 |
| 개발·유지 비용 | 낮음 — Paper API 안정, 버전 갱신 용이 | 모드 간 호환성 지옥 | 높음 — 클라·서버 양쪽 개발, 버전마다 재작성 부담 |
| 신규 유저 진입 | **최저 마찰** — 주소만 치면 입장 | 런처 안내 필요 | 런처 안내 필요 |

## 2. 결정: ① 플러그인 + 서버 리소스팩

근거:

1. **이 게임의 정체성은 클라이언트가 아니라 서버에 있다.** 소문·세력 반응·지역 상태·기연·수련 — 차별점 전부가 백엔드 로직이고, 방금 core 룰 엔진으로 검증까지 끝났다. 모드가 필요한 건 '보이는 것'뿐이다.
2. 보이는 것의 대부분은 리소스팩으로 닿는다: 무기·의상 커스텀 모델, 스킬 이펙트(파티클+사운드), 커스텀 GUI(폰트 트릭), 경공(이동 속도·velocity 서버 제어). 기와지붕은 바닐라 블록 조합으로 — 맵 생성 파이프라인이 어차피 바닐라 블록 전제다.
3. 솔로 개발 + 커뮤니티 서버는 **진입 마찰이 생존 문제**다. "정품 런처로 주소만 치면 되는 무협 서버"가 强이다.
4. 모드 병행의 호환성·버전 추종 비용은 솔로 규모에서 치명적이다.

**자체 모드의 자리 (후순위)**: 서버가 자리 잡은 뒤, **없어도 접속 가능한 선택 설치 클라이언트 모드**(강화 이펙트, 전용 UI, 검격 애니메이션)로. 필수 모드는 끝까지 만들지 않는다 — 진입 마찰 원칙 유지.

## 3. 서버 버전: Paper 1.21.4

- **1.21.4 권장 근거**: 아이템 모델 컴포넌트 등 리소스팩 표현력이 크게 확장된 세대 + 주요 플러그인 생태계(Citizens, ProtocolLib, FAWE 등)가 안정 지원하는 구간. "최신"이 아니라 **"생태계가 무르익은 버전"**을 고른다.
- 현재 저장소의 빌드 파일은 1.20.4로 고정돼 있다 → 서버 모듈을 실제로 빌드하는 시점(로드맵 M2)에 1.21.4로 상향한다. core 룰 엔진은 MC 버전과 무관하므로 영향 없음.
- 운영 원칙: **버전을 고정하고 시즌 단위로만 상향 검토.** 신버전 추종은 콘텐츠 개발을 잡아먹는다.

## 4. 표현 계층 매핑 (플러그인+리소스팩으로 무엇이 되는가)

```text
무공 시전     스킬 4슬롯(핫바/단축), 파티클·사운드 연출, 쿨다운 아이콘(커스텀 폰트)
경공         이동 속도/velocity/Elytra-류 제어 — 서버 사이드로 충분
무기·복식     커스텀 아이템 모델 (문파별 검·도복)
판정의 가시화  액션바·타이틀 연출 ("한백이 눈을 피한다") — 수치 비노출 원칙 그대로
소문         NPC 잡담(대사 풀 재생), 객잔 채팅 브로드캐스트
NPC          Citizens류 + core 엔진의 기억 태그/의심도 연동
한계(모드 필요) 신규 블록 형태, 본격 검격 애니메이션 → 선택 모드의 몫으로 보류
```

## 5. 이 결정이 잠그는 것 / 잠그지 않는 것

```text
잠그는 것:   필수 클라이언트 개조 없음 (바닐라 접속 보장) — 이건 정체성으로 유지
잠그지 않는 것: 선택 설치 모드, 버전 상향, 리소스팩 고도화 — 전부 나중에 열 수 있다
```
