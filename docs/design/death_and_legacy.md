# 죽음과 유산 — 공유 세계에서 캐릭터가 끝나는 법 (G3 해소)

> 빈사까지만 있던 규칙의 완결: 사망 확정 파이프, 유산의 행방, 세계의 기억, 새 캐릭터.
> 원칙: **부활은 없다** (선천진기 소진 = 혼백 분리 — 세계관 정합). 대신 죽음에
> 이르는 길을 길게, 죽음 이후를 무겁고 의미 있게. 기계 판독용: `config/death_and_legacy.yml`

---

## 1. 죽음은 갑자기 오지 않는다 — 사망 확정 파이프

```text
패배 ≠ 죽음이 기본값이다 (NPC 전의 시스템의 대칭 — 플레이어도 항복·제압·강탈당한다):
  전투 패배 → 대부분 제압·강탈·중상 (상대에게 살인은 비싸다 — 소문·수배·세력 반응)
  살의 있는 상대(사선)만이 아래 파이프를 태운다

빈사 (내구 0 / 부상 3단) → 매 라운드 체력 판정 (비대립 12, 기존 규칙)
  실패 → '사망 위기' — 마지막 개입 창구 (1라운드):
    ① 회생 발동: 선천진기 10년 소모, 자동 통과 (기존 규칙 — 본인 의지 불요, 사전 선언제)
    ② 동행·NPC 구조: 지혈(의술 판정 어려움 14) 또는 전장 이탈
    ③ 상대의 선택: 숨통을 끊는 것도 '행동'이다 — 그 사이 세계가 개입할 수 있다
  개입 없음 → 사망 확정 (비가역)
```

## 2. 유산 — 죽은 자의 것은 세 갈래로 흩어진다

```text
현장의 것   전낭(소지금 전액)·착용 장비 = 그 자리에 드랍 — 줍는 자의 것 (economy 기존 규칙)
           애병은 남의 손에서 등급값 (약탈 메타 차단 기존 규칙이 여기서도 일한다)
맡긴 것     전장 예치금·부동산·보관품 = 상속 규칙:
           생전 지정 상속인 (동행·결의·NPC 관계 중 선언) > 혈연 NPC > 무주공산(세력 귀속)
           전표는 지참인 지불 — 시신에서 나온 전표는 주운 자의 것 (긴장 유지)
새긴 것     비급·수련 성과는 상속 불가 — 화후는 몸에 있다 (무경험치 설계 정합)
           단, 생전에 '남긴 것'은 예외: 직접 필사한 비급(하위 사본), 가르친 제자(사사 기록)
```

## 3. 세계의 기억 — 죽음은 기록이다

```text
소문      사망 = 강도 2 소문 자동 (사인·장소 포함 — 정확도 규칙 적용: 억울한 죽음은 왜곡된다)
명성      동결 — 별호는 역사가 된다 (세계 연표 기록, NPC가 회고 가능)
관계      NPC 기억 유지 — 은인의 죽음은 favor를 유족·제자에게 일부 승계 (개입 기록의 상속)
원한      살해자에게 이관 — 피살자의 마크·기록은 '피의 장부'로: 유족 NPC·새 캐릭터의 복수 훅
미해결 훅  개인 스레드의 떡밥은 세계 스레드로 이관 — 죽음이 이야기를 죽이지 않는다
수배      살인의 대가: 목격·시신 경유로 관아 수배·현상금 (경제 현상금 표 연동) — 세계가 청구
```

## 4. 새 캐릭터 — 같은 세계, 새 인생

```text
재생성: 즉시 가능, 쿨다운 없음 — 죽음이 이미 충분히 비싸다 (유년/소년 시작 규칙 그대로)
계승 선택 (생성 시 1택):
  혈연 시작   전 캐릭터의 유족·제자로 시작 — 상속분 접근 + 피의 장부(원한)도 상속
             집안 = '몰락 무가의 자식' 문법 재사용 (물려받은 것 = 유산 일부)
  무관 시작   완전한 백지 — 전 캐릭터와 접점 없음
이전 금지: 화후·마크·favor·경지 — 몸에 새긴 것은 무덤까지 (계정 귀속 아님, 캐릭터 귀속)
세계 정원: 사망 슬롯은 즉시 반환 (120명 상한 정합)
```

## 5. MC 절차 — 다운·이송·기상 (리스폰이 아니라 이송이다)

바닐라 사망 화면은 **거의 등장하지 않는다** — 내구 0은 즉사가 아니라 다운이다:

```text
① 다운 (내구 0)   체력 1 고정 + 엎드림 포즈 + 이동 속도 최저(기어가기만) + 시야 암전 연출
                 사망 위기 타이머 시작: 90초 (텍스트 '매 라운드 체력 판정'의 실시간 환산)
                 회생 사전 선언자는 여기서 자동 발동 (수명 10년 — 타이머 리셋 + 기력 회복)
② 개입 창구       동행/행인: 지혈 (우클릭 유지 3초 — 의술 판정, 성공 시 타이머 정지 '안정')
                 부축: 안정 상태의 다운자를 우클릭 = 들쳐업기 (업은 자는 속도 -30%, 전투 불가)
                 적: 강탈 (인벤토리 열람 — 전낭·장비) / 확인 사살 (별도 3초 시전 — '행동'이다:
                 그 3초가 세계의 개입 창구. 목격 시 살인 소문·수배는 기존 규칙)
③ 방치된 다운자    타이머 만료 전 목격 NPC 판정 (일과 시스템): 마을 안 = 순찰·행인이 의방으로
                 이송 (치안·민심 연동 — 치안 낮으면 아무도 안 옮긴다, 대신 털린다)
                 야외 = 2차 조우 판정 (야수·도적 — 산길의 다운은 진짜 위험하다)
④ 기상           의방 침상에서 깨어난다 — 중상 상태 + 의원비 외상 장부 (빚으로 기록,
                 economy 의원 표 — 못 갚으면 유문의 '일손' 의뢰가 태어난다)
                 강탈당한 자는 그 자리 또는 근처 헛간에서 — 전낭은 이미 없다
⑤ 진짜 사망       타이머 만료 + 무개입, 또는 확인 사살 완료 = 사망 확정 (비가역)
                 그 자리에 전낭·장비 드랍 → 짧은 관전 시점 (자기 시신과 현장을 본다 —
                 죽음의 무게 연출) → 생성 로비로 (새 캐릭터 — 혈연/무관 선택)
                 바닐라 리스폰 지점·침대 리스폰은 사용하지 않는다 (부활 없음 원칙)
```

**"의학당 소환"이 아닌 이유**: 부활·소환은 혼백 분리 세계관과 충돌한다. 대신 **이송**은
세계가 하는 일이다 — 누가 옮겨주느냐(동행·행인·순찰)가 치안·민심·관계의 함수이므로,
쓰러지는 위치 선택부터가 플레이가 된다 (마을 앞에서 지는 것과 산속에서 지는 것은 다르다).

## 6. 밸런스 — 죽음의 빈도 통제

```text
죽음이 흔하면 유산 규칙이 세계를 어지럽히고, 없으면 사선 마크가 가짜가 된다. 통제 3겹:
① 패배의 기본값 = 제압·강탈 (살의는 사선 조우·처형·복수 등 서사적 상황에 한정)
② 회생 = 전원 1회의 보험 (수명 10년 — 쓰고 나면 다음 사선이 진짜가 된다)
③ 관측: 시즌당 사망률을 이벤트 로그로 집계 (G10 장기 시뮬 입력) — 과도하면 사망 위기
   개입 창구를 2라운드로 완화, 과소하면 유지
```
