# 크기의 자(尺) — 장소의 성격마다 다른 자로 잰다

> **출처: 사용자가 직접 결정했다 (2026-07-13).** 추측이 아니다.
> 이 문서는 `config/world_map.yml §17` 의 해석을 **정정한다.**

## ★ §17 의 오독을 바로잡는다

> *"크기는 영향력의 함수다"* 에서 말하는 **영향력은 모든 장소에 동일한 수치를 강제하는 것이 아니라,
> **장소의 성격에 맞는 영향력**을 뜻하는 것으로 해석한다.*

**하나의 자를 온 세계에 들이대지 않는다.** 상인의 도시를 무력으로 재면 **성곽 도시가 오두막이 된다.**

| 장소의 성격 | 무엇으로 재는가 |
|---|---|
| **무림 문파** | 무력 · 문파 영향력 (`martial + mandate_weight`) |
| **관부(官)** | 행정 위계와 방어 기능 (`rank` — 이미 `pinned_by_archetype`) |
| **상업 거점** | **상업 영향력** (아래 신설) |
| **새외 도시** | 도시 기능과 교역·군사적 위상 |

## 상업 거점 — 「상업 영향력 척도」

### 왜 `roster` 에 안 넣는가
`상단연합` 은 **무림 문파도 정치 세력도 아니다.** 그러므로:
- **`roster` 에 추가하지 않는다**
- **`martial` · `mandate_weight` 를 임의로 부여하지 않는다**
- 기존 세력 관계표에도 포함하지 않는다

### 크기를 정하는 세 요소
`tier` 하나로 정하지 않는다 (네 곳이 모두 `rich` 라 변별력이 없다).

1. **`wealth_tier`** — 지역에 축적된 부와 시장 규모
2. **`route_centrality`** — 교역로가 몇 갈래로 연결되는지. 중원↔서역, 항구↔내륙을 잇는 정도
3. **`settlement_role`** — 객잔·역참 수준인가 / 정기 시장인가 / 지역 상업도시인가 / 대륙 규모 교역 중심지인가

### 상업 등급 (`commercial_class`)
**도시마다 새 숫자를 지어내지 않는다.** 위 세 요소로 아래 등급을 **판정**한다.

| 등급 | 무엇인가 |
|---|---|
| **`commercial_outpost`** | 소규모 교역소·대상 숙영지. 건물 수는 적지만 **창고와 마구간 비중이 높다** |
| **`market_town`** | 지역 정기시장과 상단 지점이 형성된 시장도시. 상점가와 주거지가 함께 |
| **`trade_city`** | 여러 교역로가 만나는 상업도시. **객잔·창고·환전소·표국·상단 회관**이 구역을 이룬다 |
| **`grand_trade_hub`** | 중원 또는 서역 전체에 영향을 주는 대형 교역 중심지. **복수 시장·대상 집결지·대형 창고지구·외지인 거류지** |

## ★ 크기와 형태를 분리한다

```
도시 크기 = 상업 등급 (commercial_class)
도시 형태 = 건축 원형 (archetype)
```

최종 **반경은 상업 등급이 결정**하고, **건축 원형은 그 반경 안의 내부 구성**을 결정한다.

## 등록부에 추가할 필드
```yaml
scale_system: commercial     # 이 곳은 어느 자로 재는가
commercial_class:            # outpost | market_town | trade_city | grand_trade_hub | unresolved
wealth_tier:
route_centrality:
settlement_role:
```
**`martial` 과 `mandate_weight` 는 추가하지 않는다.**

## ★ 모르는 것은 모른다고 적는다
> *"아직 각 도시의 교역로와 역할에 관한 **근거가 없는 경우에는 세부 숫자를 지어내지 않는다.**
> 지도나 등록부에 **명시된 기능만으로** 상업 등급을 판정하고,
> **근거가 부족한 장소는 `commercial_class: unresolved` 로 남긴다.**"*

**이것이 이 문서의 가장 중요한 조항이다.** 지금까지 린트는 미결을 **채우라고 짖기만** 했고, 채우려면 **지어내야** 했다. 이제 **"모른다"고 적을 수 있는 칸**이 있다. `unresolved` 는 **실패가 아니라 정직**이다.

## 적용 범위
- **상단의 도시 4곳**: 태원 · 무한 · 소주 · 강남 상로
- **상업 성격의 서역 거점 2곳**: 고창 · 돈황
