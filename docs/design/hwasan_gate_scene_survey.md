## 0. 계측의 자 — 블록 = 화면 18px

- 계단 디딤 주기 자기상관: **18~19 px** (x 700·740·780 대역에서 일관)
- 문루 하층 적주 폭 육안: **~17 px**
- 석전 블록 면 육안: **~18 px**
- → **1 블록 ≈ 18 px** 로 확정. 단 이 자는 **카메라를 마주보는 면**(문루 정면·계단)에만 유효하고,
  깊이(z) 방향은 부감각 때문에 더 짧게 맺힌다.
- ⚠ 자기상관이 6~8px 주기를 자주 잡는데 이는 **석전 텍스처의 벽돌 눈금**(블록의 1/2~1/3)이지
  블록 격자가 아니다 — 이걸 블록으로 오인하면 척도가 2~3배 틀어진다.

2. **중앙 개구 — 우리 11×12 vs 목표 5×(6~7) (약 2배)**
   목표의 문은 사람 둘이 나란히 지나는 크기이고, 우리 것은 수레가 지나는 크기다.

   ★슬라이스 8 에서 「대계단 20」을 사용자 기준자로 삼았는데, 이번 실측은 **보행 11 + 난간
   2+2 = 총 15**로 나왔다. 「20」이 무엇을 잰 값이었는지 **사용자 확인이 필요하다** —
   보행 폭인지, 난간 포함 총폭인지, 또는 더 아래 넓은 구간을 잰 것인지.
