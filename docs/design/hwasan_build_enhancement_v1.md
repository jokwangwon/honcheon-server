## 1. 레퍼런스에서 추출한 설계 문법

12장을 관통하는 문법 여섯:

1. **석축 테라스 단(段)식 배치** — 모든 건물은 절벽을 깎은 게 아니라 **쌓은 석축 위**에 선다.
   옹벽(retaining wall) 높이 4~12칸, 상단에 난간/여장. 단과 단은 대계단·협계단으로 잇는다.
   → **이것이 B-146(건물이 뜬다)의 구조적 처방이다.** 테라스가 먼저 서면 건물은 뜰 자리가 없다.
2. **하나의 중심축** — 산길 대계단(깃발·석등 열주) → 산문(문루) → 의식 광장 → 연무장 →
   본전. 축선 위에서 항상 「다음 단」이 올려다보인다 (이미지 1·2·6·7).
3. **재료 삼색** — 회백 석재(몸체·석축) + 백벽·적목(건물) + 흑기와(지붕). 금 현판·온광 등롱이 점정.
   사용자 블록 표(캠퍼스 문서)와 일치 — 그대로 쓴다.
4. **매화가 점을 찍는다** — 군락이 아니라 단마다 1~3그루가 자리를 잡는다 (이미지 1·2·6·7).
   매화림(군락)은 본산 밖 영역 설계(영역 문서 §4)의 몫.
5. **절벽 끝의 실루엣** — 3층 망루 전각(이미지 9)·정상 사당+정자(이미지 10)·절벽 정자(이미지 8).
   본산의 스카이라인을 만드는 원경 요소.
6. **생활감** — 창고 상자·깃발 건조대·밭·마구간·연못 정원 (이미지 4·5). 「궁전」이 아니라 「사는 곳」.

이미지별 대응은 §5 표에 있다.

## 2-b. 기존 산세 문법과의 대조 — 무엇을 지키고 무엇을 고치는가

사용자 물음 「기존 문법이 이를 해친다면 수정 필요」의 답:

**지킨다 — 골격은 이 그림과 싸우지 않는다.**
- `RangeSpec.hwasan` 의 골격-먼저 C 파이프라인(사용자가 A/B/C 실루엣에서 확정): 주봉 Pm(북·최고)
  + 서봉 Wm + 동봉 Em·Es + 남 전초봉 O + 협곡 2줄. **남→북으로 오르는 척추**가 마스터플랜의
  축과 같은 결이고, **곁봉 Em·Es(동) / Wm(서)** 가 19·20(동편 곁봉 건축)과 18(서편 다리)의
  자리를 이미 갖고 있다.
- H-6·H-7 확정값(honsanR 124·midDepth 140 등)도 그대로 — 캠퍼스는 본산권 안에 선다.

**고친다·새로 짓는다 — 골격 위에 없는 네 가지.**
1. **척추 테라스**: 단(段) 조성 기계 (TerraceForge — 슬라이스 1 진행 중). 골격은 능선만 주고
   단은 안 준다 — B-146(건물이 뜬다)의 뿌리.
2. **곁봉 정상 패드**: Peak 레코드에는 평탄부가 없다 (정상 평탄부는 주봉 전용 반경 10).
   19·20 이 앉으려면 곁봉에 소형 패드(반경 5~8)를 깎는 기계가 필요하다.
3. **운무교**: 협곡·골을 건너는 다리 기계가 없다 (현공교 — 사용자 영역 문서 랜드마크 표에
   이미 「절벽을 잇는 현공교」가 있다). 목교+석교 혼합, 난간·등롱.
4. **절벽 결 연출**: 마스터플랜·렌더의 세로 결(주상절리 띠)·바위턱 소나무·운해는 골격이 아니라
   **표면 연출**이다 — FloraForge/표면 띠 기계의 확장 (조경 패스).

## 3. 기계 【제안】 — 석축 테라스 조성기 (B-146 의 처방)

새 조각 `TerraceForge` (forge/ 패키지):

1. **단 판독**: 앵커·축선 방위·단 표를 받아 각 단의 평탄 폴리곤을 지형 위에 잡는다
   (기존 지형 스캔 → 「깎기 최소·쌓기 우선」 — 사용자: 산이 먼저, 건물이 적응).
2. **옹벽 세우기**: 단 가장자리에서 아래 지형까지 석축(stone brick·andesite 층결)을 내린다.
   상단 여장(담)·배수구 멋내기. **옹벽 아래가 허공이면 그것이 곧 검수 위반** — 「뜬 건물」이
   구조적으로 불가능해진다.
3. **단 잇기**: 대계단(축선)·협계단(단 내부)·잔도(절벽 우회) — 기존 TrailForge/천계단 재사용.
4. **검수 눈**: 조성 후 ①단 위 건물 기초 접지 100% ②옹벽 하단 접지 100% ③축선 보행 도달
   (기존 「걸어 닿은 칸」 검수 재사용 — 화산이 y78 에서 막혔던 그 눈). self-test 동반 (계율).

건물 자체는 기존 SectBuilder 부품(plasterHall·tiledRoof·mountainGate·pagoda·woodenDummy 등)을
재사용하되, 도관 원형을 「본전 한 채」에서 「20구역 표」로 확장한다.

## 6. 미결 【사용자 결정 대기】

1. **build_radius 64 → 128**: 등록부는 64 (「이미 선 땅은 안 흔들린다」). 캠퍼스 판정과 B-148 의
   128 배정 후보를 따르면 등록부 개정이 필요하다. — 개정할가?
2. **절벽 망루(이미지 9)·정상 사당(이미지 10) 채택 여부** — 랜드마크 표(영역 문서)의
   봉수대/망루·수행대와 맞물린다.
3. **폭포 수계(이미지 8)** — 본산 단에 물을 끌어올릴가, 계곡(영역 §5)으로 미룰가.
4. **본세계 재조성 시점** — 시험 월드 확정 후 기존 화산(본전 한 채)을 헐고 다시 세우는 회차.
