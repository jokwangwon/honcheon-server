# 성장 v3 — 체감 설계 (플레이어가 성장을 어디서 어떻게 느끼나)

> 2026-07-23 사용자와 함께 설계. `growth_v3_impl_plan.md`(배선 순서)의 **위층** — 무엇을
> 만드느냐가 아니라 **성장이 어떤 감각으로 오느냐**를 정한다. 저울(B-137)·헌법
> (cultivation_v3_levels.md)은 확정 전제. 이 문서의 결정은 구현 계획 단계 4·5의 정본이 된다.

---

## 1. ★ 두 개의 성장 속도 (핵심 구조 — 사용자 확정)

성장의 "큰 순간" 예산을 **드문 승급에 몰고**, 잦은 레벨업은 조용히 둔다. 무협의 리듬
("매일 조금씩 강해지다 어느 날 벽을 깬다")이 그대로 나온다.

| | **레벨업** (잦음 · 100번+/커리어) | **승급/경지** (드묾 · ~7번) |
|---|---|---|
| 방식 | **조용히 스며든다** (알림만) | **터진다 · 기념한다** |
| 체감 | 몸이 바뀐다 (아래 §2) | **연출 + 칭호** (아래 §3·§4) |
| 서사 | 수련의 나날 | 깨달음의 장면 |

- 레벨업은 **화면 연출 없음** — 조용한 알림. 강해졌다는 건 플레이가 말한다.
- 승급은 **연출 + 칭호** 둘 다 (경지 칭호: 삼류무사 → 일류고수 → 절정 …).

## 2. 몸으로 느끼는 성장 (레벨업의 체감 — 사용자 확정)

숫자판이 아니라 **손에 잡히는 변화**로 성장을 본다:

| 체감 | 무엇이 커지나 | 구현 접점 (이미 있음) |
|---|---|---|
| 더 아프게 때린다 | **대미지 숫자↑** | HitFeedback (2026-07-23 완료) |
| 더 튼튼하다 | **HP·내력바의 숫자↑** | Vitality · internal_energy (√원장 파생) |
| 더 멀리 난다 | **경공이 멀리** (이속비례) | gyeonggong.yml 이속/도약 = 민첩실수×계수 |
| 새 길이 열린다 | **무공이 열린다** | (문턱 설계 — §5 미결) |

→ 구현 계획 **단계 3(파생치 √원장)** 이 이 체감의 대부분을 자동으로 낳는다.
   능력치가 오르면 바·숫자·도약이 **저절로** 커진다 (별도 연출 코드 없이).

## 3. 칭호(稱號) 시스템 — 새 시스템 (사용자 확정)

기억에 남는 장면을 **영구 정체성**으로 새기는 층.

### 3.1 힘의 흐름 — ★세계-반응으로만 (헌법 유지 · 사용자 확정)
칭호는 **순수 전투 능력치를 주지 않는다** ("명성은 세계의 반응이지 성장 재료가 아니다"
보존 · 판정 공식 무변경 · 하네스 유효). 대신 위엄이 세 갈래 **세계 반응**으로 온다:

| 효과 | 어디로 | 예 |
|---|---|---|
| **위세** — 적이 위축됨 | 기존 npc_combat `morale.상대_위세` | 무림맹주 앞 졸개 전의 붕괴 |
| **경제** — 값을 깎고 얻는다 | 사회·경제 스탯 | 매화검의 이름값으로 흥정 |
| **친화** — 청이 통한다 | favor·세력 반응 | 산채 정리자에게 관군이 호의 |

→ "매화검을 달면 강해진 느낌"은 완벽히 나되(세상이 널 대하는 게 달라짐), 네 팔뚝(execBase)은
   불변. 검성의 힘은 근력이 아니라 그 이름이 주는 위압이다.

### 3.2 보임과 선택 (사용자 확정)
- **남도 본다** — 머리 위 명패에 칭호 (HitFeedback 명패 시스템에 얹음). "명호가 사람보다 먼저 온다."
- **본인이 고른다** — 여러 칭호 중 **달 것 하나를 선택** (정체성 표현). 한월식.

### 3.3 출처 — 다 열되 퀘스트·소문 집중 (사용자 확정)
- 승급 자동 (경지 칭호)
- 사건 마크 ("생사의 문턱을 넘은 자")
- 숨은 위업
- **★집중: 퀘스트 → 소문 연계 칭호** — 매화검 · 무림맹주 · 산채를 정리한 자.
  퀘스트 완수 → 소문 발생 → 칭호 획득이 **한 삼각형**으로 돈다 (기존 소문 시스템과 한 몸).

### 3.4 중첩 상한 — ★없음 (보유 시 전부 적용 · 사용자 확정)
칭호를 많이 모을수록 그만큼 대단한 사람이다 — 칭호 하나 더 낀다고 다른 칭호 위력이 줄면 안 된다.
**보유한 모든 칭호가 동시 적용된다.** 무제한 중첩이 안전한 이유는 §3.1 세계-반응 라우팅이다:
위세(경지 격차 큰 상대는 안 밀림)·경제(값 바닥 있음)·친화(favor 상한)가 **각자 천장을 가져
스스로 자기 제한**한다. 전설이 잡졸을 확실히 위압하되 진짜 고수는 안 밀린다 — 자연 균형.
구현 못: 칭호당 효과는 **작게**(누적을 천천히 체감) · 고경지 위세 저항 유지.

## 4. 승급 — 경지가 바뀌는 순간 (사용자 확정: 연출 + 칭호)
레벨업과 다른 무게. **연출**(Title+버스트류)로 표현하고 **경지 칭호**를 준다. 커리어에 ~7번뿐이라
매번 특별해도 싸구려가 안 된다.

## 5. 포인트 — 선택의 무게 + 기연 초기화 (사용자 확정)
- 매 레벨 3포인트 = **빌드의 정체성.** 신중히 고른다 (가볍게 툭툭 아님).
- **초기화는 기연(奇緣)으로만** — 상점 리스펙 아님. 비급·고인의 가르침·영약·퀘스트 같은
  **하나의 사건**으로 환골탈태. 초기화 자체가 기억에 남는 콘텐츠가 된다.

### 5.1 ★ 무공 문턱 = 벽이 아니라 대가 곡선 (사용자 확정 · 핵심 설계)

**B안 확정: 능력치가 무공 길을 연다** — 내공 몰빵 → 내공 무공, 민첩 몰빵 → 속검. 포인트가
숫자가 아니라 **갈 수 있는 길**을 정한다 (그래서 신중히 고르고, 그래서 기연 초기화가 의미심장).

**문턱은 잠그지 않는다 — 미달이면 대가를 물고 억지로 쓴다** (초기화 = ①유지의 진화형).
무협의 "경지 넘어 억지로 펼치면 몸이 상한다"를 그대로. 무공 종류마다 미달 대가가 다르다:

| 무공형 | 문턱 능력치 | 미달 시 억지 사용의 대가 |
|---|---|---|
| 내공형 | 내공 | **선천진기(수명)를 태워 쓴다** — 내력 대신 체력/수명 소모 (internal_energy 선천진기·연수 문법 재사용) |
| 콤보/연계기 | (해당 축) | **끝까지 안 나간다** — 5타 초식이 3타에서 끊김 (단계 상한 = f(능력치)) |
| 속검/민첩형 | 민첩 | 회복 길어짐 · 연계 불가 |
| 위력형 | 근력 | 위력 감소 · 자기 반동 |
| 오의/절기 | (해당 축) | 완성 실패 · **주화입마 판정 위험** (qi_deviation 재사용) |

- **초기화(기연)는 무공을 안 잠근다** — 능력치만 되돌린다. 옛 길 무공은 남되, 문턱 미달이면
  위 대가를 물고 써야 한다. 환골탈태로 길을 갈아타면 옛 절기는 "억지로만" 나온다 — 되돌릴 여지 O.
- **이미 있는 정본과 접합**: 선천진기·원기·후천진기 삼원(internal_energy.yml) · 주화입마·
  qi_deviation · 연수(수명 연소) — **새 개념 0, 배선만.**
- 구현: 각 무공이 config 에  +  을 등재 (simbeop.yml/skill_mechanics.yml).

**이로써 성장 v3 체감 설계의 미결이 전부 닫혔다.** 구현(B-135·B-176) 착수 가능.
