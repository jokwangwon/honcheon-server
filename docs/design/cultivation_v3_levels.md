## 0. 네 기둥 (사용자 결정 2026-07-15 — 전부 확정)

| ② | **포인트 → 능력치 7종** | 근력·민첩·체력·내공·감각·화술·지혜 (judgment.yml attributes 그대로) |

한 문장의 계약: **"스탯은 레벨업에서 찍고, 기술은 써야 는다."**

## 1. 경험 층 (신설)

- **원천**: 몬스터 처치 (사냥 등록부의 기존 등급이 XP 눈금의 뼈대) · 의뢰 완수 ·
  일과(B-134 디제시스 — 스승·문파 일과는 XP **보너스**로 편입).
- **레벨업**: 경험이 곡선을 넘으면 레벨 +1 → **스탯 포인트 P 지급** → 능력치 7종에 찍는다.
- **찍은 능력치는 판정 공식에 그대로** (judgment.yml: 실행력 = 능력치 + 기술 + 보정 + 2d6) —
  새 공식 없음.
- **곡선의 산출 (★사용자 확정 2026-07-15)**: 수치를 손으로 짓지 않는다 — **플레이 시간대별
  데이터를 분석해 XP/시간 율을 재고, 경지별 목표 도달 시간에서 곡선·자격 레벨을 역산한다.**
  절차: ① XP 원천 배선에 계측을 함께 심는다 (세션별 획득량·시간) ② 모델 도구
  `tools/xp_pacing.py` 【신설 예정】 — 입력: 실측 XP/시간 + 목표 도달 시간 H_k, 출력: 곡선·N_k
  제안표 ③ 목표 도달 시간 H_k 와 산출표는 **사용자가 승인**한다. 실측 전 초기값은
  기존 사냥·의뢰 등급 눈금에서 유도한 제안치로 시작하고, 데이터가 쌓이면 재보정한다.
- **죽음 (★사용자 확정 2026-07-15)**: **레벨 처분 없음** — 죽음의 대가는 의학당 부활의
  이동시간과 시간이다 (B-111 의 "항상 부활" 계약과 정합. 레벨·경험은 유산 목록 무관).

## 2. 경지 층 (유지 — 관문만 이중)

경지 9단계·이름·순서 불변 (cultivation_stages). 승급 = **레벨 자격 N_k 【미결 ①】 도달 +
기존 사건 마크** (기연·사선·실전 — battle_marks 불변). 레벨 노가다만으로 경지를 못 사고,
사건만으로도 못 오른다 — 숫자와 서사의 이중 관문 (사용자 결정 ①).

## 3. 행위 층 (B-134 — 대상 한정)

`docs/design/training_by_doing.md` 의 문법(행위 → 적립 · 스승·일과 디제시스)은 그대로 살되,
**쌓이는 곳이 기술·화후(숙련)로 한정된다** — 검을 쓴 손은 검술이, 숨은 발은 은신이 는다
(judgment.yml skills · combat_accrual 결). **능력치에는 한 톨도 안 쌓인다** — 그 선을
눈(audit)이 지킨다. B-134 미결 중 "문턱 N"은 남고, "하루 5구간"은 ④로 소멸.

### 4-b. 바닐라 XP바 — 표시 계약 (★사용자 확정 · 캐비앳 둘)

레벨 숫자·게이지는 서버가 원장에서 계산해 그린다 (`setLevel`/`setExp` — 표시 전용이라
"레벨당 경험치량 조절"은 바닐라 제약 없이 자유다). 디자인 개선은 사용자가 리소스팩으로.

- **캐비앳 ① — 바에는 이미 주인이 있다**: 현행 `SkillHud.energyBar` 가 레벨 숫자 = 내공
  화후 단계, 게이지 = 내력으로 쓴다. 【제안】 바를 v3 경험/레벨에 내주고 — 내력은 액션바
  energySeg 에 이미 있으므로 중복 해소가 되고, 내공 화후 단계는 시트(`/혼천 시트`) + 변동
  플래시로 옮긴다. (한 줄의 주인 원칙 — B-116 과 같은 결)
- **캐비앳 ② — 바닐라 XP 경제와의 절연**: 몹 오브·화로 경험이 진짜 레벨을 흔들면 원장이
  둘이 된다 — 오브 획득은 흡수(0)하거나 v3 XP 로 환수하고, 레벨 소비처(모루·인챈트대)의
  처분을 정해야 한다 【미결 ④′】.

## 5. 미결 — 사람이 정한다 (수치는 지어내지 않는다)

1. ~~경지별 자격 레벨 N_k~~ → **방법 확정**: 페이싱 모델 산출 + 사용자 승인 (§1). 남은 것:
   **목표 도달 시간 H_k** (경지별 예상 플레이 시간) 승인.
2. **XP 곡선의 꼴** (선형/지수·만렙 유무 — 모델의 입력) · **레벨당 포인트 P**.
3. **원천별 XP 값** — 몬스터 등급별·의뢰 난이도별 초기 제안치 (기존 등급 눈금에서 유도 —
   조율자가 제안, 사람이 승인. 실측 후 재보정).
4. ~~MC 인지~~ → **바닐라 XP바 확정** (§4-b). 남은 것 ④′: 오브 환수/흡수 · 모루·인챈트대 처분 ·
   내공 단계 표시의 이사처 (§4-b 제안 승인 여부).
5. ~~죽음과 레벨~~ → **확정: 처분 없음** (§1 — 대가는 의학당 부활의 이동시간·시간).
6. **사선 보너스 귀속** — 배분표 소멸 후 사선_경험이 어디로 가는가 (XP 보너스로 흡수?).
7. B-134 잔여 미결: 기술 문턱 N · 심안의 행위 · 발판/명령 철거 범위 · 나루의 가르침.
