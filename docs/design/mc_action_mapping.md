# MC 행동 구현 전수 매핑 — 모든 행동을 바닐라 입력으로

> 요구: 실시간은 마인크래프트로 구현 가능해야 한다 — **모든 행동**의 구현 구상.
> 제약: 바닐라 클라이언트 (필수 모드 금지 — platform_decision). 입력 예산이 좁다:
> 좌클릭 / 우클릭 / Shift / F(스왑) / Q(버리기) / 핫바 1~9 / 점프 / 이동.
> 원칙: 서버 권위 — 모든 판정·게이지는 서버 산수 (<1ms), 클라이언트는 입력과 연출만.

---

## 1. 입력 매핑 (전역)

| 입력 | 평시 | 전투·긴장 시 |
|---|---|---|
| 좌클릭 | 상호작용 공격 | **공격/콤보** (육합검 3타 = 연속 좌클릭 체인) |
| 우클릭 (무기 들고) | 오브젝트 상호작용 | **가드** (유지) / **패링** (가드 시작 4틱 창) |
| Shift 탭 + 방향 | — | **회피** (스텝 3m, 무적 4틱, 충전 2) |
| Shift 유지 | **은신 모드** (감지 게이지 활성) | 동일 |
| Shift 유지 + 정지 3초 | **운기조식 진입** (채널링) | 불가 (전투 중 회복 불가 규칙) |
| F (스왑) | 도구/무기 전환 | **오의** (발동권 획득 시에만 활성 — 획득 순간 연출로 고지) |
| Q (버리기) | 아이템 버리기 | 재정의 없음 (오입력 방지) |
| 핫바 1~2 | 무기/도구 | 무기 |
| 핫바 3~5 | 소모품(음식·약) | 동일 |
| 핫바 6~9 | **스킬 4슬롯** (우클릭 시전, 쿨다운 표시) | 동일 |
| 점프 (달리며 연속) | **경공 모드** (내력 소모 이동 — 이속·도약 강화) | 경공 이탈 (무적 없음) |

## 2. HUD 매핑 — 바닐라 UI의 재해석 (커스텀 클라 없이)

| 바닐라 UI | 재해석 | 근거 |
|---|---|---|
| 하트 (HP) | **내구** (10+체력×2 스케일링) | 부상 3단계는 하트 색/흔들림 |
| 허기 바 | **원기** — 음식·수면으로 회복되는 생명력과 정합 (허기 시스템 오버라이드) | 쇠약 구간 = 이동 페널티 자연 재현 |
| 경험치 바 | **내력** (숫자 = 내공 화후 단계) | 시전마다 즉각 피드백 |
| 액션바 | 시간 구간(새벽~밤)·날짜, 상태 한 줄 ("피로하다") | 수치 비노출 — 서사어만 |
| 보스바 | **감지 게이지** (은신 모드 중에만 표시) | 잠입 긴장의 시각화 |
| 아이템 쿨다운 | 스킬 쿨다운 | 바닐라 기본 |
| 발광 효과 | 조사 하이라이트 (감각 수치별 반경) | 감각 성장 체감 |
| 채팅 | 대화·소문·서사 채널 (클릭 컴포넌트 = 선택지) | 텍스트 자산 재사용 |

## 3. 행동 전수표

### A. 판정 행동 12종 (judgment.yml action_pairs 전량)

| 행동 | 조작 | 서버 처리 | 연출 |
|---|---|---|---|
| 은신/잠복 | Shift 유지 | 시야각·거리·광량·소음 → **감지 게이지** 누적, 임계 시 1회 판정 | 보스바 게이지, NPC 머리 위 ?→! |
| 미행 | Shift 이동 + 대상 추적 | 적정 거리 밴드 유지 검사 (가까움/노출 = 게이지 가속) | 대상 발자국 파티클 (추적 기술 보유 시) |
| 설득/교섭 | NPC 우클릭 → 대화 | 채팅 클릭 선택지 → 선택 순간 숨은 판정 | NPC 자세·대사 변화 |
| 정보 캐기 | 대화 내 [떠보기] 선택지 | 동일 + 실패 시 NPC 의심도 기록 | 눈빛 연출 대사 |
| 증거 제시 설득 | 대화 GUI에 **단서 아이템 첨부** (인벤토리 '단서' 항목) | 정보량 보정 자동 가산 | 단서 명세 툴팁 |
| 잠입 | 은신 + 문/창 우클릭 | 감지 게이지 + 진입 판정 1회 | 자물쇠 소리, 실패 시 소음 이벤트 |
| 엿듣기 | 은신 상태로 가청 반경(8m) 진입 | 접근 시 판정 1회 → 성공 시 대화 채팅 스트림 수신 | 대화 텍스트가 흐릿→선명 |
| 기습 | 은신 상태 첫 공격 | 기습 판정 → 성공 시 선공+방어측 −2 (combat) | 급소 타격 연출 |
| 추적 | 흔적 오브젝트 우클릭 연쇄 | 감각+추적 수치별 흔적 표시 반경·지속 | 발자국·핏자국 발광 |
| 도주 | 경공 모드 + 시야 이탈 | 거리+차폐 유지 시간 → 이탈 판정 | 추격자 포기 대사 |
| 치료 | 의술 도구 들고 대상 우클릭 (채널링 3초) | 지혜+의술 판정, 재료 소모 | 붕대 감기 자세 |
| 조사 | 오브젝트 우클릭 / 접근 | 감각별 하이라이트 + 상세 판정 | 발광 + 채팅 단서 카드 |

### B. 전투 (skill_mechanics 기확정 + 조작 확정)

| 행동 | 조작 | 비고 |
|---|---|---|
| 기본 공격/콤보 | 좌클릭 연쇄 (입력 유예 10틱) | 프레임 데이터 그대로 |
| 스킬 시전 | 핫바 6~9 우클릭 | 8단계 파이프라인 경유 (성능 문서) |
| 가드/패링 | 우클릭 유지 / 시작 4틱 | 패링 성공 = 반격창 + '흐름' 적립 |
| 회피 | Shift 탭+방향 | 충전 UI = 갑옷 칸 아이콘 |
| 잡기(파격) | 스킬 슬롯 배정 | 근접 1.5m 지향 |
| 오의 | F (발동권 시에만 활성) | 시전 확인 불필요 — 발동권 자체가 게이트. 격돌 = 쌍방 F 동시 |
| 연혼일격/회생 | 사망 직전·오의 강화 시 **채팅 확인 버튼** | 수명 연소 확인 대화 — 유일한 수치 노출 예외 |
| 경직/다운 | (피격) 입력 무시 + 시점 흔들림 + Slowness | 기상 무적 3틱 |

### C. 내공·심법

| 행동 | 조작 | 서버 처리 |
|---|---|---|
| 운기조식 | Shift 정지 3초 → 채널링 (이동 시 취소) | 구간당 내공×1 회복, 심법 색 파티클 회전 (은밀 운기 토글: 회복 −20%) |
| 축기/수련 선언 | 침상·방석·수련장 우클릭 → 메뉴 | 수련 상태 진입 (오프라인 정산 — training.yml) |
| 경락도 | 핫바 9 지도 아이템 우클릭 | 단전 게이지 + 혈도 점등 GUI |
| 배독/억제 | 상태 이상 시 운기조식 진입하면 자동 분기 | 3층 규칙 판정, 억제 중 이동 불가 |
| 도인도기 | 의식 대상 우클릭 채널링 (도가·불가만 활성) | 판정 — 실패 시 시전자 중독 전이 |
| 개화 의식 | 심법 습득 이벤트 (스승 NPC/비급) | 컷신급 연출 + 경험치 바 활성화 |

### D. 생활·사회·세계

| 행동 | 조작 | 서버 처리 |
|---|---|---|
| 소문 듣기 | 객잔 홀·장터 존 체류 | 브로드캐스트 존 — NPC 잡담 채팅 버블 (소문망 대사 풀) |
| 의뢰 | 의뢰소 게시판 우클릭 → GUI | 우호 등급별 의뢰 목록 (favor 연동) |
| 상점/흥정 | 상인 우클릭 → 거래 GUI + [흥정] 버튼 | 흥정 판정 → 가격 변동 |
| 진맥 | 의원 NPC 대화 선택지 | 은유 사전 문장 출력 (수치 비노출) |
| 글·기술 배우기 | 스승 NPC 대화 → 수련 선언 | 환산표 정산 |
| 기연 | 트리거 존 + 조건 충족 시 자동 발화 | 등록제 — 시험은 대화 선택지로 (인품을 본다) |
| 데드라인 사건 | 시간 도달 시 월드 이벤트 발화 | 예고는 소문·NPC 대사로만 (타이머 비노출) |
| 세력 반응 체감 | — (수동) | 순찰 밀도, NPC 태도 대사, 수배서 오브젝트 |
| 서장/출도 | 신규 접속 = 프롤로그 인스턴스 → 출도 의식 후 본서버 이동 | runtime_architecture 3.2 |

## 4. 구현 우선순위 (프로토타입 순서)

```text
P1. 입력 계층: 회피(Shift 탭)·가드/패링·콤보 체인 — 전투 손맛의 뼈대
P2. HUD 재해석: 내력=경험치 바, 원기=허기, 액션바 시간 — 자원 루프 체감
P3. 은신·감지 게이지 (보스바) — 비전투 판정의 대표 1종 검증
P4. 대화 시스템 (채팅 클릭 선택지 + 단서 첨부) — 사회 판정 전체의 기반
P5. 운기조식 채널링 + 심법 파티클 — 내공 루프
P6. 스킬 4슬롯 + 프레임 데이터 로더 (skill_mechanics.yml 소비)
이후: 오의/격돌, 기연 트리거, 수련 선언, 서장 인스턴스
```

## 5. 리스크 노트

```text
- Shift 과부하: 은신/회피/운기가 모두 Shift — 문맥 분기(탭 vs 유지 vs 정지 3초)의
  오입력 실측 필요 (P1에서 튜닝). 대안: 회피를 F로, 오의를 Shift+F로.
- 채팅 대화의 몰입: 클릭 컴포넌트는 바닐라 호환 최선이나 텍스트량 조절 필요 —
  대사 풀은 짧게, 서사는 연출로.
- 콤보 입력 지연: 좌클릭 체인은 핑 편차에 민감 — 유예창 ±2틱 (netcode 기존 규칙).
```
