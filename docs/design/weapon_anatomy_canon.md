## 1c. 날몸의 3층 — 벼린 날의 단면 (`_BLADE_D` 0.7/1.25/1.7 【잠정】)

실검의 단면: **인선(刃先)** 은 종잇장처럼 얇고 → **사면(刃面)** 이 비스듬히 오르고 →
**능선(鎬)/척(脊)** 이 가장 두껍다. 복셀러(`_voxelize`)는 태그 없는(날) 픽셀에 실루엣
가장자리까지의 거리로 3층 깊이를 준다 — **단면 마름모 근사**. 값의 이유:
- 인선 0.7 = 시트 1px(64px 자) 두께 — "벼려졌다"가 옆에서 읽히는 최소.
- 능선 1.7 = 인선의 ~2.4배 — 실검 단면비의 과장 없는 근사. 코등이(3.4)의 절반 — 날은
  관문보다 얇아야 한다.
- 칼끝은 가장자리 거리가 저절로 줄어 **저절로 얇아진다** (11차).

### 1c-19. 볼록 단면 — 다단 렌즈 (19차 · 사용자 정밀 스펙 · `_R19` 파일럿)

사용자(19차): *"Do NOT simply increase the blade thickness. Rebuild the crescent blade as a
**volumetric convex cross-section** instead of a flat slab. Multiple cuboids with gradually
changing depth. **The center ridge should be the thickest. The cutting edges should taper
smoothly to a thin profile. The silhouette must remain the same while the volume becomes
rounded.** Think of the blade as **forged steel** rather than a flat metal plate."*

3층(0.7/1.25/1.7)은 **너무 거칠다** — 옆에서 세 계단만 보여 판(板)으로 읽힌다. 정본 개정:
날 단면은 **7단 볼록 렌즈**다 (`_BLADE_CONVEX` 0.4·0.62·0.86·1.12·1.36·1.55·1.7 【잠정】).

- **정규화 거리 → 깊이**: `_voxelize` 는 날(무태그) 픽셀의 실루엣 가장자리 거리를 **blade
  전역 최대**로 정규화(0=인선 → 1=능선)해 렌즈 깊이를 준다. `frac^0.72` 로 능선 쪽을
  완만하게 — **마름모(선형)가 아니라 둥근 볼록** (단조된 강철의 부푼 날).
- **능선 최두께·인선 최소·단조 감소**: 능선 1.7에서 인선 0.4까지 계단이 **단조**로 줄어든다
  (무근거 요철 금지 — R2 정신을 z 축에 옮긴 규율). 계단 간격이 능선 쪽에서 좁아 볼록이
  매끄럽다.
- **정면 폭(xy 실루엣) 불변**: 개정은 **z 두께만** 만진다 — 복셀 from/to 의 xy 는 그대로다.
  R2(실루엣 상/하연 단차)는 xy 를 재므로 **무영향** · body_extent(display 분모)도 xy 라 불변.
- **곡선 날 우선, 전 계열 표준**: 초승달(월아산)·낫(겸)·갈고리(구)·휨(도)처럼 곡선 날에서
  평판 문제가 가장 도드라지니 거기부터 — 단 이 볼록 단면은 **9계열 전 날의 구축 표준**이다
  (검·창 포함). 양끝 병기(월아산)는 두 날이 각기 렌즈다 (단면 컷이 쌍 렌즈).
- **원소 예산**: 다단화로 z 계단이 늘어 그리디 병합 상자가 는다 — 파일럿 실측 검 185 · 도
  339~389 · 월아산 268 · 겸 301~372 (상한 600 초과 0). 초과 계열 관측 시 단수(7→5) 완화.

★배선 이력: `_R19` 게이트 뒤 파일럿(검·도)이다 — **팩 현행은 3층**(`_BLADE_D`)이고 비트
불변이다. 전 계열 전파(볼록 표준 채택)는 사용자 눈 확정 뒤 **20차** 소관. `_R19=False` 로
되돌리면 3층이 비트 단위로 재현된다.

## 2. 계열 해부 9벌 + 명병 — 부위 사슬 (x 순서 = R4 가 잰다)

각 줄 = 물미 쪽 → 날끝 쪽. `→` 사이가 §3 의 "부위 경계" (겹침 스팬으로 잇는다).
괄호 = 실병기 해부학 근거.

| 계열 | 부위 사슬 | 계열 고유 부위의 근거 |
|---|---|---|
| **검(劍)** | 물미구슬 → 물미관(검수) → 자루(병) → 코등이(검격 — 십자 가로대·플레어) *또는* 목띠(하바키)+기환/의장 관문 → **검신**(인선·사면·능선 — 좌우대칭 양날) → 검봉(날끝) | 곧고 대칭 — 등줄기(鎬)가 끝까지. 테이퍼 `_taperw(tip .74, slim .09)` = 실검의 원위 수렴 |
| **도(刀)** | 물미관 → 자루 → 코등이(원반 — 도의 통형 호수) → **도신**(한날 — 척(脊)이 등을 지고 배가 부르다, bez 휨) → 도첨 | 한날의 문법: 혈조는 척 밑(§4 Codex) · 무게는 등에 있다 |
| **비수(匕首)** | 물미관 → 자루 → 코등이(짧다 — 걸리면 늦다) → **비수날** | 검의 축소가 아니라 응축 — 전장이 검의 2/3 아래 |
| **창(槍)** | 준(鐏 — 자루 밑 쇠물미) → 자루(간杆 — 가장 가늘다 0.62) → 등급고리 → 홍영(紅纓 — 창날 밑 붉은 술: 피가 자루로 흐르는 것을 막고 상대 눈을 흐린다 · float) → 소켓(교구 — 창날 슴베를 무는 관) → **창날**(잎꼴 — leafw 폭곡선) | "창은 긴 막대에 촉을 단 것" — 자루:날 비율이 정체 |
| **부(斧)** | 물미관 → 자루(0.68 — 굵다: 무게는 굵기로 말한다) → 폴(poll — 도끼 등의 망치면) → 도끼목(eye/socket — 자루가 날 눈을 꿴다) → **부채날**(bit — 호) + 수염(beard — 아래로 흘러내린 뿔) | 도끼 해부학 그대로: poll–eye–bit–beard |
| **겸(鎌)** | 물미관 → 자루 → 슴베목(탕 — 낫날 슴베를 무는 관) → **낫날**(호 176° — 안쪽이 인) → 끝휨(방향선 — 바깥 15° 휨) | 걸어 채는 병기 — 안쪽 인·끝이 손 쪽으로 돈다 |
| **월아산(月牙鏟)** | **삽날**(鏟 — 판) → 삽목 → 자루 → 달목(소켓+**슴베** — 초승 아가리 속 16.2 까지 뻗어 월아를 문다 · 17차 신설, §7) → **월아**(초승 — 두 뿔이 자루를 향해 벌다) | 양끝 병기 — 유일. 쇠가 양끝에 달린 비대칭이 곧 이름 |
| **구(鉤)** | 물미관 → 자루 → 코등이(월아형 호수 — 鉤 고유) → **구신**(곧은 몸) → 갈고리(되꺾인 끝) + 미늘(逆鉤 — 걸린 것이 안 빠지는 턱) | 겸과 비율이 반대: 자루가 길고 발톱이 작다 |
| **권갑(拳甲)** | 손목띠(+띠끝 — 몸에 매는 것) → **손등판**(사다리꼴 — 마디 쪽이 넓다) → 마디 4(아치 — 가운뎃마디가 높다) + 엄지(비대칭) | 방패가 아니라 손: 마디 톱니·엄지 비대칭·아래로 늘어진 띠 |
| **봉(개방 명병)** | 봉마디(짚어 닳은 끝) → **봉** → 매듭 3(계급 — 삼줄) + 끈꼬리 → 봉마디 | 날이 없다 — 쇠 장식 0 (거지의 병기) |

**명병 12** — 실루엣·문양은 `sect_lineage.md` §2 지문 도출 그대로 (`pack_art_direction.md` §3).

- **R3 기맥 연속** (선협 calm) — 기맥은 **등록 오버레이(`_qi_vein`) 한 획**: 1개 연결 성분 ·

### 4-오라-1. 대원칙 — 오라는 **빛(기의 발광)**이다, 무기에 붙은 부산물이 아니다

기(氣)는 물질이 아니라 **빛나는 흐름**이다. 그래서 오라 요소는 전부 **광원처럼** 렌더된다 —
심이 희게 뜨고, 바깥으로 부드럽게 falloff 한다. 15~18차의 오라가 부산물처럼 읽힌 병의 실체:
**단수 플랫 램프**(`_qi_glow` — 4단 색 계단)로 발광을 흉내 냈다. 딱딱한 색 계단은 빛이 아니라
**얼룩**이다. 이 팩은 OptiFine 없는 바닐라라 진짜 emissive 텍스처를 못 쓴다 — **그림으로 빛을
더 잘 흉내내야 한다** (`_bloom_color`).

- **블룸 falloff (핵심)**: 오라 발광은 **부드러운 그라데이션** — 흰-핫 심 → 채도 악센트색 →
  어둡게 falloff → 가장자리(알파 2px 예산 안). ★**오라 한정 그라데이션 예외**: 무기 몸·날의
  픽셀아트 플랫 규율은 **불변**이고, 그라데이션은 오라 층에만 푼다 (감사 축 ㉓ 은 그라데이션을
  안 잰다 — 평균채도·알파만. 오라도 그 예산 안이라 20차 전파 가능 — 실측은 pack_upgrade §5).
- **핫 코어**: 발광 요소의 정중앙은 거의 **흰색**(과노출) — 광원은 심이 하얗게 뜬다
  (`_bloom_color`: 중심 밝기 b>1.0 → `mix(악센트hi, 흰, …)`). 채도 악센트색은 그 둘레 후광.
- **어두운 몸 위의 대비**: 오라는 조용한 먹/옥 몸 위에 얹혀야 산다 (additive 착시 — calm 몸이
  이미 어두우니 유리). 그래서 §4 의 "무기가 먼저, 기운은 양념"이 이 발광의 전제다.
- **번짐 폭**: 헤일로·기맥·광점 모두 밝은 심 + 바깥으로 몇 px 옅어지는 후광 (128px 라 곱다).

### 4-오라-2. 요소별 근거 — [세계관 근거 · 위치 도출 · 양 비례]

| 요소 | 세계관 근거 (무엇인가) | 위치가 어디서 도출되는가 | 양이 무엇에 비례하는가 |
|---|---|---|---|
| **발광 윤곽 (헤일로)** | 벼려진 인선에 **맺힌 기** — 날의 베는 기능 부위에 서린 발광 | **인선이 있는 곳에만** (양날 검=양쪽·한날 도=인선 쪽만·등엔 없다). 날 실루엣에서 틈(`_R19_GAP` 1.4u) **밖**에 떠서(±z `_R19_HALO_Z` 0.9u) 각도가 바뀌면 날에서 분리돼 보인다 (오라 분리) | 겹 수 = **인선 수** (검 2·도 1). 밝기 = 발광 강도 g. 뿌리 흐림→칼끝 맺힘 (기는 인선·칼끝에 모인다) |
| **기맥 (meridian)** | 내공이 흐르는 **길** — 단전에서 손으로, 손에서 날끝으로 | 자루(단전 곁)→관문→날끝 **한 획** (R3 가 기계로 잰다 — 흐름이라 끊길 수 없다). `_qi_vein` 오버레이 (색·빛만) | 가닥 수 = **축기 깊이(등급)** — 보병 1·신병 2·마병 3. 지류(nvein≥2)는 본류에서 갈라져 기혈에 맺힌다 |
| **부유 광점 (mote)** | **경혈(氣穴)의 잔광** — 기맥 위에서 기가 맺히는 혈자리(기혈)의 떠오른 빛 | ★**기맥 경로 위의 마디**(`_meridian_motes` — `_vein_style` 의 node>0.93 기혈 자리 t 를 경로에서 골라 앉힌다). 방사 폭발 상수(`_P7_BURST`)나 기환 축 임의 오프셋(r+2.7)이 **아니다** | 수 = 등급 광점 수 (신병·마병 2 — 절제). 원위(칼끝 쪽) 경혈부터 — 기는 인선으로 갈수록 맺힌다 |

### 4-오라-3. 등급 사다리 재정의 — 근거 있는 다이얼 (`_QI_GRADE_CALM`)

사다리의 두 축은 임의 튜닝값이 아니라 **세계관 량**에서 도출된다:

- **발광 강도 g** = **축기(蓄氣)의 깊이** — 기운이 얼마나 열렸는가. 범철 0(안 열린 쇠는 그냥 쇠) →
  정련 0.15(기미) → 보병 0.3(흐르기 시작) → 신병 0.75(가득) → 마병 0.8(검붉게 뒤틀린 가득).
- **기맥 밀도 (가닥 수)** = **뚫린 경맥의 수** — 축기가 깊을수록 더 많은 길로 흐른다.
  보병 1 → 신병 2 → 마병 3(막힌 기혈이 갈라진 균열 길).
- **광점 수** = **맺힌 경혈의 수** — 절제(2)를 상한으로 둔다. "많을수록 세다"가 아니라 "적은
  오라가 살아 움직인다"(19b 절제 승계). 광점이 늘면 그건 세기가 아니라 난잡이다.

【무근거였던 것 — 자체 검토가 적발】 ⓐ 광점 위치가 기환 축 r+1.5/r+2.7 임의 오프셋이었다
(경혈이 아니라 방사 상수의 잔재) → 기맥 경혈로 이전. ⓑ 발광이 단수 플랫 램프라 부산물로
읽혔다 → 블룸. ⓒ 19차가 광점 거리를 r+1.5→r+2.7 로, 자락 길이를 3.5→4.8 로 "이유 없이"
늘렸다 (분리 명분이었으나 양의 증가였다) → 분리는 gap·±z(위치)로만 하고 거리·길이 증량은 철회.

### 4-오라-4. 일렁임 (오로라) — 실현 판정과 위상 설계

사용자: *"오로라처럼 빛이 일렁거리는 느낌"* = 오라에 **움직임**을 원한다.

**실현 판정 = 조건부 가능** (실증):
- 정지 텍스처로는 불가. 바닐라 유일 길 = **애니메이션 텍스처**(PNG 세로 프레임 적층 +
  `.mcmeta` `animation` 순환). OptiFine 불요 · 손/GUI 재생. 감사 축 ⑯ 은 이미 세로 스트립+
  `.mcmeta` 를 합법으로 받는다 (`aspect_axis`: `h>w and h%w==0 and has_meta`).
- **선행 3건** (20차 애니 회차 소관 — 이 회차는 착수 안 함): ① 오라를 **별도 텍스처층**(슬롯 2)
  으로 분리 — 지금은 몸/날과 같은 페인트 시트라 애니하면 몸도 흔들린다 (복셀 UV 재배선).
  ② 새 오라 텍스처는 바닐라 mcmeta 가 없으니 **팩이 `.mcmeta` 를 굽는다** (contract-legal —
  campfire·kelp 스트립 전례. 메뉴 나인슬라이스 mcmeta 를 안 굽는다는 계약은 바닐라 mcmeta
  **덮어쓰기** 금지지, 신규 텍스처 mcmeta 금지가 아니다). ③ 축 ㉓ 치수 검사(`w!=h` 위반)를
  오라 글롭에 한해 **세로 스트립 허용**으로 확장 (등록부 hi_res_channels 한 항).
- **이 회차**: 위상 설계만 심는다 (`_R19_PHASE` — 프레임 인덱스=사인 위상, 난수 0 결정론).
  블룸 심의 밝은 마디가 인선을 따라 **흐르고**(`_aura_rim`), 경혈 광점이 **맥동**한다
  (`_meridian_motes`). 스크래치가 프레임을 굽어 일렁임이 결정론·가독임을 증명 (`v19c_aura_frames.png`).

### 4-오라-5. 자체 검토의 세 눈 (`_aura_selftest` — 임포트마다)

① **광점이 경혈 위인가** — 각 부유 광점 중심이 기맥 중심선의 마디(node>0.9) 위에 얹혔나
(임의 좌표면 실패). ② **헤일로가 인선 쪽인가** — 한날(도) 1겹·양날(검) 2겹. ③ **블룸이
광원인가** — 핫 코어(심)가 악센트보다 밝고, falloff 이 있다(딱딱한 계단이면 실패 = 부산물).
