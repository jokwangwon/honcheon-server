# 스탯과 성장 — 레벨은 없다, 경지가 레벨이다

> 질문: 스탯·레벨업 시스템의 구상.
> 흩어져 있던 조각(능력치 7종 · 화후 · training 환산표 · 경지 사다리)을 한 장의
> 캐릭터 시트와 하나의 성장 원장으로 통합하고, 구판 `cultivation.yml`(레벨·경험치·
> 평판 수치·% 보너스)을 전면 교체한다.
> 기계 판독용: `config/cultivation.yml` v2

---

## 0. 두 가지 원칙

```text
① 레벨은 없다 — 경지가 레벨이다.
   경지는 숫자가 아니라 관문: 요건(수치)을 채우고 계기(사건)를 만나야 오른다.
② 경험치는 없다 — 시간과 사건이 경험치다.
   모든 성장은 화후(실수 적립) 원장 하나로 쌓인다. 수련은 매일 조금씩,
   실전은 한 번에 크게 — 적립 속도가 다를 뿐 장부는 같다.
```

## 1. 캐릭터 시트 전모 — 4층 구조

```text
[1층] 판정 능력치 7종 (1~10, 내부 실수) — 주사위 옆에 서는 숫자
[2층] 자원 (실수 파생)                  — 싸움과 삶을 지탱하는 통화
[3층] 이력 (스스로 쌓는 것)             — 숙련·경지·실전 마크
[4층] 세계가 매기는 것                  — 명성/악명·favor·심마 흔적·별호
```

### 1층 — 판정 능력치 7종

| 능력치 | 대표 판정 | 파생 |
|---|---|---|
| 근력 | 완력·위협·도수 위력 | 무기 요구치, 짐 |
| 민첩 | 회피·잠입·도주·기습 | 회피 기본치, 보법 궁합 |
| 체력 | 강행군·버티기 | **내구(MC)**, 부상 회복 배율, 노쇠 저항 |
| 내공 | 기 운용 판정 | **내력 = round(실수 × 3)**, 정화력 |
| 감각 | 은신 감지·엿듣기·추적 | 감지 게이지(MC), 견식 판정 |
| 화술 | 설득·교섭·정보 캐기 | 소문 정확도 보정 |
| 지혜 | 조사·의술·비급 입문(오성) | 학습 판정 전반 |

**밴드의 서사** — 숫자가 아니라 사람이 보이게:

```text
1 아이·노쇠   2 성인 평균   3 단련된 자   4 삼류의 한계(생성 캡)
5~6 일류 무인   7 절정 — 인간의 껍질 안에서의 끝   8 초인(초절정)
9 전설(화경)   10 인간의 끝 — 그 너머는 능력치가 아니라 격(어검·심검)의 영역
```

- 성장 상한 = **경지 캡**(player_creation attribute_cap_by_realm) ∧ **나이 캡**(age_brackets).
  아이는 몸이 자라야 하고, 무인은 경지가 열려야 한다 — 캡이 곧 성장 서사의 마디.

### 2층 — 자원 (전부 실수 파생, 화후 규칙)

```text
내력      round(축기_세월(내공) × 3) — 축기_세월(x) = x(x+1)/2 년. 소모 밴드·다운캐스트 (internal_energy)
          ★ 단전에 쌓이는 것은 '단계'가 아니라 앉아 있던 시간이다 (내공만이 배증형 능력치)
원기      0~100 — 생명력·피로 통합 (음식·수면 보충)
선천진기  100년 — 수명. 태우는 것만 가능 (연혼일격·파벽·회생)
내구(MC)  20 + round(체력실수 × 2), 상한 40 — 하트 재해석
          부상 매핑: 내구 75%↓ = 경상 / 40%↓ = 중상 / 15%↓ = 빈사 (텍스트 3단과 동형)
```

### 3층 — 이력: 숙련·경지·실전 마크

- **숙련** (무공·일반기술 0~10): training 환산표. 5→6부터는 수련만으로 불가.
- **경지** (범인~생사경 9단): 아래 3장 — 이 게임의 '레벨업'.
- **실전 마크** (신설): 엔진이 자동 기록하는 사건 축 — 조작 불가.
  - `실전 마크`: 생사가 걸리지 않은 실전의 해소 (비무 승리·제압·실전 도주 성공)
  - `사선(死線) 마크`: 생사가 걸린 전투 생존 (빈사 경험·격상 상대 생존)
  - 마크가 될 사건은 대개 소문도 된다 — **성장과 명성은 같은 사건의 두 얼굴.**

### 4층 — 세계가 매기는 것 (성장이 아니라 반응)

명성/악명(소문 축), 세력 favor(안면→은인), 심마 흔적, 별호. 플레이어가 올리는 게 아니라 **세계가 매긴다** — 시트에 있지만 내 것이 아닌 숫자들.

## 2. 성장의 4원천 — 전부 화후 원장으로 적립

```text
① 수련 (시간)   training.yml 그대로 — 능력치 +1 = 1년, 숙련 환산표, 축기 = 심법
② 실전 (사건)   수련이 살을 만들고 실전이 뼈를 만든다 (신설 수치 ↓)
③ 깨달음 (벽)   숙련 6+와 경지 승급의 유일한 문 — 수치가 아니라 사건
④ 기연 (외부)   영약·벌모세수·비급 — 등록제 (fortune_encounters)
```

> **★ 2026-07 성장 축 패스 — 빠져 있던 것은 원천이 아니라 「선택」이었다.**
> 위 4원천은 *성장이 어디서 오는가*를 말한다. 그러나 **플레이어가 무엇을 고르는가**는 어디에도 없었다 —
> ①의 '수련'은 하나의 덩어리였고, 엔진에는 능력치 시트조차 없었다 (`SkillListener`: *"MVT 근사:
> 능력치 시트가 없다 — 경지가 능력치의 자리를 대신한다"*). **같은 경지의 두 사람은 같은 사람이었다.**
>
> → **수련 배분(修練配分)**: 하루 5구간(`time.yml`)을 **외공·내공·초식·신법·심안**에 나눈다.
> 1구간 = 0.2일치 (수련 하루 1일치 ÷ 5구간 — *고른 값이 아니라 두 정본의 나눗셈*).
> 한 과목 몰빵 = 1.0일치/일 = 위 *"능력치 +1 = 1년"* 과 정확히 맞물린다.
> **새 사다리를 만들지 않았다 — 삼중 사다리(1층 능력치·3층 숙련·2층 내공)의 분모를 드러냈을 뿐이다.**
>
> 그리고 **②실전은 초식 원장 하나에만 쌓인다** — 늑대를 백 마리 잡아도 몸은 안 만들어진다.
> 예외는 사선(+30일치, 현재 배분의 주 과목으로). **정본: `docs/design/growth_axes.md` · `training.yml curriculum`**

**실전의 경험치화 (v2.1)** — 마크 로직을 연속식 화후 적립으로 내재화한다.
사냥·소탕·대련 전부가 적립 대상이다. 단, **배움의 양은 상대가 정한다**:

```text
유효 전투 1회 = 사용 무공·기술 숙련 화후 +0.3일치 수련 상당 × 배율
  상대 격차    상수(나보다 위) ×2 / 동수 ×1 / 하수 ×0.25 / 압도적 하수 ×0
              — 늑대 백 마리째에는 늑대에게 배울 게 없다 (자동 판정권 = 적립 0)
  목숨의 무게  생사 ×2 / 실전·사냥 ×1 / 비무·대련 ×0.5
  반복 감쇠    같은 상대 유형 연속 — 회당 -50% (반토막), 새 유형·새 지역 리셋
  일일 상한    +3일치 — 실전은 수련(1일치/일)을 대체하지 않고 압축한다
사선 경험      관련 능력치 화후 +30일치 (장당 1회 — 죽다 살아나면 몸이 는다) [유지]
대성공/치명    해당 기술 화후 +1일치 (기술당 1일 1회 — 티끌) [유지]
견식           skill_lifecycle 그대로 (입문 기간 -30%)
```

**한 판의 값 (2026-07 재조정)** — `+2일치 → +0.3일치`, 감쇠 `-25% → -50%`, 일일 상한 `16 → 3일치`.

구판은 표준 플레이(수련 1회 + 사냥 2회 + 의뢰 1건 / 일)가 **하루 10일치**를 적립했다.
실전이 수련을 *압축*하는 게 아니라 *대체*했고, '개화한 몸'인 일류에 **73일** 만에 닿았다 — 1년의 20%.
무협의 시간 감각이 무너지는 자리였다.

고친 것은 **한 판이 얼마냐** 하나다. 배율표(상대 격차·목숨의 무게)와 숙련 환산표는 그대로 뒀다 —
그 둘은 *무엇이 사람을 가르치는가*를 말하는 정본이고, 틀린 것은 값이었다.

| | 구판 | 신판 |
|---|---|---|
| 하루 적립 | 10.0일치 | **2.2일치** |
| 삼류 | 9일차 | **41일차** |
| 이류 | 37일차 | **144일차** |
| 개화 (심법 전수) | 3일차 | **30일차** |
| **일류** | **73일차** (0.20년) | **308일차** (0.86년) |
| 격상 사냥 시 일류 | 63일차 | 287일차 |

**남긴 것**: 하위 3단 자동 승급('성실하면 오른다')과 사선 단발 보정(+30일치)은 손대지 않았다.
→ 늑대를 백 마리 잡아도 안 오른다. **한 번의 사선이 한 달을 앞당긴다.** 그라인딩이 아니라 사선이 키운다.

**사냥이 주는 것** — 짐승에게도 격이 있다:

```text
들짐승(늑대·멧돼지) 삼류 상당 / 맹수(호랑이·곰) 일류 상당 / 영물 절정+ (등록제 — 소문·기연 연동)
소년기 삼류에게 첫 늑대는 사선이고(적립 크다), 절정 고수에게는 소일거리다(적립 0).
사냥터의 진짜 소득은 둘: ① 아직 배울 게 있는 몸에겐 실전 화후
② 부산물 — 가죽·육포·담낭 = 생계 수입(생활_노동 대체), 영물 재료 = 영약 연계 (경제 시스템 훅)
```

## 3. 경지 승급 — 관문표 (레벨업의 실체)

**요건(수치)을 채우고 계기(사건)를 만나야 오른다.** 요건은 문턱이고 계기가 문이다:

| 승급 | 요건 | 계기 |
|---|---|---|
| 범인→삼류 | 아무 무공 입문 + 기초 단련 3개월 | 자동 |
| 삼류→이류 | 주력 숙련 2 + 실전 마크 1 | 자동 |
| 이류→일류 | 주력 숙련 3 + **개화**(단전·심법 축기 시작) + 실전 마크 10 | 자동 — 숙련(화후)과 개화를 **둘 다** 채운 날 |
| 일류→절정 | 주력 숙련 5 + 내공 3 + 실전 마크 5 + 사선 1 | **첫 벽** — 깨달음 (실전/스승의 인도/파벽) |
| 절정→초절정 | 주력 숙련 6 + 내공 5 + 사선 3 | 벽 — 깨달음 (오의 개안과 흔히 동시) |
| 초절정→화경 | 오의 개안 + 내공 7 + 사선 5 | **대각(大覺)** — 생사의 문턱의 깨달음 (등록 사건) |
| 화경→현경 | 수치 요건 없음 (내공 9+ 관행) | 서사 등록제 — 세계 유일급 사건 |
| 현경→생사경 | — | 서사 등록제 — 시대에 한둘, 도달 = 세계 이벤트 |

- 하위 3단(삼류~일류)은 **자동** — 성실하면 오른다. 절정부터 **벽** — 수련 상태(장 도약·
  수련 로그인)로는 절대 못 넘는다 (training bottlenecks와 정합). 벽 앞의 정체가
  디폴트고, 깨달음 사건이 예외다 — 그래서 절정 고수가 흔치 않다.
- **강등은 없다.** 대신 내상·심마로 경지 '봉인'(발휘 불가) 상태는 존재 — 회복 서사의 재료.
- 승급의 효과는 전부 기존 파일이 원천: 능력치 캡(player_creation) · 기 운용 게이트
  (internal_energy) · 노화 저항(internal_energy) · 오의 단계(ultimate_arts) ·
  판정 경지 격차 ±2/단계(judgment). cultivation.yml v2는 **관문(요건·계기)만 갖는다.**

## 4. 화후 파이프 — 성장이 보이는 방식

```text
적립은 매일, 돌파는 어느 날 문득.
판정은 정수부만 보므로 성장은 계단식으로 '체감'된다 — 3.9와 4.0은 세계가 다르다.
돌파 연출: 정수부가 오르는 날을 엔진이 알린다 — "오늘따라 손이 가볍다"
(MC: 경험치 획득음 + 개인 파티클 / 텍스트: 아침 서술 한 줄)
```

## 5. MC 매핑

```text
레벨 숫자   = 나이 (세계 달력 연동 — "사건이 나이를 먹인다"가 화면에 보인다)
경험치 바   = 내력 (기존 배정 유지 — 레벨업 게이지가 아니다)
하트       = 내구 20+체력×2 / 허기 = 원기 (기존)
경지 표시   = 탭리스트·명패 옆 칭호 (삼류~생사경) — 별호가 있으면 별호 우선
승급 연출   = 개인 사운드+파티클, 화경+ 는 서버 공지 (소문 강도 3와 동형)
```

### 5.1 인지 설계 — 경험치의 문법을 빌리고, 의미는 빌리지 않는다

내부 원장(화후·격차 배율)은 MC 화면에 그대로 보이지 않는다. 해법은 규칙을
경험치로 바꾸는 게 아니라, **플레이어가 이미 아는 MMO 표현 문법으로 번역**하는 것:

```text
① 격차 = 기세(氣勢) 색   상대 명패 색 4단 — 회(압도적 하수: 배울 것 없음) /
   백(하수) / 황(동수) / 적(상수). "몹 레벨 색"의 문법을 기세 읽기로 재해석 —
   회색 늑대는 건드려도 안 늘고, 붉은 이름 앞에선 도망이 답이라는 걸 한눈에 안다
② 적립 = 수련 일수 플로팅 (즉시)   처치·격돌 확정 즉시 같은 틱에 피드백:
   시체 위 "+2일" 플로팅(텍스트 디스플레이, 수명 20틱 — VFX 풀 계상) +
   액션바 "육합검이 손에 익는다 (+2일)" + 적립음. '일(日)'이 경험치 숫자의 자리
   (수련 상태 정산도 같은 단위 — 훈련과 실전이 한 화폐로 읽힌다)
   스팸 방지: 1초 내 재적립은 액션바 합산 갱신(원래 덮어쓰는 채널), 사운드 쿨다운 10틱
   일일 상한 도달: "오늘은 몸이 벅차다" (회색 표기 — 왜 안 느는지 설명된다)
③ 원장 = 경락도 GUI   로드아웃 GUI(핫바 9)에 무공·능력치별 화후 진행 바 —
```

### 5.2 즉시성 판정 — 처치 → 변화 체감의 지연 예산

```text
경로: EntityDeathEvent(처치 확정) → 화후 적립 연산 → 피드백 패킷 — 전부 같은 틱
  적립 연산 = 실수 덧셈 + 배율·감쇠·상한 조회 (O(1), ≤0.1ms — skill_execution 예산 내)
  피드백   = 사운드 1 + 액션바 1 + 텍스트 디스플레이 1 (패킷 3개 — 대역폭 무시 가능)
체감 지연 = 틱 정렬(0~50ms) + 편도 전송(10~40ms) ≈ 30~90ms
  → 인간의 '즉시' 지각 한계(~100ms) 안. 바닐라 XP 구슬 드랍과 같은 경로·같은 속도
보증: 이 경로에 LLM 없음 — 2단 파이프라인의 엔진 단 전용 (렌더 단은 텍스트 RPG의 몫)
     DB 기록은 비동기 큐(async 규칙 — 단일 작성자), 화면 피드백은 메모리 원장 기준
결론: 감당 가능. 60인 × 초당 30시전 부하 테스트 기준으로도 적립 연산은 오차 항이다
```

**"경험치로 퉁"을 규칙 층에서 하지 않는 이유**: 단일 XP 풀로 합치면
① 능력치/숙련/내공의 삼중 사다리가 무너지고 (어디에 쌓일지 엔진이 못 정한다 —
쓴 무공에 쌓이는 게 실전의 정체성) ② "수치는 문턱, 사건이 문"의 승급 철학이
'XP 채우면 레벨업'으로 회귀한다. 퉁은 눈에만 — 장부는 정직하게.
