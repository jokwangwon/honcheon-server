# 스탯과 성장 — 레벨은 없다, 경지가 레벨이다

> 질문: 스탯·레벨업 시스템의 구상.
> 흩어져 있던 조각(능력치 7종 · 화후 · training 환산표 · 경지 사다리)을 한 장의
> 캐릭터 시트와 하나의 성장 원장으로 통합하고, 구판 `cultivation.yml`(레벨·경험치·
> 평판 수치·% 보너스)을 전면 교체한다.
> 기계 판독용: `config/cultivation.yml` v2

---

## 0. 두 가지 원칙

```text
① 레벨은 없다 — 경지가 레벨이다.
   경지는 숫자가 아니라 관문: 요건(수치)을 채우고 계기(사건)를 만나야 오른다.
② 경험치는 없다 — 시간과 사건이 경험치다.
   모든 성장은 화후(실수 적립) 원장 하나로 쌓인다. 수련은 매일 조금씩,
   실전은 한 번에 크게 — 적립 속도가 다를 뿐 장부는 같다.
```

## 1. 캐릭터 시트 전모 — 4층 구조

```text
[1층] 판정 능력치 7종 (1~10, 내부 실수) — 주사위 옆에 서는 숫자
[2층] 자원 (실수 파생)                  — 싸움과 삶을 지탱하는 통화
[3층] 이력 (스스로 쌓는 것)             — 숙련·경지·실전 마크
[4층] 세계가 매기는 것                  — 명성/악명·favor·심마 흔적·별호
```

### 1층 — 판정 능력치 7종

| 능력치 | 대표 판정 | 파생 |
|---|---|---|
| 근력 | 완력·위협·도수 위력 | 무기 요구치, 짐 |
| 민첩 | 회피·잠입·도주·기습 | 회피 기본치, 보법 궁합 |
| 체력 | 강행군·버티기 | **내구(MC)**, 부상 회복 배율, 노쇠 저항 |
| 내공 | 기 운용 판정 | **내력 = round(실수 × 3)**, 정화력 |
| 감각 | 은신 감지·엿듣기·추적 | 감지 게이지(MC), 견식 판정 |
| 화술 | 설득·교섭·정보 캐기 | 소문 정확도 보정 |
| 지혜 | 조사·의술·비급 입문(오성) | 학습 판정 전반 |

**밴드의 서사** — 숫자가 아니라 사람이 보이게:

```text
1 아이·노쇠   2 성인 평균   3 단련된 자   4 삼류의 한계(생성 캡)
5~6 일류 무인   7 절정 — 인간의 껍질 안에서의 끝   8 초인(초절정)
9 전설(화경)   10 인간의 끝 — 그 너머는 능력치가 아니라 격(어검·심검)의 영역
```

- 성장 상한 = **경지 캡**(player_creation attribute_cap_by_realm) ∧ **나이 캡**(age_brackets).
  아이는 몸이 자라야 하고, 무인은 경지가 열려야 한다 — 캡이 곧 성장 서사의 마디.

### 2층 — 자원 (전부 실수 파생, 화후 규칙)

```text
내력      round(내공실수 × 3) — 소모 밴드·다운캐스트 (internal_energy)
원기      0~100 — 생명력·피로 통합 (음식·수면 보충)
선천진기  100년 — 수명. 태우는 것만 가능 (연혼일격·파벽·회생)
내구(MC)  20 + round(체력실수 × 2), 상한 40 — 하트 재해석
          부상 매핑: 내구 75%↓ = 경상 / 40%↓ = 중상 / 15%↓ = 빈사 (텍스트 3단과 동형)
```

### 3층 — 이력: 숙련·경지·실전 마크

- **숙련** (무공·일반기술 0~10): training 환산표. 5→6부터는 수련만으로 불가.
- **경지** (범인~생사경 9단): 아래 3장 — 이 게임의 '레벨업'.
- **실전 마크** (신설): 엔진이 자동 기록하는 사건 축 — 조작 불가.
  - `실전 마크`: 생사가 걸리지 않은 실전의 해소 (비무 승리·제압·실전 도주 성공)
  - `사선(死線) 마크`: 생사가 걸린 전투 생존 (빈사 경험·격상 상대 생존)
  - 마크가 될 사건은 대개 소문도 된다 — **성장과 명성은 같은 사건의 두 얼굴.**

### 4층 — 세계가 매기는 것 (성장이 아니라 반응)

명성/악명(소문 축), 세력 favor(안면→은인), 심마 흔적, 별호. 플레이어가 올리는 게 아니라 **세계가 매긴다** — 시트에 있지만 내 것이 아닌 숫자들.

## 2. 성장의 4원천 — 전부 화후 원장으로 적립

```text
① 수련 (시간)   training.yml 그대로 — 능력치 +1 = 1년, 숙련 환산표, 축기 = 심법
② 실전 (사건)   수련이 살을 만들고 실전이 뼈를 만든다 (신설 수치 ↓)
③ 깨달음 (벽)   숙련 6+와 경지 승급의 유일한 문 — 수치가 아니라 사건
④ 기연 (외부)   영약·벌모세수·비급 — 등록제 (fortune_encounters)
```

**실전 가속 수치** (신설 — 화후 원장에 큰 적립):

```text
생사 격돌 생존   사용 무공 숙련 화후 +7일치 수련 상당 (1일 1회 상한)
사선 경험       관련 능력치 화후 +30일치 (장당 1회 — 죽다 살아나면 몸이 는다)
대성공/치명 실패  해당 기술 화후 +1일치 (기술당 1일 1회 — 티끌)
견식            skill_lifecycle 그대로 (입문 기간 -30%)
```

## 3. 경지 승급 — 관문표 (레벨업의 실체)

**요건(수치)을 채우고 계기(사건)를 만나야 오른다.** 요건은 문턱이고 계기가 문이다:

| 승급 | 요건 | 계기 |
|---|---|---|
| 범인→삼류 | 아무 무공 입문 + 기초 단련 3개월 | 자동 |
| 삼류→이류 | 주력 숙련 2 + 실전 마크 1 | 자동 |
| 이류→일류 | 주력 숙련 3 + **개화**(단전·심법 축기 시작) + 실전 마크 3 | 자동 — 개화가 사실상의 관문 |
| 일류→절정 | 주력 숙련 5 + 내공 3 + 실전 마크 5 + 사선 1 | **첫 벽** — 깨달음 (실전/스승의 인도/파벽) |
| 절정→초절정 | 주력 숙련 6 + 내공 5 + 사선 3 | 벽 — 깨달음 (오의 개안과 흔히 동시) |
| 초절정→화경 | 오의 개안 + 내공 7 + 사선 5 | **대각(大覺)** — 생사의 문턱의 깨달음 (등록 사건) |
| 화경→현경 | 수치 요건 없음 (내공 9+ 관행) | 서사 등록제 — 세계 유일급 사건 |
| 현경→생사경 | — | 서사 등록제 — 시대에 한둘, 도달 = 세계 이벤트 |

- 하위 3단(삼류~일류)은 **자동** — 성실하면 오른다. 절정부터 **벽** — 수련 상태(장 도약·
  수련 로그인)로는 절대 못 넘는다 (training bottlenecks와 정합). 벽 앞의 정체가
  디폴트고, 깨달음 사건이 예외다 — 그래서 절정 고수가 흔치 않다.
- **강등은 없다.** 대신 내상·심마로 경지 '봉인'(발휘 불가) 상태는 존재 — 회복 서사의 재료.
- 승급의 효과는 전부 기존 파일이 원천: 능력치 캡(player_creation) · 기 운용 게이트
  (internal_energy) · 노화 저항(internal_energy) · 오의 단계(ultimate_arts) ·
  판정 경지 격차 ±2/단계(judgment). cultivation.yml v2는 **관문(요건·계기)만 갖는다.**

## 4. 화후 파이프 — 성장이 보이는 방식

```text
적립은 매일, 돌파는 어느 날 문득.
판정은 정수부만 보므로 성장은 계단식으로 '체감'된다 — 3.9와 4.0은 세계가 다르다.
돌파 연출: 정수부가 오르는 날을 엔진이 알린다 — "오늘따라 손이 가볍다"
(MC: 경험치 획득음 + 개인 파티클 / 텍스트: 아침 서술 한 줄)
```

## 5. MC 매핑

```text
레벨 숫자   = 나이 (세계 달력 연동 — "사건이 나이를 먹인다"가 화면에 보인다)
경험치 바   = 내력 (기존 배정 유지 — 레벨업 게이지가 아니다)
하트       = 내구 20+체력×2 / 허기 = 원기 (기존)
경지 표시   = 탭리스트·명패 옆 칭호 (삼류~생사경) — 별호가 있으면 별호 우선
승급 연출   = 개인 사운드+파티클, 화경+ 는 서버 공지 (소문 강도 3와 동형)
```

## 6. 구판 폐기 목록 (cultivation.yml v1 → v2)

```text
폐기: level/경험치 요건 · 평판 수치 요건(명성은 세계 반응이지 성장 재료가 아니다) ·
     % 보너스(회피율 +15% 등 — 판정 체계와 비호환) ·
     technique_by_internal(→ simbeop.yml 결(結)로 이관 완료)
유지: 9단계 이름·순서 (전 파일 참조 축 — lint 검증 대상)
신설: battle_marks(실전·사선) · promotion(요건+계기) · 봉인 규칙
```
