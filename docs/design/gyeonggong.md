# 경공(輕功) — 무협의 몸이 땅을 딛는 법

> `gap_audit.md §3-①` 이 이렇게 적었다: *"경공은 설계·config 에 **풍부하게** 있다 …
> **그런데 자바 프로덕션 코드에 '경공'이 0건이다.**"*
> 그 결과가 단순한 결손이 아니었다 — **절정 고수도 삼류도 같은 속도로 걷고, 같은 높이에서 죽었다.**
>
> 기준 config: `gyeonggong.yml`(신규) · `internal_energy.yml`(경신 게이트·밴드) · `skills.yml`(보법 4종) ·
> `skill_mechanics.yml`(거리·수직·변칙) · `simbeop.yml`(연비·답운) · `equipment.yml`(경공_불가) ·
> `combat.yml`(회피·선공) · `training.yml`(신법) · `performance.yml`(예산·계기)
> 엔진: `server-mvt/.../Gyeonggong.java`(등록부·산술) · `GyeonggongListener.java`(몸·티커·파티클)
> 검산: `tools/gyeonggong_audit.py`

---

## 0. 세 줄 요약

1. **경공은 개화(일류)부터다.** 새 게이트를 만들지 않았다 — `internal_energy.yml realm_gates` 가
   이미 **'경신'을 일류에 열어** 두었고, 삼류·이류의 내력 풀은 **0**이다. 그들은 **바닐라처럼 걷는다.**
   *같은 담 앞에서 삼류와 절정이 다른 사람이 되는 것* — 그것이 개화의 보상이고, 그것이 경공이다.
2. **경지가 천장을 열고, 신법(민첩)이 그 천장까지 자란다.** 이것은 `training.yml curriculum.cap` 의
   문법 그대로다 (*"몰빵을 멈추는 것은 페널티가 아니라 천장이다"*). 신법 축은 지금까지 **회피 판정만**
   샀다 — 구간을 부어도 **몸이 가벼워지지 않았다.** 이 문서가 그 절반을 채운다.
3. **몸은 내력을 태워 뜨고, 내력이 끊기면 떨어진다.** 낙법은 **기가 도는 몸에만** 듣는다
   (`qi.depleted.grace_multiplier: 0`). **쿨다운은 한 줄도 없다** — 경공을 막는 것은 시계가 아니라
   **단전·경지·갑옷**이다.

## 1. 무엇을 할 수 있는가 (전부 마인크래프트에서 실제로 구른다)

| 이름 | 무엇을 하는가 | 무엇이 여는가 | 값 |
|---|---|---|---|
| **답설무흔**(踏雪無痕) | 달리며 점프 → 경공 모드. 속도·도약이 오르고 **발밑에 자국이 남는다** | 개화(일류) | 유지 **내력 1/합** |
| **경공 도약** | 도약 초속 ×(1+n). 일류 2.1m → 생사경 3.2m | 경지 천장 ∧ 신법 | 내력 1 |
| **벽 딛기** | 벽을 차고 오른다. **지붕은 뛰어서 못 오른다 — 딛고 오른다** | 절정 ∧ **수직 보법**(제운종·답운종) | 내력 1/회 |
| **수상비**(水上飛) | 물 위를 **달린다**. 서면 빠진다 (`water.min_speed`) | **초절정** | 유지 **2/합** |
| **낙법**(落法) | 경지가 사는 높이(10~20m)는 공짜. 그 위는 **내력이 산다** (1 = 4m) | 경지 천장 ∧ 신법 | 초과분만 과금 |
| **물러남** | 회피가 성공하면 몸이 **실제로 물러난다** (보법이 거리를 정한다) | 보법 | 내력 1 |
| **파고듦** | 선공을 잡으면 먼저 붙는다 | 보법 | 내력 1 |

### 문파마다 발이 다르다 — 지어내지 않았다

`skills.yml` 에 이미 넷이 있었다. 거리·수직·변칙은 `skill_mechanics.yml` 이 정본이고,
**엔진은 그 값을 읽지 짓지 않는다**:

| 보법 | 문파 | 이동 | 지문 |
|---|---|---|---|
| **매화보** | 화산 | 5m | — |
| **제운종** | 무당 | 8m | **수직** — 벽을 딛는다 |
| **취팔선보** | 개방 | 4m | **변칙** — 물러나는 방향이 ±30° 흔들린다 (취보의 값이자 대가) |
| **답운종** | 곤륜 | **10m** | **수직** + 곤륜현천공(경신 −2)과 겹치면 **같은 내력으로 3배를 난다** |

> **화산·개방의 발로는 벽이 벽이다.** 벽 딛기는 경지 천장(절정+)과 **수직 보법**이 **둘 다** 있어야 열린다.

## 2. ★ 무엇을 **일부러 못 하게** 했는가 (이쪽이 더 중요하다)

| 못 하는 것 | 왜 |
|---|---|
| **삼류·이류의 경공** | `realm_gates` 가 경신을 일류에 열었다. 내력 풀 0 인 몸은 뜰 수 없다. **삼류는 담도 못 넘는다** |
| **도약만으로 지붕(5m)** | 전 경지 도약 최대 **3.2m**. 지붕은 **벽을 딛고** 오른다 — 그것이 경공의 문법이다 (감사 계약 `jump_never_reaches_roof`) |
| **비행** | 체공은 전 경지·전 빌드에서 **1~30초**. 경공은 **이동 수단이지 비행이 아니다** — 겉날개를 끈 자리를 대신하지 않는다 (`world_purity.yml`: *"겉날개가 경공 설계를 통째로 무너뜨린다"*) |
| **공짜 비행** | 심법 할인은 **유지 간격**만 늘린다. 단발 코스트는 `qi.floor: 1` 아래로 못 내려간다. **곤륜(−2)조차 공짜로 날지 못한다** |
| **철갑 입고 경공** | `equipment.yml armor.철갑.restrictions: [경공_불가]` — 이 규칙이 처음으로 **몸에 닿는다** |
| **쿨다운으로 막기** | 한 줄도 없다. 막는 것은 **내력·경지·갑옷**이다 (MMO 문법 거부) |
| **고갈된 몸의 낙법** | ★★ 낙법 배율 **0**. 곤륜의 답운(낙하 무효)조차 **고갈되면 안 듣는다.** 돌처럼 떨어진다 |

## 3. 지배 전략이 없는 근거 — 감사 수치

`tools/gyeonggong_audit.py` : **위반 0건 · 경고 0건**

### ★ 나는 데는 **연료**가 든다 — 그것이 매듭을 푼다

경공을 신법(민첩) 하나에 매달면 **경공 몰빵이 정답**이 된다. 그래서 매달지 않았다:
**크기는 민첩이 사고, 지속은 내공이 산다.**

```
[절정 · 수련 예산 1800일치]
  신법 몰빵   민첩 7.0 · 내력  1  →  체공  3.0초 · 거리  19m · 낙법 12m
  내공 몰빵   민첩 3.0 · 내력 10  →  체공 10.0초 · 거리  60m · 낙법  6m
  균형        민첩 4.0 · 내력  4  →  체공  4.0초 · 거리  25m · 낙법  8m
```

> ✅ **가장 빠른 몸과 가장 오래 나는 몸이 다른 사람이다.**
> 세 축(체공·속도·높이) 중 어느 빌드도 **셋을 다 먹지 못한다** (신법 2/3 · 내공 1/3 — 상한 2).

### 그리고 경공은 **전투 자원을 먹는다**

```
내력 1 = 발경 1회  ·  검기 발출 1/3회  ·  경공 1.0초   ← 셋은 같은 단전에서 나온다
```

`internal_energy.yml` 의 **조식**이 이 규칙을 완성한다: *"내력을 쓴 합에는 단전이 돌지 않는다."*
→ **경공을 켜 둔 자는 숨을 고르지 못한다.** 담을 넘은 자는 그 합에 발경을 못 싣는다.
**쿨다운이 아니라 경합으로 과금한다** — 이 프로젝트의 문법 그대로다.

### 떨어지면 아프다 (연출이 아니라 규칙이다)

```
경지   다니던 높이   내구   기가 돌면        고갈이면
일류    20.0m        22     7.0            17.0  (내구의 77%)
절정    20.0m        26     5.0            17.0  (내구의 65%)
초절정  22.5m        30     5.5            19.5  (내구의 65%)
화경    26.7m        34     7.7            23.7  (내구의 70%)
현경    30.0m        38     9.0            27.0  (내구의 71%)
생사경  33.2m        40    10.2            30.2  (내구의 76%)
```

전 경지에서 **내구의 50% 이상** — `combat.yml wound_thresholds.경상`(50%)을 한 번에 넘긴다.
**공중에서 내력이 끊기는 것은 죽음에 가깝다.**

## 4. 도구가 나를 세 번 고쳤다 (기록해 둔다)

성장 축 담당이 남긴 문장 그대로다 — *"검수의 눈이 거짓말하면 루프가 헛돈다."*

1. **`lint ③` — 천장이 장식이었다.** 처음엔 낙법 천장을 8→**48m** 로 크게 잡았다. 그런데
   **신법을 캡까지 몰아도 그 천장에 못 닿았다** (화경 캡 9 × 1.6 = 14.4 < 24).
   즉 *"경지가 천장을 열고 수련이 그 천장까지 자란다"* 는 내 문장이 **내 config 안에서 거짓**이었다.
   → 천장을 **수련이 닿는 곳**으로 내렸다. 그리고 그것이 옳다: **공짜로 사는 높이는 경지가 주고,
   그 위는 내력이 산다** (내력 1 = 4m — 화경의 단전은 84m 를 살 수 있다).
2. **`game_audit` — `on:`/`off:` 가 불리언이었다.** `messages.on` 을 무따옴표로 썼더니 YAML 1.1 이
   **`True`/`False`** 로 읽었다. SnakeYAML(엔진)도 똑같이 읽으므로 `message("on")` 조회가
   **조용히 실패**했을 것이다 — 화면이 아무 말도 안 하는 버그. 따옴표로 고쳤다.
3. **`고갈 낙하` 검사 — 내가 눈을 속이려 했다.** 절벽(20m) 하나로 재니 현경(내구 38)이 45% 로
   계약을 깼다. 나는 **낙하 배율을 새로 지어내려** 했다. 그건 세계를 고치는 게 아니라 **눈을 속이는
   것**이었다 — 현경은 20m 절벽에서 떨어지지 않는다. **자기가 오른 높이**에서 떨어진다.
   → 측정을 고쳤다(`max(절벽, 낙법 천장 + 도약 + 벽)`). **높이 나는 자가 더 크게 떨어진다.**

## 5. ★ 지어낸 것의 장부 (없는 것을 있다고 하지 않기 위해)

| 지어낸 것 | 근거 / 정도 |
|---|---|
| **`config/gyeonggong.yml` 전체 수치** (천장·눈금·코스트) | ★지어냄. 다만 **코스트는 `internal_energy.yml cost_bands.경신 [1,2]` 안**에 갇혀 있고(린트), **천장은 `attribute_cap_by_realm` 이 정한 민첩 캡이 닿는 곳**에 맞췄다. 자유롭게 고른 값이 아니라 **기존 등록부가 조인 값**이다 |
| **'답설무흔'을 모드 이름으로 씀** | ★지어냄 — 일반 무협 용어(브리프가 쓴 말)다. **문파 무공이 아니다.** `skills.yml` 에 등록하지 않았다 (무공 등록부를 오염시키지 않는다) |
| **벽 딛기 = 수직 보법 보유자만** | 반쯤 지어냄. `skill_mechanics.yml jewoon_jong.vertical: true` (*"무당의 지문 — 수직 이동(벽·나무)"*)·`dabun_jong.vertical: true` 를 **그대로 게이트로 썼다** |
| **수상비 = 초절정+** | ★지어냄. 어떤 config 도 수상비를 말한 적이 없다 — **경지 사다리 위의 새 자리**다 |
| **바닐라 흉갑 → 갑 계열 매핑** (`armor_gate.by_chestplate`) | ★지어냄 (철=철갑, 가죽=무복 …). MVT 에 **방어구 착용 체계가 없어서** 필요했다. 이것이 없으면 `경공_불가` 는 영원히 문서로만 존재한다 |
| **`mc:` 절 (0.2 / 0.42 / 1.25 / 3 / 5.6)** | 지어낸 것이 **아니다** — **마인크래프트가 정한 상수**다. 코드가 갖지 않게 등록부에 적어 두었다 |
| **심법 결(`simbeop_effects`)** | 지어낸 것이 **아니다** — `simbeop.yml` 의 **프로즈를 기계 키로 옮긴 번역**이다 (`qi_profile.연비` · `passive`). **감사가 원문과 대조해 어긋남을 잡는다** (lint ⑤) |
| **보법 목록·거리·수직·변칙** | 지어낸 것이 **아니다** — `skills.yml` + `skill_mechanics.yml` 을 **런타임에 읽는다**. 코드에도 config 에도 **목록을 복제하지 않았다** (감사가 복제를 잡는다) |

## 6. 배선 (담당자용)

| 파일 | 상태 |
|---|---|
| `config/gyeonggong.yml` | ✅ 신규 — 등록부 |
| `config/performance.yml` | ✅ `metrics.probes.gyeonggong → effect_ticker` **한 줄만** 더했다 (재는 자) |
| `server-mvt/.../Gyeonggong.java` | ✅ 신규 — 등록부·산술 (수치 0개) |
| `server-mvt/.../GyeonggongListener.java` | ✅ 신규 — 몸·중앙 티커 1개·파티클 |
| `tools/gyeonggong_audit.py` | ✅ 신규 — 위반 0 · 경고 0 |
| **`HoncheonMvt.java`** | ⛔ **배선 필요** — `Gyeonggong.init(cfg)` · 리스너 등록 · `start()` · `shutdown()` |
| **`SkillListener.java`** | ⛔ (권장) 회피 판정에 `gyeonggongMastery` — 그러면 `combat.yml` 의 *"민첩 + 경공"* 이 **처음으로 참**이 된다 |
| **`MvtCommand.java`** | ⛔ (권장) `/혼천 경공` — 이 몸이 무엇을 할 수 있는지 화면이 말한다 |

배선 코드는 보고서에 그대로 적어 두었다.

### 남은 구멍 (내가 못 한 것)

* **방어구 감쇄(`armor.mitigation`)는 여전히 미구현이다.** `gap_audit §3-①` 의 세 덩어리 중
  **경공·회피(경공 쪽)** 는 섰지만, **피해 파이프라인의 감쇄**는 `SkillListener` 의 것이다 (내 파일이 아니다).
  갑옷은 이제 **경공을 팔지만**, 아직 **경감을 주지 않는다** — 즉 지금 갑옷은 **손해만 본다.**
  감쇄를 배선하기 전에는 아무도 갑옷을 입지 않을 것이고, 그러면 `경공_불가` 게이트도 사실상 잠자는 규칙이다.
* **회피 분기 자체가 없다** (`SkillListener.defend()` 는 호신강기·패링·태극반격만 안다).
  `retreat()` 는 **피해가 취소되는 순간**에 스스로 붙도록(`MONITOR`) 만들어 두었다 —
  회피가 서는 날 **저절로 살아난다.** 그때까지는 조용하다.
* **도주(`combat.yml escape`)·추격**에 경공을 걸지 않았다. `민첩+도주 vs 감각+추적` 은 판정 층이고,
  그 판정은 내 파일이 아니다. 지금 경공이 주는 것은 **실제 이동 속도**뿐이다 (그것으로 충분히 도망칠 수 있다).
