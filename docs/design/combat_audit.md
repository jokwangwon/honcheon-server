# 전투 감사 (combat_audit)

무공·전투에는 검수 도구가 없었다. 맵에는 `/혼천 검수`, 리소스팩에는 `texture_audit.py`,
게임 시스템에는 `game_audit.py` — 그 셋과 같은 자리에 놓는 네 번째 자다.

    python3 tools/combat_audit.py                # 전체
    python3 tools/combat_audit.py --lint-only    # ① 정합 린트만
    python3 tools/combat_audit.py --sim-only     # ② 전투 시뮬만
    python3 tools/combat_audit.py --rounds 30    # TTK 상한 합 수 (기본 25)

외부 라이브러리 없음. `game_audit.py` 의 YAML 서브셋 파서·`Report` 를 그대로 계승한다.
**config 를 고치지 않는다 — 재기만 한다.** 위반(❌) 1건 이상이면 종료 코드 1.

## ① 전투 정합 린트

| 검사 | 묻는 것 |
| --- | --- |
| 무공 참조 | 요구 경지·등급·능력치가 등록부에 실재하는가. 등급 → 무공 위력, 계열 → 무기 위력 대응이 있는가 |
| 격 게이트 | 무공의 시전 코스트가 요구 경지의 `realm_gates` 에서 **실제로 열려 있는가** |
| 내력 수지 | 그 경지의 내력 풀(`round(내공×3)`)로 그 무공을 몇 번 쓰는가. 0회면 ❌ |
| 액션 데이터 | 프레임·경직·쿨다운이 정의된 무공과 안 된 무공 |
| 격 사다리 | `qi_manifestation` ↔ `internal_energy` ↔ `ultimate_arts` 의 경지 게이트 일치 |
| 무기 파괴 | 감당 격이 두 정본(`qi_manifestation`·`equipment`)에서 같은가 |
| NPC·짐승 | 전의(morale)가 수치 축을 갖는가. 짐승에게 스탯이 있는가 |

무공에는 **'요구 격' 필드가 없다.** 도구는 액션 코스트로 격을 역추정한다
(cost 0 = 외공기 / cost>0 = 내력 소모 = 개화 이후). 이 역추정 자체가 첫 번째 결함의 증거다.

## ② 전투 시뮬 — 해석적

2d6은 36가지뿐이다. **몬테카를로를 쓰지 않는다.** 마진 분포를 `Fraction` 으로 전개해
명중률·기대 피해를 정확히 계산하고, 라운드마다 기대 내구를 깎아 TTK를 구한다.

- **TTK**: 삼류 vs 늑대 / 이류 vs 도적 / 일류 vs 맹수 / 절정 vs 절정
- **내력 곡선**: 발경 지속 합수, 고갈 후 다운캐스트로 싸울 수 있는가
- **격 상성**: 발경·검기·강기가 피해에 몇 % 기여하는가. 호신강기 앞의 하위 격
- **무기 등급**: 판정 보정(0~1) vs 무기 파괴(감당 격)
- **협공**: 인원별 총 피해와 캡의 실효. 산길 도적 5인 매복
- **죽은 선택지**: 코스트 대비 이득이 0이거나 시전 불가한 무공

### 판정 기준

| 기준 | ❌ |
| --- | --- |
| TTK | 3합 미만(전투가 없다) / 20합 초과(지루하다) |
| 내력 | 2합 안에 고갈 (자원 관리가 아니라 형벌) |
| 무기 등급·격 상성 | 결과에 5% 미만 영향 (장식이다) |
| 무공 | 코스트 대비 이득이 하위 호환 (죽은 선택지) |

## 도구의 한계

- **부상 단계·대성공의 급소 효과를 피해로 환산하지 않는다.** 마진 ≥ 0 에서만 피해가 나고,
  부분 성공(−3~−1)은 피해 0으로 본다. `critical: 부상 단계 즉시 +1` 은 계산에 안 들어간다.
- **방어구 `mitigation` 이 피해 공식에 들어갈 자리가 없다** (부상 등급 완화로만 표현됨) → 무시한다.
- **짐승 스탯이 config 에 없다.** 늑대·맹수는 경지 상당치(`attribute_cap_by_realm − 1`,
  `cultivation` 승급 요건의 숙련)로 대체 계산한다 — 표에 `대체치`로 표기된다.
- **일류급 무공 위력이 `combat.yml` 에 없다.** 대체값 2 를 쓰고 그 사실을 경고로 남긴다.
- 라운드는 선공 → 후공 순차. 회피·가드·패링·프레임은 **전투 라운드 모델에 반영하지 않는다**
  (`skill_mechanics` 는 틱 단위 액션층, `combat.yml` 은 합 단위 판정층 — 두 층은 아직 접합되지 않았다).
- PvP(양측 2d6)는 근사한다. 대립 판정의 정본은 `judgment.yml pvp.direct_opposed`.
