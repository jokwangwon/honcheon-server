# 캐릭터 생성 및 초기 능력치 설계

> 기준 기획 문서 5장(플레이어 시작), 6장(성장 시스템)을 수치로 구체화한 문서.
> 판정에서의 사용법은 `docs/design/judgment_system.md`, 기계 판독용 데이터는 `config/player_creation.yml` 참조.
> 기획서 23장 보완 과제 1번("플레이어 초기 능력치가 아직 구체적이지 않다")에 대한 답.

## 1. 생성 흐름

```text
1. 성향 테스트 또는 직접 선택  → 성향 유형 결정 (추천일 뿐, 강제 아님)
2. 시작 신분 선택             → 시작 위치, 초기 기술, 초기 관계, 초기 소지품
3. 능력치 배분                → 기본 2 + 자유 배분 6포인트
4. 초기 목표 선언             → 길라잡이 시스템의 입력값
```

성향 테스트는 배정 장치가 아니다. 추천 프리셋을 보여주되 플레이어는 전부 무시하고 직접 배분할 수 있다.

## 2. 능력치 배분 규칙

```text
기본치:     모든 능력치 2 (평범한 백성 수준)
배분 포인트: 6
생성 시 상한: 4  (삼류 무인의 한계. 이후 경지 상승·수련으로 돌파)
생성 시 하한: 1  (1포인트를 깎아 다른 곳에 쓸 수 있다. 최대 2회)
```

- 합계 기대값: 2×7 + 6 = 20.
- 상한 4는 "생성 직후엔 숙련 NPC(4~5)와 대등한 축이 하나쯤"을 의미한다. 시작부터 고수는 없다.

## 3. 성향별 추천 프리셋 (7종)

| 성향 | 추천 배분 (근/민/체/내/감/화/지) | 추천 시작 신분 | 어울리는 루트 |
|------|----------------------------------|----------------|----------------|
| 협의형 | 3/3/3/3/3/3/2 | 낭인 지망생, 문파 지원자 | 정파, 협객, 화산파, 소림사, 관군 협력 |
| 생존형 | 2/3/4/2/4/2/3 | 고아 출신 부랑객, 낭인 | 개방, 사파 접촉, 정보상, 은거 전승 |
| 야망형 | 4/3/3/3/2/3/2 | 몰락 세가 자제, 낭인 | 세가 재건, 문파 권력, 사파 두각 |
| 자유형 | 3/4/3/2/3/3/2 | 떠돌이 표사, 유랑 예인 | 낭인, 표국, 유람 |
| 탐구형 | 2/2/3/3/3/2/5* | 의원 제자, 서생 | 제갈세가, 무당파, 의원, 약왕곡 |
| 은밀형 | 2/4/2/2/4/3/3 | 하오문 말단, 도망자 | 하오문, 살막, 사천당가, 히든 루트 |
| 이익형 | 2/3/3/2/3/4/3 | 상단 견습, 장사꾼 | 상단, 정보상, 중개인 |

\* 탐구형의 지혜 5는 하한 규칙(다른 능력치 1을 2회 감소)을 사용한 예시.

**첫 10턴 테스트 기준 플레이어** = 협의형 프리셋 + 낭인 지망생 신분. 판정 검증(judgment_system.md 8장)은 이 수치를 쓴다.

## 4. 시작 신분

시작 신분은 직업이 아니라 **출발점**이다. 초기 기술, 초기 관계, 초기 소지품, 시작 소문을 정한다.

| 신분 | 초기 기술 (2/1/1) | 시작 위치 | 초기 관계·비고 |
|------|-------------------|-----------|----------------|
| 낭인 지망생 | 조사2, 은신1, 추적1 | 청하현 | 무소속. 무엇이든 될 수 있는 백지 |
| 문파 지원자 | 교섭2, 조사1, 호위1 | 청하현 의뢰소 인근 | 소연과 안면. 문파 직행 루트 열림 |
| 고아 출신 부랑객 | 은신2, 정보수집1, 도주1 | 청하현 뒷골목 | 민간 하층 소문망 접근 |
| 몰락 세가 자제 | 교섭2, 검법1, 조사1 | 청하현 | 가문의 이름값 (양날: 명성이자 표적) |
| 떠돌이 표사 | 호위2, 추적1, 도주1 | 북쪽 산길 방면 | 곽진과 구면 (신뢰 0이지만 안면) |
| 의원 제자 | 의술2, 조사1, 교섭1 | 약재상/의원 | 유문과 사제 관계. 열병 사건 최근접 |
| 하오문 말단 | 정보수집2, 은신1, 교섭1 | 청하객잔 인근 | 묵삼의 존재를 이미 안다 (양날) |
| 상단 견습 | 상술2, 교섭1, 조사1 | 상단 숙소 | 상단 내부 정보 접근, 곽진과 동료 |

## 5. 성장 연결 (기획서 6장과의 접합)

- **신체 성장**: 능력치는 수련(개인 시간 소모) + 실전 + 경지 돌파로 오른다. 경지별 능력치 상한: 삼류 4 / 이류 5 / 일류 6 / 절정 7 / 초절정 8 / 화경 9 / 현경·생사경 10.
- **무공 성장**: 기술·무공 숙련은 사용과 수련으로 오른다. 무공 습득 조건은 `config/skills.yml`의 카탈로그를 따른다.
- **사회적 성장**: 명성/악명, NPC 신뢰·경계, 세력 관계. 판정 보정(심리 상태, 의심도)으로 되먹임된다.
- **세계 영향 성장**: 지역 상태(치안/경제/민심) 변화와 소문. 능력치가 아니라 세계 쪽에 기록된다.

네 축 중 판정식에 직접 들어가는 것은 신체(능력치)와 무공(기술)이고, 사회적 성장은 NPC 측 보정으로, 세계 영향은 지역 상태와 사건 단계로 들어간다. **네 축 모두가 수치 시스템에 접점을 가진다.**
