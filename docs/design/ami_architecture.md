## 세력의 결
- **여성 중심 문파** — 작품에 따라 남성 제자도 있지만 **비구니와 여협이 중심**
- **검법과 경공** — 부드럽고 우아하되 **빠르고 예리한** 검술
- **강유병제(剛柔竝濟)** — 겉은 유연하고 섬세하나 **순간적으로 강한 힘을 폭발**시킨다
- **불교적 규율** — 금욕·절제·문파의 명예. 세속적 욕망에 엄격
- **장문인** — 온화한 수도자형도 있으나 무협에서는 **원칙적이고 자존심 강한 여성 장문인**

## 원형: 「운해 비구니원」 — 산악형 비구니 사찰군
불문 계열이므로 **사찰의 문법**을 쓰되, **소림의 웅장한 대가람과 명확히 구별한다.**
거대한 단일 사찰이 아니라, **안개 짙은 산허리의 좁은 지형을 따라 여러 수행원이 층층이 이어지는** 구조.

### 핵심 인상
- 화려하지 않고 **정갈하다**
- 외부에는 **닫혀 있고** 내부에는 **넓은 수련 마당이 숨어 있다**
- 건축이 **산을 누르지 않고** 산비탈과 절벽선을 **따라 올라간다**
- 장식보다 **반복되는 기둥·회랑·처마선과 빈 공간**으로 질서를 표현
- 소림의 '강대한 불문'이 아니라 아미의 **'고요하고 날카로운 불문'**

### 재료와 색
| | |
|---|---|
| 벽 | 회백색 또는 옅은 회황색 **회벽** |
| 지붕 | 짙은 회색 기와 |
| 목재 | 채도 낮은 **적갈색·암갈색** |
| 기단 | 현지 산석을 다듬은 **회색 석축** |
| 장식색 | 탁한 청록 또는 옅은 옥색을 **극소량** |
| 최소화 | 금색 · 선명한 주홍 · 대형 불상 장식 |

> 멀리서 보면 **흰 벽과 검은 지붕이 안개 사이에서 층층이 드러나는 모습**이 대표 실루엣이다.

### 배치 — 산 아래에서 정상으로
1. **청심문** — 규모가 작은 산문. 위압적인 사천왕상·거대한 홍문 **없음**. 문을 통과해도 **내부가 한눈에 안 보이도록 꺾인 길**
2. **접객원** — 외부인·속가제자. **중심부와 직접 연결되지 않는다.** 낮은 객당·약방·차를 내는 작은 누각
3. **수행원** — 비구니 제자들의 생활 중심. 선방·경당·식당·침방을 **작은 중정 주변**에. 건물 사이를 **비와 안개를 피하는 좁은 회랑**으로
4. **연검대** — ★ **아미의 대표 공간.** 절벽/운해가 내려다보이는 넓은 목제·석제 수련대. **기둥·장식물을 적게** 두어 검술 동작이 선명하게. 바닥에 **원형이 아니라 길고 흐르는 검로(劍路) 문양**을 얕게 새긴다
5. **장문원** — 가장 높은 곳의 **폐쇄적인 작은 원**. 처소·비전 무공각·회의실. **크기는 작지만 산문 전체를 내려다보아 권위를 만든다**
6. **사리암 / 금정별원** — 정상 부근의 **단독 수행처**. 일반 제자 접근 어려움. 주요 퀘스트·장문인 수행·비급 보관·최종 시험 장소

### 아미만의 요소
- 백벽 위 **가늘고 긴 세로 창**
- 처마 아래 작은 **풍경(風磬)과 목패**
- 대형 종루 대신 **작은 범종각**
- 빗물·산수를 모으는 **얕은 석수로**
- **대나무 · 매화 · 약초밭**
- 절벽을 잇는 **가느다란 석계단과 목제 회랑**
- 검을 씻고 마음을 가라앉히는 작은 **세검지(洗劍池)**
- 수련장 주변에 늘어뜨린 **얇은 천막 / 경문 천**

| 문파 | 그들 | 아미 |
|---|---|---|
| 소림 | 거대한 축선 · 웅장한 전각 | **작고 세밀한 다층 수행원** |
| 종남 | 흩어진 은둔 암자 | **규율 있게 연결된 공동체형 사찰** |
| 무당·화산 | 도교적 전각·도관 | **불교적 선방·경당** |
| 곤륜 | 무겁고 폐쇄적인 석조 | **흰 벽 · 목조 회랑 · 열린 절벽 수련대** |
| 해남 | 해안의 개방적 목조 검문 | **안개 낀 산악의 폐쇄적 검원** |

### ★ 조성 원칙 (가장 중요)
> **'여성적 장식'을 많이 붙여 표현하지 않는다.**
> **분홍색 · 꽃문양 · 과도한 곡선으로 여성 문파를 묘사하는 방식을 피한다.**
> 대신 **청결함 · 절제 · 정돈된 반복 · 가느다란 구조선 · 조용한 공간 속의 날카로운 검술**로 정체성을 표현한다.
