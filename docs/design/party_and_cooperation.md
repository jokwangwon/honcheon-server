# 동행(同行)과 협동 — 파티 규칙

> 마지막 백로그: 파티 결성·협력 판정·협공·분배·배신.
> 원칙: 파티는 편의 기능이 아니라 **관계다** — 세계는 무리를 하나의 소문 주체로 본다.
> 기계 판독용: `config/party.yml`

---

## 0. 전제 — 동행은 출도 이후의 것

서장(개인 시간축 샌드박스)에서는 파티가 성립하지 않는다 — 시계가 다르기 때문이다.
**출도해 공유 세계의 단일 달력에 합류한 자들만 동행할 수 있다** (시간축 모델과 정합).

## 1. 동행의 형태 — 셋의 층위

```text
동행(同行)   느슨한 무리 — 선언만으로 성립, 언제든 해산. 기본 형태 (상한 5인)
결의(結義)   의형제·자매 — 의식(등록 이벤트) + 상호 서약. 배신 시 '배의(背義)' 소문
            (결의는 favor가 아니라 낙인이다 — 깨는 순간 세계가 기억한다)
사제(師弟)   플레이어 간 사사 — training 규칙 그대로 (스승 기술이 높으면 성립,
            효율 1.0 + 스승 경지 2단 우위 시 1.2) — 가르침도 플레이다
5인 초과의 무리는 파티가 아니라 '세력'의 영역 (표국·문파 규칙으로)
```

## 2. 협력 판정 — 함께 굴리는 법

```text
① 조력 판정 (한 명이 하고 나머지가 돕는다) — 기본형
   대표 1인이 판정. 해당 기술 1+ 보유 조력자당 +1 (상한 +2, 상황보정 캡 ±5 내 계상)
   무기술 조력자는 보정 없이 리스크만 공유한다 ("도우려다 밟은 나뭇가지")
② 전원형 판정 (전원이 성공해야 한다 — 은신·잠입·도주)
   판정 1회, 실행력 = 최약자 기준. 4인 이상은 추가로 -1
   — 무리는 가장 서툰 발소리만큼 조용하다 (혼자가 유리한 일이 존재해야 한다)
③ 분담 판정 (동시에 다른 일을) — 각자 판정, 같은 구간 소모
   "네가 망을 봐라, 내가 딴다" — 실패는 각자의 것, 결과는 모두의 것
```

## 3. 협공 — 그리고 합격진(合擊陣)

```text
협공 보정: 같은 대상 공격 인원당 +1 (상한 +3) — npc_vs_npc 협공과 동일 문법
포위: 퇴로 차단 시 대상 도주 판정 -2
합격진(등록제 무공): 훈련된 협공 — 같은 진법을 숙련한 동행끼리만
  예: 매화검진(화산 — 2~5인, 협공 상한 +3→+5, 진 붕괴 조건: 1인 무력화)
  진법은 무공이다: 습득(사사 — 문파 비전)·숙련·경지 게이트 전부 카탈로그 규칙
  진 상대 규칙: 진을 아는 자(견식)는 '진 눈(眼)'을 노릴 수 있다 — 파훼 판정
MC: 협공 보정은 서버가 근접 아군 수로 자동 계상 / 합격진은 파티 스킬 슬롯 (진주창 발동)
```

## 4. 시간과 이동 — 파티의 시계

```text
같은 장면의 동행 = 같은 시계 (구간 동기화 — 가장 느린 행동 기준)
텍스트 턴: 장면 단위 선언 라운드 (선언 순서 자유, 해소는 엔진 일괄)
흩어지면: 개인 구간으로 분리 — 재합류는 약속 장소·시점 선언 ("해질녘 객잔에서")
  분리 중 사건은 각자 진행된다 — 세계는 기다려주지 않는다 (deadline 규칙 그대로)
```

## 5. 분배 — 성장·공적·전리품

```text
성장: 분배 없음 — 무경험치 설계의 우아한 귀결. 화후는 각자 쓴 무공에 쌓인다
     (검을 휘두른 자에게 검이, 망을 본 자에게 감각이 — 버스는 원리적으로 불가능:
      압도적 하수 ×0 규칙은 파티에도 그대로, 고수 옆 저격은 배움이 없다)
마크: 개별 기여 기준 — 사선 마크는 실제로 사선에 섰던 자의 것
공적·favor: 세력이 본 대로 — 대표로 나선 자에게 크게, 동행에게 나머지
           (누가 나서서 보고하는가 자체가 파티 내 선택이다)
전리품: 시스템 분배 없음 — 협의가 원칙, 다툼은 그대로 플레이 (아래 6장)
명성: 무리 자체가 소문 주체가 된다 — "그 삼인조" (파티 별호 = 등록 명명)
```

## 6. 배신 — 시스템은 금지하지 않는다, 세계가 청구한다

```text
동행 중 공격(PvP)·전리품 독식·정보 팔아넘김: 전부 가능하다
대가: ① 목격·생존자 경유 소문 (기습-비열 행위와 동일 문법)
     ② 결의 위반은 '배의' 낙인 — 정파 favor 하락, 결의 문화권 NPC 저항 +2
     ③ 개입 기록 — 배신당한 플레이어의 생애·favor 회수 루프는 NPC와 동형
비무(比武): 동행 내 겨룸은 '비무 선언'으로 보호 — 사선 아님, 부상 경상 상한
MC: PvP는 상시 가능(공유 세계) — 단 안전 지역(관아·문파 내부)은 예외 (location_safety)
```

## 7. MC 매핑

```text
파티 UI: 탭리스트 그룹핑 + 사이드바 동행 상태 (내구·원기 요약 — 파티원만)
프렌들리 파이어: 파티원 스킬 피해 기본 면제 / 오의·광역은 예외 (긴장 유지 —
              "매화만개 앞에서는 아군도 물러선다")
합격진: 파티 스킬 슬롯 — 진주(리더) 발동, 성원 위치 조건 충족 시 활성
초대/해산: 채팅 명령 + GUI, 결의는 의식 장소 필요 (등록 이벤트)
```

## 8. 접합

```text
시간축(서장·출도) — 동행은 출도 이후만 / judgment 캡 — 조력 보정 계상
npc_vs_npc 협공 문법 재사용 / skills.yml — 합격진은 무공 카탈로그 등록
training — 플레이어 간 사사 / rumor·faction — 파티 단위 소문 주체·비열 행위 청구
cultivation combat_hwahu — 압도적 하수 ×0 = 버스 원천 차단
```
