# 판정 수치 계산 시스템

> 기준 기획 문서 8장(판정 시스템)의 원칙을 실제 수치 계산식으로 구체화한 문서.
> 기계 판독용 데이터는 `config/judgment.yml` 참조.

## 0. 설계 원칙 (기획서 8장 계승)

1. 판정은 모든 행동에 적용하지 않는다. **실패 가능성, 위험, 상대 저항, 숨겨진 정보**가 있을 때만 사용한다.
2. 판정은 고정 난이도가 아니다. 같은 행동이라도 플레이어 상태, 준비도, 정보량, 환경, NPC 능력치, NPC 경계도에 따라 달라진다.
3. 수치는 내부 처리용이다. 플레이어 출력에는 수치와 플래그를 과하게 노출하지 않는다 (기획서 17장).
4. 성공에도 긴장감이 있어야 한다 — 등급제 결과(아슬아슬한 성공, 부분 성공)로 구현한다.

## 1. 수치 스케일

### 1.1 기본 능력치 (1~10)

| 능력치 | 한자 | 관장 영역 |
|--------|------|-----------|
| 근력 | 力 | 타격력, 완력, 무거운 무기 |
| 민첩 | 敏 | 속도, 회피, 손재주, 경공 |
| 체력 | 體 | 지구력, 부상 저항, 연속 전투 |
| 내공 | 內 | 축적된 진기. 무공 위력과 지속력 |
| 감각 | 感 | 관찰, 위기 감지, 기척 읽기 |
| 화술 | 辯 | 설득, 교섭, 거짓말, 떠보기 |
| 지혜 | 智 | 추리, 학식, 의술·독술의 기반 |

수치 감각 기준:

```text
1     범인 이하
2     평범한 백성
3     훈련받은 사람 (병졸, 낭인)
4~5   숙련자 (노련한 호위, 하오문 요원)
6~7   고수 (일류~절정 무인의 주 능력치)
8~10  절대고수의 영역
```

### 1.2 기술 (0~10)

능력치와 별개로, 훈련으로 익힌 전문성. NPC 능력치 표기(`미행_감지`, `호위_전술` 등)와 같은 층위다.

```text
일반 기술: 은신, 추적, 조사, 정보수집, 교섭, 잠입, 도주, 의술, 독술, 호위, 상술
무공 숙련: 검법, 도법, 경공, 심법 등 — 무공 카탈로그(config/skills.yml)의 숙련도와 연동
```

### 1.3 NPC 동적 상태 (0~5)

- **경계도(alertness)**: 주변 전반에 대한 긴장 수준. 저항값에 그대로 가산.
- **의심도(suspicion)**: 특정 대상(플레이어)을 향한 의심. 그 대상의 행동에 대해서만 가산.

## 2. 판정 계산식

### 2.1 대립 판정 (vs NPC)

```text
실행력 = 능력치 + 기술 + 상황 보정 합계 + 2d6
저항값 = NPC 능력치 + NPC 기술 + 경계도 + 의심도 + NPC 상태 보정 + 7

마진 = 실행력 − 저항값
```

- 플레이어만 주사위(2d6, 기대값 7)를 굴린다. NPC 쪽은 고정값 +7로 대체한다.
  → GM(LLM) 처리 단순화, 판정당 난수 1회.
- 어떤 능력치+기술 조합을 쓰는지는 4장의 행동-판정 대응표를 따른다.

### 2.2 비대립 판정 (환경/과제 난이도)

상대가 없는 행동(자물쇠, 험로 주파, 문헌 해독 등)은 저항값 대신 난이도 기준치를 쓴다.

```text
쉬움 10 / 보통 12 / 어려움 14 / 매우 어려움 16 / 극한 18
```

### 2.3 상황 보정 (합계 캡: ±5)

| 항목 | 범위 | 예시 |
|------|------|------|
| 준비도 | +1 ~ +2 | 사전 계획, 도구, 변장 |
| 정보량 | +1 (핵심 단서당, 최대 +2) | "묵삼", "내일 해 질 무렵" 같은 구체 단서 제시 |
| 환경 | −3 ~ +3 | 어둠·소음·군중은 은신에 +, 관찰에 −. 같은 환경이 행동에 따라 부호가 바뀐다 |
| 신체 상태 | −3 ~ 0 | 경상 −1, 중상 −2, 빈사 −3, 피로 −1, 내공 고갈 −2 |
| 경지 격차 | 단계당 ±2 | 무공이 개입하는 판정에만 적용 (전투, 기습, 경공 추격 등) |

### 2.4 NPC 상태 보정

| 항목 | 범위 | 예시 |
|------|------|------|
| 목적 집중 | −2 ~ 0 | 접선·이동 등 다른 일에 몰두 중이면 감지에 − |
| 심리 상태 | −2 ~ +2 | 보복 공포(한백의 사파 보복 우려)는 설득 저항에 +, 다급함은 − |

## 3. 결과 등급

| 마진 | 등급 | 처리 |
|------|------|------|
| +4 이상 | **대성공** | 목표 달성 + 추가 이득(보너스 단서, 흔적 없음, 관계 +2) |
| +2 ~ +3 | **성공** | 목표 달성 |
| 0 ~ +1 | **아슬아슬한 성공** | 목표 달성하되 부수 리스크 1개 발생 (의심도 +1, 흔적, 시간 소모, 소문 후보) |
| −1 ~ −3 | **부분 성공** | 목표 일부만 달성. 제한된 정보, 조건부 협조, 대가 요구 |
| −4 ~ −5 | **실패** | 목표 실패. 상황 악화 가능 (경계도 상승, 기회 소멸) |
| −6 이하 | **치명적 실패** | 즉각적 위험 (정체 노출, 전투 강제, 관계 붕괴, 소문 확정) |

### 3.0 문턱은 왜 이 자리인가 (2026-07 재설계)

**2d6은 36가지뿐이다.** 대등 판정(실행력 5 vs 저항 13)의 마진은 `2d6 − 8` — **−6에서 +4까지**가 전부다.
구판 문턱(대성공 +6 / 치명 −8)은 그 범위 **바깥**에 있었다. 6단 등급표를 만들어놓고 대등한 상대
앞에서는 4단만 굴렸고, 나머지 2단은 '선택 규칙'인 극단 주사위에만 매달려 있었다.

새 문턱을 마진 분포에 맞춰 다시 놓았다 (해석적 계산 — 몬테카를로 불요):

| 마진 | −6 | −5 | −4 | −3 | −2 | −1 | 0 | +1 | +2 | +3 | +4 |
|------|----|----|----|----|----|----|---|----|----|----|----|
| 가짓수 | 1 | 2 | 3 | 4 | 5 | 6 | 5 | 4 | 3 | 2 | 1 |

| 등급 | 마진 | 가짓수 | 대등 판정 확률 |
|------|------|--------|----------------|
| 대성공 | ≥ +4 | 1 | **2.8%** — 쌍륙(12) 그 자체 |
| 성공 | +2 ~ +3 | 5 | 13.9% |
| 아슬아슬한 성공 | 0 ~ +1 | 9 | 25.0% |
| 부분 성공 | −3 ~ −1 | 15 | 41.7% |
| 실패 | −5 ~ −4 | 5 | 13.9% |
| 치명적 실패 | ≤ −6 | 1 | **2.8%** — 뱀눈(2) 그 자체 |
| | | | 실패권(실패+치명) = **16.7%** |

- **대성공·치명적 실패가 드물지만 일어난다.** 대등한 상대 앞에서 쌍륙은 대성공이고 뱀눈은 파국이다.
- **준비가 값한다.** 준비도·정보 보정 +2가 붙으면 대성공은 2.8% → 16.7%로 뛴다.
- **격차가 파국을 낳는다.** 저항 14짜리 상대(마진 = 2d6 − 10)에게는 치명적 실패가 16.7%다.
- 극단 주사위는 이제 등급표의 **목발이 아니다**. 꺼도 6단이 전부 굴러간다.

선택 규칙(극단 주사위): 2d6이 2면 등급 1단계 하락, 12면 1단계 상승. 대립 판정에만 적용한다.
대등 판정에서는 무해하고(쌍륙 = 이미 대성공, 뱀눈 = 이미 치명), 격차 있는 판정에서만 물린다.

### 3.1 부수 리스크 목록 (아슬아슬한 성공용)

GM은 아래에서 상황에 맞는 것 1개를 고른다. 반드시 서사로 표현하고 수치는 노출하지 않는다.

```text
- 대상 NPC 의심도 +1          (예: 자갈 밟는 소리 — 턴 5)
- 제3자 목격 → 소문 후보 생성
- 물리적 흔적 (발자국, 떨어뜨린 물건)
- 시간 추가 소모 (다음 기회 상실)
- 자원 소모 (내공, 도구 파손)
```

## 4. 행동-판정 대응표

| 행동 | 플레이어 측 | NPC 저항 측 |
|------|-------------|-------------|
| 은신 / 잠복 관찰 | 감각 + 은신 | 감각 (+ 경계도) |
| 미행 | 감각 + 추적 | 감각 + 미행_감지 |
| 설득 / 정보 요청 | 화술 + 교섭 | 화술 또는 위험_회피 (심리 상태 보정) |
| 정보 캐기 (떠보기) | 화술 + 정보수집 | 감각 + 고객_파악 등 |
| 잠입 | 민첩 + 잠입 | 감각 + 경비 기술 |
| 엿듣기 | 감각 + 은신 | 내부 인물 감각 (+ 경계도) |
| 조사 (현장) | 감각 + 조사 | 비대립 난이도 |
| 기습 | 민첩 + 은신 (+ 무공, 경지 격차) | 감각 + 위협_감지 |
| 추적 (도주자) | 감각 + 추적 (+ 경공) | 민첩 + 도주 |
| 도주 | 민첩 + 도주 (+ 경공) | 감각 + 추적 |
| 치료 | 지혜 + 의술 | 비대립 난이도 (병세) |
| 증거 제시 설득 | 화술 + 교섭 + 정보량 보정 | 위협_감지 또는 의심 성향 |

## 5. 판정 생략 규칙

기대 마진 = (능력치 + 기술 + 보정) + 7 − 저항값 으로 먼저 어림한다.

- **기대 마진 ≥ +8** → 판정 생략, 자동 성공. "판정 없는 행동"으로 처리한다.
- **기대 마진 ≤ −8** → 자동 실패. 단, 바로 실패시키지 않고 GM이 서사로 무모함을 암시해 한 번 재고 기회를 준다. 플레이어가 강행하면 치명적 실패 위험을 안고 판정한다.
- 기획서 8장의 "판정 없는 행동"(단순 이동, 상점 이용, 안전한 대화, 확보한 정보 확인)은 이 계산 자체를 하지 않는다.

## 6. 재시도 규칙

- 같은 대상에게 같은 접근을 반복하면 저항값 +2 (경계 상승). 실패가 쌓이면 의심도도 오른다.
- **새로운 정보나 새로운 접근**을 가져오면 페널티 없이 새 판정으로 취급한다.
  (예: 한백에게 재차 캐묻기는 +2 페널티. 하지만 "묵삼의 창고 접선을 봤다"는 새 단서를 가져오면 새 판정)

## 7. 전투 판정 (개요)

전투는 라운드제 대립 판정의 연쇄로 처리한다. 상세 규칙은 후속 문서(`combat_system.md`)로 분리한다.

```text
공격 판정: 관련 능력치 + 무공 숙련 보정 + 경지 격차 vs 상대 회피/방어
피해     = 무공 기본 위력 + (마진 ÷ 2, 내림)
부상 단계: 경상(-1) → 중상(-2) → 빈사(-3)  # 상황 보정의 신체 상태와 연동
```

원칙: 전투도 "이긴다/진다"가 아니라 등급 결과를 쓴다. 아슬아슬한 승리는 부상을 남기고, 부분 성공은 격퇴는 했으나 도주를 허용하는 식이다.

## 8. 검증 — 첫 10턴 재계산

새 계산식이 기획서 18장의 첫 10턴 판정 결과를 재현하는지 검증한다.
플레이어는 `config/player_creation.yml`의 "협의형+무공형 낭인 지망생" 프리셋
(근력 3 / 민첩 3 / 체력 3 / 내공 3 / 감각 3 / 화술 3 / 지혜 2, 기술: 조사 2 / 은신 1 / 추적 1)을 쓴다.

| 턴 | 행동 | 실행력 계산 | 저항값 계산 | 마진 | 등급 | 기획서 결과 |
|----|------|-------------|-------------|------|------|-------------|
| 3 | 한백 설득 | 화술3 + 교섭0 + 조심스러운 접근+1 + 🎲7 = **11** | 위험_회피5 + 보복 공포+1 + 신뢰 낮음+1 + 7 = **14** | −3 | 부분 성공 | 부분 성공 ✓ |
| 4 | 야간 잠복 | 감각3 + 은신1 + 어둠+2, 단서("2층 손님")+1 + 🎲7 = **14** | 묵삼 감각4 + 의심0 + 접선 준비로 목적 집중−1 + 7 = **10** | +4 | 대성공 | 성공 ✓ (신 문턱에선 대성공 — 어둠+단서로 준비를 갖춘 잠복이 값을 받는다) |
| 5 | 묵삼 미행 | 감각3 + 추적1 + 어둠+1, 술집 소음+1 + 🎲9 = **15** | 감각4 + 미행_감지4 + 7 = **15** | 0 | 아슬아슬한 성공 → 부수 리스크: 의심도 +1 | 아슬아슬한 성공, suspicion +1 ✓ |
| 6 | 창고 조사 | 감각3 + 조사2 + 🎲9 = **14** | 비대립 · 보통 **12** | +2 | 성공 | 성공 ✓ |
| 7 | 엿듣기 | 감각3 + 은신1 + 엄폐(술독)+2 + 🎲8 = **14** | 내부 인물 감각3 + 경계1 + 7 = **11** | +3 | 성공 | 성공 ✓ |
| 8 | 곽진 설득 | 화술3 + 교섭0 + 핵심 단서 2개+2 + 🎲6 = **11** | 위협_감지3 + 낯선 이 의심+2 + 7 = **12** | −1 | 부분 성공 (신중한 신뢰) | 부분 성공 ✓ |
| 9 | 소연 설득 | 화술3 + 교섭0 + 핵심 단서 2개+2 + 🎲9 = **14** | 감각 상당(3) + 조심성+1 + 7 = **11** | +3 | 성공 | 성공/부분 성공 ✓ |

🎲 = 해당 턴의 2d6 결과. 모든 턴이 기획서의 서술 결과 범위 안에서 재현된다.

**검증에서 확인된 성질:**

1. 삼류 낭인은 숙련 NPC(합계 8 수준)를 상대로 보정 없이는 이기기 어렵다 → 준비·정보·환경을 만드는 플레이가 수치로 보상받는다.
2. 증거(정보량 보정)가 설득 판정을 실질적으로 좌우한다 → "구체적 단서를 제시하면 태도가 달라진다"는 곽진·소연 설계가 식으로 구현된다.
3. 마진 0 부근이 자주 나오는 밸런스라서, 성공에도 부수 리스크가 자연스럽게 붙는다.

## 9. 실패 분기 예시 (기획서 23장 보완 6번)

같은 첫 10턴에서 주사위가 나빴다면 어떻게 갈라지는지 정의한다. 실패는 게임 오버가 아니라 **다른 루트의 입구**여야 한다.

### 9.1 턴 5 실패 — 미행 발각 (마진 −4 ~ −5)

```text
묵삼이 모퉁이에서 걸음을 멈춘다. "…거기, 밤길이 심심한가?"

내부 처리:
- muksam.suspicion_toward_player: +3
- 접선 취소 → 창고 단서 루트 폐쇄 (이번 기회)
- 분기:
  a. 낭인 행세로 둘러대기  → 화술 판정 (묵삼 의심도가 저항에 가산)
  b. 도주                → 민첩+도주 vs 감각+추적
  c. 그 자리에서 제압 시도 → 전투. 성공해도 "증거 없는 폭행" 소문 후보
- 이후: 하오문에 "낯선 무인이 냄새를 맡는다" 보고 → 사파 반응 1→2단계
       역으로, 플레이어가 하오문의 접촉(회유/경고)을 받는 루트가 열림
```

### 9.2 턴 5 치명적 실패 (마진 −6 이하)

```text
- 묵삼이 플레이어의 얼굴을 확실히 기억한다 (suspicion 5)
- 그날 밤 접선이 앞당겨지고 창고가 비워진다 → 물증 루트 소멸
- 하오문이 플레이어 신원 조사 의뢰를 띄운다 → 세력 반응 2단계(정보 수집)로 직행
- 한백이 이를 전해 듣고 경계 → 객잔 정보 루트 위축
```

### 9.3 턴 8 실패 — 곽진이 경고를 무시 (마진 −4 이하)

```text
"낭인의 말 한마디로 호위 계획을 바꿀 수는 없네."

- 상단은 예정대로 출발 → 다음 날 해 질 무렵 습격 발생
- 지역 상태 변화: 치안 −5, 경제 −3 (지역 누적 시간에 기록)
- 그러나 폐쇄가 아니라 전환:
  a. 플레이어가 독자적으로 산길에 매복 → 구출전 (성공 시 곽진의 신뢰가 오히려 급상승)
  b. 습격 후 증거 수습 → 정파 보고 루트는 유지 (공적은 절반)
  c. 방관 → 소문: "청하현 산길에서 상단이 당했다" → 상단 세력 반응, 관군 개입
```

### 9.4 실패 분기 설계 규칙

```text
1. 실패는 루트 폐쇄가 아니라 루트 전환으로 처리한다.
2. 실패의 대가는 즉시 죽음이 아니라 의심도, 소문, 기회 상실, 지역 상태 악화로 지불한다.
3. 치명적 실패만이 되돌리기 어려운 흔적(정체 노출, 세력 반응 단계 점프)을 남긴다.
4. 실패 후 NPC는 그 실패를 기억 태그로 보존한다 (NPC 영속성).
```
