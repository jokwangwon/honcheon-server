# 내공 시스템 — 스킬 사용 기반 내공 운용과 선천진기(先天眞氣)

> 스킬 사용 관점에서 내공의 규칙을 명확화한다. 기존 뼈대(내력=내공×3, combat.yml)를
> 확장하여 기(氣)의 이중 구조 — 후천진기(자원)와 선천진기(근원) — 를 완성한다.
> 기계 판독용: `config/internal_energy.yml`

---

## 1. 기의 이중 구조

```text
후천진기 (後天眞氣) — 자원. 심법 수련으로 쌓고, 쓰고, 회복한다.
                    내공 능력치가 그릇의 깊이, 내력(내공×3)이 현재 잔량.
선천진기 (先天眞氣) — 근원. 태어날 때 지닌 유한한 기. 원칙적으로 회복 불가.
                    재능의 실체이자 목숨의 예비비. 태우면 돌아오지 않는다.
```

## 2. 선천진기 — 유한한 근원

### 2.1 총량과 나이 (유년 시작 설계와의 접합)

```text
시작 총량: 유년(8~12) 시작 = 7점 / 소년(13~15) 시작 = 6점
자연 유실: 약관(16세) 도달 시 -1, 이후 게임 10년마다 -1 (몸이 굳는다)
          단, 개화(2.2-a)를 마친 뒤에는 자연 유실이 멈춘다 — 단전이 근원을 붙잡는다
```

**이것이 문파가 아이를 거두는 이유의 수치적 실체다**: 어린 몸일수록 선천진기가 온전하고, 늦게 시작할수록 이미 새어나갔다. "무조건 어린 시작" 결정(age_and_lifepath v2)과 "은거 기인은 무공 백지를 선호한다"(백지의 역설)가 이 한 자원으로 통합된다.

### 2.2 사용처 — 4가지, 전부 되돌릴 수 없다

| 용도 | 소모 | 효과 | 비고 |
|------|------|------|------|
| a. **개화(開花)** | 심법 등급별 1~3 | 단전을 연다 — 심법 입문, 내공 성장 개시 (범인→삼류의 실체) | 좋은 심법일수록 소모가 적다. 취걸개의 심법 = 소모 1 |
| b. **파벽(破壁)** | 1 | 경지 승급 조건의 '깨달음' 재료 — 벽 앞에서 근원을 태워 길을 본다 | 절정 이상 승급마다 선택지로 등장 (필수는 아님 — 실전 깨달음으로 대체 가능) |
| c. **연혼일격(燃魂一擊)** | 1 | 전투 중 즉시: 이번 시전 1회를 경지 +1로 취급 (위력·경직 저항) | 대가: 사용 직후 **내상(중상 -2)** + 내력 전소. 목숨 건 마지막 수 |
| d. **회생(回生)** | 2 | 빈사에서 사망 위기 판정을 자동 통과 1회 | 죽지 않았을 뿐 — 빈사 상태는 유지 |

### 2.3 복원 — 예외 두 가지뿐

```text
대기연 영약: +1~2 복원 (지역권당 0~1개의 그 대기연 — 무림이 영약에 목숨 거는 이유)
벌모세수(伐毛洗髓): 화경 이상의 스승이 자신의 선천진기 1을 태워 제자에게 1을 준다
                  — 은원 상속의 극한 형태. 이 은혜는 평생의 종속을 만든다 (서사 장치)
```

## 3. 후천진기 — 스킬 사용의 실제 규칙

### 3.1 자원 정의 (기존 combat.yml 유지 + 명확화)

```text
내력(현재치) = 내공 능력치 × 3
회복: 자연 회복 = 심법 등급별 (구간당 0.5~2) — 전투 밖에서만
     운기조식 = 1구간 집중 시 내공×1 (기존) — 무방비 상태
     전투 중 회복 불가 (원칙 유지)
고갈: 내력 0 = '내공 고갈' 상태 (판정 -2) + 내공기 시전 불가
```

### 3.2 스킬의 내력 소모 밴드 — "무엇을 쓰면 얼마가 드는가"

| 밴드 | 소모 | 해당 스킬 | 예 |
|------|------|-----------|-----|
| 외공기 | 0 | 몸과 무기만 쓰는 기술 | 육합검 1·2타, 기본 회피 |
| 발경(發勁) | 1 | 타격에 내력을 싣는다 | 육합검 3타, 정심검결 태세 |
| 경신(輕身) | 1~2 | 보법·경공에 기를 두른다 | 매화보(2) |
| 검기(劍氣) | 2~3 | 기를 밖으로 발출 | 검기 참격, 제왕검형(4) |
| 강기(罡氣) | 4~6 | 발출한 기를 응집 | 화경급 기술 |
| 오의(奧義) | 전체의 50%+ | 별도 설계 | — |

### 3.3 경지 게이트 — 기 운용 단계

```text
삼류~이류: 외공기 + 발경 (내력을 몸 안에서만 굴린다)
일류:     경신 자유 + 발경 강화
절정:     검기 — 기가 처음으로 몸 밖에 나온다 (cultivation.yml "검기에 내력" 정합)
화경:     강기
현경+:    오의 상시, 창작 오의(생사경)
```

경지가 낮은데 상위 밴드 기술을 (비급 등으로) 알아도 **시전 자체가 잠긴다** — 아는 것과 굴리는 것은 다르다.

### 3.4 내력 부족 시 — 다운캐스트 규칙

내력이 모자라면 시전 불가가 아니라 **맨 기술로 나간다**:

```text
검기 참격(내력 3)을 내력 0으로 시전 → '맨 검' 버전:
  무공 위력 보정 상실, 특수 속성(경직 상향/관통) 상실, 프레임은 동일
→ 고갈 상태에서도 손은 멈추지 않지만, 검은 가벼워진다.
  (MC: 이펙트가 눈에 띄게 빈약해짐 — 상대도 고갈을 읽을 수 있다. 심리전 요소)
```

긴급 대체: 내력 부족분을 선천진기 1 연소로 메꿀 수 있다 (= 연혼일격 규칙 적용, 내상 동반). 시스템이 묻는다 — *"근원을 태우시겠습니까?"*

### 3.5 주화입마 (독학 리스크의 실체)

```text
스승 없는 심법 수련(training.yml 독학 0.5)의 위험 이벤트:
  운기 중 판정 실패 → 내상(중상) + 내력 전소 + 확률적 선천진기 -1
  심마(心魔): 금기 심법은 실패 시 성향 태그에 '심마' 흔적 — 히든 루트 재료
```

## 4. 텍스트 / MC 공용성

```text
텍스트 RPG: 내력·선천진기 전부 서사+내부 수치로 이미 굴러간다 (판정 보정, 선언 사용)
MC:        내력 = HUD 게이지 (경험치 바 또는 보스바 활용)
           선천진기 = 평시 비노출, 사용 가능한 순간에만 어두운 UI로 등장
           ("근원을 태우시겠습니까?" — 희소함을 UI 밀도로 표현)
다운캐스트·연혼일격·고갈 이펙트 강등은 파티클 예산 규칙(performance.yml)과 정합
```

## 5. 밸런스 확인 (기존 수치와의 정합)

```text
삼류 초입(내공 3): 내력 9 — 발경 9회 또는 매화보 4회. "몇 합이면 바닥"이 의도.
절정(내공 6~7):   내력 ~21 — 검기 7발. 고수전은 내력 관리전이 된다.
선천진기 6~7점:   일생 동안 개화(1~3) + 파벽 몇 번 + 비상금 1~2 — 늘 부족하게.
                 전부 아껴도 10회 미만: '언제 태울 것인가'가 인생 단위의 선택.
```
