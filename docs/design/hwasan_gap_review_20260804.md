# 레퍼런스 ↔ 실물 격차 대조 (2026-08-04)

> 사용자 지시: 「사진과 얼마나 비슷한지 확인하고 개선 방향 탐색」. codex 독립 검토(레퍼런스
> 1·8호 vs 실물 s18 2컷) + 조율자 판정 — 슬라이스 9~12 이후의 남은 격차.

## 한 줄

**레퍼런스의 풍부함은 디테일의 총량이 아니라 「자연 암반 → 축대 → 정원 → 회랑 → 본전」이
끊김 없이 이어지는 밀도 단계에서 나온다.** 우리는 그 사슬 중간이 비어 거대한 회색 옹벽 면이
남는다.

## 우선순위 5

1. **중앙 거대 회색 옹벽 → 3~5개 불규칙 테라스로 분해** (가장 큰 효과 — 산을 더 키우거나
   건물을 더 장식하는 것보다 이것이 먼저)
2. **10~30블록급 중간 요소 추가**: 측문·보조 계단·소회랑·정원·화단·난간 — 옹벽과 전각
   사이의 빈 스케일을 메운다
3. **따뜻한 구조별 팔레트 패스**: 돌·안산암·응회암 중심으로 회백을 덥히고, 구조 부위별로
   재료를 갈라 (기단/벽체/축대가 같은 회색이면 안 된다)
4. **나무 25~35% 덜어내고 재군집**: 고르게 흩뿌리지 말고 **능선·선반·균열·건물 모서리**를
   따라 모은다 (레퍼런스의 나무는 「자리」에 선다)
5. **본전 처마 확대 + 좌우 부속 전각 연결**: 처마 2~4블록 더 돌출 · 하층 지붕을 좌우 행랑으로
   이어 수평 실루엣 · 중앙 3칸 높이고 좌우 낮춰 위계 · 월대를 계단/화단/난간으로 세 구역화

## 부수 (그다음)

- 암봉 표면의 사선 반복 — 경사면 안에 2~5블록 돌출·함몰, 수직 균열, 비대칭화
- 촬영·조명 — 정오 대신 낮은 해, 처마 밑·회랑 뒤 암부 유지, 등롱을 면에 뿌리지 말고
  문·계단참·난간 모서리에 집중
