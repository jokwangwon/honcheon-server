# 기 발현(氣發現) 체계 — 검기 · 검강 · 호신강기 · 이기어검

> 질문: 검기/검강/강기/이기어검의 사용 방식과 전투 방식의 차이.
> 기존 소모 밴드(검기·강기)를 **형태(形) × 격(格)** 2축으로 세분한다.
> 기계 판독용: `config/qi_manifestation.yml`

---

## 1. 두 개의 축 — 형태와 격

```text
형태(形) — 기를 '어떻게' 쓰나:  두름 / 쏨 / 두름(몸) / 부림
격(格) —  기가 '얼마나' 응집됐나: 발경 < 검기 < 강기(검강) < 어검 < 심검
```

같은 격 안에서도 형태가 다르면 전투 방식이 다르고, 격이 다르면 **상성이 갈린다.**

## 2. 격의 사다리 — 경지 게이트와 전투 스타일

| 격 | 경지 | **위력** | 발현 | 전투 방식의 정체성 |
|---|---|---|---|---|
| **발경(發勁)** | 일류 | **+1** | 타격에 기를 싣는다 | 붙어야 싸운다 — 근접 유일 |
| **검기(劍氣)** | 절정 | **+2** | 기가 날에 서린다 / 날아간다 | 근접 주력 + 가끔 발출. **일반 병기를 상하게 한다** (무기 내구) |
| **강기(罡氣)** | 화경 | **+3** | 응집 — 검에 두르면 **검강(劍罡)**, 몸에 두르면 **호신강기(護身罡氣)** | 걸어 들어온다 — 하위 공격이 닿지 않는다. 유지비의 전투 |
| **어검(馭劍)** | 현경 | **+4** | **이기어검(以氣馭劍)** — 검이 손을 떠난다 | 방향이 사라진 전투 — 가드가 무의미해진다 |
| **심검(心劍)** | 생사경 | **+5** | 무형검 — 뜻이 곧 베기 | 창작 오의의 영역 (별도 설계) |

**위력 = 피해 공식의 '격 위력' 항** (`피해 = 무기 위력 + 무공 위력 + 격 위력 + floor(마진/2)`).
2026-07 이전에는 이 항이 없었다 — 격은 코스트만 있고 이득이 없는 장식이었고,
**보병 한 자루(판정 +1 = 피해 +28%)가 강기보다 강했다.** 이제 내력을 태우면 아프다.
발출형은 더 아프다 (검기_참격 +3, 강기_포 +5) — 1회에 몰아 쓰는 것의 값이다.

## 3. 형태 4종 — 사용 방식

```text
① 두름 (인챈트형)  지속 — 라운드당 유지비. 근접 강화
   검기 두름(유지 1/합, 위력 +2) · 검강 두름(유지 2/합, 위력 +3, 하위 기 절단)
② 쏨 (발출형)      1회 대량 소모. 원거리 — 시(투사체)/선(참격) 히트박스
   검기 참격(3, 위력 +3) · 강기 포(6, 위력 +5) — 빗나가면 그냥 사라진다 (내력 관리의 도박)
③ 두름-몸 (전개형)  호신강기 — 반응 방어. 전개 4 + 유지 2/합 + 피격 시 상쇄 소모
   하위 격 자동 무효 — 그러나 무효화 1회당 유지 내력 -1. 절대 방어는 없다 (§4.2)
④ 부림 (어검형)     채널링 — 검이 독립 유닛이 된다 (시전 4 + 유지 2/합, 위력 +4 — 아래 5장)
```

**중요 — 내력을 먹는 것은 초식이 아니라 격이다.**
무공 초식 자체의 코스트는 0이다(외공 초식). 초식에 격을 얹는 순간 위 코스트를 낸다.
삼류·이류의 내력 풀은 0이므로, 초식이 내력을 요구하면 '배워도 못 쓰는 무공'이 된다 —
그래서 육합검 3타·매화보·금나수의 코스트를 0으로 내렸다 (combat_system.md §6).

**전투 방식 차이의 핵심**: 절정까지는 "언제 쏘나"(자원 도박)의 전투, 화경은 "얼마나 버티나"(유지비 소모전), 현경은 "어디서 오나"(방향 상실)의 전투다. 격이 오를 때마다 **전투의 질문 자체가 바뀐다.**

## 4. 격 상성 — 막기를 부수고, 회피는 격을 속인다

```text
원칙 1. 한 격 위의 기운은 아래 격의 '기 방어'를 관통·파괴한다
        검강은 검기를 벤다 — 검기로 검강을 막으면 검째 잘린다
        호신강기 앞에 검기 발출은 소모 상쇄전 (강기 앞에 발경은 무효)
원칙 2. 격은 막기(가드·기 방어)를 부수지만, 회피를 부수지 않는다
        몸을 빼는 것에는 격이 없다 — 초절정이 화경 앞에서 버티는 유일한 길
        (조작·보법 실력이 격을 초월하는 유일한 변수 — 무협의 그 서사)
원칙 3. 무기가 격을 견뎌야 한다 (무기 내구 등급)
        범철(맨 무기): 검기에 상함 / 정련: 검기 감당 / 보병(寶兵): 검강 감당 /
        신병(神兵): 어검·심검의 그릇 — 보검이 비싼 이유가 규칙이 된다
        (등급은 판정 보정을 주지 않는다 — 전부 0. 등급의 값은 '부러지지 않는 것'뿐이다)
원칙 4. 기 방어는 소모품이다 — 하위 격이라도 때린 만큼 상대의 내력을 깎는다
        절대 방어는 없다. 두들기면 마른다 (§4.2)
```

### 4.2 호신강기 — 절대 방어가 아니다 (상쇄 소모)

구 규칙은 "하위 격 자동 무효 / 동격은 소모 상쇄전"이라고만 썼다. **상쇄 소모량이 수치로 없었다.**
그 결과 절정(최대 격 = 검기)이 화경의 호신강기 앞에서 **피해 0 — 승률이 구조적으로 0** 이었다.

```text
전개 4 · 유지 2/합
피격 시 상쇄 소모:
  하위 격  피해 0, 유지 내력 -1   ← 무효화는 공짜가 아니다
  동격     피해 0, 유지 내력 -2   ← 먼저 마르는 쪽이 진다
  상위 격  관통 — 격 위력 차만큼 피해 + 유지 내력 -2
붕괴: 상쇄 소모를 낼 내력이 없으면 그 즉시 소멸 — 다음 타격은 맨몸으로 받는다
```

화경(내력 풀 21) 검산:

| 상황 | 초당 소모 | 버티는 합 |
|---|---|---|
| 아무도 안 때림 | 2/합 | 8합 |
| 절정 1인이 매 합 검기로 때림 | 3/합 | 5합 |
| 절정 3인 협공 (포위 슬롯 3) | 5/합 | **3합** |

**하위 격의 답이 규칙에 생겼다:** ① 두들겨 말린다 ② 회피로 시간을 벌고 유지비를 태운다
③ 격을 안 쓰는 지구전. 화경은 여전히 강하지만, 이제 **소모될 수 있다.**

### 4.1 무기 파괴 — 검이 맞닿는 순간의 규칙

일반 검객과 검기 검객이 검을 맞대면 **일반 검이 잘려나간다.** 무기 파괴는 정식 규칙이다:

```text
발동 조건: '무기 접촉'이 있는 격돌만 — 가드/패링/합(맞부딪힘)
          회피·흘리기에는 접촉이 없다 — 무기가 상하지 않는 대응 (원칙 2와 동일 논리)
막기의 값:  막기는 피해 -3 을 준다 (combat_system.md §4.1). 범철로 검기를 세 번 막으면
          검이 부러지지만, 그 세 합 동안 아홉의 피해를 검이 대신 먹었다.
          검을 태워 목숨을 사는 것 — 그것이 막기이고, 그래서 막기는 죽은 선택지가 아니다.
          정련이 없는 자의 세 번째 길: '흘리기'(판정 -2, 피해 -1, 무기 무손상)
파괴 판정: 무기의 감당 격 vs 상대 발현 격
  감당 ≥ 발현        손상 없음 (정련검은 검기를 받아낸다)
  1격 초과           손상 누적 — 격돌 3회째에 파괴. 1회째부터 '금이 간다' 예고
                     (범철 vs 검기: 세 합이면 부러진다 — 도망칠 시간은 있다)
  2격 초과           즉시 절단 — 한 합 (범철 vs 검강: 검째 잘린다, §4 원칙 1의 장면)
발경 예외:  발경은 기가 몸·무기 안에 머문다 — 상대 무기를 상하게 하지 않는다
자기 무기:  자기 검이 자기 격을 못 견뎌도 상한다 — 범철에 검기를 두르면
           시전 3회마다 손상 1 (절정 고수가 좋은 검을 찾아다니는 이유)
파괴 이후:  맨손 — 무기 요구 무공은 다운캐스트('맨 기술'), 재무장은 행동 1개
MC 구현:   바닐라 내구도 시스템 재활용 — 등급별 내구 배정, 절단 = 파괴음+파편 파티클
```

무기 파괴는 **경지 격차의 서사를 3합 안에 보여주는 장치**다: 검이 갈라지는 소리에서 도주(회피 전환)를 결심하는 것 — 그것이 하수가 배워야 할 생존술이다.

## 5. 이기어검 — 방향이 사라진 전투 (상세)

```text
발동: 현경 이상 + 채널링 (부림 형태). 시전 4 + 유지 2/라운드 — 가장 비싼 상시기
검의 독립: 검이 별개 유닛으로 비행 — 본인은 맨손/다른 병기로 동시 전투 (이도류적 압박)
사각: 검이 등 뒤·머리 위에서 온다 — 가드 방향 무의미. 유효 대응은 회피/호신강기/격추뿐
격추와 회수: 검 자체를 쳐내면(대립 판정) 낙검 — 회수 2라운드. 어검의 유일한 빈틈
집중의 대가: 부리는 동안 시전자 본체의 회피 -2 (마음이 검에 가 있다)
             — 어검사를 잡는 법: 검이 아니라 사람을 쳐라 (무협 문답의 규칙화)
MC 구현: 디스플레이 엔티티 검 비행 (VFX 풀), 시점 지정 유도 + 자동 선회 패턴
```

## 6. 기존 체계 접합

```text
소모 밴드 세분: internal_energy.yml 검기(1~3)·강기(2~6)가 형태별 코스트로 구체화
               (밴드 하단 = 두름의 유지비, 상단 = 쏨의 발출비 — 두르는 것은 싸고 쏘는 것은 비싸다)
               (config/qi_manifestation.yml costs — 두름은 유지비, 쏨은 일시불)
경지 게이트:    현경에 '어검' 추가, 심검은 생사경 창작 오의 연계 (게이트 갱신)
기운 프로파일:  연비(태극 검기·강기 -1)는 형태 불문 적용 — 지구전형은 유지비에서 웃는다
오의와의 관계:  오의 ≠ 격. 오의는 '기술의 정점'(절정도 개안 가능), 격은 '기운의 등급'.
               검강 오의도, 검기 오의도 존재한다 — 두 사다리는 독립적으로 오른다
NPC 대칭:      고수 NPC의 격 발현도 동일 규칙 + 텔레그래프 (검강의 응집은 빛으로 보인다)
전의 연동:     격 차이의 목격(검강 응집)은 하위 NPC 전의를 즉시 꺾는다 — 위세
```
