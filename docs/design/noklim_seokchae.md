# 녹림 총채 — 「녹림 석채(綠林石寨)」

> **출처: 사용자가 직접 설계했다 (2026-07-13).** 추측이 아니다.

## 왜 예외인가 — ★ 규칙의 우선순위

§17 의 문장은 **폐기하지 않는다**:
> *"도적의 집은 영향력이 커도 목책이다."*

이것은 **일반 산채와 지역 녹림 세력의 거점에 적용되는 기본 규칙**이다.
녹림 총채는 **등록부가 직접 "목책 아닌 석성"이라 지정한 특수 장소**이므로 예외 처리한다.

| | |
|---|---|
| 일반 산채 | **목책** |
| 부유한 산채 | 목책 유지, **내부 시설만** 확대 |
| **녹림 총채** | **석축으로 조성되는 유일한 총본산** |
| 다른 도적 거점 | ★ **녹림 총채의 석축 형식을 자동 상속하지 않는다** |

**녹림 총채는 "도적의 영향력이 커져서 자동으로 석성이 된 것"이 아니다.**
여러 산채와 녹림 세력의 물자·인력·약탈품과 권력이 한곳에 축적된 **명시적 총본산이기 때문에 생긴 예외**다.

> ★ **최종 원칙: 일반 규칙은 명시적인 예외를 지우기 위해 존재하지 않는다.**

**이름을 「석성」으로 두지 않는다** — 관부의 성곽도시 · 군사 요새 · 마교의 흑성과 혼동되지 않도록 **녹림에 한정된 「녹림 석채」**를 쓴다.

## 건축적 성격
관군이 평지에 세운 정형적 성곽이 **아니다.** 산을 깎아 네모난 성을 얹는 방식도 **아니다.**
자연 암벽·산등성이·협곡과 절벽을 방어선으로 삼고, **빈틈에만** 석벽과 문루를 세운 **산악형 석축 총채**다.

- 산 전체가 외곽 방어선 역할
- 자연 암벽과 인공 석벽이 **구분되지 않게** 이어짐
- 평지 성곽처럼 사방을 완전한 성벽으로 **둘러싸지 않음**
- **접근 가능한 능선과 협곡만** 석벽으로 봉쇄
- 내부는 하나의 궁성이 아니라 **여러 층의 채와 마당**
- 관부의 규격화된 축성과 달리 **증축 흔적과 불균형**이 드러남
- **빼앗은 석재·목재·기와가 섞여** 재료가 통일되지 않음

> ★ **잘 훈련된 관군이 설계한 성이 아니라, 여러 세대의 산적이 조금씩 확장한 결과물처럼 보여야 한다.**

## 공간 구성
1. **외채문** — 산길과 협곡을 막는 첫 관문. 목책 대신 **석벽과 철문**. 감시대·낙석 장치. 거대한 정문이 아니라 **좁고 깊은 살상 통로**. 공격자가 한꺼번에 못 들어오게 **길을 꺾는다**
2. **하채** — 외부인·행상·포로·하급 녹림도. 마구간·수레 정박지·임시 숙소·검문소·압수 물품 분류장. **핵심부와 직접 연결되지 않도록 중간 관문**
3. **녹림 시장** — 등록부의 "약탈물 창고와 시장"의 핵심. 약탈품 교환·장물 매매·무기와 말 거래·정보 거래·산채 간 물자 분배. **정식 도시 시장처럼 깨끗하고 계획적이지 않다** — 천막·가판대·창고·개조 건물이 밀집해 **끊임없이 형태가 변한다**
4. **대창고군** — 곡물창고·병기고·직물과 귀중품·각 산채에 보낼 물자 집산소·**별도 잠금 보물고**. 화재와 내부 약탈을 막기 위해 **생활 구역과 분리**
5. **중채** — 각 산채 두령과 정예. 두령 숙소·회의당·연무장·주방과 공동 식당·무기 수리소. 일반 산채보다 크고 견고하나 **관청·귀족 저택처럼 정제되지 않는다**
6. **총표파자 / 취의당** — 권력의 중심. 총채주와 두령의 회합·녹림의 규율과 분쟁 판정·전리품 배분. **호화로운 왕좌나 궁전을 두지 않는다.** 권위는 장식이 아니라 **넓은 회의 공간·무기·깃발·여러 산채의 표식**으로
7. **상채와 비상 퇴로** — 가장 높은 능선의 최후 방어 구역. 총채주 거처·핵심 병기고·비상 식량고·**은밀한 하산로**. 비상 퇴로는 **총채 내부에서만** 확인 가능 (광역 이동망·비밀 통로로 확대하지 않는다)

## 재료
현지의 **거친 산석** · **재사용된 성돌과 건물 석재** · 어두운 목재 · 철제 문과 보강판 · 부분적 회색 기와 · 천막과 거친 직물

**석축이라고 모든 건물을 돌로 짓지 않는다:**
| | |
|---|---|
| 방어벽 · 핵심 창고 | **석축** |
| 생활 건물 · 시장 | **목조** |
| 임시 구역 | **천막·가설물** |
| 문 · 보강 구조 | **철재** |

> 전체 인상은 "돌로 지은 도시"가 아니라 **「돌로 지킨 거대한 산적 공동체」**다.

## 일반 성곽과의 구별
| | |
|---|---|
| 관부 성곽 | 행정 질서와 정규군의 방어 |
| 마교 흑성 | 압도적인 **단일 권력**과 폐쇄성 |
| **녹림 석채** | **약탈 경제**와 **다수 산채의 느슨한 연합** |

녹림 석채는 **직선 축·대칭 배치·정규 도로망을 쓰지 않는다.** 산세와 기존 암반에 따라 길과 건물이 **불규칙하게 누적**되어야 한다.

## ★ 검수 기준 (전부 만족해야 한다)
- 일반 목책 산채와 **즉시 구별**되는가
- 석축이 **자연 산세와 연결**되어 있는가
- 반경 48의 규모를 **실제 기능 공간이 사용**하고 있는가
- **시장과 대창고가 총채의 핵심**으로 드러나는가
- **여러 산채의 연합 본부**로 보이는가
- 관부의 성곽도시처럼 **정형화되지 않았는가**
- 마교의 흑성과 **다른 재료·배치·권력 구조**를 갖는가
- ★ **녹림 총채 이외의 산채에 석축 예외가 전파되지 않는가**
