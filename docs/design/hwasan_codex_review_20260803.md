## 치명 간극 5

1. **거대 평면 석대가 산을 지운다** — 침봉이 클수록 건물이 작아 보인다. 단구 3~5로 쪼개고,
   측면은 수직 벽이 아니라 암반·축대·돌출 바위 교차. 전각 일부는 절벽 위로 내밀고 일부는
   암벽에 파묻는다.
2. **밀도 — 크기 단계의 단절**: 침봉(수백)과 전각(수십) 사이 중간 크기(작은 문루·회랑·담·
   소나무·바위·등롱)가 없다. 최소 4~5단계.
3. **위계 부재**: 전 건물이 비슷한 층고. 산문 = 1.5~2배 높이 · 지붕 두께 2배 · 공포·기단 돌출.
4. **입면 깊이·질감**: 기둥 / 벽 −1 / 창호 −2 세 겹 + 공포층(계단·담장·덫문 2~3 깊이) +
   지붕 재료 혼합(심층암 타일 60/벽돌 25/흑암 10/균열 5) + 풍화는 원인 있게 (하단 이끼·
   모서리 깨짐·처마 밑 그을림).
5. **★인간 단위 (스케일 체감의 뿌리)**: 문·기둥 간격·계단 폭을 키우면 사람 기준이 사라져
   **오히려 작아 보인다**. 웅장함 = 인간 단위(문 2 · 층고 3~4 · 기둥 간격 5~7)가 수십 칸
   **누적**되는 것 + 도착 시퀀스(계단→참→소문→비석→수목→산문)에서 나온다.
   → 슬라이스 8의 벽 10·간격 6 확대는 이 축에서 역효과였다.
