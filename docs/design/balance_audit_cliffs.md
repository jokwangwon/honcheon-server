# 저수치 절벽 감사 — 파생치 전수 점검

> 화후 시스템(dantian_and_simbeop.md 6.4) 도입에 따라, 모든 파생 수치를 전수 감사해
> "달력의 절벽(버그)"과 "벽의 절벽(설계)"을 구분하고 처분을 확정한다.

## 대원칙 — 판정은 정수, 자원은 실수, 벽은 벽

```text
판정 가산 (능력치·기술 +n):   정수 유지 — 2d6 분산(±5)이 1점 차이를 완충 (등급 이동 ~10%p)
자원·시간·파생치:            실수(화후) 기반 — 반올림 경계의 절벽 제거
상태·단계 임계:              의도된 벽 — 시간이 아니라 사건·돌파·상태로 넘는 질적 전환
```

능력치 전반으로 화후 확대: **모든 능력치는 내부 실수로 적립**된다 (수련 진행도).
판정에는 정수부만 쓰고, 파생치 계산에는 실수치를 쓴다.

## 감사 표

| 파생치 | 공식 | 절벽 여부 | 처분 |
|--------|------|-----------|------|
| 내력 | 내공×3 | 6 vs 9 (50%) — 심각 | **실수화 완료** — round(실수×3) |
| 정화력 | 내공×순도 | 있음 | **실수화 완료** |
| 내구 | 10+체력×2 | 14 vs 16 (14%) — 경미하나 동종 | **실수화** — round(10+체력실수×2) |
| 회피 충전 회복 | −3틱/민첩 | 있음 | **실수화** — 내부 틱 계산에 실수 사용 |
| 후딜 감소 | −5%/민첩 | 백분율 — 이미 연속 | 유지 (실수 적용 명시) |
| 패링 유예 | +0.5틱/감각2 | 반틱 단위 — 이미 세분 | 유지 |
| 능력치·기술 판정 가산 | +n | 완충됨 | **정수 유지** (대원칙) |
| 부상 단계 | 내구 50%/25% | 상태 임계 | 의도된 벽 — HP 임계는 절벽이 맞다 |
| 원기 구간 | 80/50/20 | 상태 임계 | 의도된 벽 |
| 경지 게이트·격차 | 단계제 | 벽 | 의도된 벽 — 돌파로만 넘는다 |
| 심법 용량·순도 | 심법별 고정 | 선택의 차이 | 의도된 벽 (심법 선택 = 질적 선택) |
| 세력 반응·우호 임계 | 단계제 | 조직 행동의 질적 전환 | 의도된 벽 |
| 무기·무공 위력, 협공 | 정수 | 장비/전술 선택 | 의도된 정수 |
| 아이 보정 해제 | 16세 정각 | 생일 절벽 | **허용** — 성년의 서사적 문턱 (관례冠禮) |
| 유년→소년 전투 보정 | −2→−1 (13세) | 생일 절벽 | **허용** — 동상, 성장의 문턱 |
| 선천진기 | 년 단위 | 수명 — 연 단위가 주제적 | 유지 |

## 결론

심각한 절벽은 내력 하나였고(해결됨), 동종 원리로 내구·회피 회복을 실수화했다.
나머지 불연속은 전부 **상태·선택·돌파의 벽**으로, 저수치 시스템의 가독성을 지탱하는
의도된 구조다. 이후 새 파생치를 추가할 때는 대원칙 세 줄로 분류부터 한다.
