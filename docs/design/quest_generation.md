# 의뢰 생성기 — 세계가 아프면 의뢰가 난다 (G1 해소)

> 의뢰는 템플릿 뽑기가 아니라 **세계 상태의 증상**이다. 지역이 나빠지면, NPC가
> 벽에 부딪히면, 시세가 흔들리면 — 그것이 의뢰가 되어 게시판에 걸린다.
> 기계 판독용: `config/quest_generation.yml`

---

## 1. 발생원 4종 — 의뢰는 어디서 오는가

```text
① 지역 상태 (region_state 임계 연동 — 이미 있는 수치가 의뢰를 낳는다)
   치안 < 30   도적 소탕(현상)·상단 호위·야간 순찰 보조
   경제 < 30   물자 호송·채무 회수·일손 (보수는 낮아진다 — 배율 정합)
   민심 < 30   실종 조사·유언비어 추적·민원 중재
② NPC 생애 (계절 정산 연동 — 문턱의 NPC가 손을 빌린다)
   상승 도전 중  호위·시세 정보·거래처 소개 (성공 시 개입 기록 +1 자동 — 회수 루프 입구)
   하락 위기    채무 해결·구출·누명 벗기기 (몰락을 막으면 은인이 된다)
③ 시세 이벤트 (price_events 연동)
   약재 +50%   약초 채집 (수매가 상승분 반영) / 곡물 폭등 → 호송 의뢰 보수 ↑
④ 세력 (faction_standing 연동)
   favor 신용+  세력 전용 의뢰 접근 (문파 임무·상단 전속 표행) — 공개 게시판에 없는 것
   주목 상승    "그 아이를 시험해 보자" — 세력이 먼저 의뢰를 들고 찾아온다
```

## 2. 생성 파이프 — 자정 배치의 한 단계

```text
자정 배치: 발생원 스캔 → 의뢰 후보 생성 → 게시
  보수 = economy 의뢰_보수 기준표 × 지역 경제 배율 (기존 수치 재사용 — 신규 표 없음)
  게시 슬롯: 지역당 활성 5~8 (초과 후보는 대기열 — 세계가 좁게 느껴지지 않을 만큼만)
  게시처: 의뢰소(공개) / 세력 경유(favor 게이트) / NPC 직접 (개입 기록 있는 상대가 지명)
데드라인: 모든 의뢰에 만료일 — 기존 데드라인 규칙 그대로: 세계는 기다려주지 않는다
  방치된 호위 의뢰 → 상단 습격 사건 발생 → 지역 델타 악화 → 더 나쁜 의뢰가 태어난다
  (의뢰 무시가 곧 세계 악화 루프 — 의뢰가 '할 일'이 아니라 '증상'인 이유)
```

## 3. 수주와 해결

```text
수주: 비독점 원칙 — 같은 의뢰를 복수 파티가 물 수 있다 (먼저 해결한 자의 것)
     단, 세력 지명 의뢰는 독점. 수주 = scenes 스레드 개설 (동시성 잠금 정합)
보상: 보수(문) + 발주처 favor + 마크(전투 의뢰) + 정보(단서 — 정보 경제 연동)
실패·포기: 발주처 favor 하락 + 의뢰는 게시판으로 복귀 (만료 시계는 계속 돈다)
검수: 발주 NPC 판정 — 증거 요구 (수급, 장부, 생존자 증언 — 조사 판정의 무대)
```

## 4. 등급 사다리 — 성장과 의뢰의 동행

```text
잔심부름(범인~) → 조사·채집(삼류) → 호위·소탕(이류) → 표행·현상금(일류+) → 세력 전속(절정+)
등급 게이트는 느슨하게 (도전 허용 — 격상 의뢰는 사선이 될 뿐, 금지는 아니다)
```
