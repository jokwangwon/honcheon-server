# 스킬 메커니즘 — 히트범위 · 회피기 · 무적기 (액션 전투 상세)

> minecraft_port_feasibility 2.1(전투의 실시간 전환)의 구체화.
> 데이터 2층 구조: `config/skills.yml` = 무공 카탈로그(습득 조건·사회적 속성, 텍스트/MC 공용)
> + `config/skill_mechanics.yml` = 액션 데이터(히트박스·프레임·무적, MC 전용).
> 시간 단위: **틱 (1틱 = 50ms)**. 성능 상한은 config/performance.yml을 따른다.

---

## 1. 프레임 모델 — 모든 스킬의 공통 골격

```text
선딜(startup) → 지속(active: 히트박스 활성) → 후딜(recovery)
```

- 선딜이 길수록 강하다 — 예고(텔레그래프)가 길어 회피 여지가 생기기 때문. **회피 가능성이 밸런스의 화폐**다.
- 적(NPC)의 강공격은 반드시 텔레그래프 연출(경로 파티클, 자세)을 가진다 — "맞은 게 억울하지 않은 전투".
- 후딜은 리스크다: 후딜 중 피격 시 데미지 +25% (카운터 히트).

## 2. 히트범위 — 유형 6종으로 표준화

| 유형 | 파라미터 | 대표 예 | 서버 판정 |
|------|----------|---------|-----------|
| 호(弧) — 부채꼴 | 각도 90~180°, 반경 2.5~4m | 검격, 도격 | 거리 + 방향 내적 검사 |
| 선(線) — 직선 관통 | 폭 1~1.5m, 길이 4~8m | 창 찌르기, 검기 발출 | 경로 AABB 스윕 |
| 원(圓) — 원형 광역 | 반경 3~6m, 자기/지점 중심 | 장력 폭발, 검화 | 반경 검사 |
| 시(矢) — 투사체 | 크기, 탄속(블록/틱), 사거리, 관통 여부 | 암기, 화구 | 투사체 엔티티/레이 |
| 돌(突) — 돌진 경로 | 경로 폭, 거리, 이동 중 히트 | 경공 돌진 베기 | 이동 경로 스윕 |
| 진(陣) — 장판 | 반경, 지속 틱, 피해 간격 | 독무, 검막 | 주기 반경 검사 |

- 모든 히트박스는 `max_targets`(기본 8)와 사거리 상한(24m)을 넘을 수 없다 (performance.yml F-P3).
- 판정은 지속 프레임 동안 **대상당 1회** (다단히트는 명시적 hit_count로만).

## 3. 회피 체계 — 3단 구조

```text
① 기본 회피 (전 캐릭터 공통, 무공 아님)
   방향 이동 + 회피 입력 → 3m 스텝. 무적 4틱(200ms), 선딜 0 (반응 기술).
   충전제: 2충전, 충전당 회복 100틱(5초). 내력 소모 없음.
② 보법 무공 (스킬 슬롯 — 문파별 개성)
   예: 매화보 — 더 긴 무적, 잔상, 재배치. 내력 소모.
③ 경공 이탈 (전투 이탈용 장거리 이동)
   무적 없음 + 이동 중 피격 시 경직 2배 — 도주는 회피가 아니다.
```

- 연속 회피 체감: 5초 안에 회피 2회 소진 시 충전 회복 50% 지연 — 회피 난사 방지.
- 민첩 능력치 연동: 민첩 1당 충전 회복 -3틱 (성장 체감).

## 4. 무적기 규칙 — 무적은 희소 자원이다

### 4.1 방어 상태 4종

| 상태 | 효과 | 대가 |
|------|------|------|
| **무적 (i-frame)** | 모든 판정 통과 | 짧다 (아래 상한). 무적 중 내력 회복 정지 |
| **슈퍼아머** | 경직 무시 (피해는 그대로) | 시전 유지용 — 방어가 아니라 뚝심 |
| **가드** | 정면 120° 피해 -70% | 가드 게이지 — 브레이크 시 큰 경직 |
| **패링** | 정확한 타이밍 가드 → 무적 2틱 + 반격 윈도우 | 실패 시 일반 가드보다 나쁜 후딜 |

### 4.2 무적 시간 상한 (등급별 — 절대 규칙)

```text
기본 회피          4틱 (200ms)
보법 무공(이류급)   6틱
절정급 방어 오의    10틱
오의(별도 설계)     최대 20틱 — 지역에 한둘뿐인 기술
```

### 4.3 남용 방지 3장치

```text
1. 무적 후 취약: 무적 종료 직후 후딜 동안 카운터 히트 판정 (+25%)
2. 파격(破格) 속성: 잡기·금나수 계열은 무적을 관통한다 — 희귀 속성, 무공 카탈로그에 명시
3. 자원 이중과금: 무적기는 내력 소모 + 충전/쿨다운 둘 다 가진다
```

### 4.4 상성 삼각 — 구조가 밸런스를 지킨다

```text
타격 ──이긴다──▶ 잡기 (잡기는 선딜이 길다)
잡기 ──이긴다──▶ 가드/패링 (파격 — 막을 수 없다)
가드/패링 ──이긴다──▶ 타격 (받아친다)
무적(회피)은 삼각 밖의 만능 답 — 그래서 짧고, 비싸고, 끝나면 취약하다.
```

### 4.5 판정 충돌 우선순위 (동일 틱)

```text
무적 > 파격 > 패링 > 가드 > 슈퍼아머 > 일반 피격
단, 파격 vs 무적 = 무적 승 (무적 관통은 '가드류'에만 유효 — 무적까지 뚫는 것은 없다)
동시 타격(양측 히트) = 쌍방 히트 허용 (트레이드) — 경직 강한 쪽이 유리할 뿐
```

## 5. 경직과 넉백

```text
경직 등급: 약 2틱 / 중 5틱 / 강 10틱 / 다운 20틱(기상 무적 3틱)
경직 저항: 경지가 2단계 이상 높으면 경직 1등급 경감 (텍스트 룰의 경지 격차 재해석)
넉백: velocity 규칙 준수 (틱당 1회, 연속 이동계 2틱 간격 — F-N3)
경직 면역 시간: 같은 대상에게 강경직은 3초에 1회 — 무한 경직 콤보 방지
```

## 6. 텍스트 룰과의 접점 (능력치 매핑)

| 텍스트 룰 | 액션 표현 |
|-----------|-----------|
| 민첩 | 이동속도, 회피 충전 회복, 후딜 -5%/점 |
| 감각 | 패링 유예창 +0.5틱/2점 (상한 +2틱), 적 텔레그래프 강조 표시 |
| 근력/내공 | 피해 계수 (combat.yml 피해 공식 그대로) |
| 체력 | 내구(HP), 가드 게이지 |
| 경지 격차 | 피해 배율 ±, 경직 저항 |
| 아슬아슬한 성공 | 패링 성공·회피 성공의 액션 재해석 — "등급제가 조작 기술이 된다" |

## 7. 문파 무공 프레임 데이터 예시 (config/skill_mechanics.yml)

| 무공 | 유형 | 프레임 (선딜/지속/후딜) | 방어 속성 | 요점 |
|------|------|------------------------|-----------|------|
| 육합검 (3타 콤보) | 호 100°/3m | 3/2/4 → 4/2/5 → 6/3/10 | — | 3타는 강경직, 후딜 큼 — 넣을 타이밍이 기술 |
| 매화보 | 이동 5m | 0/—/3 | **무적 6틱** | 잔상 남김. 내력 2 + 쿨 8초 |
| 정심검결 (패링 태세) | 정면 가드 10틱 | 2/10/6 | 패링 (성공 시 무적 2틱 + 반격창 10틱) | 심법답게 '받아치는 검' |
| 제왕검형 (남궁 비전) | 선 1.5m/8m | 12/3/14 | 슈퍼아머 (시전 중) | 긴 선딜 = 긴 텔레그래프 — 맞으면 강경직+다운 |
| 금나수 (잡기 예시) | 근접 1.5m | 8/2/12 | **파격** (가드/패링 관통) | 무적에는 안 통함. 성공 시 다운 |
| 갈호의 산도(NPC) | 돌진 4m | 10(텔레그래프)/3/12 | — | 예고가 뚜렷한 적 강공 표본 |

## 8. 검증 계획

```text
- 프레임 데이터 표는 스프레드시트 검산: DPS·안전 후딜·상성 조합 표를 자동 계산 (tools/)
- 부하: 히트박스 판정은 performance.yml 예산 내 (판정 자체는 산수 — 파티클이 비용)
- 상성 삼각의 실감 검증은 M3(전투 프로토타입)의 봇 대전으로
```
