### ★ 계획을 바꾸는 발견: DDL 마이그레이션 불요
능력치가 이미 `sheet_json` **안에** 산다. 원장·레벨·XP·미사용 포인트는 **같은 JSON에 키를
더하면 된다** — `CREATE/ALTER TABLE` 이 없다. 그래서 "봇 정지 + 스키마 마이그레이션" 규약은
**이 작업엔 해당 없다.** 대신 **읽을 때 기본값 채움**(backfill): sheet 에 원장이 없으면 옛
능력치 실수 x 로 `원장 = x²`(B-137 ③ 실수 보존안)을 그 자리에서 만든다. 무손실·무DDL·가역.

## 1. 단계 (앞이 뒤를 막지 않는다 · 각 단계 독립 검증)

### 단계 0 · config v3 — 등록부가 먼저 (코드 0줄)
`cultivation.yml` v2 → v3, 승인된 수치만 옮긴다:
- 레벨 사다리 (base 20 · growth 1.0565 · 자격 레벨 N_k — cultivation_v3_levels.md §5)
- 레벨당 3포인트 · 생성 원장 배분(유년 19 · 소년 53 — §8.7 ⑤)
- 경지 캡 제곱표 (9·16·25·36·49·64·81·100·100 — §8.5) → `player_creation.yml` 캡 갱신
- 포인트 은행 규약 (미사용 무기한 보유 — §8.9 ⑨)
- **검증**: `python3 tools/lint_config.py` · v2 폐기 조항은 묘비 주석으로

### 단계 1 · sheet_json 진화 + 읽기 backfill (봇측 · 무DDL)
- sheet 에 `원장:{축:정수}` · `레벨` · `경험치` · `미사용포인트` 키 신설.
- **읽기 backfill**: 원장 없으면 옛 능력치 실수 x → `원장 = x²`(실수 저장 · 판정치 보존).
- 새 캐릭터: 생성 배분을 제곱 저장 (§8.7 ⑤).
- **검증**: 봇 단위 시험 — 옛 sheet 로드 → 원장 backfill → 판정치 = 옛 능력치 (하네스 ⑤와 동형)

### 단계 2 · 판정 이음 — 판정치 = floor(√원장) (봇측 · 핵심)
- execBase 조립 자리에서 능력치 대신 `floor(√원장(축))` 사용. **성별 ±1·기술·보정은 √ 밖**(후치).
- `JudgmentEngine.resolve` **무변경**(설계대로) · NPC 무환산(원장 없음 · 등록값 그대로).
- **검증**: `judgment_scale_harness.py`(이미 통과) 가 회귀 감사. 세 함정 감시(floor·backfill round 금지·성별 후치).

### 단계 3 · 파생치 — √원장 실수치 (봇·MVT)
- 내력 풀 = round(내공실수(내공실수+1)/2×3) · 이속/도약 = 민첩실수×계수 · 내구 = 10+체력실수×2.
- 플레이어 실수치 = √원장 · NPC 실수치 = 등록값 (§8.9 ⑩).
- **검증**: 왕복 검산(하네스 ⑥) · 인게임 내력바·경공·내구 실측

### 단계 4 · 성장 로직 — XP→레벨→포인트→배분 (봇: Growth/ProgressionEngine v3)
- XP 획득(combat_hwahu 연속식 재사용) → 레벨업 → 3포인트 지급 → 축 배분(캡 c² 준수).
- 포인트 은행: 캡 초과 미사용분 보유 → 승급 시 해금.
- 승급 = 자격 레벨 + 사건 마크(기존 battle_marks 재사용).
- **검증**: `xp_pacing.py` 대조 · 인게임 레벨업·포인트 배분 명령

### 단계 5 · UI/UX — 연출과 시트 (MVT · 한월식)
- 레벨업 연출(Title+버스트 — 한월 A5) · 시트에 **원장만 표기**(§8.9 ⑪) · 포인트 배분 화면.
- 획득 토스트·경험치 바(한월 A6) — 타격 피드백·명패와 같은 표시 계열.
- **검증**: 인게임 눈

## 2. 위험과 못

| 위험 | 못 |
|---|---|
| 옛 캐릭터 데이터 손실 | 무DDL·읽기 backfill — 옛 sheet 무변경 · 원장 없으면 x² 유도 (가역) |

| 봇/MVT 이중 구현 | 능력치는 봇 단일 작성자 · MVT 는 다리로 읽기만 (읽는 곳·손대는 곳 한 해석기) |
| 정체 시 포인트 소멸 | 포인트 은행(§8.9 ⑨) — 무기한 보유 |
