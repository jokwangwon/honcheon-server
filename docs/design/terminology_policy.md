# 용어 정책 — 신무협 기준의 표시 용어

> 문제 제기: "너무 옛날 무협 단어가 많다 — 신무협처럼 간단한 용어로 혼선을 줄이자."
>
> **`config/terminology.yml` (폐기 — 2026-07 에 묻었다)** — 표는 아래 4·5장에 그대로 옮겨 왔다.
> 그것은 config 가 아니라 **용어집**이었다: 엔진이 런타임에 치환을 수행하지 않는다(할 수도 없다 —
> 표시 문자열은 embed·명령 설명·간판에 흩어져 사람이 쓴 문장 안에 있다). 아무도 읽지 않는 파일이
> config 폴더에 앉아 있으면 "엔진이 집행하는 규칙"이라고 거짓말한다. 이 표의 독자는 **사람**이다 —
> 그러니 문서에 산다. 집행자는 코드 리뷰와 아래 등록제 규칙이다.

## 1. 세 원칙

1. **신무협 표준어는 유지** — 비무·내공·경지명(삼류~생사경)처럼 독자가 이미 아는 말이 가장 쉬운 말이다.
2. **고문투·장부투는 치환** — 화후(火候)·전낭(錢囊)·원장(元帳)·"지참인 지불"처럼 사전이 필요한 말은
   뜻이 같은 쉬운 말로 바꾼다: 수련·소지금·정보·"가져온 이가 임자".
3. **내부 키 불변** — 치환은 표시층(embed·액션바·명령 설명·간판)에서만. DB 시트 키(`화후_원장` 등)·
   config 키·이벤트 타입은 그대로 둔다 (마이그레이션 문제 원천 차단 — 3차 검증 선례).

## 2. 적용 범위

| 층 | 적용 | 예 |
|---|---|---|
| 봇 표시 (embed·명령 설명) | ✅ 치환 | "화후 +2.00일치" → "수련 +2.00일치", 원장 제목 → 정보 |
| MVT 표시 (채팅·액션바·간판) | ✅ 치환 | "── 화후 원장 ──" → "── 수련 기록 ──" |
| 명령어 | 신구 병행 | `/혼천 정보` 신설, `/혼천 원장` 하위호환 유지 |
| DB·config·이벤트 타입 | ❌ 불변 | sheet `화후_원장`, 이벤트 `사사_문답` 그대로 |
| 설계 문서 | 새 문서부터 | 기존 문서 소급 개정 안 함 (역사 기록) |

## 3. LLM 렌더러 연동

turn_renderer 시스템 프롬프트의 문체 규정에 본 정책이 우선한다 — 고문투 단어를 서사에서
새로 만들어 쓰지 말 것 (등록제 명사 원칙의 어휘판). 은유 사전(단전 은유 등)은 별도 축.

## 4. 치환표 (등록제 — 이 표에 없는 치환 금지)

고문투·장부투 → 신무협/쉬운 말. **내부 키는 불변** — 치환은 표시층에서만 한다 (마이그레이션 0).

| 원어 | 표시 | 불변 내부 키 | 이유 |
|---|---|---|---|
| 화후(火候) | **수련** | sheet `화후_원장`·`오늘_적립`·`적립일` | 단약·수행 문맥의 고문투. "수련 +2일치"가 즉독 가능 |
| 원장(元帳) | **정보** | 명령 `/혼천 원장` 은 하위호환 유지 (= `/혼천 정보`) | 장부투. 캐릭터 조회의 표시명으로는 '정보'가 평이 |
| 전낭(錢囊) | **소지금** | — | 사전 없이 안 읽힌다 |
| 문답 | **시험** | 이벤트 타입 `사사_문답` 은 내부 키라 불변 (사사 흐름 표시만 치환) | — |
| 지참인 지불 | **"가져온 이가 임자"** | — | 어음 법률투 — 뜻은 같고 말은 쉽게 |

## 5. 유지표 — 치환하지 않는다 (신무협 표준)

| 용어 | 이유 |
|---|---|
| 비무 | 장르 표준 — 대체어(스파링)가 오히려 톤을 깬다 |
| 경지명 (삼류~생사경) | 신무협 공용 사다리 |
| 내공·심법·단전 | 장르 기초 어휘 |
| 기세 | 직관어 |
| 사사 | "~에게 사사했다" — 현대 국어에서도 통용 |
| 서장·출도 | 장 구조·데뷔의 장르 관용 |
| 전장(錢莊) | 은행의 무협 표준 대응어 — 대체 시 세계관 이탈 |
| 문·냥·금 | 화폐 단위 — 단순 서수라 혼선 없음 |
