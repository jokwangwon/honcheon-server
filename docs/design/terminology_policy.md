# 용어 정책 — 신무협 기준의 표시 용어

> 문제 제기: "너무 옛날 무협 단어가 많다 — 신무협처럼 간단한 용어로 혼선을 줄이자."
> 기계 판독: `config/terminology.yml` (치환표 + 유지표, 등록제)

## 1. 세 원칙

1. **신무협 표준어는 유지** — 비무·내공·경지명(삼류~생사경)처럼 독자가 이미 아는 말이 가장 쉬운 말이다.
2. **고문투·장부투는 치환** — 화후(火候)·전낭(錢囊)·원장(元帳)·"지참인 지불"처럼 사전이 필요한 말은
   뜻이 같은 쉬운 말로 바꾼다: 수련·소지금·정보·"가져온 이가 임자".
3. **내부 키 불변** — 치환은 표시층(embed·액션바·명령 설명·간판)에서만. DB 시트 키(`화후_원장` 등)·
   config 키·이벤트 타입은 그대로 둔다 (마이그레이션 문제 원천 차단 — 3차 검증 선례).

## 2. 적용 범위

| 층 | 적용 | 예 |
|---|---|---|
| 봇 표시 (embed·명령 설명) | ✅ 치환 | "화후 +2.00일치" → "수련 +2.00일치", 원장 제목 → 정보 |
| MVT 표시 (채팅·액션바·간판) | ✅ 치환 | "── 화후 원장 ──" → "── 수련 기록 ──" |
| 명령어 | 신구 병행 | `/혼천 정보` 신설, `/혼천 원장` 하위호환 유지 |
| DB·config·이벤트 타입 | ❌ 불변 | sheet `화후_원장`, 이벤트 `사사_문답` 그대로 |
| 설계 문서 | 새 문서부터 | 기존 문서 소급 개정 안 함 (역사 기록) |

## 3. LLM 렌더러 연동

turn_renderer 시스템 프롬프트의 문체 규정에 본 정책이 우선한다 — 고문투 단어를 서사에서
새로 만들어 쓰지 말 것 (등록제 명사 원칙의 어휘판). 은유 사전(단전 은유 등)은 별도 축.
