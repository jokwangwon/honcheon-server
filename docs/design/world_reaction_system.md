# 세계 반응 시스템 — 소문 · 세력 반응 · 지역 상태 · 시간

> 설계 검토(design_review.md 4장)에서 확인된 공백 G1~G4·G6의 해결 문서.
> "행동 → 판정 → NPC 변화"까지는 judgment_system.md가 굴린다.
> 이 문서는 그 뒤 — **NPC 변화 → 소문 → 세력 반응 → 지역 상태 → 후속 사건** — 를 수치화한다.
> 이로써 세계 반응 루프 전체가 기계 계산 가능해진다.
>
> 기계 판독용: `config/time.yml`, `config/rumor.yml`, `config/faction_reaction.yml`, `config/region_state.yml`
> 검증 도구: `tools/simulate_world_reaction.py`

---

## 1. 루프 전체 조감

```text
플레이어 행동
  → 판정 (judgment_system.md)
  → NPC 상태 변화 (기억 태그, 의심도, 생사)
  → 소문 생성 판정 (노출 수준 → 강도)          ← 3장
  → 소문망 전파 (며칠 만에, 어디까지, 얼마나 왜곡되어)  ← 3장
  → 세력의 조직적 인지 (조직 채널 도달 시 점수 가산)   ← 4장
  → 세력 반응 단계 전이 (점수 임계값)            ← 4장
  → 지역 상태 변화 (사건 결과 → 치안/경제/민심)     ← 5장
  → 임계 효과 → 새 사건 발생 → (루프 재시작)
```

모든 수치는 내부 상태다. 플레이어에게는 언제나 서사(소문의 말, NPC의 태도, 거리의 분위기)로만 보여준다 — 기획서 10·17장의 원칙.

## 2. 시간 시스템 (G4)

### 2.1 하루 5구간제

```text
새벽 → 아침 → 낮 → 해질녘 → 밤
```

행동 비용은 5등급: **minor**(구간 소모 없음, 같은 구간에 3회까지) / **segment**(1구간) / **half_day** / **full_day** / **multi_day**. 행동별 비용은 `config/time.yml` 참조. 대화·엿듣기는 minor, 소문 수집·조사·잠복·현 내 이동은 segment, 수련은 full_day.

### 2.2 데드라인 사건

사건 타이머는 **남은 구간 수**로 카운트다운한다. "내일 해 질 무렵 습격"을 밤에 인지했다면 잔여 8구간. 플레이어가 구간을 소모할 때마다 타이머가 줄고, **소진되면 사건은 플레이어 없이 진행된다.** 이것이 "세계는 기다려주지 않는다"의 수치적 실체다.

### 2.3 피로

밤 구간에 휴식하지 않으면 다음 날 피로(판정 −1), 이틀 연속이면 −2. 데드라인 압박과 결합해 "무리해서 잠복을 이어갈 것인가"가 실제 트레이드오프가 된다.

## 3. 소문 시스템 (G1)

### 3.1 생성 — 노출 수준이 강도를 정한다

| 노출 수준 | 강도 | 예 |
|-----------|------|-----|
| 공개 + 다수 목격 | 3 | 장터 습격, 공개 결투 |
| 소수 목격 / 간접 | 2 | 객잔 안의 소동 |
| 흔적만 | 1 | 시체, 핏자국 |
| 완전 은밀 | 0 (소문 없음) | — |

판정 연동: **대성공은 강도 −1** (흔적을 지운다), **아슬아슬한 성공의 부수 리스크**로 강도 1 소문 후보, **치명적 실패는 강도 +1** (요란한 노출). 은신 판정의 질이 곧 소문의 크기다.

### 3.2 전파 — 6개 소문망

청하현 기준: 민간/장터, 객잔/낭인, 상단 연락망, 하오문/암시장, 정파/의뢰소 연락망, 관청/관군. 각 망은 **전파 속도(도달 일수)**, **왜곡률(정확도 감소)**, **관심사(반응하는 태그)**를 가진다. 하오문 망은 빠르고 정확(1일, −5), 정파 연락망은 느리지만 정확(3일, −5), 민간은 빠르지만 크게 왜곡(1일, −20).

전파 범위는 강도가 정한다: 1=발원 장소의 망 하나 / 2=현 내 관심 일치 망 전체 / 3=현+인접 현 / 4=지역권 / 5=천하.

### 3.3 왜곡 — 같은 사건, 다른 이야기

초기 정확도(직접 목격 90 / 간접 70 / 흔적 추론 50)에서 망을 건널 때마다 왜곡률만큼 깎인다. 정확도 구간이 곧 표현 지침이다:

```text
80~100 사실적:  사건이 거의 그대로
50~79  과장:    규모·실력·잔혹함이 부풀려짐
30~49  오해:    범인·동기·대상이 뒤바뀜   ← 플레이어에게 누명 또는 은폐막이 된다
 0~29  괴담:    원형을 알아볼 수 없는 흉흉한 이야기
```

### 3.4 소멸과 기억

강도는 3일마다 −1. 0이 되면 소문은 죽지만, **접촉했던 NPC의 기억 태그로 잔존**한다(G6). 기억 태그는 `직접_경험 / 전해들음 / 소문` 3종 — 직접 경험은 소멸하지 않고, 전언·소문은 30일 후 세부를 잃는다. NPC 간 대화로 전달 가능하되 전달마다 정확도 −10. **세계는 잊지만 사람은 기억한다.**

## 4. 세력 반응 시스템 (G2)

### 4.0 세력 id 규약 — 이름은 하나여야 한다 (2026-07)

세력을 부르는 이름이 **세 갈래**로 갈라져 있었다: 구성원 id(`haomun`) · 계열 id(`unorthodox`) ·
한글명(`하오문`). 같은 세력을 파일마다 다른 철자로 불렀고, 12종이 등록부에서 해소되지 않았다
(`gwangun` vs `gwan_gun`, `jeongboSang` vs `jeongbosang`, `사파`, `표국`, `의가` …).
조인이 안 되는 참조는 **조용히 빗나가는 참조**다.

**규약: 전 config 의 `faction:` / `factions:` / `group:` 값은 `factions.yml` 의 id 를 쓴다.**

```text
계열(5)     faction_groups 의 키           orthodox · unorthodox · forbidden · authority · civilian
조직·문파   faction_groups.*.members 의 키  소문자 스네이크 (haomun · hwasan · pyoguk · gaebang …)
한글명      표기 전용 — 참조 값으로 쓰지 않는다
별칭        factions.yml `aliases` — 한글·구철자 입력(LLM·플레이어 발화)을 id 로 정규화
예외        무소속 · 미상 · 없음 · 해당_문파 (세력이 아닌 서술 값)
```

개별 참조되던 문파·세가는 **1급 id 를 받았다** (화산파 `hwasan`, 소림사 `sorimsa`, 무당파 `mudang`,
남궁세가 `namgung`, 사천당가 `dangga` — `parent` 로 상위 조직을 가리킨다). 실재하는데 등록만 없던
세력도 등재했다: 개방 `gaebang` · 불가 `bulga` · 독문 `dokmun` · 표국 `pyoguk` · 의가 `uiga`.
`sects` / `clans` 명단은 상위 조직의 로스터로 그대로 남는다.

### 4.1 조직적 인지의 규칙

핵심 설계 결정: **세력의 반응은 그 세력의 조직 채널에 정보가 도달했을 때만 시작된다.** 조직원 개인이 객잔에서 들은 것은 그 NPC의 기억 태그일 뿐이다. 이 규칙 덕분에 망별 전파 속도가 곧 "세력별 반응 시차"가 된다 — 하오문은 하루 만에 움직이고 정파는 사흘 뒤에 보고를 받는다.

### 4.2 반응 점수와 단계 전이

세력 반응은 **세력 × 대상별 점수(0~30)**의 누적이다.

```text
0 무관심(0) → 1 소문 인지(1) → 2 정보 수집(4) → 3 접촉/경고(8)
→ 4 의뢰/회유/협박(13) → 5 직접 개입(19) → 6 토벌/전쟁(26)
```

입력 점수표(발췌): 소문 도달 +1(정확도 70↑이면 +2), 조직원 사망/중상 확인 +4, 연락책 연락두절 +3, 거점 노출 +3, 금전 손실 대규모 +5, 이익 제공 −2, 큰 공적 −4. 전체는 `config/faction_reaction.yml`.

중복 가산 금지 3원칙: 직접 겪은 사건의 소문은 가산하지 않는다 / 연락두절 후 사망 확인은 차액만 / 같은 소문은 세력당 1회.

### 4.3 대상 추적 — "누구를 향한 반응인가"

점수는 대상별로 관리한다. 정체를 모르면 **"미상의 낭인" 같은 가상 대상에 누적**하고, 정체가 확인되는 순간 실제 대상으로 병합한다(합산, 상한 30). 병합 자체가 "하오문이 네 이름을 알아냈다"는 사건이다. 플레이어가 정체를 숨기는 플레이(변장, 가명)는 병합을 늦추는 행동으로 수치화된다.

### 4.4 감쇠 — 세계는 잊는다, 단 한계가 있다

7일마다 −1. 단, **3단계(접촉)까지 갔던 대상은 점수 4 아래로 떨어지지 않는다** — 한번 조직의 장부에 오른 이름은 완전히 잊히지 않는다.

### 4.5 우호 축 (F3 해결 — PT-001 발견 과제)

주목(위협) 축만으로는 "상단을 구한 공로"가 세력 차원에 기록되지 않았다 (곽진 개인 신뢰로만 남음). 그래서 **세력 관계를 두 축으로** 완성한다:

```text
주목(score):  얼마나 신경 쓰는가 — 0~6단계 (기존)
우호(favor):  어느 편으로 보는가 — 낯섦(0) → 안면(4) → 신용(8) → 공신(13) → 은인(19)
```

- 입력: 공적 대(+4 — 습격 저지, 조직원 구명) / 공적 소(+2 — 의뢰 완수) / 협조(+1) / 배신(−4, 주목 축에도 동시 가산)
- 등급별 혜택: 안면=하급 의뢰 → 신용=신원 보증 → 공신=**추천장**·세력 비호 1회 → 은인=자원 동원, 문파 입문 대폭 가점
- 감쇠는 30일 −1로 위협보다 느리고, 공신 도달 이력은 신용(8) 밑으로 잊히지 않는다 — **은혜는 장부에 남는다.**
- **두 축은 독립이라 조합이 서사를 만든다**: 주목 높음 × 우호 높음 = "유능하고 위험한 자" → 3단계 접촉이 협박이 아니라 회유·영입 제안이 된다. PT-001의 종료 구도(습격을 막은 공로자이자 하오문 요주의 인물)가 정확히 이 조합의 예다 — 상단 우호 4(안면) × 하오문 주목 3.
- NPC 개인 신뢰와는 별개 축: 곽진이 고마워하는 것(개인)과 상단이 기억하는 것(조직)은 다르며, 개인 신뢰는 보고를 거쳐 우호 입력이 된다.

## 5. 지역 상태 변화 (G3)

치안/경제/민심(0~100, 기준 50)에 사건 결과가 즉시 반영된다. 변화량 표는 `config/region_state.yml` — 상단 습격 성공 {치안 −5, 경제 −3, 민심 −2}, 도적 두목 제거 {치안 +5, 민심 +3}, 열병 방치 주당 {민심 −3, 경제 −2} 등.

**이 표가 곧 '지역 누적 시간'의 실체이자 공유 세계의 접합점이다** — 서로 다른 플레이어의 사건 결과가 같은 수치에 쌓인다.

자연 회복: 사건이 없으면 10일마다 기준값 방향으로 1. 임계 효과: 치안<30이면 도적 사건 자동 발생 판정·야간 조우, 민심<30이면 소문 왜곡 +20·민간 협조 저항 +2, 치안>70이면 관군 순찰로 은밀 행동 −1 — **지역 상태가 판정과 사건 발생으로 되먹임되는 지점**이다.

## 6. 검증 — 경로 B(폭력 루트) 기계 재생

`tools/simulate_world_reaction.py`가 위 규칙만으로 설계 검토의 경로 B를 하루 단위로 재생한다. 수동 입력은 플레이어 행동과 그 직접 결과뿐이고, 전파·인지·감쇠는 전부 자동 계산이다.

```text
D+0 밤   객잔에서 묵삼 기습 제압 → 소문 R1(강도2, 정확도70) 발생
         지역: 증거_없는_폭행 (치안 48, 민심 54)
         하오문: 연락두절 +3 → 1단계 [소문 인지]
D+1      R1이 하오문 망 도달(정확도 65) +1 → 2단계 [정보 수집] — "범인 찾는 의뢰"
D+2      흑랑 보고 (차액 +1) → 점수 5 / 관군·상단 망에도 R1 도달(정확도 60, 과장)
D+3 해질녘 상단 습격 발생 (정보는 이미 흑랑에게) → 치안 43, 경제 45
         상단: 대규모 손실 +5 → 2단계 [조사 착수] / 관군: 중대사건 +3
         정파 연락망에 R1 도달 → 1단계 [소문 인지]
D+5      관군 망에 R2(정확도 80, 사실적) 도달 → 순찰 강화
D+6      R1 소멸 — 접촉 NPC 기억 태그로만 잔존
```

**D+7 결과가 설계 검토 3장의 스트레스 테스트 표와 일치한다**: 하오문 0→2(수배 의뢰), 정파 0→1, 상단 0→2, 치안 −7/경제 −3. 검토 당시 GM 재량으로 메꿨던 6개 지점(소문 도달 범위·사파 반응 근거·치안 −5의 출처·소연의 인지 경로·습격까지의 시차·점수 귀속)이 전부 설정 파일의 규칙으로 대체되었다.

검증 과정에서 발견되어 수정된 설계 결함 2건:
1. 세력 접속망에 객잔망을 포함하면 발원지 소문을 당일 인지해버림 → **조직 채널 원칙**(4.1)으로 해결
2. 당사자 세력이 자기 사건의 소문으로 이중 가산됨 → **중복 가산 금지 3원칙**(4.2)으로 해결
