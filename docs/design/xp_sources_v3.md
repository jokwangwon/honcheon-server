# 원천별 XP 값 — 성장 v3 단계 4 (cultivation_v3_levels §5 미결 ③·⑥) ★확정

> 2026-07-24 조율자 제안 → **같은 날 사용자 결정 회차로 확정** (아래 §0). config 정본 =
> `cultivation.yml levels.xp_sources`. 기술 화후(0.3일치)는 그대로 산다 — XP 는 **같은
> 사건에서 다른 축**(레벨)이 자라는 것.

## 0. ★확정 (사용자 2026-07-24 — 아래 §1~4 의 원안과 다른 곳은 이 절이 이긴다)

1. **전투 XP = 클래식 고정값**: `몹 레벨 × 등급 계수` (잡졸 1.0 · 정예 1.5 · 두목 3.0).
   상황 배수(격차·목숨 무게)·반복 감쇠·일일 상한 **전부 없음** — §1 의 연속식 재사용안은 기각.
   미등록 몹 레벨 = 상당 경지의 자격 레벨 (삼류=10 · 이류=40 · 일류=65 · 절정=80 — 자동 유도).
   몹 레벨제의 부산물 = **사냥 구간** (지역별 레벨 대역이 몹 배치에서 드러난다).
   ★후반 도달 시간이 승인표(화경 400h)보다 압축되는 것 **수용** — 실측 후 계수 재보정,
   승급은 사건 마크가 잠근다.
2. **무명의뢰 XP 승인**: §2 표 그대로 (80/50/40/30 · 실패·만료 0 · 끼인 전투 XP 별도).
3. **사선 보너스 폐지** (§3 기각): 사선 '마크'(승급 요건)만 남는다. 파악법은 현행 기계 정의
   그대로 — 처치 순간 내 체력 절반 미만 + 격상 상대 (HuntListener).
4. **내공 축 A안 · 통일** (§4): 내력 풀 = √원장[내공] 파생 — 포인트가 단전을 키운다.
   축기·심법은 개화(자격)로만 남는다.

## 1. 유효 전투 (연속식 — combat_hwahu 재사용)

| 항 | 값 | 근거 |
|---|---|---|
| base_xp (동수·실전_사냥) | **10** 【제안】 | 유효 전투 ~20회/h 가정 × 10 = 200 XP/h 앵커 |
| 상대_격차 배수 | 상수 2.0 · 동수 1.0 · 하수 0.25 · 압도적_하수 0 | combat_hwahu.multipliers **동일 값 재사용** |
| 목숨_무게 배수 | 생사 2.0 · 실전_사냥 1.0 · 비무_대련 0.5 | 〃 |
| 반복 감쇠 | 같은 유형 연속 회당 −50% | 〃 (repetition_decay_rate 0.5) |
| 일일 상한 | **없음** 【제안】 | 사다리(growth 1.0565)가 이미 감속. 하드코어 8h/일=화경 50일 모델은 무상한 가정. 화후의 3일치/일 상한은 "몸의 한계"라 기술 축에만 |
| 짐승 | beast_ranks 상당 경지로 격차 계산 | 기존 규칙 그대로 (들짐승=삼류 · 맹수=일류 · 영물=절정+) |

체감 검산: Lv1→2 = need 20 = 동수 2마리. 첫 1시간 ≈ Lv10 (삼류 자격 — "첫 저녁에 무공").

## 2. 무명의뢰 (단발 — populace.yml quests.rules 4종)

앵커: 의뢰 한 건의 놀이 시간 ≈ 10~25분 → 200 XP/h 비례.

| 의뢰 | XP 【제안】 | 시간 가늠 |
|---|---|---|
| 산길_대행 | 30 | ~10분 (이동 위주) |
| 야간_순라_보조 | 40 | ~12분 (대기+순찰) |
| 시신_수습 | 50 | ~15분 (수색+운구) |
| 아이_실종 | 80 | ~25분 (수색+전투 가능) |

실패(fail_body)·만료 = 0. 전투가 낀 의뢰는 전투 XP 가 따로 든다 (중복 아님 — 다른 사건).

## 3. 사선 보너스 귀속 (미결 ⑥)

옛 규약(사선_경험 = 관련 능력치 화후 +30일치)은 v3 에서 갈 곳이 없다 — 행위→능력치가 소멸했다.

**【제안】 사선 1장 = XP + need(현재 레벨) × 0.5** (반 레벨 — 죽을 뻔한 값은 레벨에 비례해 자란다).
장당 1회 상한 유지. 마크(승급 요건 카운트)는 별개 축 그대로.

## 4. 내공 축 (조율자 발견 — 두 장부: 원장[내공] vs 축기_원장)

판정의 내공은 원장[내공](포인트로 큼)을 읽는데, **내력 풀은 축기_원장(앉아서 모은 일치)** 을 읽는다.
포인트를 내공에 부어도 단전이 안 커진다 — 통일 여부는 세계관 결정이다:

- **A안 · 통일**: 내력 풀 = √원장[내공] 파생. 포인트가 단전을 키운다. 축기·심법은 개화(자격)로만 남음.
- **B안 · 현행 유지**: 포인트 내공 = 판정(운기·요상 판정)만. 단전은 앉아서 만든다 (축기 정본).
  "단전은 수련의 것"이라는 로어 보존 — 대신 내공 포인트의 가치가 다른 축보다 얇다.

## 5. 승인 뒤 배선 순서 (단계 4)

XP 적립(연속식 재사용 · 봇 정산) → 레벨업 판정(need 곡선 · cultivation.yml levels) → 3포인트 지급
→ 배분 명령/버튼(원장 캡 c² · 포인트 은행) → 승급 게이트(자격 레벨 N_k + 사건 마크 — battle_marks 재사용)
→ v2 수련→능력치 경로 동결(화후 동결 — backfill 화해가 자연 무연산이 되는 그 시점).
검증: xp_pacing.py 대조 · growth_v3_backfill_selftest(raise-only 눈 이미 있음) · 인게임.
