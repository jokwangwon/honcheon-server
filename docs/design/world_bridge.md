# 세계 다리 (世界橋) — 몸과 장부를 잇는다

## 1. 문제 — 세계가 둘로 쪼개져 있었다

이 프로젝트는 몸이 둘이다.

- **마인크래프트 (MVT, Paper 플러그인)** — 사건이 **벌어지는** 곳. 사람이 죽고, 도적이 베이고, 검기가 터진다.
- **디스코드 봇 (JDA + SQLite)** — 세계의 **장부**. 소문·명분·수사·세력·의뢰.

그런데 둘 사이에 다리가 없었다. 마크에서 마을 사람을 스무 명 죽여도 봇의 소문망은 조용했고,
관은 그를 쫓지 않았고, 정파는 그의 이름을 몰랐다. **사건이 세계에 등록되지 않으면 그것은 일어나지 않은 것이다.**

이 문서는 그 다리를 정한다.

---

## 2. 무엇으로 잇는가 — 후보 셋과 판정

두 프로세스는 **별도 JVM** 이고, **봇은 항상 떠 있지 않다**. 이 두 사실이 모든 것을 결정한다.

### (c) 로컬 소켓 / HTTP — **탈락**

가장 먼저 떠오르지만 가장 먼저 죽는다. 봇이 꺼져 있으면 **사건이 증발한다.**
"그럼 MVT 가 버퍼링하면 되지 않나" — 그 버퍼가 유실되면 안 되니 결국 디스크에 써야 하고,
그 순간 이것은 (a)에 소켓 계층을 얹은 것에 불과하다. 다리 하나를 놓자고 배송 계층을 둘 만들 이유가 없다.
게다가 요청/응답의 동기성은 마크 메인 스레드에게 독이다 — **봇이 느리면 서버가 렉이 걸린다.** 인과가 거꾸로다.

### (b) 봇의 SQLite 에 MVT 가 직접 이벤트 테이블로 적재 — **탈락**

가장 유혹적이다 (표가 이미 있으니까). 그러나 셋이 걸린다.

1. **잠금.** WAL 이 다중 프로세스를 견디는 것은 맞다. 그러나 견딘다는 것은 **기다린다**는 뜻이다.
   봇이 세계일 정산으로 쓰기 트랜잭션을 물고 있는 동안 마크가 `INSERT` 를 시도하면 그 스레드가 **막힌다.**
   그것이 메인 스레드면 그 순간이 곧 TPS 붕괴다. "쓰기 스레드로 빼면 되지 않나" — 그러면 또 큐가 필요하다.
2. **단일 작성자 규약의 파기.** `Db.java` 는 첫 줄부터 "단일 파일·**단일 작성자**·WAL" 이라고 적혀 있다
   (persistence.md). 스키마 마이그레이션(`tools/migrate_db.py`)은 **봇이 멈춘 상태**를 전제한다.
   마크가 같은 파일을 쥐고 있으면 그 전제가 무너진다.
3. **결합.** 플러그인이 봇의 스키마 버전을 알아야 한다. 봇의 표가 바뀔 때마다 마크가 깨진다.

### (a) 파일 기반 append-only JSONL + 봇의 폴링 — **채택** ✅

```
MVT ──emit()──▶ run/bridge/mvt/20260712.jsonl  ──poll(5초)──▶ 봇
                (한 줄 = 한 사건, 추가만)                       │
                                                              ▼
MVT ◀──poll(20초)── run/bridge/world_state.json ◀──publish()── 봇
                    (원자적 교체 — 최신이 이긴다)
```

- **유실이 없다.** 봇이 사흘 꺼져 있었어도 사흘치가 파일에 그대로 있다. 켜는 순간 커서가 따라잡는다.
  *파일은 잊지 않는다.*
- **쓰는 쪽이 막히지 않는다.** `emit()` 은 큐에 넣고 즉시 돌아온다. 디스크 쓰기는 데몬 스레드가 한다.
  마크 메인 스레드는 봇의 존재조차 모른다.
- **결합이 없다.** 봇의 스키마가 바뀌어도 마크는 모른다. 계약은 JSON 봉투 하나뿐이다.
- **사람이 읽을 수 있다.** 세계에 무슨 일이 있었는지 `cat` 으로 본다. 재생·감사·디버그가 공짜다.
- **잠금이 없다.** `O_APPEND` 한 번의 `write` 로 줄 단위 원자성을 얻는다. 읽는 쪽은
  **개행으로 닫히지 않은 마지막 줄을 읽지 않는다** — 반쪽 사건이 세계에 들어올 길이 없다.

대가는 지연(최대 5초)이다. 소문이 5초 늦게 도는 세계 — 값싸다.

### 방향에 따라 실어 나르는 것이 다르다 (이 다리의 핵심 비대칭)

| | 흐르는 것 | 방식 | 왜 |
|---|---|---|---|
| MVT → 봇 | **사실** (사건) | append-only 큐 | 순서가 있고, 하나도 잃으면 안 되고, 두 번 적용되면 안 된다 |
| 봇 → MVT | **상태** (소문판·수배·우호) | 스냅숏 (원자적 교체) | 최신만이 참이다. **어제의 소문판을 다시 트는 것은 세계가 아니라 녹음이다** |

되먹임을 큐로 만들면 재생·순서·유실을 다 걱정해야 한다. 그럴 필요가 없다 — 상태에는 역사가 없다.

## 3. 멱등 — 사람은 두 번 죽지 않는다

커서(`world_meta '다리:커서'` = `"파일:바이트오프셋"`)는 **한 줄마다** 갱신된다. 그러나 커서를 쓰기
직전에 봇이 죽으면? 그 줄을 다시 읽는다. 그래서 커서만으로는 부족하다.

진짜 못은 **`bridge_inbox`(PK = event_id)** 다. MVT 가 발신 때 봉투에 박은 uuid 를 봇이 먼저 표에 꽂고,
꽂히지 않으면(이미 있으면) 건너뛴다.

> **재생은 무해하다.** 커서를 통째로 지우고 파일 전체를 다시 읽혀도 세계는 같은 자리에 선다.
> (검증 완료 — 5절)

## 4. 이벤트 등록부 — `config/world_bridge.yml`

**config 가 단일 진실 원천이다.** 여기 없는 kind 는 MVT 가 발신해도 봇이 버린다(경고 로그).
페이로드도, 그 사건이 낳는 소문의 태그·강도·정확도도, 지역 델타도 전부 이 파일이다.

| kind | 뜻 | 봇에서 벌어지는 일 |
|---|---|---|
| `npc_death` | 사람이 죽었다 (무명 / 등록 NPC) | 사망 등록 → **목격·시신이 정하는 소문**(npc_death.yml `rumor_matrix`) → 민심 −1 → (관이면) 법명분 |
| `bandit_slain` | 도적을 베었다 | 소문(도적·치안·무재) + **치안 +1** (두목 ×2) |
| `beast_slain` | 짐승을 잡았다 | 장부에만. 늑대 한 마리는 소문이 못 된다 — **영물만** 사람들이 말한다 (강도 3) |
| `qi_manifested` | **격이 터졌다** | "그자가 검기를 뿜었다더라" — 소문의 씨앗. 강도는 격이 정한다 (발경 1 … 강기 3) |
| `sparring` | 비무 | 낮은 소문. 장터에서 하면(구경꾼 다수) 이야깃거리가 된다 |

**새 수치를 발명하지 않는다.** 다리는 이미 있는 세계 기계에 사건을 밀어 넣을 뿐이다:
`Deaths.rumorFor`(목격 × 시신 행렬) → `Rumors.arrivals`(망별 속도·왜곡) → `Db.spreadRumor` →
`GameListener.factionAwareness`(조직 채널에 닿으면 주목). 다리가 세계를 왜곡하지 않는 유일한 방법이다.

### 두 개의 접합표

- **신원** (`mvt_link`) — 마크의 몸(uuid) ↔ 봇의 캐릭터(character_id).
  이것이 없으면 **소문에 주체가 없다** → 어느 세력도 그를 주목하지 않는다. 사건은 세계의 배경음이 된다.
- **장소** (`place_map`) — populace.yml 의 자리(`산길_어귀`) → rumor.yml 의 장소 키(`north_road`).
  이 번역이 없으면 **산길에서 난 일이 장터의 소문이 된다.** 발원망이 곧 그 소문이 처음 도는 곳이다.

### 목격이 모든 것을 정한다

`npc_death` 의 소문 강도·정확도는 **실제로 센 목격자 수**와 시신 처리가 정한다 (`rumor_matrix`).

- 백주 장터(목격 2+) → 강도 3, 정확도 90, **가해자의 이름이 소문에 실린다** → 관군·정파가 그를 주목한다.
- 아무도 없는 골목 + 시신 은닉 → **소문 없음.** 대신 3일 뒤 *실종*이 게시판에 뜬다.
  은밀형의 보상이자, 이 세계가 목격을 존중한다는 증거.

같은 이유로 **아무도 없는 산속의 검기는 소문이 되지 않는다** (`min_witnesses: 1`).
무공은 목격될 때 비로소 강호의 일이 된다.

## 5. 굴러가는 줄기 (검증 완료)

`무명 사망 → 봇 DB 적재 → 소문 생성 → 세력 주목 → 되먹임`

실 DB 사본에 대해 통줄기를 돌렸다 (세계일 22, 캐릭터 #1 '디돈' ↔ mc `1111…`):

```
① MVT   WorldBridge.npcDeath("populace","namu_kkun_1","박씨","나무꾼","산길_어귀", 목격 3, …, "Lindydone")
        → run/bridge/mvt/20260712.jsonl 에 한 줄
② 봇    Bridge.drain() → 적용 3건
        npcs      : 무명:namu_kkun_1 | tier 0 | 사망 | {사망일 22, 목격 2, 시신 즉시_발견 …}
        rumors    : 4개 망 도달 — sangdan_net(22일, 정확도 90) · mingan_market(23일, 70)
                    · inn_net(23일, 75) · gwan_net(24일, 80)
                    내용 "Lindydone이(가) 나무꾼 박씨를 베었다" · 주체_id 1
        events    : 사망 / 토벌 / 격_목격 (actor = character #1)
        세력 인지 : gaebang 주목 4 · sangdan 주목 2   ← 소문이 조직 채널에 닿았다
        regions   : 민심 50 → 49 (무명의 죽음) · 치안 50 → 52 (도적 두목 ×2)
③ 봇    publish() → run/bridge/world_state.json (원자적 교체)
④ MVT   스냅숏 판독 → 행인 반응 스위치 [도적_소문, 열병_소문]  ← Populace.rumor(tag, true) 로 들어간다
⑤ 멱등  커서를 지우고 파일 전체 재생 → 적용 0건. 소문 19 → 19.  ✓ 사람은 두 번 죽지 않는다
```

부수 검증:
- **발원망 접합** — `산길_어귀` 의 죽음은 `sangdan_net`(상단망)에서 시작한다. 장터가 아니다.
- **중복 발신 차단** — 한 전투에서 검기를 5번 뿜어도 **소문은 하나** (`dedupe_seconds: 600`).
  매 타격을 다리에 실으면 장부가 검기로 덮인다.

## 6. 되먹임 — 장부가 몸에게

`run/bridge/world_state.json` 한 장에 세계의 지금이 담긴다.

| 담기는 것 | 마크에서 무엇이 되는가 |
|---|---|
| `populace_reactions` | **`Populace.rumor(tag, on)`** — 도적 소문이 돌면 나무꾼이 산길을 피한다 (이미 있는 API) |
| `wanted` (법명분) | 문턱 8 = 포두가 움직인다 → 마을 관졸이 적대. 10 = **강호의 절연** (정파도 등을 돌린다) |
| `favor` (세력 우호) | 산문의 문이 열리고 닫힌다 |
| `region` | 치안·경제·민심 — 스폰 정원·물가의 입력 |

`WorldBridge.state()` 로 언제든 읽는다: `state.wanted(uuid)` · `state.mandate(uuid)` ·
`state.favor(uuid, "hwasan")` · `state.reactions()`.

**중요.** `WorldBridge` 에는 `org.bukkit` import 가 **하나도 없다.** 일부러 그렇다 —
① 헤드리스로 검증되고 ② 메인 스레드를 절대 건드리지 않는다. 되먹임을 세계에 **적용**하는 것
(= 메인 스레드 진입)은 `onState(...)` 를 등록하는 **배선 쪽의 몫**이다.

## 7. 운용

- 다리 폴더: `run/bridge/` (`.gitignore` 의 `run/` 아래 — 커밋되지 않는다).
- MVT 는 데이터 폴더에서 거슬러 올라 저장소 루트를 찾는다 (`config/` + `.git`). 환경변수
  `HONCHEON_HOME` 으로 덮어쓸 수 있다 (마크 서버를 저장소 밖에서 돌릴 때).
- 조각 파일은 날짜별(`20260712.jsonl`)이라 이름순 = 시간순. 처리 끝난 조각은 **지우지 않는다** —
  세계의 원장이다 (`retain_days: 30`, 청소는 사람이).
- **봇이 꺼진 채로 마크만 돌아도 된다.** 사건은 쌓인다. 봇을 켜는 순간 세계가 따라잡는다.
