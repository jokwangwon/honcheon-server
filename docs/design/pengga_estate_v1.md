## 1. 한 줄 컨셉 【제안】

**"도적을 소탕하는 가업의 집"** — 하북 평야의 관도가 지나는 벌판에 담을 두른 무가 장원.
상업 도시가 아니라 **일하는 집**이다: 연무장에서 도성(刀聲)이 그치지 않고, 정문 앞 관도로
상단이 지나가며 호위를 청한다. 시작하는 아이는 이 집의 자제(또는 객)로 아침을 맞는다.

- 크기의 자: 상업 자(commercial) 아님 — **장원 자(footprint = 기능 구획의 합)**.
  `commercial_class: unresolved` (교역 근거 없음 — 정직하게 미결).

## 3. 시작 동선 【제안】 — 뿌리내림의 장원판

서장(세가 내 이야기 — B-187 계율: **장원 실물과 같은 회차에 나간다**)이 끝나면, 아이는
**내원 자제방에서 아침**을 맞는다. 청하현 릴레이(섭구→장쇠→곽진)의 장원 대응:

| 청하현 | 장원 대응 【제안】 | 가르치는 것 |
|---|---|---|
| 섭구 (맞이) | **집사** — 정문·외원 안내, 첫 심부름 | 생계·상점 문법 (월례 지원 수령 포함) |
| 장쇠 (병기) | **도장고지기** — 대여 병기 수령 (가문_대여 배선의 실물) | 무기·장비 |
| 곽진 (수련·승급) | **도장 사범** — ★가전 무공 입장권의 소비처: 개산도법 사사 | 수련·운기·승급 조건 |

- 사냥터 대응: 장원 밖 평야의 **도적 무리** (가업 = 첫 사냥 서사가 공짜로 선다).
- 문파 추천(확정 ①): 이 마을의 추천 소속 = **하북팽가** — 강요 없음, 심리 테스트 결과에
  「이 벌판이 너를 불렀다」 결로 안내만.

## 4. 미결 — 사용자 결정 대기 (지어내지 않는다)

1. **딸린 촌락** — 장원 단독인가, 정문 앞 작은 마을(주막·대장간)을 두는가.
2. **안내인 3인의 이름** — 집사·도장고지기·사범 (npcs 등록부 신설 — 이름은 사용자 몫).
3. **청하현과의 관계** — 관도로 잇는가(도보/역참), 당분간 서사상 별개인가 (funnel_rule 역방향).
4. **비(非)팽가 아이가 이 마을에 뽑히면** — 객사에서 시작하는 객(客)인가, 팽가 방계인가.
5. **서장 B안 (세가 내 이야기)** — 발단 4종(비무행·그림자_시험·밀서·견문)을 장원 기준으로
   재결할지, 유지할지 (계율: 문장은 장원 실물과 한 회차).
6. 치수·구획 전부 (§2).
