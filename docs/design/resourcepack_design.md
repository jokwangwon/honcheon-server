# 리소스팩 디자인 규정 — 디자인 언어·슬롯 등록제·제작 경로

> 질문: 리소스팩의 디자인 결정은 어떻게 되는가.
> 답: 스펙과 아트를 분리한다 — **슬롯(코드포인트·크기·의미)은 등록제로 고정**하고,
> 아트(PNG 내용물)는 언제든 교체 가능하게. 지금 든 것은 플레이스홀더다.
> 기계 판독용: `config/resourcepack_design.yml`

---

## 0. 현재 상태 — 정직한 표기

```text
현재 팩 = 프로그래머 아트 (build_resourcepack.py가 코드로 그린 도형)
목적   = MVT 기능 검증 (글리프 파이프라인·틴트·게이지가 '동작'하는지)
아트 품질은 결정 사항이 아니라 보류 사항 — 슬롯 계약만 지키면 PNG 교체로 승격된다
```

## 1. 디자인 언어 — 무협 수묵(水墨) 문법 (제안 기준선)

```text
기조   먹과 한지 — 저채도·저명도 기본, 채도는 '의미'에만 허락한다
색 규율 시스템 색 = 의미 색 (변경 금지 — 색맹 대응은 아이콘 병기로):
        기세 4색   회(§압도적 하수)/백/황/적 — MC 색 코드 틴트라 팔레트가 곧 규칙
        경지 색    칭호 표기용 — 삼류~생사경 8단 (등록)
        품질 색    범철 회 / 정련 백 / 보병 청 / 신병 금 / 마병 암적 (장비 등급)
형태   곡선보다 획(劃) — 글리프는 붓끝의 느낌, 도형은 각지게 (픽셀 아트 규율과 상합)
장식   금지에 가깝게 — "정보가 장식보다 먼저": HUD 글리프는 1초 안에 읽혀야 한다
      화려함은 세계(오의 파티클·검강 응집)에 몫이 있고, UI는 조용해야 한다
```

## 2. 슬롯 등록제 — 코드포인트는 계약이다

사설 영역(U+E000~)을 **용도별 대역으로 선할당**한다. 코드(Glyphs.java)와 팩이 이 표로만 만난다 — 아트를 갈아도 코드는 불변:

```text
E000~E00F  기세·전투 아이콘 (E000 기세 ✅사용 중)
E010~E01F  게이지 (E010~18 화후 ✅사용 중 — 내력·원기 게이지 예약)
E020~E03F  경지·칭호 문장(紋章) 8단 + 별호 장식
E040~E05F  장비 등급·품질 아이콘 (범철~신병, 마병 혈향)
E060~E07F  세력 문장 (구파일방·오대세가·사파·관)
E080~E09F  GUI 배경 (경락도 전면, 전낭 탭, 상점) — 음수 공백 기법
E0A0~      예약
등록 규칙: 슬롯 추가 = config 등록 + 컴파일러 반영 (창작 오의·명명과 같은 등록제 문법)
```

## 3. 제작 규율 — 픽셀 스펙

```text
폰트 글리프   아이콘 8×8 / 게이지 20×6 (height·ascent은 컴파일러가 고정)
             백색+투명 2값 원칙 — 색은 코드(틴트)가 입힌다. 회색조 안티앨리어싱 최소
GUI 배경     256×256 기준 (인벤토리 규격) — 여기만 먹색 직접 채색 허용 (틴트 불가 채널)
아이템 텍스처  16×16 바닐라 해상도 준수 (32× 고해상도 금지 — 바닐라 이질감 방지)
사운드       .ogg 모노 — 돌파·적립은 짧게(<1.5s), 세계 공지는 종(鐘) 계열
```

## 4. 결정 절차 — 누가 정하는가

```text
① 디자인 토큰(색·슬롯·크기) = config 등록제 — 본 문서 + yml이 단일 원천, 변경은 커밋으로
② 아트 제작 경로 (승격 시점에 선택):
   A. 픽셀 아티스트 커미션  일관성 최고 — 슬롯 표+이 문서가 그대로 발주서가 된다 (권장)
   B. AI 생성 + 수작업 보정  빠름 — 2값 규율·픽셀 정합은 보정 필수
   C. 자체 제작            MVT 수준 유지 — 기능 검증엔 충분
③ 판정 기준 (어느 경로든): 1초 가독 / 2값 규율 / 틴트 검증(4색 모두) / 바닐라 이질감 없음
④ 승격 타이밍: 아트는 게임플레이를 막지 않는다 — M3(정식 서버) 전까지 플레이스홀더 허용
```

## 5. 확장 로드맵 (슬롯은 지금, 아트는 나중)

```text
MVT(현재)  기세 + 화후 게이지 — 플레이스홀더 ✅
M2와 함께  내력·원기 게이지, 경지 칭호 문장, 경락도 GUI 배경
M3와 함께  장비 등급 아이콘(팔기·전낭 UI), 세력 문장(명패), 커스텀 사운드(돌파·종)
원칙: 슬롯·컴파일러 대응을 먼저 넣고 아트는 교체형으로 — 코드 재작업 0
```
