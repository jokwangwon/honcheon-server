## 0. 바뀌는 것과 안 바뀌는 것

| | 현행 (B-179) | B안 (이 시안) |

| 선택 | 글자 패를 클릭 | **행동이 곧 선택** (웅크림·시선·상호작용) |

| 항해·격리·재접속 | Voyage 한 벌 | **그대로** (정박 무대 + 암전 도하 문법 재사용) |

★헌법 유지: **봇이 저자, 마크는 서책.** 행동 감지는 「어느 패를 눌렀는가」의 번역기일 뿐

choice 가 클릭 대신 행동에서 온다).

## 1. 파일럿 무대 — 「그날 밤」 (재난 7발단 공용)

서장 월드(honcheon_seojang) 밤바다 한쪽에 **기억의 마을** 세트 하나 (결정론·멱등 조성 —
buildBarge 문법):

- **방 안** (기상 지점): 이부자리 · 등잔 · 문 하나. 어둡다.
- **마당**: 우물 · 담 · 대문. 소리와 빛의 방향이 있다 (발단별 연출이 여기 갈린다).
- **골목 어귀** (퇴장 방향): 어둠 속으로 이어진다 — 장면이 끝나면 여기서 암전.

**흐름**: 정거장 1 접근 → 눈깜빡임(암전 12틱 — 기존 수치) → 방 안에서 깨어남 →
내레이션(발단별 첫머리 — 기존 문장) → **행동 대기** → 행동 감지 → seojang_choice 발신 →
발단별 결말 연출 → 암전 → 배 위 (2장은 현행 책 그대로 — 파일럿 범위 밖).

## 2. 행동 문법 — 패 3장의 번역 【제안】

| 패 (기존) | 행동 | 감지 |
|---|---|---|
| 숨을 죽이고 숨는다 (민첩) | **웅크린 채 3초** | sneak 지속 (TutorialGuide.gesture 웅크림 문법) |
| 소리 나는 쪽을 살핀다 (감각) | **소리·빛의 방향을 2초 주시** | 시선 벡터가 연출 지점을 향함 |
| 식구들부터 깨운다 (체력) | **식구에게 달려가 우클릭** | 방 안 NPC(식구 실루엣) 상호작용 |

- 안내는 화면이 아니라 **장면이 한다**: 소리가 나고, 빛이 새고, 식구가 뒤척인다.
  다만 첫 판이므로 액션바에 은은한 힌트 한 줄(「숨을까, 살필까, 깨울까」)을 둔다 【제안】.
- **오답 없음** — 셋 중 무엇을 하든 그것이 그 아이다 (기존 패와 동일). 60초(【제안】)
  아무것도 안 하면 기존 글자 패로 강등 폴백 (갇힘 금지 헌법 — 행동 감지가 죽어도 서장은 흐른다).

## 3. 발단별 연출 — 같은 무대, 다른 그날 밤 【제안】

| 발단 | 마당의 연출 (소리·빛·소품) |
|---|---|
| 가문의_몰락 | 담 너머 어른들의 언성(웅얼거림 소리) · 사랑채 창의 불빛이 흔들린다 |
| 습격 | ★개 짖는 소리가 **뚝 끊긴다** → 말발굽 소리 · 담 너머 주홍 불빛(화광) |
| 역병 | 멀리 곡소리 · 옆집 문에 흰 천 · 마당에 아무도 없다 |
| 목격 | 달빛만 밝다 · 골목 어귀에 **실루엣 하나가 느리게 고개를 돌린다** (BetterModel 또는 armor stand) |
| 맡겨짐 | 마당에 낯선 어른의 그림자 · 아버지의 등 — 둘 다 이쪽을 보지 않는다 |
| 핏줄의_비밀 | 방 안 벽장이 반쯤 열려 있다 · 문밖에서 발소리가 **멎는다** (소리가 끊기는 연출) |
| 아이_거두기 | 대문 밖에 등불 둘이 서 있다 — 움직이지 않는다 |

## 4. 리소스팩 연출 강화 — 「다른 RPG 하듯이」 【제안】

이미 있는 것 위에 얹는다 (새 발명 최소):
- **글리프 UI** (검기 시트판·기억첩 E0B0~ 문법 그대로): 장 제목 카드(「第一章 — 그날 밤」
  붓글씨 일러스트)를 화면 타이틀로 · 내레이션 틀(한월풍 장식 테두리) 유지
- **소리**: 앰비언트(밤벌레·바람) + 발단별 효과음(말발굽·곡소리·언성) — ogg 팩 수록
- **모델**: 식구·실루엣은 BetterModel(이미 기동 요건) 또는 armor stand + 커스텀 모델 소품
  (이부자리·등잔·흰 천)
- **빛·안개**: 기존 안개 링·시간 고정 문법 재사용 — 무대는 어둡게, 연출 지점만 밝게
- ★계율: 팩은 3정본 sha1 관리 그대로 · 팩 경로 겹침 함정(클라 로그 확인) 주의

## 5. 배선 뼈대 (파일럿)

- `config/seojang.yml`: 장면 1에 `enactment:` 절 신설 — 무대 id · 행동 3종(패 순서 대응) ·
  발단별 연출 키 · 폴백 초 (등록부가 정본, 코드는 지어내지 않는다)
- `Voyage`: 정거장 1 정박 → 무대 진입/복귀 (veil·relocate 재사용)
- 신규 `SeojangStagePlay` (MVT): 무대 조성(멱등) + 행동 감지 + 연출 발화 + choice 번역
- 눈: `antechamber_audit`에 enactment 검사(무대 실재·행동 3종=패 3장 대응·폴백 존재) + 뮤테이션

## 6. 미결 — 빨간펜 자리

1. 행동 3종의 매핑(§2)이 이대로 좋은가 — 특히 「살핀다」의 시선 감지가 체감상 자연스러운가
2. 폴백 60초·힌트 액션바 문구
3. 발단별 연출(§3)의 결 — 특히 목격의 실루엣, 습격의 화광 수위
4. 식구를 몇 명 세우나 (어머니 하나면 되는가 — 발단마다 가족 구성이 달라질 수 있다)
5. 2·3장(길 위·낯선 고을)도 체험형으로 갈지, 파일럿 평가 후 결정할지
6. 장 제목 카드 일러스트의 결 (검기 시트판 화풍 그대로인가)
