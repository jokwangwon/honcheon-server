# 문파 생활 — 입문 '이후'의 삶 (G2 해소)

> 입문 루트(추천·시험)는 있었으나 그 다음이 없었다. 문파는 혜택 꾸러미가 아니라
> **거래다**: 무공과 보호를 주고, 시간과 자유를 가져간다.
> 기계 판독용: `config/sect_life.yml`

---

## 1. 신분 사다리 — 플레이어는 진전제자까지

```text
속가/외문 제자 → 내문 제자 → 진전(眞傳)제자        [플레이어 영역]
집사·당주·장로·장문                                [NPC 영역 — 생애 사다리 '무인의 길' 문파 트랙]
승격 = 경지 관문과 같은 문법: 요건(공적·경지·연차) + 계기(사부 추천·비무·기여 사건)
```

## 2. 공적(功績) — 문파 내부 통화

```text
적립   문파 임무 수행(의뢰 생성기 ④ 세력 발생원과 직결)·기여 사건·비무 입상
소비   비급각 열람(층별 게이트) / 영약·재료 불하 / 폐관실 신청 / 사사 우선권
원칙   명성과 별개의 내부 축 — 강호에서 유명해도 문파 안에서는 공적으로 말한다
      (favor는 세력 '밖'의 축, 공적은 '안'의 축 — 이중 장부)
```

## 3. 얻는 것

```text
무공     비급각 — 1층(입문·삼류급, 외문부터) / 2층(이류급, 내문+공적) / 3층(절정급·
        심법, 진전+장로 허가) / 최심부(비전 오의 — 전승 자격, ultimate_arts 정합)
사사     사부 배정(내문부터) — 효율 1.0~1.2 + 경지 우위 보정 (training 기존 수치)
봉록     월 은 1~5냥 (신분별) — 생계 해방이 문파의 첫 번째 실질 혜택
보호     문파가 뒤를 봐준다 — 소속원 피습 = 문파의 세력 반응 자동 개입 (혼자가 아니다)
장소     정규 수련(효율 1.2)·폐관실(1.5)·안전 지역 (training location_safety 최상급)
이름     "화산의 제자" — 명성 보정이자 행동 제약 (아래 4장과 한 몸)
```

## 4. 치르는 것

```text
시간     월 임무 1회 의무 (거절 누적 = 문규) + 정규 수련 참석 — 자유 시간이 준다
문규     3진 체계: 경고 → 면벽(N일 — 폐관 아님, 시간 몰수) → 파문
        대상: 임무 거부 누적·사문 무공 무단 전수·타파 심법 겸수(simbeop 정합)·강호 물의
겸수 제한 심법은 사문 계보만 (dual_approved 목록 — 기존 규칙이 여기서 집행된다)
이름의 무게 소속원의 비열 행위·물의는 문파 favor·명성에 연대 반영 — 문파가 청구서를 받는다
        (그래서 문파는 사고뭉치를 파문한다 — 세계 반응 루프의 자연 귀결)
```

## 5. 파문(破門) — 문파판 죽음

```text
사유    문규 3진 / 금기(살문·마공 겸수·비급 유출)
집행    공적 몰수·비급 반납 요구(몸에 새긴 무공은 못 뺏는다 — 그래서 문파는 추격한다)
        '파문제자' 낙인 = 강도 3 소문 + 문파 적대 + 정파권 NPC 저항 +2 (배의 문법 재사용)
서사    파문제자는 히든 루트의 단골 재료 — 사문의 비전을 품고 강호를 떠도는 자
복권    가능 — 대공(大功) 1건 + 장문 재가 (등록 사건)
```

## 6. 사형제 — 관계의 격자

```text
서열 = 입문 순 (사형·사매·사제) — 동행 결의의 문파판 (배신 = 배의 + 문규)
알력 이벤트: 진전 자리·사사 우선권·비무 서열전 — 계절 정산이 NPC 사형제의 궤적을 굴린다
사문의 정: 사형제 사망 시 복수 의뢰가 문파 발생원에서 태어난다 (죽음 규칙 접합)
```

## 7. NPC 대칭

NPC 제자도 같은 공적 축·같은 승격 관문 — 생애 사다리 '무인의 길'의 문파 트랙이 이것이다.
플레이어가 게으르면 NPC 사제가 먼저 진전이 된다. **문파 안에서도 세계는 기다려주지 않는다.**
