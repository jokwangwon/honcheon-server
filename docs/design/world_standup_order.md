# 마크 세우기 순서 — 세계 기립(起立) 설계도

> 2026-07-14 · 작성: Fable (정찰 근거: TerrainForge/Gate/Ledger·world_map·RemoteBuilder·purity 실측)
> 전제(사용자): **지형 불명확 · 지도 미결정 · 건물 없음** (있어도 전부 밀고 재건축)
> 헌법 두 문장: **"땅에 맞게 건물이 올라간다"** · **"땅은 한 번만 선다"** (`TerrainLedger.java:18` · `gate_and_watertown.md`)

## 0. 지금 서 있는 것과 없는 것

**기계는 완비다.** 지도 등록부(world_map.yml) → 지형 계층(TerrainForge, 게이트 6문·원장·봉인·판 승인) →
건축 계층(RemoteBuilder 원형 21종·CheonghaBuilder) → 눈 9종(map_lint·MapAudit·TerrainAudit·Seal·
TownAudit·원형대조·앵커검사·purity·grain). 순서는 기계가 강제한다 — 미승인 판으로는 한 블록도 안 쓰고,
땅은 두 번 안 빚어지고, 건축 미결은 땅을 못 막는다.

**없는 것은 둘이다:** ① **결정** — 조성 53곳 중 15곳이 원형(archetype) 미결로 안 선다 (코드가 아니라
사람의 답이 없어서). 지도 자체(어느 고을을 세우나)도 미확정. ② **새 월드** — purity(바닐라 잔재 제거)는
기존 청크를 못 고치므로, "밀고 재건축"은 우회가 아니라 **유일하게 옳은 길**이다.

## 1. 기립 순서 (7막)

각 막은 **닫는 조건(눈)** 을 통과해야 다음 막으로 간다. 괄호는 실행 주체.

```
0막 결정의 밭 (사람)          지도 범위·원형 15곳·수향 여부  ──★ 지금 여기
1막 새 월드 (기계)            fresh_start.sh — purity 데이터팩이 붙은 처녀지
2막 지도 등록 (Fable)         world_map.yml 좌표·지형·등급 → map_lint 초록
3막 지형 (기계+사람 승인)      shaping → 지형 게이트 → 조성 → 조감 → 판 승인 → 원장
4막 건축 (기계)               원형 확정분부터 → 건축 게이트 → 조성 → Seal·검수
5막 생명 (기계)               NPC·사냥터·대기소(입도진) → antechamber/game_audit
6막 문 (이미 완비)            팩 게이트·접합·서장 → 사람이 들어온다
```

### 0막 — 결정의 밭 (P2 · 사람의 몫, **지금 던질 질문들**)

묻는 것은 싸고, 답을 기다리는 동안 다른 막(기계 준비)과 병렬 루프(P1·P3·P4)가 돈다.

| 결정 | 내용 | 안 정하면 |
|---|---|---|
| **D-1 지도 범위** | 1차 기립에 세울 고을 목록 (지금 완비는 청하현 하나 — `mvt_start.playable`). 강남_상로를 1차에 넣나? | 청하현 단독 기립으로 진행 (가장 안전) |
| **D-2 원형 15곳** | 상단 6(B-047) · 새외 4(B-048) · 점창/청성(B-049, 사용자 직접 설계 예약) · 제갈(B-050) · 독문/마교분타/시박사(B-051) | 그 땅은 **땅만 서고 집은 안 선다** (게이트의 정상 상태 — 뒤에 채워도 됨) |
| **D-3 수향(강남)** | 「수향」 프로파일 구현 + gate_and_watertown 12단계를 1차에 태우나 | 강남은 pending 유지 (이미 등록된 사유 있음) |
| **D-4 조성 상한** | 화산파 729초/상한 900초 (B-100) — 더 큰 봉우리 땅의 상한 근거 | 큰 산 지형은 반쯤 서다 중단될 수 있음 (소리는 냄) |

★ **D-2 는 부분 답이 가능하다** — 정해진 원형부터 순서대로 선다. 전부를 기다리지 않는다.

### 1막 — 새 월드

- `scripts/fresh_start.sh` — 백업 → 정지 → 월드·원장·접합 삭제 → 재배포 → 기동.
  **남는 것**: whitelist·ops·**디스코드 캐릭터(PostgreSQL — 월드와 무관)**.
- purity 데이터팩(구조물 20종·야생 스폰·사막 바이옴 차단)이 **새 청크에만** 듣는다 — 그래서 이 막이 먼저다.
- 닫는 눈: `python3 tools/world_purity_audit.py` · 기동 로그.
- ★ 기존 점묘판 땅 문제(B-092)는 이 막이 **통째로 해소**한다 (갈아엎기 불요 — 세계가 새것).

### 2막 — 지도 등록

- D-1 의 답을 `world_map.yml` 에: 좌표·`terrain`(§3 어휘)·`region`·크기(§17 자 — 수동 반경 금지,
  영향력의 함수) · 안 세울 땅은 `pending_why` **사유와 함께** (침묵 금지).
- 닫는 눈: `python3 tools/map_lint.py` 위반 0 — 스키마 정합·어휘 실재·추측 자리 0.

### 3막 — 지형 (판 승인이 사람의 서명이다)

- `terrain.yml shaping:` 에 장소→윤곽(봉우리·중턱단·들·사막·그대로) 등록 → `/혼천 지형조성 <id>`
  (건축과 분리 — 건축 미결이 땅을 못 막는다) → **`/혼천 조감`으로 사람이 본다** →
  `terrain_gate.yml approved_forge_version` 서명 → 원장(`terrain_built.yml`)에 굳는다.
- 닫는 눈: 환경검수(TerrainAudit — 공동·급단차·연결성) · TerrainGrainSelfTest(점묘) · 원장 영수증.
- ★ 이후 이 땅은 **다시 안 빚어진다.** 순서를 어길 수 없다 — 게이트 6문이 기계다.

### 4막 — 건축

- 원형 확정분부터: `regions/*.yml`·§16 archetype 등재 → `/혼천 지역조성 <id>` (청하현은 `/혼천 세계조성`).
- `장터` 앵커 = 마을 원점 (B-032 — 옮기면 마을이 이사한다. 재조성 좌표는 원장이 쥔다).
- 닫는 눈: **TerrainSeal**(건축이 땅을 안 바꿨다) · TownAudit 12종 · 원형대조 · **앵커검사**(사람이 설 수 있는가).

### 5막 — 생명

- NPC 스폰(등록제 — 야생 스폰은 purity 가 전부 껐다) · 사냥터 · 대기소(입도진).
- 닫는 눈: `antechamber_audit` · `game_audit` · `mob_model_audit`.

### 6막 — 문 (이미 완비, 재검만)

- 팩 게이트(B-004 실물 축) · 접합 · 서장(SJ 트랙이 조판을 올리는 중).
- 닫는 눈: `pack_gate_audit` · 접합 실기동 · 서장 실기동.

## 2. 병렬 루프와의 접합

- **0막의 질문(D-1~4)은 즉시 던진다** — 답을 기다리는 동안 병렬 루프는 P1·P3·P4 와 SJ 트랙을 계속 돈다
  (BACKLOG 의 전략 그대로: "묻는 것은 싸고, 답을 기다리는 동안 P3·P4를 한다").
- 1막(새 월드)은 **운영 결정** — MVT 를 밀는 순간이므로 사람이 시점을 정한다 (봇·PostgreSQL 은 무관).
- 2~5막은 답이 오는 대로 지역 단위로 **막을 되돌며** 진행 가능 (청하현 먼저 완주 → 다음 고을).
- 수향(D-3 채택 시)은 `gate_and_watertown.md` 의 12단계가 별도 트랙으로 선다.
