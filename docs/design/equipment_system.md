# 장비 체계 — 등급 구체화 · 애병(愛兵) · 혈교 마병(魔兵)

> 질문: 무기·장비 등급의 구체화, 스탯 차별점, 주인과 함께 성장하는 무기,
> 혈교의 잔해로 생긴 '마법을 쓰는' 무기.
> 기계 판독용: `config/equipment.yml`

---

## 0. 대원칙 — 장비는 격차가 아니라 속성과 서사를 만든다

```text
캡 규칙: 장비 유래 판정 보정 총합 ≤ +2 (상황보정 캡 ±5의 내부에서 계상)
이유:   경지·수련이 만든 격차를 장비가 덮어쓰면 이 게임의 서사가 죽는다.
       장비의 가치는 수치가 아니라 ① 감당 격(무기 파괴 규칙) ② 특수 속성
       ③ 내구 ④ 이름(소문 주체) — 넷에서 나온다. 파밍 게임이 아니다.
```

## 1. 무기 등급 구체화 — 감당 격에 살을 붙인다

| 등급 | 감당 격 | 판정 보정 | 특수 속성 | 입수 | 수량 정책 |
|---|---|---|---|---|---|
| **범철(凡鐵)** | 발경 | 0 | — | 아무 대장간 | 무제한 |
| **정련(精鍊)** | 검기 | 0 | 명공 각인 가능(1개) | 명공·표국·문파 병기고 | 흔치 않음 |
| **보병(寶兵)** | 강기 | +1 | 1개 내재 | 문파 신물·경매·기연 | 세력 보물급 — **소지 자체가 소문** |
| **신병(神兵)** | 심검 | +1 | 2개 내재 + 내력(來歷) | 기연·강탈·계승뿐 | **세계 등록제 — 서버당 한 자릿수** |

- **정련의 가치는 보정이 아니라 생존이다**: 절정 고수와 3합을 버티는 검 (무기 파괴 규칙).
- 보병부터는 물건이 곧 신분: "그 검을 보았다"가 소문망을 탄다 — 차고 다니는 것이 선언이다.
- 신병은 창작 오의와 같은 **세계 유일 등록제**. 내력(어느 대협의 검이었나)이 붙어 있고,
  소유의 이동 자체가 강호의 사건이 된다 (세력 반응 입력).

## 2. 방어구 — 갑옷은 회피를 판다

상성 원칙 2("회피는 격을 속인다")의 뒷면이 방어구 규칙이 된다:

```text
무복/경장   감쇄 0, 회피 0     — 무림인의 표준 (경공·보법 온전)
피갑/경갑   감쇄 1, 회피 -1    — 표사·관군 (한 대는 버티고 한 발은 늦는다)
철갑/중갑   감쇄 2, 회피 -2, 경공 불가 — 관군 중장보. 무림인은 안 입는다
내갑(內甲)  감쇄 1, 회피 0, 암기 무효 + 검기 1회/일 방어 — 금사갑류 보물급
```

- 감쇄 = 부상 등급 1단 완화 (중상→경상). 격 상성은 못 이긴다 — 검강 앞에서 피갑은 종이.
- **내갑이 무협의 방어구다**: 회피를 팔지 않으면서 한 번의 암수를 막는 보험 —
  "금사갑이 아니었으면 죽었다"가 규칙으로 성립한다.

## 3. 기물(器物) — 장신구 2칸, 상황 속성만

```text
슬롯 2칸. 판정 보정형은 캡 +2에 계상. 예시 카탈로그(등록제):
피독주(避毒珠)  독 저항 판정 +2          — 당문 상대의 보험
야명주(夜明珠)  야간 시야 페널티 무효
청낭(靑囊)     의술 판정 +1, 지혈 도구 상시
호신부(護身符)  치명적 실패 1회/장 → 실패로 완화 (소모)
천잠사 요대    금나수·포박 탈출 +2
```

## 4. 특수 속성 카탈로그 — 스탯 차별점의 문법

속성은 "센 것"이 아니라 "**어느 상황의 것**"으로 설계한다 (등록제, GM/생성기 공용):

```text
파사(破邪)    마공·사술 상대 위력 +2       — 마병·혈교전 특효
한철(寒鐵)    빙공 연계 시 경직 +1단
경명(輕鳴)    발도 소리 없음 — 기습 판정 +1
명공각인     내구 1등급 상향 취급 (정련이 보병처럼 버틴다 — 감당 격은 그대로)
음양쌍인     이도류 무공 요구 해제
탈혼(奪魂)   위세 연출 — 발검 목격 하위 NPC 전의 -1 (npc_combat morale)
```

## 5. 애병(愛兵) — 주인과 함께 자라는 무기

**검이 자라는 게 아니라, 검과 사람이 서로 길든다.** 그래서 모든 보정은 **주인의 손에서만** 산다 — 강탈한 남의 애병은 그냥 등급값이다 (약탈 메타 차단).

```text
이력 축적: 동행 년수 · 생사 격돌 생존 · 함께 넘긴 생사 고비 · 오의 동반 시전
1단 손에 익다   동행 1년+ 또는 격돌 30회 — 주인 손 한정 판정 +1 (캡 내)
2단 명병(名兵)  생사 고비 3회 + 명성 사건 — 이름을 얻는다 (오의와 같은 세계 유일 명명)
               검이 소문의 주체가 된다 + 파괴 판정 1회/전투 유예 ("금이 가도 부러지지 않는다")
3단 통령(通靈)  동행 10년+ & 주인 화경 이상 — 감당 격 +1 취급 (정련이 보병처럼)
               이기어검 궁합: 유지 -1, 격추 회수 2라운드 → 1라운드
주인 사망 시:   유품 — 새 주인은 0단부터. 단, 이름과 이력은 검에 남아 소문망을 탄다
               ("그 검이 다시 강호에 나왔다" — 유산 서사 훅)
```

범철도 애병이 될 수 있다 — 소년기의 낡은 도가 명병이 되는 것이 이 시스템의 존재 이유다.

## 6. 마병(魔兵) — 혈교의 잔해, 힘과 침식

'마법 무기'의 이 세계 문법은 **사술(邪術)의 응결**이다: 혈교 인신공양 의식의 잔재 — 수백의 원기가 기물에 응겨 스스로 갈증을 갖게 된 물건. 삼원 구조의 마공 분류가 그대로 적용된다: **휘두르는 순간 ①(타인 원기 약탈)을 행하는 것이다.**

```text
힘:   감당 +1격 취급 · 위력 +2 · 흡성 — 적중 시 대상 원기 -2 → 자기 내력 +2
대가: 침식   전투마다 심마 흔적 +1 누적 (internal_energy simma 연동 — 히든 루트 재료)
     갈증   열흘 이상 피를 못 마시면 주인의 원기를 마신다 (-5/열흘)
     놓기   침식 3+부터 손에서 놓으려면 지혜 판정 — 갈수록 검이 사람을 쓴다
감정: 감정 전엔 정체를 모른다 ("좋은 검인 줄 알았다" — 기연의 탈을 쓴 저주 훅)
     도가·불가 심법 보유자와 신의(神醫)만 혈향(血香)을 감지
세계: 소지 발각 = 강도 3 소문 · 정파/관군 적대 입력 · 혈교 잔당 회수조 이벤트
     — 시스템은 금지하지 않는다, 세계가 청구한다 (기습-비열 행위와 동일 문법)
파훼: 정화 — 도가 순도 판정, 기물 정화 기준치 16 (독 정화 규칙 확장) / 파괴 — 신병으로만
등록 예시: 혈음도(血飮刀 — 기본형) · 백골염주(白骨念珠 — 승려 염주 위장, 미혹 사술
          화술 +2, 매 사용 원기 -1) — 마병도 등록제다 (양산 금지)
```

## 7. 접합

```text
무기 파괴: qi_manifestation.yml weapon_break — 감당 격의 원천은 그쪽, 살은 이쪽
경제:     가격은 밴드만 표기 (서민 연수입 대비) — 경제 시스템 설계 시 economy.yml로 이관
MC:      등급·속성 = 아이템 lore/커스텀모델데이터, 애병 이력 = PDC, 내구 = 바닐라 재활용
소문:     보병+ 소지·신병 이동·명병 명명·마병 발각 — 전부 소문·세력 반응 표준 입력
생성기:   시작 장비는 범철 고정 (유년·소년 시작과 정합 — 좋은 검은 서사로 번다)
```
