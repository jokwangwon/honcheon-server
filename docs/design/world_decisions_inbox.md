# 세계관 결정 인박스 — 아직 배선 안 된 것

> **2026-07-28 신설.** `/세계` 대화 회차에서 나온 **확정**을 여기 쌓는다.
> 그리고 **작업 세션이 이것을 읽고 등록부(config)에 반영**한다.
>
> ★왜 나눴나: 대화하는 자리와 배선하는 자리를 갈랐다.
> **두 세션이 동시에 등록부를 갈면 깨진다.** 그리고 대화 중에 배선하면 대화가 끊긴다.
>
> ★**여기 있는 것은 아직 세계가 아니다.** 세계의 정본은 `config/` 이고,
> 읽는 정본은 `docs/design/world_bible.md` 다.

---

## 쓰는 법

한 회차 = 한 절. **덧붙인다** (덮어쓰지 않는다).

```markdown
## YYYY-MM-DD 회차 N — <한 줄 제목>

### 확정
- **<무엇>** — <내용>
  - ★귀결: <어느 막/세력/기계에 닿는가>
  - 배선할 곳: `config/<파일>` <절>

### 【제안】 (빨간펜 대상)
- ...

### 남은 문답
- ...
```

## 배선한 뒤에는

작업 세션이 반영을 끝내면 그 절 머리에 **`✅ 배선 완료 (커밋 <해시>)`** 를 적는다.
**지우지 않는다** — 무엇이 언제 어떻게 들어갔는지가 남아야 한다.
