# 경제 체계 — 문(文)과 냥(兩), 전장(錢莊), 그리고 살 수 없는 것들

> 그동안 훅만 걸어둔 갈래의 회수: 사냥 부산물 · 장비 price_band · 생활 노동 보수 ·
> 상단 · 정보상 가격. 기계 판독용: `config/economy.yml`
> 기준 물가는 청하현. 지역 상태(경제 지표)가 배율로 얹힌다.

---

## 0. 세 가지 원칙

```text
① 돈은 원기의 짝이다 — 먹고 자는 것이 원기 회복이므로, 생존 루프 자체가 경제 루프다
② 강함은 돈으로 못 산다 — 보병+·진본 비급·영약은 비매품 (장비 캡 +2와 같은 방어선)
   돈이 사는 것은 시간(수련 여건)과 정보와 안전이다
③ 돈은 세계와 물려 있다 — 물가·보수는 지역 경제 지표의 함수, 시세는 사건의 함수
```

## 1. 화폐 — 문·냥·금·전표

```text
문(文)   동전 — 서민의 화폐. 만두 한 끼 8문
냥(兩)   은자 = 1,000문 — 무림인의 화폐. 객잔 독방 하룻밤 100문
금(金)   금자 = 은 10냥 — 상단·세가의 화폐
전표(錢票) 전장 발행 어음, 은 10냥 단위 — 지참인 지불 (훔치면 훔친 놈 것이라는 뜻)
기준 앵커: 서민 일당 30~50문 / 1인 월 생활 ≈ 은 1냥
```

## 2. 전낭과 전장 — 돈을 어디에 두는가가 리스크다

```text
전낭(소지금)  즉시 쓴다 / 사망 시 전액 드랍, 제압당하면 갈취 협상 대상
             — 유일한 즉시성. 기연 경매·급전 흥정·뇌물은 전낭만 받는다
전장(예치금)  안전하다 / 현급 이상 지점에서만 인출 (수수료 5%, 타지 환거래 10%)
             인출 당일 불가 — 청구 다음 날 구간부터 수령 (급전은 전장에서 나오지 않는다)
             5,000문 이하 소액은 수수료 면제 (서민 생계 보호 — 긴장은 목돈에만 건다)
             사망 시 예치금 봉인 → 상속 절차(시간·증인)를 밟아야 풀린다
             전표로 고액 이동 — 지참인 지불이라 표행(호위)이 산업이 되는 이유
강호 문법: 몸에 지닌 것만 진짜 내 돈이다. NPC도 같은 규칙 —
도적이 몸값 대신 전표를 못 쓰게 하는 것, 그것이 도적의 생계 문제다 (대칭 원칙)
```

**예치의 기회비용 (2026-07)** — 구판 수수료는 1%였다. 하루 순수지에 비해 미미해서, 합리적
플레이어는 **전액 예치**했고 '사망 시 전낭 드랍'이라는 돈의 유일한 긴장이 공짜로 무력화됐다.
안전에는 값이 있어야 한다: **수수료 5% + 당일 인출 불가 + 사망 시 봉인·상속 절차.**
돈을 안전하게 두는 대가는 **지금 못 쓴다**는 것이다. 무인이 전낭을 차고 다니는 이유가 여기 있다.

## 3. 물가 기준표 (청하현, 문 단위 — 발췌)

| 분류 | 품목 → 가격 |
|---|---|
| 생활 | 만두 8 · 국밥 10 · 술 20 · 봉놋방 20/밤 · 독방 100 · 상방 500 · 목욕 15 |
| 이동 | 뱃삯 50/구간 · 마차 200/일 · 나귀 8,000 · 말 30,000 |
| 장비 | 단검 1,000 · 범철 검 3,000 · 피갑 5,000 · 범철 수리 200 · **정련 80,000~150,000 (명공 주문 반년 대기)** · 보병/신병 **비매 — 경매·서사만** |
| 의원 | 진료 50 · 경상 500 · 중상 2,000~5,000 · 요양 300/일 · 중급 해독 20,000+조건 |
| 정보 | 뜬소문 100 · 검증 소문 1,000 · 핵심 단서 10,000+ (정보상은 돈보다 정보를 좋아한다 — 등가 교환 우대) |
| 무공 | 사사 예물 관례 10,000+ · 삼류 필사본(암시장) 20,000 · 이류급 200,000 · **진본 비매** |
| 사냥 | 늑대 가죽 60 · 여우 가죽 180 · 웅담 3,000 · 호골 5,000 · 호랑이 가죽 9,000 · 영물 재료 경매 |
| 의뢰 | 잔심부름 15~25 · 조사 300 · 단거리 호위 1,200 · 표행 동행 6,000+ · 도적 소탕 현상 12,000+ · 고수 현상금 50,000+ |

- 시작 자금: 유년 10~30문 / 소년 30~80문 × 집안 배율 (상가 ×3, 객잔 ×2, 농가 ×0.5).
  몰락 무가는 돈 대신 **가보**(팔 수 있는 물건 — 파는 순간 서사 대가)를 갖는다.
- 상점 매입가 = 시세의 **40%** (상술 판정으로 상향, 캡 70%) — 장사가 기술인 이유.

### 3.1 수지 — 돈에 긴장을 되돌린다 (2026-07 재조정)

구판은 표준 플레이어(사냥 2점 + 잔심부름 1건 / 일)가 **생계비의 4.9배**를 벌었다.
늑대 가죽 한 장의 매입가(50문)가 서민 일당(40문)을 넘었고, 범철 검은 **22일치 저축**이었다.
돈이 긴장이 아니라 시간문제였고, 무기는 이야기가 아니라 소모품이었다.

사냥 부산물 전 품목을 ×0.6, 잔심부름을 15~25문으로 내리고 매입가를 40%로 조였다.
생활비(36문/일)는 **건드리지 않았다** — 정본(서민 1인 월 생활 1,000문 ÷ 30 = 33.3문/일)이 옳다.

| | 구판 | 신판 |
|---|---|---|
| 수입/일 | 175문 | **68문** |
| 지출/일 | 36문 | 36문 |
| 수입/지출 | **4.9배** | **1.9배** |
| 순수지/일 | +139문 | **+32문** |
| 서민 일당 대비 | 4.4배 | 1.7배 |
| **범철 검 (3,000문)** | **22일치** | **94일치** |
| 피갑 (5,000문) | 36일 | 156일 |
| 사사 예물 (10,000문) | 72일 | **313일 — 스승을 모시는 데 1년** |

생계는 된다(+32문/일). 그러나 검 한 자루가 **계절**이 되고, 사사 예물이 **1년**이 된다.
돈이 사는 것은 여전히 시간·정보·안전이지, 강함이 아니다.

## 4. 순환 — 수입원과 싱크

```text
수입: 노동(일당 30~50) · 의뢰(요청 게시판) · 사냥 부산물 · 상술(매매 차익 — 시세)
     현상금 · 문파 봉록 · 암시장 (장물 30% — 소문 리스크)
싱크: 생활비(원기 회복 = 식사·숙박) · 장비 구입/수리 · 사사 예물·비급 · 의원·해독
     정보비 · 뇌물·성문세·자릿세 · 전장 수수료
인플레 방어: NPC 상점 일일 매입 한도 (늑대 가죽 20장/일 — 초과분 시세 하락)
            비매품 원칙 (최고가 물건은 애초에 시장 밖) · 수리비 (장비는 닳는다)
```

## 5. 지역 연동 — 물가는 세계 상태의 함수

region_state 경제 지표(0~100)가 배율로 얹힌다:

```text
경제 70+   물가 ×0.9  의뢰 보수 ×1.1  (호황 — 씀씀이가 커진다)
경제 50±   물가 ×1.0  의뢰 보수 ×1.0
경제 30↓   물가 ×1.3  의뢰 보수 ×0.7  (threshold_effects '물가 상승, 보수 하락'의 수치화)
경제 15↓   물가 ×1.6  의뢰 보수 ×0.5  (기근 문법 — 곡물은 별도 시세 폭등)
```

**품목 시세 이벤트** (등록제): 사건이 특정 품목을 흔든다 — 상단 습격 성공 → 해당 품목 +20% (4주 감쇠), 열병 → 약재 +50%, 대량 사냥 → 가죽 -30%. 시세 정보 자체가 소문망을 탄다 — **"북로가 막혀 소금값이 뛴다더라"는 상인에게는 돈이 되는 소문이다** (정보 경제와 상술의 교차점).

## 6. 살 수 없는 것들 — 비매품 원칙

```text
보병·신병 / 진본 비급 / 오의 / 영약(대기연) / 경지 / 사면(관의 죄)
→ 이들은 경매(등록 이벤트)·기연·서사 교환으로만 움직인다.
   경매는 돈의 정점이 서사의 입구가 되는 장치 — 낙찰자는 소문의 주인공이 된다.
돈의 상한 효용: 부자는 편하고 안전하고 빠르다. 그러나 절정은 못 산다.
(수련 여건 구매 = 시간 효율 — 폐관 장소 대여, 영약 아닌 보약, 좋은 스승의 예물)
```

## 7. MC 매핑

```text
원장 기반 — 아이템 화폐 없음 (복제 버그·인플레 원천 차단, 단일 작성자 규칙)
전낭 드랍   사망 시 전낭 아이템 엔티티 1개 (내용 = 소지금 전액) — 줍는 자의 것
상점       대화 GUI (재고·시세 반영) / 플레이어 간 거래 = 거래 GUI (사기 방지)
소지금 표시  경락도 GUI 옆 전낭 탭 + 거래 시 액션바 (상시 HUD 점유 없음)
전장       지점 NPC GUI — 예치·인출·전표 발행
```

## 8. 접합

```text
equipment.yml   price_band → economy.yml price_table로 이관 완료 (밴드는 서사 표기 유지)
cultivation.yml hunting_yield 가격 = economy.yml 사냥_부산물
training.yml    생활_노동 "보수 발생" = 일당 30~50문으로 수치화
region_state    경제 지표 → 물가·보수 배율 (5장)
rumor           시세 정보 = 소문 (정확도 규칙 그대로 — 틀린 시세 소문에 돈을 걸 수도)
원기(internal_energy) 식사·숙박 = 원기 회복 — 경제와 생존의 접점
```
