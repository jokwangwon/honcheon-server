# NPC 일과와 생애 — 세계가 살아 있는 두 개의 시계

> 질문: NPC 일과 진행 + NPC 자체 진화(가난한 상인이 전장 가주가 되는) 가능한가.
> 답: 가능하다 — 매 틱 시뮬이 아니라 **두 개의 주기**로. 일과는 하루 5구간의 시계,
> 생애는 계절 1회의 시계. 기계 판독용: `config/npc_lifecycle.yml`

---

## 0. 원칙 — NPC도 플레이어와 같은 문법으로 산다

```text
일과   = 플레이어의 하루 5구간제를 NPC에게 적용한 것 (time.yml)
생애   = 플레이어의 경지 승급 문법(요건+계기 관문)을 인생 사다리에 적용한 것
정산   = NPC 판정 문법 그대로 (능력치+기술+상황+7, 주사위 없음 — npc_vs_npc)
성능   = 개체 시뮬은 등급 3+ 한정, 계절 1회 배치 — 비용은 사실상 0
```

## 1. 일과(日課) — 하루 5구간의 시계

NPC마다 `schedule`: 구간(새벽~밤) × (장소, 활동, 접근성). 이것이 정하는 것:

```text
어디서 만나나   NPC 위치의 원천 — "낮의 한백"은 카운터에, "밤의 묵삼"은 창고에
어떻게 만나나   활동별 판정 컨텍스트: 접객 중 화술 +1 / 집무 중 -1 / 술자리 +1
              (환경 보정 ±3 안에서 계상 — 만남의 '때'를 고르는 것이 전략이 된다)
경계의 리듬    구간별 경계도: 밤 침소 = 경계 -2 (기습·잠입 유리)
              단, 발각 = 즉시 적대 + '밤손님' 소문 — 싸게 들어가면 비싸게 나온다
세계의 개폐    상점·의뢰소·관아의 영업 구간, 순찰조의 경로와 교대
```

**일과는 깨지라고 있다** — 오버라이드 3종이 서사를 만든다:

```text
① 사건: 활성 incident가 스케줄을 깬다 — 습격 예고일의 갈호는 산길에 나와 있다
② 지역 상태: 임계 효과 연동 — 열병 지역의 유문은 밤에도 진료한다 (과로 서사의 실체)
   치안<30이면 밤거리에서 민간 NPC가 사라진다 (위험 조우만 남는다)
③ 장날: 5일 주기 — 상인·농민 스케줄 일괄 대체, 시장 인구 밀도 상승 (소문 전파 +)
평소와 다른 위치 = 그 자체가 단서다 ("묵삼이 오늘은 낮에 나갔다?")
```

MC: 등급 3+ NPC는 구간 전환 시 **경로 이동** (텔레포트 금지 — 이동이 목격 가능해야
미행이 성립한다). 로딩 밖 전환만 재배치. 배경 NPC(1~2)는 구간별 스폰 프리셋.

## 2. 생애(生涯) — 계절 1회의 시계: "자체 진화"의 실체

### 2.1 정산 방식 — 가능한 이유

계절마다(세계 달력 분기) 등급 3+ NPC 전원에 대해 **생애 판정 1회**:

```text
생애 판정 = NPC 능력치 + 기술 + 상황 보정 + 7  vs  다음 칸의 난이도
상황 보정 입력: 자산 · 지역 경제 지표 · 세력 favor · 활성 사건 · 플레이어 개입 기록
성공 누적 + 계기 사건 → 사다리 한 칸 상승 / 실패 누적 → 하락 판정 (하락 이벤트 표)
```

주사위 없는 결정론이지만 입력(세계 상태)이 계속 변하므로 결과는 살아 있다.
지역당 개체 ~20명 × 계절 1회 = 부하는 오차 항. **어려운 건 성능이 아니라 서사
일관성이고, 그건 등록제(사다리·칸·계기)가 통제한다.**

### 2.2 생애 사다리 — "가난한 상인 → 전장 가주"의 규칙화

플레이어 경지 관문과 같은 문법. 등록 사다리 3종으로 시작:

```text
상인의 길   행상 → 점포주 → 상단 지점주 → 상단주 → 전장 가주
           칸마다 요건(자산·favor·연속 성공)과 계기(등록 사건 — 대상단 계약, 위기 극복)
무인의 길   cultivation.yml 그대로 — NPC도 같은 관문 (실전 마크·벽·깨달음. 완전 대칭)
관인의 길   서리 → 현승 → 현령 → 지부사 (관군·관청 favor가 재료)
하락 이벤트 표: 도박 빚 / 병(원기) / 습격 / 배신 / 후계 분쟁 — 몰락도 서사다
```

- 속도: **1칸 = 보통 수년** (계절 성공 누적 + 계기). 세계가 살아 있되 어지럽지 않게.
  급성장은 등록 기연뿐 — NPC에게도 기연은 등록제다.
- 정점 칸(전장 가주·현령급)은 **세계급 등록 이벤트**: 소문 강도 3 + 세력 지형 변화.

### 2.3 플레이어의 손 — 은혜와 원한의 장기 회수 (이 시스템의 존재 이유)

```text
개입 기록: 호위 성공·결정적 정보(시세!)·치료·누명 벗김 = 그 NPC 생애 판정 +1~+3
          약탈·사업 방해·신용 훼손 = -1~-3 (전부 기록제 — 엔진이 잊지 않는다)
회수:     칸 상승 시 기여자에게 favor 상향 + 회수 이벤트 자동 발화
          "10년 전 북로에서 호위했던 소금 행상이 — 이제 전장 가주가 되어 찾아온다"
          원한도 동형: 몰락시킨 상인의 아들이 자객이 되어 돌아온다
```

플레이어는 NPC를 '키울' 수 있다 — 투자·호위·정보로. 그 상인이 크면 나의 전장이
되고, 나의 신용이 된다. **세계에 심는 것이 최고의 저축이다** (경제 비매품 원칙과 접합:
돈으로 못 사는 것을 세월과 은혜로 산다).

### 2.4 죽음과 세대 — 사다리의 끝

```text
NPC도 수명 100년·원기 규칙 대칭 — 노환·병·사건으로 죽는다 (사망 = 소문 자동)
핵심 NPC 사망 = 후계 이벤트 등록: 상속 분쟁, 유산(애병·비급!), 조직 승계전
— 전장 가주가 죽는 날, 그 전장을 둘러싼 장(章)이 열린다
```

### 2.5 등급 이동 — 배경에서 개체로, 개체에서 배경으로

```text
승격: 배경 NPC(1~2)가 사건으로 '이름'을 얻으면 → 등급 3 개체화 (시트 생성, 생애 시뮬 편입)
     — 플레이어가 이름을 물은 점소이가 인물이 된다 (관측이 개성을 만든다)
강등: 은퇴·잊힘 → 배경화 (시트 동결 — 삭제가 아니라 동면. 재등장 가능)
```

## 2.6 창발 상호작용 — 마병을 줍는 NPC, 혈교가 되는 NPC (부하 판정)

경지 변화·물건 습득·전향까지 넣어도 **감당 가능하다.** 단, 구현 방식이 갈림길이다:

```text
금지: NPC가 세계를 스캔 ("모든 NPC × 모든 물건 × 매 틱" — 이것이 폭발하는 길)
채택: 접점 판정 — 등록 물건(마병·보병·비급: 이미 전부 등록제)이 자기 좌표의
     통행자(일과·사건 동선이 교차하는 NPC)만 계절 정산 때 굴린다
     → 비용 = O(등록 물건 수) — 세계 전체 수십 건/계절
전향 파이프: 마병 습득 → 침식 규칙(equipment)을 계절 입자로 → 심마 → 전향 후보
           → 혈교화 = 등록 이벤트 (소문·세력 반응 자동) — 전부 기존 규칙의 재사용
```

진짜 위험은 CPU가 아니라 **서사 폭주**(연쇄 이벤트·고수 인플레)다. 밸브 4개:

```text
① 지역별 계절 이벤트 예산 상한 3건 — 초과분 다음 계절 대기열 (연쇄 폭주 차단)
② 정점·금기 변화(전장 가주·전향·신병 이동)는 세계 동시 진행 등록 큐
③ 관측 기반 렌더 — 엔진은 전부 계산, LLM 서사화는 플레이어가 접한 것만
④ 고수 총량 상한 — 초절정+ NPC 세계 상한 (사선 마크가 실제 사건에서만 나오므로
  벽 규칙 자체가 자연 억제 장치다)
부하 추산: 개체 ~500명 × 계절 1회 + 접점 수십 건 = 자정 배치 수 ms — MSPT 예산 무관
```

## 3. 렌더와 체감

```text
정산 = 엔진 표 (2단 파이프라인의 엔진 단) / 서사화 = LLM 렌더 단
체감 경로: ① 귀환 리포트 다이제스트 ("당신이 없는 사이 — 한백이 2호점을 냈다")
          ② 소문망 (칸 상승·몰락·사망은 소문이다) ③ 재방문 시 달라진 일과·간판
MC: 계절 정산은 자정 배치 (world_batch_apply 예산) — 간판·상점 GUI·NPC 위치 갱신
```

## 4. 접합

```text
time.yml 5구간 / region_state 임계 효과(일과 오버라이드) / economy.yml 자산·시세
favor(faction_reaction) = 생애 판정 입력이자 회수 통화 / rumor = 생애 변화의 방송
cultivation.yml = 무인의 길 그대로 / internal_energy = NPC 수명·원기 대칭
equipment 애병·비급 = 유산의 실체 / npc_combat 대칭 원칙의 생애판 확장
```
