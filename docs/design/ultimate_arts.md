# 오의(奧義) 시스템 — 깨달음의 일격

> 무공 체계의 정점. cultivation.yml의 경지 서술("초절정: 오의를 느끼기 시작 /
> 화경: 오의 예외 / 현경: 오의 완전 사용 / 생사경: 창작 오의")을 실제 규칙으로 완성한다.
> 기계 판독용: `config/ultimate_arts.yml`

---

## 1. 오의란 무엇인가 — 기술이 아니라 도달

```text
오의는 배우는 것이 아니라 얻는 것이다.
초식의 끝에서, 무공의 정수가 시전자의 깨달음과 하나가 된 상태 —
같은 매화만개라도 두 사람의 것이 같지 않다.
게임적으로: 오의 = 최상위 자원(내력 50%+, 때로 수명)을 태우는, 전투의 문장부호.
           남발할 수 없고, 꺼내는 순간 세계가 알게 된다.
```

## 2. 경지 게이트 — 오의의 계단 (기존 경지 서술과 정합)

| 경지 | 단계 | 내용 |
|------|------|------|
| 초절정 | **개안(開眼)** | 오의를 "느낀다" — 전승 오의의 **불완전 시전**: 위력 절반, 시전 직후 내공 고갈 + 내상 판정. 벽 너머를 훔쳐보는 대가 |
| 화경 | **완성** | 전승 오의 1개 완전 시전. **전투당 1회** |
| 현경 | **자재(自在)** | 횟수 제한 해제 (내력이 허락하는 한). 복수 오의 보유 가능 |
| 생사경 | **창작** | 자기만의 오의를 만들고 **이름을 짓는다** (5장) |

※ 정합 수정: internal_energy.yml 기 운용 게이트에 누락됐던 초절정 단계를 추가하고
(검기까지 — 강기는 화경부터), 오의_개안/오의를 각 경지에 배치했다.

## 3. 시전 규칙

### 3.1 비용과 제한

```text
내력:   총량의 50% 이상 (오의별 명시) — 시전 후 그 전투의 여력이 반토막난다
횟수:   화경 이하 전투당 1회 / 현경부터 해제
발동권: 전투 중 '흐름'을 얻어야 한다 — 아래 중 하나가 그 전투에서 선행되어야 시전 가능:
        패링 성공 / 회피 후 반격 적중 / 아슬아슬한 성공 이상 공방 3회 누적
        (오의는 버튼이 아니라 '읽어낸 순간'이다 — cultivation.yml '오의 충전'의 실체)
```

### 3.2 프레임과 방어 속성 (skill_mechanics 준수)

```text
무적 상한 20틱 (기존 절대 상한) / 긴 선딜 = 긴 텔레그래프 (세계가 멈춘 듯한 연출)
시전 중 슈퍼아머 또는 무적 — 오의별 명시. 후딜은 크다 (빗나간 오의는 목숨이 위험하다)
```

### 3.3 오의 격돌 — 오의 vs 오의

```text
양측이 같은 라운드에 오의를 선언하면 '격돌'이 된다:
  양측 실행력 경합 (각자 굴림, 마진 비교) — 승자의 오의가 관통, 패자는 마진 차만큼 피해
  무승부(차 0~1) = 상쇄 — 충격파가 주변을 쓸고 양측 내력 전소
무협 클라이맥스의 그 장면이 규칙으로 존재한다. MC: 전용 격돌 연출 (파티클 예산 최우선순위)
```

### 3.4 연혼일격 조합 — 경지를 넘는 한 수

```text
오의 + 수명 연소(연혼일격 3년) = 시전 1회를 경지 +1로 취급 (기존 규칙 그대로 중첩)
→ 초절정이 화경급 오의를 뽑는 '최후의 수'. 대가: 수명 3년 + 내상 + 내력 전소.
  몸에서 금빛 초연이 오른다 — 보는 자는 안다, 저자가 무엇을 태웠는지.
```

## 4. 습득 — 전승과 깨달음

```text
전승 오의 (문파 비전의 정점):
  요구: 해당 계열 무공 숙련 6 이상 + 초절정 이상 + 전승 자격
       (장문·장로급 전수 or 최심부 비급 — 문파 서사의 정점 콘텐츠)
  개안 이벤트: 요구 충족 후 '깨달음 사건'에서 개안한다 —
       생사의 실전 대성공 / 파벽(수명 5년) / 스승의 마지막 가르침
  ※ 오의 비급이 유출되면? — 소문·세력 반응 최대 등급의 사건. 문파는 전쟁을 불사한다.
```

## 5. 창작 오의 (생사경) — 이름을 짓는 자

생사경의 특권. **예산 12점**을 배분해 자기만의 오의를 조립하고, 이름을 짓는다:

```text
위력:   1점 = 무공 위력 +1 (최대 6)
범위:   1점 = 히트박스 확장 1단 (호→광호→원→광역, 최대 3)
무적:   2점 = 무적 +4틱 (상한 20틱 절대 준수)
특수:   파격 3점 / 다단히트 2점 / 경직 1단 상향 2점 / 자기 회복 3점 /
       기질 각인 2점 (자기 심법의 결을 오의에 새김 — 도가: 시전 시 정화 동반 등)
사거리: 1점 = +4m (성능 상한 24m 준수)
```

```text
이름 짓기: 플레이어가 명명한다 — 그리고 세계에 등록된다 (등록제 원칙).
창작 오의는 세계 유일: 같은 세계에 같은 이름의 오의는 없다.
그 이름이 소문망을 타고 별호와 함께 퍼진다 — "낙화검 모 대협의 '일몰참(日沒斬)'을
보았는가" — 공유 세계에서 이름은 가장 비싼 재산이다.
```

## 6. 전승 오의 초기 4종 (config에 등록)

| 오의 | 문파 | 유형 | 요점 |
|------|------|------|------|
| 매화만개(梅花滿開) | 화산 | 원형 광역 + 다단 | 검화가 만발한다 — 자하신공과 공명 시 범위 +1단 |
| 태극혜검(太極慧劍) | 무당 | 반격 오의 | 시전 후 10틱, 받은 공격을 무효화하고 되돌린다 (패링의 극의) |
| 제왕검형·군림(君臨) | 남궁 | 직선 관통 극대 | 선딜 20틱의 왕도 — 맞으면 다운 + 내구 절반. 혈통 제한 |
| 혈해만리(血海萬里) | 혈교 | 흡수 광역 | 범위 내 원기·내력 약탈 (마공 분류 ①+② — 목격자는 토벌령의 증인이 된다) |

## 7. 세계적 무게 — 오의는 신분증이다

```text
오의 시전 목격 = 강도 3 소문 자동 생성 (억제 불가 — 숨길 수 있는 기술이 아니다)
+ 시전자의 경지·소속이 사실상 노출 (전승 오의는 문파의 지문)
+ 세력 반응: 해당 문파 (자파 오의를 쓰는 미지의 인물 = 즉시 조사),
  적대 세력 (고수 출현 경보), 관군 (초절정 이상 = 관찰 대상)
→ 오의를 꺼낸다는 것은 정체를 거는 것이다. 그래서 고수는 침묵하고,
  침묵이 깨지는 순간이 이야기가 된다.
```

## 8. 접합 확인

```text
내력 50%+ (internal_energy cost_bands 오의) ✓ / 무적 20틱 상한 (skill_mechanics) ✓
연혼일격 중첩 (선천진기) ✓ / 경지 서술 (cultivation.yml) ✓ — 초절정 게이트 누락 수정
소문·세력 (world_reaction) ✓ / 등록제·세계 유일 (기연·세계 정원의 원칙 재사용) ✓
파티클 예산: 오의는 '예산 내 최우선순위' — 예외가 아니라 우선권 (performance 원칙 유지)
```
