# 적(敵)의 배치 — 마을 무스폰 · 사람 · 비무 · 짐승

> 대상 코드: `server-mvt/.../HuntingGrounds.java`, `server-mvt/.../Sparring.java`
> 정본 config: `npcs/cheongha_npcs.yml` · `npc_combat.yml` · `combat.yml` · `cultivation.yml` · `economy.yml`

## 0. 병(病)과 약(藥)

**병.** v6.9 까지 인게임의 적은 전부 **바닐라 스폰**이었다.

1. 향촌 마당에 좀비와 거미가 섰다 (무협 세계에 언데드는 없다).
2. 사냥터의 짐승은 바닐라 재생산에 맡겨져 **사냥하면 고갈**됐다.
3. `cheongha_npcs.yml` 에 등록된 짐승 스탯(격·내구·자연 무기·전의)이 **어떤 엔티티에도 실리지 않았다**.
4. 무엇보다 — **무협의 적은 짐승이 아니라 사람이다.** `cultivation.yml` 의 목숨_무게
   (`생사 2.0 / 실전_사냥 1.0 / 비무_대련 0.5`)가 이미 **세 층**을 규정하고 있었는데,
   인게임엔 "몹을 때려잡는다" 하나뿐이었다. 그것은 마인크래프트의 문법이지 무협의 문법이 아니다.

**약.** 적을 세 층으로 나눠 배선한다.

| 층 | 무엇인가 | 목숨 무게 | 구현 |
|---|---|---|---|
| **사람** | 산적·녹림·낭인 — 가장 흔한 적 | 실전_사냥 1.0 (사선이면 생사 2.0) | `HuntingGrounds` — 병기를 든 사람, 전의, 두목 |
| **비무** | 무인과 겨루는 자리 — **죽이지 않는다** | 비무_대련 0.5 | `Sparring` — 중상에서 멈춘다 |
| **짐승** | 생계·재료·초심자의 수련. **주역이 아니다** | 실전_사냥 1.0 | `HuntingGrounds` — 구역 정원제 |

## 1. 마을은 무(無)스폰

`CreatureSpawnEvent` 한 곳에서 심판한다 (`HuntingGrounds.onSpawn`).

| 조건 | 판정 | 근거 |
|---|---|---|
| `SpawnReason` = CUSTOM · COMMAND · SPAWNER_EGG · BREEDING · EGG · DISPENSE_EGG · BUILD_IRONGOLEM/SNOWMAN · CURED | **통과** | 우리가 부른 것 — 조성기의 NPC(Villager), 이 파일의 짐승·산적, 농가의 번식 |
| 그 밖의 이유 + `Enemy` (좀비·거미·크리퍼·스켈레톤·팬텀…) | **세계 전역 취소** | 무협 세계에 언데드는 없다. 적은 사람과 짐승이다 |
| 그 밖의 이유 + 마을 안 (구역 「청하현」 상자 + 담장 밖 8칸) | **취소** | 가축이라도 마을에 저절로 솟지 않는다 |
| 그 밖의 이유 + 사냥터 구역 안 (가축 제외) | **취소** | 개체군은 정원제다 — 바닐라가 씨를 뿌리면 census 가 깨진다 |
| 그 밖 (야외) | 통과 | 야생의 가축은 바닐라 그대로 |

- **NPC 는 건드리지 않는다** — `CheonghaBuilder` 의 Villager 는 `world.spawnEntity` = CUSTOM 이라 위 첫 줄에서 통과한다.
- **가축은 허용한다** — 마당의 닭·소는 마을 살림이다. 다만 자연 스폰이 아니라 **번식·알**로만 는다.

## 3. 사람 적 — 왜 ZOMBIE 인가

무협의 적은 사람이다. 그러려면 **손에 든 병기가 보이고, 근접 AI 가 돌고, 사람의 실루엣**이어야 한다.

| 후보 | 판정 |
|---|---|
| `VILLAGER` + 커스텀 AI | **탈락** — 공격 AI 가 아예 없다. 길찾기·타격·표적을 전부 손으로 써야 한다 (MVT 범위 초과) |
| `PIGLIN` | **탈락** — Brain 기반이라 `setTarget` 이 뇌에 덮인다. 금 줍기·후퇴·춤 행동이 붙는다 |
| `ZOMBIE` | **채택** — 인간형 실루엣 · 손의 아이템이 보인다 · 근접 AI · 장비 슬롯 |

ZOMBIE 를 **사람으로 만드는 봉인 세 가지**:

1. `setShouldBurnInDay(false)` — 낮에도 산길에 선다 (+ 가죽 투구 이중 방어).
2. `setSilent(true)` — 신음을 죽인다. **사람은 신음하지 않는다.**
3. `EntityTargetLivingEntityEvent` 취소 — 산적은 **마을 사람(Villager)·골렘을 물지 않는다.** 표적은 플레이어뿐.

**무장** — `Weapons.make()` 로 **진짜 병기**를 들린다. PDC(계열·등급·품·치우침)가 그대로 새겨진 병기다.

| 개체 | 무장 | 죽으면 |
|---|---|---|
| 산길 도적 (졸개, 삼류) | 범철 도 + 가죽 투구 | **50%** 확률로 그 도를 떨군다 |
| 갈호 (두목, 이류) | 정련 검 + 철 흉갑 | **100%** — 두목의 검은 전리품이다 |
| 곽진 (비무 상대) | 범철 검 | 떨구지 않는다 (죽지 않는다) |

**격(格)의 대칭 — 남은 한계.** `npc_combat.yml symmetry` 는 "NPC 도 플레이어와 같은 규칙"이라 말한다.
지금 배선된 것은 **무기 위력 + 무공 위력**까지다. **격 위력**(발경 +1 · 검기 +2)은 내력 지불이 붙는
라운드 개념이라 `SkillEngine` 이 플레이어에게만 배선돼 있다 — NPC 격 시전은 `SkillEngine` 공개 API
(`planStrike(realm, energy, armed)` 를 엔티티에도 열어 주는 것)가 먼저다. 그전까지 일류+ NPC 는 외공기로 싸운다.

## 4. 비무(比武) — 죽이지 않는 싸움 【가장 무협적이고, 없던 층】

`Sparring.java`. **무협에서 무인이 무인과 칼을 맞대는 자리는 대개 여기다** — 죽이려는 게 아니라 이기려는 것이다.

### 끝나는 조건

| 조건 | 판정 |
|---|---|
| **중상** | 내구가 25% (`combat.yml durability.wound_thresholds.중상.below_ratio`) 아래로 떨어질 피해 → **피해를 취소하고** 체력을 문턱에 고정, 그 자리에서 패배 확정 |
| **항복** | `/혼천 비무 항복` — 무인은 질 줄도 알아야 한다 |
| **장외** | 비무 자리에서 20칸 이탈, 또는 상대와 24칸 넘게 8초 |
| **시간** | 90초 → 남은 내구 비율로 판정 (5% 이내 차이면 무승부) |

### 죽지 않는 보장 (이중)

1. `EntityDamageByEntityEvent` (HIGHEST) — **상대의 칼**이 중상 문턱을 넘기면 취소.
2. `EntityDamageEvent` (HIGHEST) — **낙사·환경 피해**도 참가자를 죽이지 못한다. 비무 중의 낙사는 비무가 아니다.

> 제3자의 칼은 예외다 — 비무 중에 산적이 끼어들면 그건 **실전**이다 (피해가 그대로 들어간다).

### 적립 — 목숨 무게가 실제로 반영된다

```
적립 = ProgressionEngine.combatAccrualDays(격차, "비무_대련", 반복) → ×0.5
```

- **이기면 실전 마크** (`cultivation.yml`: "실전_마크 = 비무 승리, 제압, 실전 도주 성공").
- **지는 쪽도 배운다** (같은 공식, 마크는 없다). 진 자가 아무것도 못 배우면 아무도 두 번째 비무를 청하지 않는다.
- 안전하지만 적게 배운다 → **수련의 주된 방법**이 되고, 죽지 않으므로 **무공을 시험하는 무대**가 된다.

### 자리와 상대

- **곽진** (상단 호위무사 — 등록 NPC) 이 **표국 마당**에 상시 서 있다. 우클릭 = 비무 신청.
  판이 끝나면 30초 뒤 몸을 추스르고 다음 사람을 기다린다 (죽지 않는다).
- **사람과 사람** — `/혼천 비무 <플레이어>` → 상대가 `/혼천 비무 수락`. **죽지 않는 PvP**.
- 별도의 비무장(比武場) 건물은 짓지 않았다 — 표국 마당이 이미 그 자리다 (조성기 소유, 이 패스의 범위 밖).

| 개체 | 낮 정원 | 밤 정원 | 비고 |
|---|---|---|---|
| 산늑대 | 4 | **6** | 무리 |
| 멧돼지 | 3 | 2 | 단독~2 |
| 호랑이 | 0 | **1** | 맹수 — 밤에만 나온다 |
| 반달곰 | 0 | **1** | 맹수 |
| 산길 도적 | 3 | 4 | 사람 — 낮에도 있다 (도적은 밤눈이 밝지 않다) |
| 갈호 (두목) | 1 | 1 | **재생 5분** — 두목은 흔하지 않다 |
| 백영묘 (영물) | **0** | **0** | 등록제 — 관리자 소환만 (`양산 금지`) |

- **재생 주기 10초, 구역당 최대 1마리/주기** → 6마리를 몰살해도 1분이면 되찾는다. **고갈되지 않되 무한하지도 않다.**
- **구역 개체 상한 18** (performance.yml 예산).
- **스폰 조건**: 플레이어가 96칸 안에 있을 때만 · 사람에게서 20~64칸 · 지면이 고체이고 위 2칸 공기 ·
  **짐승은 블록 광원 ≤ 7** (v6.9 의 "불이 끝나는 곳부터가 사냥터다"가 그대로 규칙이 된다 — 야영터·등롱 밑엔 서지 않는다).
  사람(산적)은 불을 쬔다 (광원 무관).
- **마을로 새지 않는다**: 후보 좌표가 마을 상자 안이면 버린다. 구역 상자는 애초에 마을과 겹치지 않는다
  (사냥터 z ≤ -540, 마을 z ≥ -538).

## 6. 짐승 스탯 → 인게임 (등록부가 그대로 몸이 된다)

| 개체 | 격 | 내구 → 최대 체력 | 자연 무기 → 공격력 | 명패 | 전의 (시작/도주) |
|---|---|---|---|---|---|
| 산늑대 | 들짐승 (삼류) | **16** | 이빨 = 맨손 **1** | 백 `§f산늑대` | 4 / 3 |
| 멧돼지 | 들짐승 (삼류) | **20** | 엄니 = 단검 **3** | 백 `§f멧돼지` | 6 / 2 |
| 호랑이 | 맹수 (일류) | **20** | 발톱 = 단검 **3** | 적 `§c호랑이` | 7 / 2 (내구 25% 이하 결사 +3) |
| 반달곰 | 맹수 (일류) | **24** | 앞발 = 봉 **3** | 적 `§c반달곰` | 7 / 1 |
| 백영묘 | 영물 (절정) | **22** | 발톱 = 검 **4** | 진홍 굵게 `§4§l백영묘` + 발광 | 10 / 0 (붕괴 없음 — **떠난다**) |
| 산길 도적 | 사람 (삼류) | **16** = round(10+체력3×2) | 범철 도 **4** + 무공 1 = **5** | 백 | 5 / 3 |
| 갈호 | 사람 (이류·두목) | **18** | 정련 검 **4** + 무공 1 = **5** | 황 | 9 / 2 |

- **내구 → `MAX_HEALTH`** (1.21.4 에서 `GENERIC_MAX_HEALTH` 는 `MAX_HEALTH` 로 개명됐다).
  플레이어 20 과 같은 눈금이다 — 늑대 16 = 8하트.
- **무기 위력 → `ATTACK_DAMAGE`** (`combat.yml damage.formula` 의 첫 항).
- **명패 색** = `resourcepack_design.yml semantic_colors.기세` 4단(회/백/황/적)을 **절대 격**에 건다:
  회 = 가축 · 백 = 삼류 · 황 = 이류 · 적 = 일류+ · 진홍 = 영물.
  (플레이어별 **상대** 격차는 `HuntListener` 의 액션바가 실시간으로 말한다 — 명패는 개체당 하나뿐이라
  "이 몸이 어느 층인가"를 말하는 편이 읽힌다.)
- **PDC 태그** (`honcheon:foe_id` · `foe_kind` · `beast_rank` · `foe_realm` · `foe_role` · `foe_zone` · `foe_morale`)
  — `HuntListener` 는 **재질이 아니라 태그로** 격차·부산물을 판단한다 (`Weapons` 가 PDC 로 계열을 새긴 것과 같은 문법).

### 전의 (npc_combat.yml morale)

매 2초 재계산 (누적 아님 — 상황이 나아지면 전의도 돌아온다):

```
게이지 = 시작값
      + 내구 50% 이하 -2 / 25% 이하 -4  (맹수는 25% 이하에서 결사 +3)
      + 혼자 남음 -3 / 수적 우세 +2      (들짐승은 무리가 흩어지면 추가 -3)
      + 경지 격차 -1 / 2경지 (상한 -4)
      + 두목 사망 -5                      (졸개만)
게이지 ≤ 도주_문턱 → 붕괴
```

- **짐승·사람**: 도주 (`setTarget(null)` + 반대 방향 velocity + 신속). 쫓을지는 플레이어의 선택이다.
- **영물**: 붕괴하지 않는다 — **떠난다** (END_ROD 파티클 + 제거. "산이 데려갔다").
- **두목이 쓰러지면 졸개가 무너진다** — 갈호를 먼저 치면 도적 무리가 흩어진다.

## 7. 전리품 — 경험치 구슬은 없다

`HuntingGrounds.onDeath` (priority HIGH) 가 **바닐라 드롭과 경험치 구슬을 걷어내고**(`setDroppedExp(0)`)
등록부의 것을 준다. 성장은 오직 **화후**로 온다 — 마인크래프트의 문법(경험치 구슬)을 빌리지 않는다.

| 등록 drop | 인게임 | 상태 |
|---|---|---|
| `늑대_가죽` | `Goods.pelt("늑대")` — 60문 | ✅ |
| `호피` | `Goods.pelt("호랑이")` — 9000문 | ✅ |
| `웅담` | `Goods.ungdam()` — 3000문 | ✅ |
| `고기`·`늑대_고기`·`멧돼지_고기` | `PORKCHOP` | ✅ (임시 — 육포 채널 미등록) |
| `멧돼지_가죽`·`곰_가죽`·`엄니`·`호랑이_뼈(호골)`·`백영묘_가죽`·`영단_재료` | — | **등록 대기** (§8) |

미등록 부산물은 **떨구지 않는다** — 없는 이름의 물건을 만들면 장터에서 팔리지 않고 인벤토리만 더럽힌다.

## 8. config 등록 제안 (YAML)

### ① `config/hunting_grounds.yml` — **신설 완료 (2026-07)**. 개체군·스폰이 데이터가 됐다

> 이 절은 오래도록 **죽은 약속**이었다 — 문서가 없는 파일을 가리키고 있었다.
> 이제 파일이 실제로 있고, `HuntingGrounds.init(cfg)` → `loadGrounds()` 가 읽는다:
> 정원(낮·밤)·재생 주기·마을 무스폰 여유·병기 전리품 확률이 전부 등록부에서 온다.
> 코드에 남은 값은 **폴백**이다 (등록부가 유실돼도 산은 서야 한다 — 폴백은 사본이지 다른 정본이 아니다).
> 아직 코드가 갖고 있는 것: `mc_entity` 매핑 · `loadout` — 그 둘은 아래 ② 대로 **npcs 등록부**의 몫이다.

```yaml
# 사냥터 개체군 — 구역이 곧 생태계다. 정원(定員)과 재생 주기가 '고갈되지 않되 무한하지 않게' 만든다.
spawn:
  cycle_seconds: 10            # 재생 주기 — 구역당 최대 1마리/주기
  player_near: 96              # 사람이 이 안에 없으면 산은 조용하다 (성능)
  min_distance: 20             # 눈앞에 튀어나오지 않는다
  max_distance: 64
  max_block_light: 7           # 짐승은 어둠에서 온다 (불이 끝나는 곳부터가 사냥터다)
  zone_entity_cap: 18          # performance.yml 예산
  boss_respawn_seconds: 300    # 두목은 흔하지 않다

grounds:
  북쪽_산길:                    # zones.yml zone8
    zone: "북쪽 산길"
    population:                # {낮 정원, 밤 정원}
      san_neukdae:    { day: 4, night: 6 }
      metdwaeji:      { day: 3, night: 2 }
      horangi:        { day: 0, night: 1 }   # 맹수는 밤에 나온다
      bandal_gom:     { day: 0, night: 1 }
      north_road_bandit: { day: 3, night: 4 }
      galho:          { day: 1, night: 1 }
      baegyeongmyo:   { day: 0, night: 0 }   # 영물 = 등록제 (양산 금지)
loot:
  weapon_drop_chance: { 졸개: 0.5, 두목: 1.0 }
```

## 9. 인게임 검증 순서

1. `scripts/run_mvt_server.sh` 기동 → `/혼천 조성` (구역 재등록).
2. **마을 무스폰** — 밤이 될 때까지 마을에 서 있는다. 좀비·거미가 **한 마리도** 나오지 않아야 한다.
   `/kill @e[type=zombie]` 로 기존 개체를 걷어낸 뒤 확인 (스폰 취소는 새 스폰에만 적용된다).
3. **사냥터** — 북쪽 산길로 간다. `/혼천 사냥터` 로 census 확인 (정원 대비 현재 수).
   낮엔 늑대·멧돼지·도적, 밤엔 호랑이·반달곰이 추가로 선다.
4. **스탯** — 늑대를 친다: 8하트(16), 명패 백색. 호랑이: 붉은 명패, 10하트.
5. **사람** — 산길 도적을 죽인다 → **범철 도가 떨어진다** (50%). 갈호를 먼저 죽인다 → 졸개들이 **도망친다**.
6. **비무** — 표국 마당의 곽진을 우클릭 → 90초 안에 중상까지 몰아붙인다.
   **죽지 않는다.** 액션바에 `겨루며 배운다 (+N일 · 비무 ×0.5)`.
   `/혼천 정보` 에서 「비무」 숙련이 오르는지 확인.
7. **재생** — 늑대를 전멸시키고 1분 기다린다 → 정원까지 다시 찬다.

## 10. 남긴 한계

- **NPC 격 시전 없음** — 일류+ NPC 가 발경·검기를 두르지 못한다 (`SkillEngine` 이 플레이어 전용).
  대칭 원칙의 마지막 한 칸이다.
- **짐승 고유 액션 미구현** — 멧돼지 돌진 후딜, 호랑이 은신 기습(+2), 곰 슈퍼아머는 바닐라 AI 로 근사했다.
- **피해 공식의 `floor(마진/2)` 항 없음** — 바닐라 타격에는 판정 마진이 없다. 짐승·사람의 공격력은
  무기 위력(+무공 위력)까지만 실린다.
- **비무장(比武場) 건물 없음** — 표국 마당을 빌렸다 (조성기 소유).
- **팩 게이트** — 호랑이가 약탈수로, 산적이 좀비로 보인다. 텍스처 교체 전까지는 이름·스탯·행동이 대신 읽는다.
