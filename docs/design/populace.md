# 인구(人口) — 무명(無名)의 층

기계 판독 규칙: `config/npcs/populace.yml`
구현: `server-mvt/src/main/java/com/honcheon/mvt/Populace.java`
상위 규약: `docs/design/npc_lifecycle.md` · `docs/design/npc_death_consequences.md` · `docs/design/world_reaction_system.md`

## 1. 병(病)

청하현에 사람이 아홉뿐이었다. 객잔 주인·의뢰소 관리인·의원·잡화상·전장 지점주·포두·표국주·표사·현령 —
전부 **계약**을 진 사람들이다. 그들만 있는 마을은 마을이 아니라 **접수처**다.
물을 긷는 사람도, 밭에서 돌아오는 사람도, 우물가에서 하루를 보내는 노인도 없는 곳에서
"이 현의 민심이 3 떨어졌다"는 문장은 아무것도 가리키지 않는다. **민심은 사람의 수에 붙는 값이다.**

## 2. 약(藥) — 무명층

행인도 등록한다. 이름·나이·생업·거처·성정을 등재한다. 다만 계약 NPC와 **층이 다르다**.

| | 계약 NPC (cheongha_npcs.yml) | 무명 (populace.yml) |
|---|---|---|
| 등급 | 1~4 (배경·기능·관계·핵심) | **0 (무명)** |
| 의뢰 | 발생원이다 | 주지 않는다 |
| 무적 | **예** (`setInvulnerable(true)`) | **아니오 — 죽는다** |
| 명패 | 흰 글씨, 상시 표시 | 회색, 숨김 (다가가 물어야 안다) |
| 생애 시뮬 | 계절 정산 (등급 3+) | 없음 (지역 통계로만) |
| 죽음의 무게 | 1~3 | **0** — 계절 예산을 먹지 않는다 |
| 사망 시 | 후계·대행·복수·의뢰 주입 | 소문 강도 1~2 + 민심 -1 (**민심 부채**) |

### 등급 번호 주의

`cheongha_npcs.yml` 의 등급표는 **5 = 세력 대표 NPC** 다. 따라서 행인에게 5를 줄 수 없다.
행인은 배경(1) *아래* 층이므로 **tier 0** 을 쓴다.
`npc_lifecycle.yml` 의 `schedule.tier_1_2 = "구간별 스폰 프리셋 (개체 추적 없음)"` 규칙이 이 층에 그대로 적용된다.
승격은 열려 있다 — 사건으로 이름을 얻은 무명은 tier 3 개체로 승격한다 (`tier_mobility.promote`).

## 3. 계약을 깨지 않는 법

`TownAudit.contracts()` 는 마을 안의 **"명패 있고 무적인 Villager"** 를 세어 9인을 확인한다.
행인은 **무적이 아니다** → 검수에 잡히지 않는다. **TownAudit 은 한 줄도 고치지 않는다.**
`TradeListener` 도 같은 조건(명패 + 무적)으로 게이트하므로 행인 우클릭이 매입 창구를 열지 않는다.

두 번째 표식: 모든 행인은 PDC 키 `honcheon:populace`(값 = 등록부 id)를 지닌다.
정리(`despawnAll`)·인구조사(`census`)·목격자 계수·사망 판별이 전부 이 키 하나로 돌아간다.

## 4. 일과 — 하루 5구간

`config/time.yml` 의 `day_segments`(새벽·아침·낮·해질녘·밤)를 그대로 쓴다.
`populace.yml segments` 가 각 구간의 월드 시각 시작점을 정한다 (새벽 22000 / 아침 1000 / 낮 6000 / 해질녘 11000 / 밤 13500).

자리(`places`)는 **좌표가 아니라 앵커 + 오프셋**이다. 조성기가 세운 앵커
(장터·청하객잔·의뢰소·의방·전장·표국·관아·북쪽_산길)에 dx/dz 를 얹고 배회 반경을 준다.
마을이 옮겨져도, 조성기가 배치를 바꿔도 인구는 따라온다. 코드에는 좌표가 한 줄도 없다.

일과(`routines`)는 프리셋 17종. 원칙은 하나다 —
**아침엔 장터, 낮엔 일터(밭·산길 어귀·표국 마당·개울), 저녁엔 객잔, 밤엔 집(골목).**
개인차는 `routine_override` 로 구간 하나만 덮는다 (우삼은 해질녘에 객잔으로 간다 — 밭을 잃은 사내의 술).

구간이 바뀌면 **걸어서** 자리를 옮긴다. 텔레포트는 금지다
(`npc_lifecycle.yml`: "이동이 목격 가능해야 미행이 성립한다").

## 5. 인구 28인

농부 3 · 나무꾼 2 · 물지게꾼 2 · 짐꾼 2 · 행상 3(장돌뱅이·두부장수·나물장수) · 주모 1 · 객잔 부엌데기 1 ·
대장장이 도제 1 · 서생 1 · 아이 3 · 노인 2 · 거지 1 · 관졸 2 · 마부 1 · 전장 사환 1 · 빨래 아낙 1 · 의방 잡일 1.

이들은 계약 NPC의 **그림자**로 설계됐다 — 석근은 야철수의 도제이고, 여분은 유문의 손이 모자란 자리를 메우고,
유칠은 술 한 잔에 수레의 짐을 부는 하오문의 값싼 귀다. 무명은 배경이 아니라 **계약층의 뿌리**다.

## 6. 사건 반응 — 행인은 세계의 증거다

`reactions` 에 소문 태그별로 **회피할 자리**와 **대체 자리**, 그리고 **입에 오르는 말**을 등록한다.

- `도적_소문` → `산길_어귀`·`북문_어귀` 회피, 장터로 대체. **나무꾼이 산에 오르지 않는다.**
- `열병_소문` → `우물가` 회피, 의방 앞으로. **우물물을 의심한다.**

코드 API: `populace.rumor("도적_소문", true)`.
지금 배선된 것은 자리 회피와 대사뿐이다. 소문 엔진(`rumor.yml` 전파·정확도)과의 접합은 다음 층의 일이며,
config 구조는 그 확장을 이미 받도록 되어 있다 (`origin_network` 키가 자리를 지키고 있다).

## 7. 죽음 — npc_death.yml 위에 얹기

무명이 죽으면:

1. **소문이 난다.** 강도는 `killer_response.variables.witness` 를 **실제로 세어** 정한다 —
   반경 16칸 안의 다른 행인·플레이어 수. 2인 이상(백주 장터)이면 강도 2, 아니면 1.
2. **민심 -1.** (`region_delta`)
3. **후계도 복수자도 없다.** 등록 관계가 없으므로 `npc_death.revenge.civil_debt` 로 떨어진다 —
   민심 델타가 자연 회복에서 제외된다. *"가장 약한 자를 죽인 대가는 복수가 아니라 지역의 냉기다."*
4. **의뢰를 낳지 않는다.** `quest_injection` 미주입 (`death_weight: 0` — 계절 예산을 먹지 않는다).

전리품도 경험치도 없다. 행인은 사냥감이 아니다.

## 8. 성능

`performance.yml` 예산: `tick_budget.subsystem_budget_ms.npc_logic = 6ms`, `effects.central_ticker = true`.

- **중앙 티커 1개** (2초 = 40틱). 개체별 태스크 없음.
- **활성 반경 56 / 비활성 88** (히스테리시스 — 경계에서 몸이 깜빡이지 않는다).
- **동시 엔티티 상한 24.** 등록 28인 > 상한 → 전원이 동시에 서지 않는다. 이것은 버그가 아니라 예산이다.
- **틱당 스폰 2 / 경로탐색 6** (라운드로빈 커서 — 모두에게 차례가 온다).
- 스폰 사유 **CUSTOM** → `HuntingGrounds.ALLOWED_REASONS` 통과. 마을 자연 스폰 차단 규칙과 충돌하지 않는다.
- `setPersistent(false)` — 디스크에 남지 않는다. 재기동하면 등록부가 다시 세운다 (중복 없음).
- `setBreed(false)` / `setAgeLock(true)` — **인구는 등록부가 정한다.** 번식으로 늘지 않고 아이는 자라지 않는다.

## 9. 결정론의 경계

스폰 **인원**과 **누가 서는가**는 등록부 순서와 거리가 정한다 (난수 없음).
난수는 두 곳에만 쓴다: 자리 안의 **어느 칸에 서는가**, 그리고 **어슬렁거림**.
사람 수가 매번 다르면 그것은 세계가 아니라 날씨다.
