## 설계 목표

화산파는 단순한 "큰 건물 하나"가 아니다.
화산은 하나의 **산악 도교 캠퍼스(Mountain Taoist Campus)** 이다.

설계 목표는 다음과 같다.

- 자연과 건축이 하나의 공간처럼 보일 것
- 산을 깎아 만든 궁전이 아니라 **산 위에 자리 잡은 문파**일 것
- 실제 중국 화산(華山)의 분위기를 참고할 것
- 무협 작품에서 표현되는 화산파 이미지를 유지할 것
- Minecraft 플레이어가 직접 탐험하는 재미를 제공할 것

## 건축 철학

### 1. 자연 우선

건축물이 산을 지배하면 안 된다.
**산이 먼저 존재하고, 건물이 그 산에 적응해야 한다.**

**허용**: 암반 위 건물 · 절벽 위 전각 · 자연 지형 활용 · 기존 암석 보존

**지양**: 대규모 평탄화 · 인위적인 거대한 광장 · 산 전체를 인공 구조물로 덮는 형태

### 2. 수직 성장

화산파는 평지가 아닌 **높이에 따라 계층이 구분**된다.

예시: **산문 → 외문 → 생활구역 → 수련구역 → 본전 → 장문인 거처 → 후산**

높을수록 **권위 · 수련 단계 · 접근 제한**이 증가한다.

### 3. 도교 건축

화려한 황궁이 아니다. 전체 분위기는 **"절제된 품격"** 이다.

건축 특징: 회색 기와 · 흰 회벽 · 짙은 목재 · 자연석 기단 · 긴 처마 · 절제된 장식 · 자연과의 조화

## 캠퍼스 구성

다음 시설은 화산파의 **기본 시설 후보**이다.
기존 설계와 충돌하는 경우 **개발 AI가 판단**한다.

| 시설 | 역할 | 추천 요소 |
|---|---|---|
| **산문** | 문파 입구 · 방문객 통제 · 첫 인상 | 패방 · 현판 · 석등 · 향로 · 계단 시작점 |
| **외문 광장** | 신입 제자 · 외부 방문객 · 간단한 행사 | 소규모 광장 · 안내판 · NPC |
| **천계단** | 화산의 대표 요소 | 긴 계단 → 쉼터 → 절벽길 → 계단 → 전각의 반복. **직선보다 굽이치는 형태를 권장** |
| **연무장** | 화산 최대 광장 — 훈련 · 결투 · 행사 · 시연 | 본전 앞 배치 추천 |
| **본전** | 문파의 중심 — 장문인 · 장로 회의 · 의식 | 가장 높은 권위를 가진 건물 |
| **수련동** | ★사용자 확정 시설 | 수련 레벨별 분리 추천: 초급 · 중급 · 고급 · 장로 전용 |
| **숙소** | 생활 공간 | 구분: 신입 · 일반 제자 · 고위 제자 · 장로 |
| **식당** | 공동 식사 공간 | **생활감을 만드는 핵심 시설** |
| **장경각** | 문파의 기록 보관 | 검법 · 심법 · 역사 · 문헌 |
| **약방** | 부상 치료 · 단약 제작 | NPC 배치 가능 |
| **무기고** | 훈련용 무기 · 실전 무기 · 창고 | |
| **객원** | 외부 손님 · 타 문파 · 사절단 | 퀘스트 NPC |
| **장문인 거처** | 가장 높은 위치 · 조용한 공간 | 본전과 직접 연결 |
| **장로원** | 장로 생활 공간 — 회의 · 연구 · 거주 | |
| **매화원** | 화산파 상징 공간 | 매화나무 · 작은 정자 · 연못 · 산책길 |
| **후산** | 비공개 공간 | 암벽 수련 · 폭포 · 검총 · 비밀 수련장 |

## 실제 화산(華山)에서 참고 가능한 요소

실제 중국 화산 및 도교 사원의 특징을 참고한다.

- **긴 석계단** — 화산을 상징하는 요소. 플레이어가 **"올라간다"는 감각**을 만들어야 한다
- **절벽길** — 좁은 길 · 난간 · 절벽 · 풍경
- **현공교** — 절벽 사이 다리 (목교 · 석교 혼합 가능)
- **전망대** — 절벽 끝 정자 · 쉼터 · NPC · 이벤트
- **자연 암반** — 건물 아래 인공 기초 대신 **암반을 최대한 유지**

## 동선 설계

플레이어는 항상 **입구 → 생활 → 훈련 → 권위 → 비공개** 순으로 이동하도록 설계한다.

중간중간 **쉼터 · 전망대 · 작은 전각 · NPC** 를 배치하여 이동이 단조롭지 않도록 한다.

## 건축 밀도 규칙

권장: **건물 → 빈 공간 → 정원 → 건물** 을 반복한다.

건물을 연속적으로 붙여 **궁궐처럼 만드는 것은 지양**한다.

## 생성 AI 구현 시 고려사항

건축 생성 AI는 다음 순서를 권장한다.

```
1. 산 능선 결정
 ↓
2. 계단 및 주 동선 생성
 ↓
3. 본전 위치 결정
 ↓
4. 주요 시설 배치
 ↓
5. 생활 시설 배치
 ↓
6. 조경
 ↓
7. NPC 배치
 ↓
8. 세부 장식
```

**지형을 모두 평탄화한 후 건물을 올리는 방식보다, 지형을 먼저 생성하고 건물이 지형에 적응하는 방식을 우선적으로 고려한다.**
