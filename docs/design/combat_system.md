# 전투 시스템 — 상세 규칙

> 설계 검토 공백 G7(=PT-001 F2), PT-002 F6의 해결 문서.
> 원칙: 새 메커니즘을 만들지 않는다 — **전투는 대립 판정의 연쇄**이며,
> 기존 판정식·등급제·보정 가드레일을 그대로 재사용한다.
> 기계 판독용: `config/combat.yml`

---

## 1. 전투의 위상 — 전투도 세계에 흔적을 남긴다

전투는 별도의 미니게임이 아니다. 승패보다 **어떻게 이겼는가/졌는가**가 세계에 기록된다:
시체는 소문(강도 2~3)이 되고, 살해는 관군·유족·소속 세력의 반응 입력이 되며,
공개된 무공은 출처 소문을 만든다 (기존 소문·세력 반응 규칙 그대로).

## 2. 전투 개시

```text
기습:    기존 기습 판정 (민첩+은신 vs 감각+위협_감지). 성공 시 첫 라운드 선공 + 방어측 페널티 -2
정면:    선제 비교 — 민첩+감각 합이 높은 쪽 선공 (판정 없음)
         동률 → 경지 높은 쪽 → 그것도 동률이면 감각 단독 비교
         최종 동률(완전 대칭) → '동시 교환': 선공 없음. 양측이 그 라운드 피해를 서로 확정한다.
         (완전 대칭 대결의 승패가 선공 결정에서 이미 끝나는 것을 막는다 — 둘 다 눕는 결말이 있어야 한다)
압도:    기대 마진 ±8 규칙 그대로 — 생사경이 삼류 잡졸과 '전투'하지 않는다 (자동 처리)
```

## 3. 라운드 — 행동 1개씩

```text
공격 / 방어 전념(이번 라운드 방어 +2) / 무공 시전 / 거리 조정·이동 /
도주 시도 / 말 걸기(전투 중 협상 — 화술 판정, 틈을 보이면 상대 공격에 -1)
```

## 4. 공격 판정 (기존 식 재사용)

```text
공격측 = 관련 능력치 + 무공 숙련 + 보정(경지 격차, 협공, 환경, 상태) + 2d6*
방어측 = 회피(민첩+경공) 또는 막기(근력+병기 기술) 중 방어자 선택 + 7*
* 플레이어가 낀 쪽만 주사위. NPC는 +7. 플레이어가 방어자면 플레이어가 굴린다.
```

- **협공: 같은 대상 공격자 1명 추가당 +1 (최대 +2) — 그리고 포위 슬롯 3**
  한 사람을 동시에 칠 수 있는 손은 셋뿐이다. 4인째부터는 대기(포위)다.
  머릿수는 '교대'가 되지 '동시타'가 되지 않는다. 다구리의 진짜 무기는 명중이 아니라 **도주 봉쇄(-2)** 다.
- **1대다 방어 이점: 다수를 상대하는 자는 방어 판정 +1/추가 적 (최대 +2)** — 사방에서 오는 검은 서로의 검로를 막는다
- 합격진(등록 무공)만이 슬롯을 연다 — 매화검진 슬롯 5. 오합지졸은 셋까지다
- 아이 페널티(v2): 성인 상대 전투 유년 −2 / 소년 −1
- 마진 등급은 그대로: 아슬아슬한 승리는 부수 리스크(자세 무너짐, 무기 손상, 소음)를 남긴다

### 4.1 방어 선택 3종 — 막기는 검을 태워 목숨을 산다

```text
회피 (민첩+경공)      피해 0, 무기 무손상.  격은 회피를 부수지 못한다 (기 발현 원칙 2)
막기 (근력+병기 기술)  피해 -3.  상위 격도 막힌다 — 대신 무기가 그 격을 대신 먹는다 (무기 파괴)
흘리기 (감각+병기 기술) 피해 -1, 무기 무손상.  판정 -2 (어렵다) — 정련 미만의 무기로 검기를 상대하는 자의 길
방어_전념             이번 라운드 방어 +2 (행동 소모)
```

범철로 검기를 막으면 **3합째 검이 부러진다.** 그러나 그 3합 동안 피해는 합당 3씩 줄었다 —
검 한 자루로 아홉의 피해를 산 것이다. 그것이 막기의 값이고, 그것이 무기가 소모품인 이유다.

## 5. 피해와 부상

```text
피해 = 무기 위력 + 무공 위력 + 격 위력 + floor(마진 ÷ 2)

무기 위력: 맨손 1 / 암기 2 / 단검·봉·활 3 / 검·도·창 4 / 중병기 5
무공 위력: 입문 +0 / 삼류급 +1 / 이류급 +1 / 일류급 +1 / 절정급 +2 / 오의 별도
격  위력: 외공기 +0 / 발경 +1 / 검기 +2 / 강기 +3 / 어검 +4 / 심검 +5
```

**위력의 축은 등급이 아니라 격이다.** 무공 등급 사다리는 일부러 눌려 있다(0·1·1·1·2) —
무공 등급의 값은 위력 보정이 아니라 ① 판정에 들어가는 숙련 상한 ② 격의 개방 ③ 습득·소문의 무게에 있다.
같은 매화검법도 발경을 실으면 +1, 검기를 실으면 +2다. **내력을 태우면 아프다.**

격 위력의 근거 (절정 대 절정, 내구 22 — combat_audit 시뮬):

| 격 | 피해/합 | 외공기 대비 | TTK |
|----|---------|-------------|-----|
| 외공기 | 3.86 | — | 6합 |
| 발경 +1 | 4.44 | +15% | 5합 |
| 검기 +2 | 5.03 | +30% | 5합 |
| 강기 +3 | 5.61 | +45% | 4합 |
| 어검 +4 | 6.19 | +60% | 4합 |

이 이상 올리면 격을 쓴 쪽이 1~2합에 끝내 전투가 사라진다. +1이면 충분하다.

무기 **등급**(범철·정련·보병·신병)은 판정 보정을 **주지 않는다**(전부 0).
등급의 값은 오직 '감당 격' — 부러지지 않는 것이다. 검에서 나오는 유일한 보정은 애병(손에_익다 +1):
검의 값은 등급이 아니라 함께한 세월이다.

```text
내구 = 10 + 체력 × 2      (체력 3 → 16)
부상: 내구 50% 이하 경상(-1) / 25% 이하 중상(-2) / 0 빈사(-3, 매 라운드 체력 판정)
대성공 공격은 부상 단계를 즉시 1단계 추가로 올린다 (급소)
```

부상 페널티는 기존 신체 상태 보정과 동일 값 — 전투 밖 판정에도 그대로 이어진다.
치료 규칙은 기존 time.yml (경상 1구간 / 중상 하루).

## 6. 내력 (내공 자원) — 내력을 먹는 것은 초식이 아니라 격이다

```text
내력 = round(내공 × (내공+1) / 2 × 3)   # 축기 세월에 비례 (internal_energy.yml pool_curve)
소모: 초식(무공)은 내력을 쓰지 않는다 (cost 0 = 외공 초식).
      내력을 먹는 것은 '격'이다 — 초식에 발경(1)·검기(1~3)·강기(2~6)를 얹는 순간 지불한다.
      예외: 절정 이상을 요구하는 비전 초식은 검기를 품고 태어난다 (cost 3).
고갈: 판정 -2 + 다운캐스트 — 초식은 그대로 나가고 격만 벗겨진다 (격 위력 0)
회복: 운기조식 1구간에 max(내공×순도, 1) 회복. 전투 중 회복 불가
```

**초식과 격의 분리가 '열어놓고 못 쓰는 문'을 구조적으로 없앤다.**
삼류·이류의 내력 풀은 0이다. 초식 자체가 내력을 요구하면 그 무공은 배워도 시전되지 않는다
(구 규칙: 육합검 3타 cost 1 · 매화보 cost 2 · 금나수 cost 2 — 셋 다 시전 불가였다).
초식을 외공으로 완결시키면 삼류 무인도 육합검을 끝까지 쓰고,
개화한 자는 **같은 육합검에 발경을 싣는다.** 그것이 개화의 보상이다.

범인·삼류·이류는 내력이 없다 — **삼류·이류 = 외공(外功)의 무인.** 몸과 무기가 전부다.

## 7. 도주와 종결

```text
도주: 민첩+도주 vs 가장 빠른 추적자 (포위 상태면 저항 +2)
     부분 성공 = 벗어나되 흔적/물건을 남긴다
종결 선언: 상대가 빈사·항복·도주하면 마무리를 선언한다 — 제압 / 살해
  제압: 포로, 심문, 관군 인도 → 각각 후속 판정과 세계 반응
  살해: 소문 강도 상향(+1), 시체 = 관군 입력(+3), 소속 세력 '조직원 사망'(+4),
       유족·동료의 기억 태그. 죽이는 것은 언제나 더 쉽고, 언제나 더 비싸다.
```

## 8. NPC 대 NPC 약식 규칙 (F6)

플레이어가 끼지 않은 전투(아버지의 결투, 곽진 대 도적들)는 주사위 없이 굴린다:

```text
양측 전력 = 능력치 + 기술 + 격 위력 + 상태 보정 + 협공 + 7 (양측 고정)
격차별 라운드 결과:
  0~1  접전   — 양측 소모 (라운드마다 양측 내구에 소폭 피해 누적)
  2~4  우세   — 열세측만 피해, 우세측 경미
  5+   압도   — 열세측 즉시 부상 단계 상승, 수 라운드 내 종결
GM은 라운드마다 서사로 표현. 플레이어가 개입하는 순간, 그 지점부터 정식 판정으로 전환.
```

## 9. 검증 — 기존 테스트 재계산

**PT-002 아버지의 결투 (NPC 대 NPC):**

```text
아버지(은퇴 일류, 실효): 근3+검법4+7 = 14  vs  원수 사제: 민3+도법3+7 = 13
격차 1 = 접전 → 라운드마다 양측 소모 → 수 합 뒤 아버지 신승, 중상
→ PT-002에서 재량으로 서술한 결과("신승, 중상")가 규칙에서 그대로 재현된다.
```

**PT-001 산길 습격 (플레이어 1합):**

```text
플레이어 공격 3(근3+검술0) + 🎲7 vs 도적 막기 근3+도법1+7 = 11 → 마진 -1 부분 성공
피해 = 검4 + 무공0 + 격0 + (-1÷2 내림 = -1) = 3 → 도적 내구 16, 유효 축적
도적 공격 4 vs 플레이어 회피 민3+7 = 10 → 접전
→ 삼류 대 삼류는 여러 합이 필요하다 — PT-001의 "양측 아슬아슬" 체감과 일치.
  당시 1합으로 처리한 것은 곽진 측 우세(NPC 약식: 곽진 14 vs 졸개 6+협공 = 압도)가
  전장을 정리했기 때문으로 소급 설명 가능.
```
