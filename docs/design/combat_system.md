# 전투 시스템 — 상세 규칙

> 설계 검토 공백 G7(=PT-001 F2), PT-002 F6의 해결 문서.
> 원칙: 새 메커니즘을 만들지 않는다 — **전투는 대립 판정의 연쇄**이며,
> 기존 판정식·등급제·보정 가드레일을 그대로 재사용한다.
> 기계 판독용: `config/combat.yml`

---

## 1. 전투의 위상 — 전투도 세계에 흔적을 남긴다

전투는 별도의 미니게임이 아니다. 승패보다 **어떻게 이겼는가/졌는가**가 세계에 기록된다:
시체는 소문(강도 2~3)이 되고, 살해는 관군·유족·소속 세력의 반응 입력이 되며,
공개된 무공은 출처 소문을 만든다 (기존 소문·세력 반응 규칙 그대로).

## 2. 전투 개시

```text
기습:    기존 기습 판정 (민첩+은신 vs 감각+위협_감지). 성공 시 첫 라운드 선공 + 방어측 페널티 -2
정면:    선제 비교 — 민첩+감각 합이 높은 쪽 선공 (판정 없음, 동률이면 경지 높은 쪽)
압도:    기대 마진 ±8 규칙 그대로 — 생사경이 삼류 잡졸과 '전투'하지 않는다 (자동 처리)
```

## 3. 라운드 — 행동 1개씩

```text
공격 / 방어 전념(이번 라운드 방어 +2) / 무공 시전 / 거리 조정·이동 /
도주 시도 / 말 걸기(전투 중 협상 — 화술 판정, 틈을 보이면 상대 공격에 -1)
```

## 4. 공격 판정 (기존 식 재사용)

```text
공격측 = 관련 능력치 + 무공 숙련 + 보정(경지 격차, 협공, 환경, 상태) + 2d6*
방어측 = 회피(민첩+경공) 또는 막기(근력+병기 기술) 중 방어자 선택 + 7*
* 플레이어가 낀 쪽만 주사위. NPC는 +7. 플레이어가 방어자면 플레이어가 굴린다.
```

- 협공: 같은 대상 공격자 1명 추가당 +1 (최대 +3)
- 아이 페널티(v2): 성인 상대 전투 유년 −2 / 소년 −1
- 마진 등급은 그대로: 아슬아슬한 승리는 부수 리스크(자세 무너짐, 무기 손상, 소음)를 남긴다

## 5. 피해와 부상

```text
피해 = 무기 위력 + 무공 위력 + floor(마진 ÷ 2)

무기 위력: 맨손 1 / 단검 2 / 검·도·창 3 / 중병기 4
무공 위력: 무공 등급별 — 입문 +0 / 삼류급 +1 / 이류급 +2 / 절정급 +3 / 오의 별도
```

```text
내구 = 10 + 체력 × 2      (체력 3 → 16)
부상: 내구 50% 이하 경상(-1) / 25% 이하 중상(-2) / 0 빈사(-3, 매 라운드 체력 판정)
대성공 공격은 부상 단계를 즉시 1단계 추가로 올린다 (급소)
```

부상 페널티는 기존 신체 상태 보정과 동일 값 — 전투 밖 판정에도 그대로 이어진다.
치료 규칙은 기존 time.yml (경상 1구간 / 중상 하루).

## 6. 내력 (내공 자원)

```text
내력 = 내공 × 3
내공이 실린 무공 시전 시 소모 (무공별 1~3). 0이 되면 내공 무공 불가 + '내공 고갈'(-2)
회복: 운기조식 1구간에 내공×1 회복. 전투 중 회복 불가
```

범인·삼류 초입은 내력이 없거나 적다 — 초반 전투가 자연히 "외공 몇 합"으로 끝나는 이유.

## 7. 도주와 종결

```text
도주: 민첩+도주 vs 가장 빠른 추적자 (포위 상태면 저항 +2)
     부분 성공 = 벗어나되 흔적/물건을 남긴다
종결 선언: 상대가 빈사·항복·도주하면 마무리를 선언한다 — 제압 / 살해
  제압: 포로, 심문, 관군 인도 → 각각 후속 판정과 세계 반응
  살해: 소문 강도 상향(+1), 시체 = 관군 입력(+3), 소속 세력 '조직원 사망'(+4),
       유족·동료의 기억 태그. 죽이는 것은 언제나 더 쉽고, 언제나 더 비싸다.
```

## 8. NPC 대 NPC 약식 규칙 (F6)

플레이어가 끼지 않은 전투(아버지의 결투, 곽진 대 도적들)는 주사위 없이 굴린다:

```text
양측 전력 = 능력치 + 기술 + 상태 보정 + 협공 + 7 (양측 고정)
격차별 라운드 결과:
  0~1  접전   — 양측 소모 (라운드마다 양측 내구에 소폭 피해 누적)
  2~4  우세   — 열세측만 피해, 우세측 경미
  5+   압도   — 열세측 즉시 부상 단계 상승, 수 라운드 내 종결
GM은 라운드마다 서사로 표현. 플레이어가 개입하는 순간, 그 지점부터 정식 판정으로 전환.
```

## 9. 검증 — 기존 테스트 재계산

**PT-002 아버지의 결투 (NPC 대 NPC):**

```text
아버지(은퇴 일류, 실효): 근3+검법4+7 = 14  vs  원수 사제: 민3+도법3+7 = 13
격차 1 = 접전 → 라운드마다 양측 소모 → 수 합 뒤 아버지 신승, 중상
→ PT-002에서 재량으로 서술한 결과("신승, 중상")가 규칙에서 그대로 재현된다.
```

**PT-001 산길 습격 (플레이어 1합):**

```text
플레이어 공격 3(근3+검술0) + 🎲7 vs 도적 막기 근3+도법1+7 = 11 → 마진 -1 부분 성공
피해 = 검3 + 무공0 + (-1÷2 내림 = -1) = 2 → 도적 내구 16, 유효 축적
도적 공격 4 vs 플레이어 회피 민3+7 = 10 → 접전
→ 삼류 대 삼류는 여러 합이 필요하다 — PT-001의 "양측 아슬아슬" 체감과 일치.
  당시 1합으로 처리한 것은 곽진 측 우세(NPC 약식: 곽진 14 vs 졸개 6+협공 = 압도)가
  전장을 정리했기 때문으로 소급 설명 가능.
```
