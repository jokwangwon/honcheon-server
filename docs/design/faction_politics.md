# 세력 정치 — 파편 · 명분 · 연합 · 관무불가침

> **무림은 하나가 아니다.** 정파도 사파도 세력이 아니라 *연합의 이름*이다.
> 평시에 그들은 15개 + α의 **단일 세력**으로 각자 논다.
> 뭉치려면 **명분**이 있어야 하고, 명분은 사건이 쌓고 시간이 깎는다.
>
> 그리고 관(官)은 유일하게 찢어져 있지 않다. 그래서 강하다.
> 그런데 관도 먼저 치지 못한다. 치는 순간 **명분을 선물하기 때문이다.**
> 이 문서는 그 손익계산서를 수치로 적는다.
>
> 기계 판독용: `config/faction_politics.yml`
> 접합: `config/factions.yml` · `faction_reaction.yml` · `rumor.yml` · `region_state.yml` ·
> `npc_death.yml` · `chapter_events.yml` · `faction_entry_routes.yml`
> 상위 문서: `docs/design/world_reaction_system.md` (주목·우호 사다리는 이미 있다 — 이 문서는 그 위에 정치를 얹는다)

## 0. 세 줄 요약

```text
① 파편화가 기본 상태다.  구파일방(10) + 오대세가(5) = 15개 독립 세력. 사파도 5개로 찢어져 있다.
② 명분이 방아쇠다.       명분 게이지가 각 세력의 임계를 넘을 때만 연합이 생긴다. 소진되면 흩어진다.
③ 불가침은 계산이다.     명분 20 & 참여 6 = 무림 승리 경로. 관은 이 상태를 만들지 않는 데에 전력을 쓴다.
```

## 1. 파편화 — '정파'는 세력이 아니다

`factions.yml`의 `faction_groups.orthodox`는 지금까지 **하나의 세력처럼** 읽혔다. 이 문서는 그것을
**연합체(coalition)** 로 재해석한다.

```text
faction_groups.orthodox   =  "지금 이 명분으로 뭉친 자들"의 동적 명단
faction_groups.*.members  =  각각이 단일 세력 (상시 존재하는 것은 이쪽뿐)
```

상시 존재하는 지휘부는 **없다.** 무림맹은 상설 기구가 아니라 사건마다 새로 짜이는 임시 조직이고,
이름조차 사안을 따라간다 (`<사안> 연합`). 이겨도 흩어진다.

- **1급** = `factions.yml` `members`에 id가 있다.
- **로스터** = `sects` / `clans` 명단에만 이름이 있다 → 8장에 1급 승격 YAML 조각을 제안한다.
- **예약** = `factions.yml` 주석의 확장 예약(아미) — `active: false`. 새 세력을 발명한 것이 아니라
  **이미 명단에 있던 이름에 id를 붙였을 뿐이다.**

두 개의 특이점:
- **개방에는 본거지가 없다.** 관이 칠 표적이 없고, 대신 어디에나 있다. 그래서 개방은 언제나
  **명분의 최초 발화자**다 (임계 8 — 15개 중 가장 낮다).
- **제갈세가는 관에 줄이 있다.** 연합에 붙으면 관의 병력 배치를 읽어준다(전투 보정 +2).
  동시에 **관의 귀이기도 하다.**

정파 15의 무력 총합 = **99**. 사파 5의 총합 = **28**. 무림 전체 = **127**.
**그리고 무림은 이 총합으로 존재한 적이 없다.**

### 1.2 사파도 하나가 아니다

하오문(5)·녹림(8)·장강수로채(7)·살막(4)·독문(4). 서로 다툰다. 육로 통행세와 수로 통행세가
환적 나루에서 매년 피를 부르고, 하오문과 수로채는 밀무역 이권으로 웃으며 칼을 간다.
**살막은 아무 편도 아니다** — 명분 임계 26. 사실상 불참. 살막은 고용될 뿐이다.

## 2. 세력 관계표 — 같은 정파끼리도 앙숙이다

`relation`: **+3 동맹 / +2 우호 / +1 거래 / 0 중립 / −1 경쟁 / −2 원한 / −3 숙적**

| 관계 | 값 | 연합 임계 효과 |
|---|---|---|
| 동맹 | +3 | −3 (상대가 당하면 −6, 자파 피해에 준함) |
| 우호 | +2 | −2 |
| 거래 | +1 | −1 (이익이 갈리면 즉시 0) |
| 경쟁 | −1 | **+2** — 저쪽이 공을 세우는 판에는 늦게 붙는다 |
| 원한 | −2 | **+5** — 앙숙이 이미 낀 연합엔 안 들어간다 |
| 숙적 | −3 | **불참** — 존망 태그일 때만 예외 |

### 2.1 정파 내부 (연합이 '느슨한' 이유의 목록)

```text
소림 ↔ 무당      +3  불·도 양대 종가. 둘이 함께 나서면 그것이 곧 명분이다 (anchor)
소림 ↔ 아미      +3  같은 불가 계보
개방 ↔ 소림      +2  속가·탁발의 오랜 연 — 개방이 소림에 먼저 알린다
무당 ↔ 곤륜      +2  도맥의 형제
화산 ↔ 남궁      +1  검의 예 — 비무로 얼굴을 익힌 사이
제갈 ↔ 현령/관청 +1  문사 계보. 관을 읽는 눈이자, 관의 귀

화산 ↔ 종남      −2  ★ 같은 섬서 땅. 도맥의 정통·향화·후원자를 대대로 다툰다
남궁 ↔ 팽가      −1  ★ 검가 vs 도가. 오대세가 서열의 앙금 — 혼담이 깨진 뒤로 더
화산 ↔ 청성      −1  검맥 우열 — 비무연에서 매번 붙는다
화산 ↔ 점창      −1  쾌검 vs 매화검, 오래된 서열 논쟁
제갈 ↔ 모용      −1  지략 vs 명성 — 조정 인맥 경쟁
팽가 ↔ 모용      −1  하북·요동 접경, 마적 토벌 공적 다툼
당가 ↔ 소림      −1  독은 협(俠)이 아니다 — 불가의 오랜 냉대
당가 ↔ 아미      −2  사천 한 땅의 두 이름
```

### 2.2 정파 ↔ 사파 / 사파 내부

```text
개방 ↔ 하오문    −2  ★ 같은 바닥, 다른 규칙. 정보 밥그릇 — 무림에서 가장 오래된 원한
팽가 ↔ 녹림      −3  하북 도적 소탕이 팽가의 가업. 대를 이은 피 (숙적)
남궁 ↔ 수로채    −2  장강 상권 — 남궁의 물류를 수로채가 먹는다
당가 ↔ 독문      −2  표면은 원한(방계의 배신). 실제는 혈연 — 당가는 독문을 끝내 죽이지 않는다
무당 ↔ 하오문     0  무당도 정보를 산다 (부인하지만)

하오문 ↔ 녹림    +1  녹림은 자체 소문망이 없다 (rumor.yml network_access — 하오문 망에 얹혀 있다)
하오문 ↔ 살막    +1  청부의 중개인
독문 ↔ 살막      +1  독과 살수 — 가장 효율적인 조합
녹림 ↔ 수로채    −1  육로 vs 수로 통행세, 환적 나루의 피
하오문 ↔ 수로채  −1  밀무역 이권 — 겉으로는 웃는다
```

### 2.3 관 (핵심)

```text
관군 ↔ 정파       0  치안에는 협력한다. 그러나 무장 집단은 언제나 경계 대상이다 (factions.yml 원문)
관군 ↔ 사파      −2  적대. 단 하오문과는 뒷거래가 있다 — 관도 정보가 필요하다
현령 ↔ 하오문    +1  장부에 없는 관계. 발각되면 관리의 목이 날아간다 — **명분의 재료**
관군 ↔ 마교       0  관계 없음 = 마교가 원하는 상태. **잠식의 전제조건이다**
마교 ↔ 혈교      −3  혈교는 마교를 기습한 적이 있다 (story_summary 2장)
```

## 3. 명분(名分) — 연합의 방아쇠

**명분은 사안(issue)마다 하나씩 생기는 0~30 게이지다.** `faction_reaction.yml`의 주목(score)·우호(favor)와
**같은 스케일, 같은 감쇠 문법**(7일 −1)을 쓴다 — 새 통화가 아니다.

```text
myeongbun {
  target:       명분이 겨누는 세력 (gwan_gun · magyo · noklim · <문파>)
  tags:         무고 · 무림침해 · 존망 · 금기 · 법의배신 · 규약 · 생계
  gauge:        0~30
  participants: 현재 붙은 세력 목록
  origin_rumor: 이 명분을 실어 나른 소문 — 정확도가 곧 명분의 진위다
}
```

### 3.1 명분은 소문을 타고 온다 — 정확도가 곧 명분의 힘

`rumor.yml`의 `accuracy_bands`를 그대로 게이트로 쓴다.

| 정확도 | 밴드 | 명분 배수 | |
|---|---|---|---|
| 80~100 | 사실적 | ×1.0 | 그대로 명분이 된다 |
| 50~79 | 과장 | ×0.7 | 부풀려진 만큼 반박당한다 — 신중한 문파(소림·무당)는 확인부터 한다 |
| 30~49 | 오해 | ×0.5 + **target_swap** | ★ 범인이 뒤바뀐다 = **명분이 엉뚱한 세력에게 붙는다** |
| 0~29 | 괴담 | ×0.0 | 명분이 되지 못한다. 흉흉함(민심 −)만 남는다 |

**오해 밴드가 마교 이간의 유일한 통로다.** 소문 시스템이 이미 "범인·동기·대상이 뒤바뀜"이라고
정의해 둔 그 구간이, 정치층에서는 **잘못된 전쟁**이 된다.

세력이 자기 조직 채널로 확인(정확도 80+)하면 배수는 1.0으로 재계산된다 — 조사가 곧 명분의 확정이다.

### 3.2 명분을 쌓는 사건

| 사건 | 값 | 태그 |
|---|---|---|
| 관과 금기세력의 결탁 증거 | **+9** | 금기·법의배신 |
| 관의 문파 토벌(멸문) | **+10** | 무림침해·**존망** |
| 관의 무림 일제 검속 | +8 | 무림침해·**존망** |
| 관의 문파 제자 다수 살해 | +7 | 무고·무림침해 |
| 관리의 사적 폭거(백성 살해) | +6 | 무고 |
| 관의 은폐 발각 | +4 | 법의배신 |
| 마교 준동 확증 | +8 | 금기·존망 |
| 인신공양 의식 발각 | +9 | 금기·무고 |
| 금기 마공 사용 확인 | +5 | 금기 |
| 문파 멸문 | +10 | 무림침해·존망 |
| 장문인 피살 | +7 | 무림침해 |
| 무고한 학살(장터·촌락) | +8 | 무고 |
| 사파의 민간 학살 | +5 | 무고 |
| 맹세 배신(동맹 공격) | +4 | 규약·법의배신 |
| 비무 규약 파기(독·암기) | +3 | 규약 |
| 상단로 장기 봉쇄 | +2 | 생계 |

### 3.3 명분을 깎는 것 — 관의 유일한 무기

| 수단 | 값 | |
|---|---|---|
| **가해자 처형 공개** | **−6** | ★ 꼬리 자르기. 관이 자기 관리를 버린다 — 가장 싸게 명분을 끄는 법 |
| 배상 공개 | −4 | `economy.yml` 보수 문법 |
| 참여 세력 이익 배분(매수) | −3 | 한 문파만 사면 연합에 금이 간다. 발각 시 +4(은폐 발각) |
| 피해 당사자 화해 | −8 | 당사자가 용서하면 남이 대신 화낼 명분이 없다 |
| **진범 규명** | **transfer** | ★ 소멸이 아니라 **진범에게 이전** — 이간 해소의 유일한 문 |
| 자연 감쇠 | −1 / 7일 | 존망 태그는 4에서 멈춘다 (score의 `floor_after_stage_3` 대칭) |

> **명분은 소진된다. 그래서 관은 버티기만 해도 이긴다.** 이것이 억지의 절반이다.

### 3.4 태그 감응 — 누가 어떤 명분에 반응하는가

| 태그 | 반응 세력 | 임계 보정 |
|---|---|---|
| **존망** | **전 무림 (사파 포함)** | **−10** — "다음은 우리 차례다" |
| 금기 | 소림·무당·화산·아미·곤륜 | −4 |
| 무고 | 소림·아미·개방·화산·무당 | −3 |
| 생계 | 개방·상단·민간·표국 | −3 |
| 무림침해 | 전 정파 (+ 사파, 존망일 때) | −2 |
| 법의배신 | 개방·제갈·민간 | −2 |
| 규약 | 정파 전반 | −1 (약하다 — 규탄·절교로 끝난다) |

**존망 태그가 유일하게 사파를 붙게 한다.** 관이 문파 하나를 멸문시키면 녹림 두목도 셈을 시작한다.

## 4. 연합 — 성립 · 크기 · 붕괴

### 4.1 임계 (base `join_threshold`)

```text
개방 8  │ 팽가 10 │ 화산 11 │ 소림 12 │ 무당 13 │ 남궁 13 │ 아미 14 │ 종남 14
청성 15 │ 제갈 15 │ 모용 16 │ 당가 17 │ 점창 17 │ 곤륜 18 │ 해남 20

녹림 20 │ 수로채 20 │ 독문 21 │ 하오문 22 │ 살막 26 (사실상 불참)
```

- **개방(8)**: 정보로 먼저 알고, 잃을 본거지가 없다. 언제나 첫 번째다.
- **팽가(10)**: 호전적 — 명분이 조금만 있어도 도를 뽑는다.
- **소림(12)**: 무겁다. 그러나 **소림이 나서면 그것 자체가 명분의 보증**이다(anchor, 아래).
- **해남(20)·곤륜(18)·점창(17)**: 멀다. 천하가 뒤집혀야 배를 띄운다.
- **하오문(22)**: 장사꾼. 명분이 아니라 이익으로 움직인다.

### 4.2 보정

```text
피해 당사자            −8   자파 제자·장문인·본산이 당했다 → 사실상 즉시
동맹 피해              −6   relation +3 상대가 당했다
인접 지역              −4
소림 또는 무당 참여    −3   ★ anchor — 종가가 나섰다는 것 자체가 명분의 보증
동맹 이미 참여         −3
태그 감응              −1 ~ −10  (3.4 표)
우호 참여              −2
경쟁 세력 참여         +2
상대와 이익 관계       +3   그 관과 거래 중 / 그 상단의 표행을 맡는 중
원한 세력 참여         +5
자파 내부 사정         +2~+6  장문 교체기·내분 (sect_life / npc_lifecycle 상태)
거리(지역권 밖)        +2
숙적 참여              불참  (존망 태그일 때만 예외)
```

**참여 판정**: `gauge >= join_threshold + Σ modifiers`, 7일마다 재평가(명분 감쇠와 동기).
평가는 그 세력의 **조직 채널에 사건이 도달한 뒤에만** 이뤄진다 — 개방 1일, 정파망 3일
(`rumor.yml faction_awareness`). **망별 속도가 곧 세력별 참전 시차다.**

### 4.3 크기

| 참여 | 이름 | 실체 | 관의 인식 |
|---|---|---|---|
| 1~2 | 규탄 | 성명·절교. 무력 행동 없음 | 무시 |
| 3~5 | 소연합 | 합동 조사·토벌대 (반응 5단계) | 경계 |
| **6~9** | **대연합** | 지역권 전쟁 상태 (6단계) | **협상** |
| 10+ | 무림공적 선포 | 천하 소문(강도 5) | **후퇴 검토** |

**맹주**는 `mandate_weight` 최고 세력(소림·무당·개방 = 3). 동률 + relation ≤ −1이면 **맹주 다툼** →
연합 명분 −2/주.

### 4.4 붕괴 — 연합은 언제나 임시다

| 방아쇠 | 효과 |
|---|---|
| 명분 < 개별 임계 | 그 세력만 이탈. 계속 줄면 순차 붕괴 |
| 명분 0 | **연합 해산.** 남는 건 개별 문파의 원한(score)뿐 |
| 목적 달성 | 가해자가 죽었다 → 명분 −6~−10 → 대부분 이탈. "이제 됐다" |
| 이익 충돌 | 명분 −3, 충돌한 두 세력 relation −1 (**영구**) |
| 맹주 다툼 | 명분 −2/주. 3주 지속 시 두 개의 작은 연합으로 분열 |
| 배신 | 이탈 세력에 배신 명분(+4) 발생 → **자신이 다음 명분의 대상이 된다** |
| 관의 매수 | 특정 세력에 `이익 관계 +3` 주입 → 이탈. 발각 시 명분 +4 |

> **연합은 이겨도 흩어진다.** 무림에 상설 지휘부가 생기지 않는 이유이자,
> 관이 무림을 두려워하되 굳이 무너뜨리지 않는 이유다.

## 5. 관무불가침 — 도덕이 아니라 손익계산서

### 5.1 관의 전력

```text
현 관군                3
지역권 상급관청 동원   20
황실 정규군            300        ← 칙명(勅命) 필요. 조정의 정치가 걸린다
병사→무력 환산         ×0.1       (병사 10 = 무인 무력 1)
방어 부담              0.75       ★ 북방 국경·타 지역 치안에 묶여 있는 비율

원정 가용   = 300 × 0.25 × 0.1 =  7.5
총력전 가용 = 300 × 0.70 × 0.1 = 21.0   ← 이것이 "국력을 태운다"의 실체
```

**관의 강함은 무력의 크기가 아니다.** 단일 지휘 · 무한 재보급 · 명분 우위 — 이 셋이다.

### 5.2 무림의 전력

```text
무림 전투력 = Σ(참여 martial) × terrain_hold × unit_quality

terrain_hold    본산·산문·수채 2.0  /  세력권 내 1.5  /  평지 원정 1.0
                ★ 무림은 지역을 사실상 점거하고 있다. 나가면 이 배수를 잃는다
unit_quality    2.0
                ★ 구성원 대다수가 무력 행사 가능. 관군은 열에 하나가 정병이다
reinforcement   0.0
                ★★ 결정적 비대칭 — 무림은 보충되지 않는다. 죽으면 그만큼 줄어든다
```

### 5.3 승리 조건이 비대칭이다 — 여기가 심장

7일 = 1라운드.

| | 관 war_cost | 무림 명분 소모 | 무림 martial |
|---|---|---|---|
| 무림 승리 라운드 | **+6** | **−2** | −3% |
| 관 승리 라운드 | +3 | **−3** | −10% |

- 관은 **라운드마다 병력이 100% 회복된다.** 국가니까. 다만 `war_cost`는 누적된다.
- 무림은 **회복되지 않는다.** martial이 초기의 50% 미만이면 이탈 연쇄(명분 추가 −5/라운드).
- 무림이 **이겨도 명분이 준다** — "이제 됐다, 물러나자"는 목소리가 커진다.
- 무림이 **지면 더 준다** — "왜 남의 일에 우리 제자가 죽나."

```text
무림의 승리 = 관의 war_cost >= 60 (국력·정치 임계)
              → 조정이 계산을 접는다 → 관이 물러서거나 그 관리를 버린다
              ※ 전멸시킬 필요가 없다. 물러서게만 하면 된다

관의 승리   = 무림 명분 = 0 → 연합 해산 → 각개격파
              (관이 원정력을 한 문파에 집중 → 단독 문파는 필패)

★ 명분의 감쇠 vs war_cost 의 누적 — 이 경주가 관무불가침의 전부다
```

### 5.4 균형점: **명분 20 · 참여 6**

**검산 A — 무림 승리** (명분 30 / 참여 10 / martial 70)
```text
본산 전투력 = 70 × 2.0 × 2.0 = 280  ≫  관 원정 7.5   → 매 라운드 무림 승리
관 war_cost = +6/라운드 → 10라운드(70일)에 60 도달  → 관 후퇴
무림 명분   = 30 − 2×10 = 10        → 아직 살아 있다
⇒ 무림 승리 (관이 꼬리를 자른다)
```

**검산 B — 관 승리** (명분 18 / 참여 5 / martial 35)
```text
참여 5   = 관이 원정력을 각개 집중할 수 있다 → 관 승리 라운드가 섞인다 (war_cost +3만 쌓임)
무림 명분 = 18, 라운드당 −2~−3 → 7~9라운드에 0
관 war_cost ≈ 35 < 60             → 관은 물러서지 않는다
⇒ 관 승리 (연합 해산 → 각개격파)
```

| 조건 | 결과 |
|---|---|
| **명분 ≥ 20 AND 참여 ≥ 6** | 무림 승리 경로. **관은 이 상태를 만들지 않는 데 전력을 쓴다** |
| 명분 ≥ 26 AND 참여 ≥ 10 | 관이 물러서도 연합이 안 멈춘다 → 황실 총력전(21) → **양패구상. 왕조가 흔들린다** |
| 명분 < 20 | 관 승리. 그래서 관은 명분을 20 아래로 관리하는 데에만 힘을 쓴다 |
| 법명분 ≥ 15 | 역방향 — 관이 쳐도 무림이 연합하지 않는다 (6장) |

### 5.5 왜 무림이 먼저 못 치는가

1. 명분 없이 관을 치면 **명분 게이지가 생기지 않는다** → 연합이 성립하지 않는다.
2. 단독 문파(5~10) × 평지 원정 1.0 × 2.0 = 10~20 vs 관 총력 21 → **진다.** 게다가 본산이 비어 있다.
3. 관은 반드시 반격한다(법명분). 그리고 **무림 전체가 그 문파를 버린다.**

> **무림의 선빵은 자멸이다. 그래서 아무도 하지 않는다.**

### 5.6 왜 관이 먼저 못 치는가

1. 선빵 = **명분 입력이다.** 문파 토벌 +10, 존망 태그 → 전 무림 임계 −10.
2. 문파 하나를 치면 명분 10~14 (인접·동맹 3~5 세력 즉시 참여). 아직 20 미만 —
   **여기서 멈추면**(그 장수 처형 −6) 진화된다.
3. **두 번째를 치면 명분 20 돌파 → 참여 6 이상 → 관 패배 경로 확정.**

> **그래서 관은 절대 두 번째를 치지 않는다. 관무불가침의 실체는 이 한 줄이다.**
>
> 관이 무림을 이기는 유일한 길 — **무림이 먼저 명분을 잃게 만드는 것.**
> 즉, 무림의 선빵을 유도하는 것. (그리고 이것이 마교가 하는 짓이다.)

## 6. 법명분(法名分) — 관 측의 게이지

관은 '의(義)'가 아니라 **'법(法)'**으로 움직인다. 대상은 개인 또는 문파. 스케일 0~30.

| 입력 | 값 |
|---|---|
| 반란 선언 | **30** (즉시 칙명 — 방어 부담 해제) |
| 상급관리 살해 | 20 |
| **현령 살해** | **14** ← `npc_death.yml jomunwon.escalation` 접합 |
| 관군 부대 습격 | 12 |
| 관아 방화·파옥 | 10 |
| **포두 살해** | **8** ← `bakho`. 절연 문턱(10) 직전 — 한 번 더 하면 끝이다 |
| 조세 강탈 | 6 |
| 무장 집단 이동 무신고 | 3 |

| 감쇠 | 값 |
|---|---|
| **무림 자체 처벌** | **−12** ★ 강호가 먼저 그를 쳤다 → 관은 더 칠 명분이 없다 |
| 자수 | −10 (`npc_death.responses.자수`) |
| 배상 | −6 (`npc_death.responses.배상`) |
| 진범 규명 | 전량 소멸 |

| 구간 | 효과 |
|---|---|
| 0~9 | 지역 수배 (기존 `official_response.수배` 그대로) |
| **10~14** | **강호의 절연(murim_disavowal) 발동** |
| 15~24 | 관이 대상 문파를 토벌해도 **무림이 연합하지 않는다** — "그놈이 잘못했다" |
| 25+ | 무림이 관에 협조한다. **강호가 먼저 그를 친다** (관에 빌미를 주지 않으려고) |

### 6.1 overreach — 관의 유일한 실수 지점

관이 대상을 넘어 확대하면(연좌·인접 문파 검속·무림 일제 단속) → **무림 명분 +8(무림침해·존망) 신규 발생**
→ 억지 복원. 법명분은 그대로 남는다.

**이겼다고 밀어붙이면 다시 명분을 준다.** 관이 늘 절제하는 이유다.

### 6.2 강호의 절연 (murim_disavowal)

> **발동**: 법명분 ≥ 10 AND 무림 명분 < 8
> **논리**: 명분이 없으니 연합이 생기지 않는다. 대신 **강호가 먼저 그를 친다** — 관에게 빌미를 주지 않으려고.

```text
정파 주목  score +6      → 3단계(접촉/경고) 이상으로 직행
정파 우호  favor −8      → 공신 이력의 floor(8)조차 무너진다 (favor 규칙의 유일한 예외)
사파 우호  favor −4      → 사파도 반기지 않는다. 관이 무림 전체를 훑으면 사파가 먼저 죽는다
비호 정지                → favor 공신(13)의 '세력 비호 1회' 사용 불가 —
                           어느 문파도 관 앞에서 그를 감싸지 않는다
토벌 명분                → npc_death.yml revenge.faction_proxy.orthodox = 토벌_명분 발동 (기존 규칙 재사용)
현상금  ×2               → economy.yml 고수_현상금 50000 → 100000. 무림 세력도 이 방을 붙인다
입문 차단                → faction_entry_routes 전 루트 게이트 폐쇄. **마교 루트만 열린다**
```

**해제**: 자수(−10) / 배상(−6) / 진범 규명(전량 + 명분이 진범에게 이전).

> 무림이 그를 버리는 것은 냉혹함이 아니라 **생존이다.**
> 한 사람 때문에 관무전쟁을 할 수는 없다.

## 7. 파열 시나리오

### 7.1 관이 선빵 — 그리고 대개는 꼬리를 자른다

```text
1단계 [지역]   관리의 사적 폭거, 백성 살해            명분 +6 (무고)
               → 개방(임계 8, 태그 −3 → 실질 5)만 반응. 참여 1 = 규탄
               ★ 관이 그 관리를 처형하면 −6 → 명분 0. 끝난다. 관은 거의 언제나 이 선택을 한다

2단계 [확대]   덮으려다 발각(+4) → 항의한 문파의 제자 살해(+7)
               명분 17. 인접·피해 당사자 3~5 세력 → 소연합 (지역권)
               ★ 배상(−4) + 장수 처형(−6) → 명분 7 → 대부분 이탈. 여전히 수습 가능

3단계 [파열]   관이 그 문파를 토벌 — 멸문 (+10, 존망)
               명분 27. 존망 → 전 무림 임계 −10 → 참여 8~12 (사파 포함) → 무림공적 선포
               war_model 가동 → 관 war_cost 60 도달 → 황제가 그 관리와 그 군을 버린다
               대가: 관 = 국력·정통성 손상 / 무림 = 문파 하나가 사라졌다. 연합은 이기고 흩어진다

4단계 [불가역] 관이 멈추지 못한다 — 잠식된 관. 그 관리가 곧 조정이다
               명분 26+ · 참여 10+ → 황실 총력전(21) → 양패구상
               왕조가 흔들리고 무림의 절반이 죽는다. ★ 마교가 웃는다
```

**플레이어의 자리**
- **불씨**: 폭거의 유일한 생존 목격자. 증언을 **어느 소문망에 넣느냐**가 누가 먼저 아는가를 정한다
  (개방망 1일 / 정파망 3일).
- **증거**: 은폐 문서 확보 → 정확도 80+ → 명분 배수 ×0.5에서 ×1.0으로 (명분이 두 배가 된다).
- **소화**: 관의 의뢰를 받아 그 관리를 잡아 온다 (꼬리 자르기 −6의 실행자). 무림은 그를 **관의 개**로 본다.
- **방화**: 위조 증거 → 거짓 명분. **발각되면 자신이 명분의 대상이 된다.**

### 7.2 무림이 선빵 — 강호가 먼저 그를 친다

```text
1 행위   플레이어가 포두(박호)를 죽인다 → 법명분 +8. 현령(조문원)이면 +14
2 인지   npc_death.yml killer_response 3변수(목격·시신·증거) 그대로 → 지목/공개 단계
3 명분   무림 명분 = 0. 관이 잘못한 게 없다 → 연합의 방아쇠가 당겨지지 않는다
4 절연   법명분 ≥ 10 → murim_disavowal → 주목 +6 / 우호 −8 / 비호 정지 / 현상금 ×2
5 추격   faction_proxy.orthodox(토벌_명분) + gwan_gun(포교_수배) 동시 가동
         → ★ 정파 토벌대가 관보다 먼저 온다. 관에게 무림을 칠 구실을 주지 않으려고
6 출구   자수(−10) / 배상(−6) / 진범 규명(전량) / 도주 → 마교 루트만 남는다
```

**문파 단위 폭거였다면**: 법명분 15+ → 관이 그 문파를 토벌해도 **아무도 안 붙는다** → 멸문.
단 관이 **연좌로 확대하면**(overreach) 명분 +8 → 억지 복원 → **반전**.

**플레이어의 자리**
- **당사자**: 이 시나리오의 주인공은 대개 플레이어다. 관을 건드리는 순간 세계 전체가 등을 돌린다.
- **누명**: 4~5단계를 남이 뒤집어씌울 수 있다 (소문 정확도 30~49 오해 밴드) → **진범 규명이 유일한 문.**
- **구명**: 남을 위해 진실을 밝힌다 (favor 공적_대 +4, 관 favor +).

### 7.3 마교의 이간 — 가장 좋은 이야기

> **마교는 관도 무림도 이길 수 없다. 그러나 둘이 싸우게 만들 수는 있다.**

| 벡터 | 수법 | 기계 |
|---|---|---|
| **관 사칭** | 관군 복색으로 문파를 친다 | 명분 +7~10이 **`gwan_gun`에게** 붙는다 (오해 밴드 `target_swap`) |
| | | **관은 결백하다 → 꼬리 자를 관리가 없다 → drains를 쓸 수 없다 → 명분이 안 꺼진다** |
| | | 명분이 20을 향해 자란다. 관은 영문도 모른 채 연합의 표적이 된다 |
| **무림 사칭** | 무림 복색으로 관아를 친다 | 법명분 +10~14가 **엉뚱한 문파에게** 붙는다 |
| | | → 절연 발동 → 무림이 자기 문파를 버린다 → 관이 그 문파를 친다 → **무림 명분 발생 → 연쇄** |
| **관 잠식** | 관리 **자체가 된다** (사람을 바꾸는 게 아니라 사람을 얻는다) | 토벌 명령이 실제로 관에서 나온다 → 7.1의 4단계(불가역)로 직행 |
| | 흔적: 심마 잔재·금기 마공 (혜각·야철수 감정 훅, `npc_death cause_modifier.자멸_심마`) | 대응: **관과 금기세력의 결탁 증거(+9)** → 명분 대상이 `gwan_gun` → `magyo`로 **이전** → 관무 공동 토벌 |

**해소 게이트**: 정확도 **80+ (사실적 밴드)** 증거를 **양쪽 조직 채널 모두에** 도달시킬 것.
- **성공** → `진범_규명 = transfer` → 명분 전량이 마교로 이전. 관+무림 임계 −10(존망·금기) → **사상 최대 연합.**
- **실패** → 관무전쟁 → 양쪽 소모 → **마교가 빈 자리를 먹는다** (치안·경제 붕괴 → 침식 가속).

**플레이어의 자리**
- 유일한 목격자가 플레이어인 구조가 **기본형**이다 — **진실은 아무도 믿지 않는다** (정확도가 낮으므로).
- 증거 3종: 시신의 마공 흔적 / 위조 관인 / 마교 접선자의 증언 — 정확도를 50 → 70 → 90으로 올린다.
- **채널 선택**: 개방(1일, −5)에 넣을 것인가, 관청(2일, −10)에 넣을 것인가 — **먼저 믿는 쪽이 이긴다.**
- **가담**: 알고도 침묵하거나 돕는다 → 마교 루트 누적 상태.

### 7.4 사파의 존망 — 정파는 붙지 않는다

관이 사파를 일제 토벌한다(법명분 충분 — 조세 강탈·통행세). **정파는 붙지 않는다** — 명분 태그가
맞지 않는다(무고 아님, 사파는 실제로 죄가 있다). 오히려 협조한다.
사파 5개는 존망 태그(−10)로 처음 뭉치지만 martial 28 — 지역별 방어전, 지원 없음.

**반전**: 관이 '무림 일제 검속'으로 확대하면(overreach) → 무림 명분 +8(존망) → **정파도 붙는다** → 억지 복원.
사파 루트 플레이어의 존망 사건이다: **정파에게 명분을 만들어 줄 수 있는가** (관의 무고한 살해를 증명).

### 7.5 연합의 붕괴 — 이겨도 흩어진다

연합이 이겼다. 관이 물러났다. **이제 무엇을 나누는가.**
목적 달성(−6~−10) + 이익 충돌(−3, relation −1 **영구**) + 맹주 다툼(−2/주) → 3주 후 분열.
화산-종남, 남궁-팽가의 앙금이 여기서 **깊어진다**.

> 이 시나리오가 왜 무림에 상설 지휘부가 없는지를 **매번 다시 증명한다.**

## 8. 기존 config 접합 — 그리고 제안하는 수정

이 설계는 **새 배선이 아니라 기존 배선 위의 층**이다.

```text
faction_reaction  주목(score)·우호(favor) = 세력 대 개인   │  명분·연합 = 세력 대 세력
                  두 층은 곱해진다:
                  · 연합 참여 세력은 그 사안 대상의 주목을 +2/라운드 (전시 = 온 조직이 찾는다)
                  · 연합 기여자는 참여 세력 **전체**에 favor +2 — 연합이 곧 인맥이다
                  · murim_disavowal 은 favor 의 floor_after_공신(8)을 무너뜨리는 유일한 예외

rumor             정확도 밴드 = 명분 배수 (오해 밴드 = 이간의 통로)
                  연합 성립 = 강도 4(지역권) / 무림공적 = 강도 5(천하)
                  조직 채널 원칙 그대로 → 망별 속도 = 세력별 참전 시차

region_state      연합 전쟁 지역: 주당 {치안 −5, 경제 −4, 민심 −3}, recovery 정지
                  치안 < 30 이 30일 지속 → 마교 침식 가속 (7.3의 토양)

npc_death         현령 살해 → 법명분 +14 → 절연 즉시. 포두 → +8 (문턱 직전)
                  responses(자수·배상·은폐) 가 그대로 법명분 drains — 새 대응 발명 없음
                  faction_proxy.orthodox(토벌_명분) 이 절연의 실행 주체

chapter_events    장(章) 사건이 명분 입력의 발생원. 연합 성립(참여 6+) = 지역권 장 승격 조건
economy           현상금·배상액 그대로. 절연 시 ×2
entry_routes      연합 참여 = favor 대량 획득 경로 / 절연 = 전 루트 폐쇄, 마교만 남는다
```

## 9. 관측 가능성 — 플레이어는 수치를 보지 않는다

```text
명분  1~ 7   객잔에서 사람들이 화를 낸다. 개방 거지가 먼저 안다
명분  8~14   문파의 사자(使者)가 오간다. 의뢰소에 '조사' 의뢰가 붙는다
명분 15~19   무림첩(武林帖)이 돈다. 각 문파의 답신이 소문이 된다 — 누가 붙고 누가 빠졌는가
명분 20~25   산문이 닫힌다. 제자들이 하산한다. 관아가 성문을 잠근다
명분 26~30   천하에 방(榜)이 붙는다. 이제 물러설 자리가 없다

법명분       수배 → 현상금 → 방(榜) → 어제까지 밥을 먹던 객잔이 문을 잠근다
```

## 10. 남은 과제

- **연합 전투의 상세 해결**: 라운드 단위 추상화까지만 했다. 개별 전장(공성·산문 방어·수로전)의
  판정은 `combat_system.md` 확장 시 접합.
- **관의 하위 조직**: 포두·현령 위의 계층(부·성·조정)은 세계 지도 담당의 `world_map.yml` 범위.
  이 문서는 `gwan_gun` / `hyeollyeong` 두 등록 id + 추상 수치(황실 정규군 300)로만 다룬다.
- **명분의 다중 사안**: 동시에 두 개의 명분이 서로 다른 대상을 겨눌 때의 세력 배분(한 문파가 양쪽에
  붙을 수 있는가) — 첫 파열 사건 실플레이 후 결정.
- **마교의 침식 게이지**: 7.3의 '관 잠식'은 여기서 결과만 정의했다. 침식의 누적 규칙은
  금기 계열 설계와 함께.
