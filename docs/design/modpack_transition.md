## 1. 이 결정이 바꾸는 것과 안 바꾸는 것

### 안 바뀌는 것 (중요 — 지금까지의 자산은 전부 산다)
- **서버는 Paper 1.21.11 그대로.** 한월도 같은 구조다: 서버는 플러그인 서버, 모드는 전부
  **클라이언트 사이드**(한월 목록 18종 전원 클라 모드). 증명: Emotecraft 는 Paper 플러그인이
  Fabric/Forge 클라 모드와 plugin message 로 동기화한다 — 우리도 같은 다리를 쓴다.
- 플러그인 전부 (판정·조성·검기·경제) · PostgreSQL · 봇 · 리소스팩 (모드팩과 병행 배급).
- 헌법의 판정 축 (격 사다리 · 몸짓이 곧 선택 · 화면=판정).

### 바뀌는 것
- **접속 클라이언트**: 바닐라 → **Fabric 1.21.11 + 필수 모드팩** (팩 게이트 → 모드팩 게이트로
  헌법 개정 — 2026-07-13 팩 게이트 개정의 상위 확장).
- 클라가 그릴 수 있는 것의 상한: 모션 · 진짜 UI · 셰이더 무드 · 미니맵.
- ★ **게이트 기술이 다르다**: 리소스팩은 서버가 수락/거절을 **직접 본다**(45초 퇴장 코드).
  모드는 서버가 못 본다 — **커스텀 채널 핸드셰이크**(우리 클라 모드가 접속 시 신원 패킷)로
  게이트해야 한다. 한월의 자체 모드(CD/WB/F3B)가 아마 이 역할을 겸한다.

## 3. 로드맵 — 세 단계 (앞 단계가 뒤를 막지 않는다)

### Phase 1 · 기성 모드팩 (개발 0 — 조립·배포·게이트만)
**얻는 것**: 셰이더 무드(등롱·역광) · 미니맵+좌표 · 이모트 · 매끈한 폰트 · 줌.
- 팩 구성(핀 고정): Fabric Loader + Fabric API · Sodium · Iris(+셰이더 프리셋 동봉) ·
  Xaero's Minimap/WorldMap · Emotecraft(클라) · Player Animation Library(Phase 2 선탑재) ·
  Caxton(또는 폰트팩) · WI Zoom · WaveyCapes(선택)
- 서버: Emotecraft Paper 플러그인 탑재.
- 배포: **Modrinth 모드팩(.mrpack)** — Modrinth App/Prism 에서 원클릭 설치. 디스코드 안내판에 설치 버튼.
- 이 단계에선 게이트 없음(겸용 허용) — 게이트는 자체 모드가 생기는 Phase 2 부터 가능.

### Phase 2 · 모션 (첫 자체 개발 — 작게)
**얻는 것**: 공격 모션·발도 자세·경공 몸짓 — "모션이 없어 획이 대역"이던 구조의 해소.
- 경로 A(먼저 평가): ZigysPlayerAnimatorAPI 서버 트리거 — 되면 개발량 최소.
- 경로 B: 자체 클라 모드 1호 — plugin message 수신 → PAL 재생 + **접속 핸드셰이크(게이트)** 겸장.
- 모션 제작: Blockbench 키프레임(JSON) — 검·도 스윙부터 (시트판 획과 합류: 모션+획+타격 피드백).
- 이때부터 **모드팩 게이트** 발동 가능 (핸드셰이크 없으면 한국어 안내 후 퇴장 — 팩 게이트와 같은 문법).

### Phase 3 · UI (가장 크다 — 마지막)
**얻는 것**: HUD(레벨·HP·재화·퀘스트 트래커) · 게임메뉴 · 장비/스탯창.
- 기술 선택: MCEF Modern(HTML — 무겁지만 자유) vs 순수 Fabric Screen API(가볍지만 손이 많다).
- 서버↔클라 데이터 채널 설계(스탯·퀘스트·재화 동기화)가 본체다. UI 는 그 위의 껍질.

## 4. 지금 당장 필요한 것 (Phase 1 착수 조건)

1. **개발 환경**: Prism Launcher 인스턴스 (Fabric 1.21.11) — 모드팩 로컬 조립·시험.
   촬영 하네스(kigibot 등)는 바닐라 프로토콜이라 그대로 접속 가능 (겸용 기간엔 문제 없음).
2. **모드 핀 목록 확정**: 위 Phase 1 목록의 정확한 버전 고정 (Modrinth에서 1.21.11 빌드 수집).
3. **Emotecraft Paper 플러그인** 서버 탑재 + 모드 클라로 실측.
4. **Modrinth 계정/프로젝트** (모드팩 배포처) — 또는 mrpack 파일 직접 배포로 시작.
5. **셰이더 프리셋 결정**: 어떤 셰이더를 동봉하나 (수묵 무협 무드에 맞는 것 — 사용자 눈 필요).

## 6. 기존 트랙과의 관계

- **시트판 검기**: 유지. Phase 2 에서 모션과 합류(모션이 몸을, 획이 궤적을). 한월 실측이
  보여준 격차는 획이 아니라 **타격 피드백**이었다 — 대미지 숫자·표적 HP바·타격 다겹(A2~A4)은
  모드 없이 지금 가능하므로 모드팩과 병행 진행 가능.
- **BetterModel 테섭 트랙(RP-4)**: BetterModel 은 서버 플러그인(디스플레이 엔티티) — 모드팩과
  독립적으로 유효. 클라 모드 시대엔 진짜 모델 모드로 승격할 수도 있으나 지금 결정 불요.
- **cultivation v3 레벨**: Phase 3 HUD 의 데이터원 — 순서상 서버 구현(B-137→B-135)이 먼저여도 맞다.
