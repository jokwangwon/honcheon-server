# 검기 재설계 v2 — 파티클 띠 (2026-07-21 · ★기본 검술 확정)

> 판(ItemDisplay 평면) 세대의 실패 후 백지 재설계. **임의 결정 금지** — 모든 수치는
> 사용자 결정 또는 레퍼런스 실측에서 온다. 구현은 이 설계의 사용자 승인 뒤에 시작한다.

## 0. 확정된 결정 (사용자 · 2026-07-21)

1. **일반 무기의 검기 = 파티클 방식** ("이런 것처럼 파티클 방식으로 고정" — 야마토 영상)
2. **매체는 교체 가능한 구조로** — 보스몹·특수 무기가 필요해지면 그 효과만 다른 매체
   (디스플레이·3D 모델)로 갈아탈 수 있게. 판 경로 코드는 지우지 않고 매체 선택지로 남긴다.
3. 검증은 **인게임 움직임(GIF)으로만** — 정지컷 최적화가 판 세대 실패의 원인이었다.

## 1. 왜 판이 실패했는가 (기록)

평면 판은 각도가 틀어지면 면→선으로 붕괴한다 (두께 0.04m 평면의 기하학적 본질).
텍스처를 3세대(삼합→톱니→검압) 갈아도 이 문제는 텍스처 밖에 있었다. 파티클은 점 하나하나가
스스로 카메라를 보므로 **어느 각도에서든 형태가 유지된다** — 근본 해결.

## 2. 레퍼런스 실측 — 「매직스펠 야마토」 (BlueberryMango · 30fps 프레임 분해)

| 항목 | 실측값 |
|---|---|
| 형태 | 폭 0.5~0.8m의 **파티클 띠(리본)**가 스윙 호를 따라 몸을 감는다 — 평면이 아니라 두께 있는 밴드 |
| 밀도 | 그레인이 보일 정도로 촘촘 (수백 점) — 몸은 짙은 채도, 흰 별 액센트가 성기게 섞임 |
| 시간 | 스윕 ~200ms(≈4틱) 급상승 → **잔류 먼지가 ~1초(≈20틱)에 걸쳐 흩어지며 소멸** |
| 리듬 | 「그렸다 지운다」가 아니라 「빠르게 긋고, 먼지로 남는다」 — 파티클 매체의 자연 리듬 |
| 각도 | 원·나선 띠가 몸을 감아 앞/뒤/옆 어디서든 입체로 읽힌다 |

기법: MagicSpells 의 파티클 연출 = EffectLib — **우리가 이미 통합해 둔 라이브러리** (QiGeometry).
이전 "티끌" 실패는 단선(1줄) + 저밀도 탓 — 띠(다열·두께·밀도)가 핵심 차이다.

## 3. 혼천 이식 설계

### 3-1. 단면 — 명암 샌드위치를 파티클로 번역 (등록부 색만)

```
   먹 dust (가장자리 소량 · 밝은 하늘 가독)     ← 폭 방향 바깥
   청회 dust 3~4줄 (몸 — 짙고 촘촘)             ← 몸체
   청백 dust 1줄 (서슬 — 날 쪽 가장자리)         ← 날
   흰 액센트 (end_rod 성기게, 머리 쪽 집중)      ← 별
```
- 폭 0.5~0.7m (레퍼런스 실측 대역) · 두께 지터 ±0.1m (그레인 입체감)
- 검압 실루엣 계승: 꼬리 가늘게 → 머리 굵게 (폭·밀도를 t 에 따라 스케일)

### 3-2. 시간 — 검끝을 따라 긋는다

- **스윕 3~4틱**: 호를 머리부터 꼬리 순으로 채운다 — 검이 지나간 궤적이 실시간으로 그려진다
  (판 세대에서 불가능했던 "스윙과의 인과"가 매체 특성으로 공짜로 생긴다)
- **잔류 12~18틱**: dust 파티클 자체 수명으로 흩어지며 소멸 (엔진이 지울 필요 없음)
- 연타: 이전 띠가 먼지로 옅어진 위에 새 띠 — 누적이 아니라 잔향

### 3-3. 예산 (기존 게이트 안에서)

- 목표: 스윙당 250~350 파티클 (밴드 호 길이 ~5m × 0.10~0.12m 간격 × 4~5줄 + 액센트)
- SkillHud.emit 경유 (기존 예산·관람자·LOD 게이트 그대로) — QiGeometry 가 이미 이 길을 쓴다
- 실측으로 20인 동시 스윙 부하를 잰다 (검토 P1 항목 승계)

### 3-4. 구현 자리

- `kigiGeomArc` (SkillDisplay → QiGeometry) 확장: 현행 단선 호 → **다열 밴드 + 스윕 타이밍 + 단면 색상**
- 판(plate)·모델(model3d) 경로는 **끄되 남긴다** — 매체 선택지 (결정 0-2)
- config: `kigi_slash.medium: particle | plate | model3d` 축 신설 — 보스·특수 무기의 교체 지점

### 3-5. 명중/빗나감 (다음 회차 — 검토 합의 승계)

- 빗나감: 띠가 먼지로 소멸 (깨끗)
- 명중: 명중점에서 법선 방향 파티클 버스트 + 충돌음 — 히트 배선과 함께

## 4. 검증 계획

- 인게임 GIF: 뒤 / 45도 측면 / 정면 3각도 × 밝은 하늘 / 밤 — **각도 붕괴가 없는지가 1번 기준**
- 밀도·폭·색 배합은 실측 GIF를 보고 사용자가 고른다 (2~3 대조군)
