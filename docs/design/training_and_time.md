# 수련과 시간 — 자동으로 흐르는 세계에서의 압축 성장

> 문제: 멀티플레이 특성상 한 명이 시간의 흐름을 통제할 수 없다.
> 시간은 자동으로 흐르고, 행위는 그 시간에 맞춰 결정되어야 한다.
> 그렇다면 "3년 수련 후 강해져 나온다"는 무협의 핵심 서사(압축 성장)를 어떻게 넣는가?
>
> 해법: **시간을 건너뛰는 것은 세계가 아니라 플레이어다.**
> 캐릭터는 세계의 시간을 온전히 산다(수련 상태). 플레이어가 그 구간을 살지 않을 뿐이다.
> 오프라인·수련 상태 = "그로부터 삼 년 후" 몽타주.
>
> 이 문서는 F7(압축 성장 환산표)의 해결 문서이기도 하다.
> 기계 판독용: `config/training.yml`

---

## 1. 원칙 — 플레이어는 사건의 시간을 산다

```text
세계 시간:   서버가 굴린다. 누구도 감거나 멈출 수 없다.
사건의 시간: 플레이어가 접속해 실제로 플레이하는 밀도 높은 시간.
수련의 시간: 캐릭터가 세계 안에서 보내지만 플레이어는 살지 않는 시간
            — 수련 상태 선언 후 로그아웃/방치. 성장은 세계 시간에 비례해 적립된다.
```

솔로 텍스트 RPG의 "장 도약"과 MMO의 "수련 상태"는 **같은 환산표의 두 인터페이스**다:
텍스트에서는 GM이 도약을 선언하고, MMO에서는 세계 달력이 흐르는 동안 자리를 비운다.

## 2. 세계 달력 — 자동 시간의 배율

```text
서버 시간 배율 (조정 가능 파라미터): 현실 1일 = 게임 15일 (권장 초기값)
  → 현실 1개월 ≈ 게임 1년 3개월
  → 현실 1년 플레이 ≈ 게임 15년 (13세 소년이 20대 후반의 고수가 되는 궤적)
나이·계절·세계 공통 이벤트(비무대회, 세력전)가 전부 이 달력에 자동 연동.
데드라인 사건도 달력에 예약된다 — 모두에게 같은 시각. 놓친 자는 소문으로 접한다.
```

## 3. 수련 상태 — 압축 성장의 그릇

플레이어는 수련을 **선언**하고 자리를 비운다. 선언에는 방식·장소·목표 기술이 들어간다.

| 방식 | 효율 | 조건 | 위험 |
|------|------|------|------|
| 생활 노동 | 0.2 | 없음 (일하며 몸이 익는다) | 없음. 돈이 나온다 |
| 독학 | 0.5 | 비급 또는 어깨너머 경험 | 심법 독학 시 주화입마 이벤트 확률 |
| 사사(스승) | 1.0 | 스승의 해당 기술이 자신보다 높을 것 | 스승과의 관계·은원 상속 |
| 문파 정규 수련 | 1.2 | 문파 소속 | 문파 잡무·규율 이벤트 |
| 폐관 수련 | 1.5 | 심법 보유 + 폐관 장소 | 최소 기간 커밋, 중단 시 성과 반감. **장소 안전도** |

추가 보정: **유년·소년 ×1.5** (어린 몸에 스며든다), 스승 경지가 2단계 이상 높으면 ×1.2.

## 4. 환산표 (F7 해결) — 수련량 → 숙련

기술 숙련 단계별 필요 수련량 (효율 1.0, 게임 시간 기준):

```text
0→1: 3개월    1→2: 6개월    2→3: 1년    3→4: 2년    4→5: 4년    5→6: 8년
(배증 구조 — 이후 단계는 수련만으로 도달 불가: 실전·깨달음·경지 돌파 필요)

능력치 +1 = 해당 능력치 집중 단련 1년 (경지·나이 상한 내에서만)
내공 성장 = 심법 보유 시에만, 심법 등급이 연간 성장량을 정한다
```

병목 규칙 (수련만으로는 고수가 못 되는 이유):

```text
- 경지 상한: 숙련·능력치는 현재 경지의 상한까지만 적립 (초과분 소멸 아닌 대기 없음 — 상한에서 멈춤)
- 실전 요구: 경지 승급 조건의 '실전 경험·깨달음'은 수련 상태로 채울 수 없다
- 수확 체감: 같은 기술 연속 수련 게임 1년 초과 시 효율 -25%씩 (몸이 아니라 벽이 문제)
```

**검증 — PT-002 소급 계산**: 소년(×1.5) 사사(×1.0) 2년 = 유효 36개월
→ 검법 0→1(3) + 1→2(6) + 2→3(12) = 21개월 소모, 잔여 15개월은 3→4(24개월)에 미달
→ **검법 3, 삼류 승급** — PT-002에서 재량으로 준 "검법 2"보다 후하지만 동일 궤도.
이 표가 이제 정본이다 (재량 폐지).

## 5. 수련 중에도 세계는 흐른다 — 위험과 귀환

수련 상태는 무적이 아니다. 세계 반응 루프는 계속 돈다:

```text
장소 안전도:
  문파 내부/관아 보호     안전 — 개입 불가
  민가·객잔              소문에 노출 ("그 낭인, 요즘 두문불출이라더군")
  야산 동굴·폐가          사건 발생 가능 — 원수·세력 반응 5단계(직접 개입)가
                         수련 중인 캐릭터를 찾아올 수 있다 (습격 이벤트로 적립)
```

**귀환 리포트**: 접속(장 재개) 시 두 가지를 받는다 —
① 수련 성과 정산, ② 부재 기간의 세계 변화 다이제스트(도달한 소문들, 지역 상태 변화, 자신에 대한 세력 반응 진행). *"그로부터 삼 년 후"의 몽타주가 로그인 화면이 된다.*

전략적 의미: 자리를 비우는 것 자체가 선택이다. 사파의 추적이 식기를 기다리는 폐관 3년 — 그 사이 원수도 강해지고, 혈교도 자란다. (세력 감쇠 vs 세계 위협 성장의 트레이드오프)

## 6. 두 매체의 통합 — 같은 표, 다른 인터페이스

```text
텍스트 RPG (솔로):  장 종결 → GM이 도약 제안 → 이 환산표로 정산 (v2 장 도약 규칙 유지,
                   단 성장량 산정은 재량이 아니라 4장 표를 따른다)
MC/MMO:           수련 선언 → 로그아웃/방치 → 세계 달력이 흐름 → 접속 시 정산
                   (프롤로그 인스턴스의 '수련 몽타주'도 같은 표로 계산)
```

동일 원칙, 동일 수치 — 텍스트에서 밸런스를 검증하면 MMO에 그대로 이식된다.

## 7. 남는 과제

```text
- 서버 배율의 실측 튜닝 (현실 1일=게임 15일은 초기 가설 — 시즌 길이와 함께 조정)
- 폐관 중 습격 이벤트의 상세 (오프라인 방어를 어떻게 처리할 것인가 — NPC 약식 전투 활용 예정)
- 문파 단체 수련·쌍수(동반 수련) 등 사회적 수련 형태
```
