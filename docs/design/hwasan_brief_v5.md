## 1.3 본산 단 사슬 세목 — 통합 사슬 5~8 (구역 8·9·10·11)의 캠퍼스 설계

영역 문서가 오기 전의 독법이다. 영역 문서 구역 11이 **정상 = 건축 최소화(전망대·수행대)** 로
확정했으므로 — **ⓑ′: 본전은 본산(구역 8)의 최고 단이다. 정상은 그 위의 자연 봉우리이고,
정상 평탄부(SUMMIT_R)는 수행대·전망대의 것이다.** 따름정리: SUMMIT_R 유도(TF:1043-1047 —
정상에 앉는 원형의 최대 발자국)의 **입력이 장소별이 되어야 한다** — 화산 정상의 최대 발자국은

## 2.5 생성 순서 — 사용자 문서의 두 8단계 ↔ 조성 파이프라인

영역 문서의 8단계(산세→수계→동선→영역→주건축→부속→식생→NPC)가 **바깥 루프**고,
캠퍼스 문서의 8단계(능선→계단→본전→주요→생활→조경→NPC→장식)는 그 5·6단계의
**본산 상세 루프**다 — 두 문서가 한 파이프라인으로 포개진다:

| 영역 문서 단계 | 파이프라인 | 계층 | 기계 (§2.2) |
|---|---|---|---|
| 1. 산세와 능선 | 주봉+능선+협곡 조성 → **원장 커밋** (땅은 한 번만 선다 — TerrainLedger) | 땅 | ① |
| 2. 계곡·절벽·수계 | 협곡 절벽면 + 폭포·개울 | 땅 | ①·② |
| 3. 주 등산로와 보조 동선 | 등산로 노반 (경유점·곁길) — **길이 먼저 나고 건물이 길에 앉는다** (사찰 축선 문법 SectBuilder:82-104 이 선례) | 땅 | ③·④ |
| 4. 영역 구분 | 구역 경계·밀도·식생 사양을 등록부에서 읽어 마스크 확정 | 지도→땅 | ⑥ (배치기의 전반부) |
| 5. 주요 건축물 | 본산 단 사슬 (본전→연무장·수련동 — 캠퍼스 8단계 2~4 상세) + 외문 + 화산촌 핵심 | 건축 | ⑥·⑦·⑧ + terrace |
| 6. 부속 건축물 | 생활 시설·차실·서고·쉼터·다리 (캠퍼스 8단계 5 상세) + 랜드마크 인공물 | 건축 | ⑤·⑦·⑩ |
| 7. 식생과 자연물 | 구역별 식생표 + 자연 랜드마크 (캠퍼스 8단계 6 조경 포함) | 땅 (조성 후) | ⑨·⑩ |
| 8. NPC 및 이벤트 배치 | NPC표 + 세부 장식 (등롱·현판·향로 — seatY 착좌 소품 · 캠퍼스 8단계 7·8) | NPC·건축(소품) | 기존 + lanternPost |

"건축보다 먼저 지형을 생성한다 … 건축은 이미 생성된 지형에 맞춰 배치한다" (영역 문서) —
3계층 헌법(지도→땅→건축)과 같은 결이다. 각 단계 뒤 §2.4 검수. 포석·석등(건축)은
노반(땅) 위에 나중에 얹는다 — 2계층 안전핀(TerrainSeal) 무변.

## 4. 이 문서가 참인지 재는 법

- §1.3·§1.4·§2.2 의 코드 수치는 전부 `file:line` — 대조가 곧 검증이다. **B-146 수리 4파일이
  개정되면 재대조하라** (특히 RB:979 stairs 조건 · RB:1007-1008 UPPER_HALF ·
  TF:1043-1047 SUMMIT_R · TF:891-893 massifR).
- §1.4 는 사칙연산뿐이다 — 아무 표에서나 재검산된다. 최종 눈은 시험 조성 1호의 사람 눈
  (1단계 문서 §4-1: 뜸·박힘 0 · 실플레이 판정) + 검수 축 §2.4.
- §1.5 의 등고선 검산은 t^0.85 프로파일 (TF:1106) 가정이다 — raiseMassif 가 바뀌면 다시 잰다.
- 세 사용자 문서의 원문 인용은 따옴표로 표시했다 — 원문 대조가 곧 검증이다.
- 「후보」가 붙지 않은 수가 근거 없이 있으면 이 문서의 결함이다 — 물어라.
