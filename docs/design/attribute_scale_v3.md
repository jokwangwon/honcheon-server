# 능력치 저울 v3 시안 — 300포인트를 담는 눈금 (B-137)

> **★★ 이 문서의 모든 수치는 「사용자 승인 대상」이다.** 이것은 결정용 시안이다 —
> 승인 전에는 config·코드 한 줄도 바꾸지 않는다 (등록제 §2.1).
> 의존: B-135 (`docs/design/cultivation_v3_levels.md`) · 연관: B-056 (성별 ±1) · B-134 (기술 층)
> 2026-07-15 작성.

## 0. 문제 — 옛 저울이 못 담는 것

옛 눈금 (`config/judgment.yml`):

| 축 | 눈금 | 비고 |
|---|---|---|
| 능력치 | 1~10 (실전 2~7) | ±1 이 등급 한 칸을 밀 확률 1/6~1/4 — **±1 이 유의미한 TRPG 저울** |
| 기술 | 0~10 | B-134 행위 적립의 것 — **이번 재설계 대상이 아니다** |
| 주사위 | 2d6 (평균 7 · 표준편차 2.42) | 분산이 판정을 지배한다 |
| 상황보정 | 캡 ±5 | |

새 세계 (B-135 확정): **매 레벨 3포인트 × Lv100 ≈ 300포인트** (+생성 배분 11).
이것을 옛 눈금에 그대로 부으면 능력치가 주사위를 수십 배 압도한다 — 등급표 6단·정적
난이도·NPC 수치표·auto_resolution 이 전부 무의미해진다. **저울을 다시 짠다.**

### 0.1 새 저울이 지켜야 할 것 (기존 등록부에서 읽은 제약)

1. **판정 공식의 뼈대** — 실행력 = 능력치 + 기술 + 보정 + 2d6 · 저항 = NPC능력치 + NPC기술
   + 경계도 + 의심도 + 상태보정 + 7 (judgment.yml). v3 헌법: *"찍은 능력치는 판정 공식에
   그대로 — 새 공식 없음."*
2. **화후 규칙** (player_creation.yml:183) — *"능력치는 내부 실수로 적립. 판정 가산은
   정수부, 파생치는 실수치."* **원장과 판정치를 가르는 층이 이미 헌법이다.**
3. **등급표 6단이 전부 굴러가야 한다** — 대등 판정에서 대성공 2.8%~치명 2.8% (judgment.yml
   재설계 주석). 쌍륙·뱀눈이 이름으로 박혀 있다.
4. **성별 ±1 은 "느껴지되 결정하지 않는다"** (player_creation.yml:68 — cap 1 · 히든).
5. **장비의 값은 보정이 아니라 생존** (equipment.yml — 등급 보정 전부 0, 애병 +1 만 ·
   판정 보정 총합 캡 2).
6. **파생치가 능력치 실수치를 읽는다** — 내력 풀 = round(내공(내공+1)/2×3)
   (internal_energy.yml:86) · 이속/도약 = 민첩 × 계수 (gyeonggong.yml:82) · 내구 = 10 +
   체력×2 (combat.yml durability). 저울이 바뀌면 이 셋이 연쇄로 흔들린다.
7. **경지별 능력치 캡** (player_creation.yml attribute_cap_by_realm: 범인 3 … 현경 10) —
   격차 폭주를 막는 기존 못. 새 눈금에서도 살아야 한다.

## 1. A안 — 십진 환산층 (원장 ×10 · 판정은 정수부)

**한 줄**: 포인트는 0~100 원장에 쌓이고, 판정은 그 십의 자리만 본다.
기존 화후 규칙("적립은 실수, 판정은 정수부")을 자릿수 하나 내린 것 — **새 층을 짓지 않는다.**

### 눈금 구조
- **원장(raw)**: 능력치별 0~100+ 정수 눈금. 레벨 포인트 1점 = 원장 1눈금.
- **판정치** = floor(원장 / 10). 옛 눈금과 1:1 대응 — **옛 값 X ↔ 원장 10X.**
- **환산 실수치** = 원장 / 10 (소수 유지). 파생치 공식이 읽는 값.

### 주사위
**2d6 유지.** 판정층의 확률 구조가 한 톨도 변하지 않는다.

### 판정 공식 재환산
```
실행력 = floor(능력치_원장/10) + 기술 + 상황보정(캡 ±5) + 2d6
저항   = NPC능력치 + NPC기술 + 경계도 + 의심도 + NPC상태보정 + 7
```
저항 쪽은 **글자 그대로 무변경** — NPC 표는 이미 판정어(1~10)로 적혀 있고, NPC 는 레벨을
먹지 않으므로 원장이 필요 없다. 등급표·정적 난이도·auto_resolution(±8)·재시도(+2)·경지
격차(+2/단)·optional_extreme_dice 전부 무변경.

### 연쇄 환산

| 대상 | 처분 |
|---|---|
| 플레이어 능력치 원장 | **×10** 1회 마이그레이션 (옛 3 → 원장 30) |
| NPC 수치표 (config/npcs/* · 85항목) | **무환산** — 판정어 그대로 |
| 장비 보정 (애병 +1 · 총합 캡 2) | **무환산** (판정층 수치) |
| 성별 ±1 (B-056) | **무환산** — 판정치 산출 뒤 ±1 로 유지 (원장 ±10 상당. 승인은 B-056 별도) |
| 경지 캡 | **×10** (범인 30 · 삼류 40 · … · 화경 90 · 현경 100) |
| 생성 배분 | ×10 (base 10 · 자유 40 · 상한 20) — 총합 논리 동일 |
| 파생치 (내력 풀·이속·내구·경공) | 공식의 "실수치" = **환산 실수치(원장/10)** — 기존 수치 전부 보존, 매 포인트가 파생치를 조금씩 민다 |

### 레벨 1~100 체감 (포인트 전부 유관 능력치, 캡 미접촉 가정)

10원장 = 판정 +1. 체감이 전 구간 **균질하다** (선형).

| 레벨차 | 판정 우위 | 대등 NPC 상대 성공권(마진 ≥ 0) | 대성공(≥ +4) |
|---|---|---|---|
| 0 | +0 | 41.7% | 2.8% |
| 3~4 | +1 | 58.3% | 5.6% |
| 10 | +3 | 83.3% | 27.8% |
| 20 | +6 | ~100% | 72.2% |

레벨차 20 은 판정을 결정해 버리지만, **경지 캡이 먼저 개입한다**: 같은 경지 안에서 특화
능력치의 격차는 캡(예: 일류 60)에서 멈춘다 — 폭주 방지는 새 수치가 아니라 기존 못이 한다.
전축 분산 시 최종장(생성 110 + 300 = 원장 410): 평균 판정 ~5.9/축 — 현행 NPC 표 최상위
(취팔선보 거지 6·5·5)와 같은 하늘에 선다.

### 장단점

| 장점 | 단점 |
|---|---|
| 판정층 완전 불변 — NPC·장비·등급표·난이도 연쇄 환산 **사실상 0건** | 판정 체감은 10포인트 계단 — 찍는 맛이 뭉툭할 수 있다 (파생치가 매 포인트 움직여 상쇄) |
| 기존 화후 규칙의 확장 — 헌법과 정합, 새로 지어내는 층이 없다 | 선형이라 후반 특화 경쟁이 캡 대기줄이 된다 (캡을 친 뒤엔 분산 강제) |
| 침묵하는 실패 표면적 최소 (건드리는 파일이 적다) | 시트에 원장·판정치 두 숫자를 보여야 한다 (UI 결정 필요) |
| 검증 쉬움 — 옛/새 동등 시나리오가 ×10 으로 기계 대조된다 | |

## 2. B안 — 동형 전면 확대 (전 눈금 ×10 직결 + 주사위 2d6×10)

**한 줄**: 환산층을 두지 않고 세계의 모든 수를 10배로 키운다. 능력치 원장이 곧 판정 수치다.
(B-137 원문의 "능력치 수백 눈금 + 주사위 폭 확대"를 곧이곧대로 세운 안.)

### 눈금 구조
- 능력치 0~100+ 정수, **공식에 직결** (환산 없음). 포인트 1점 = 눈금 1.
- 기술·보정·난이도·등급 문턱까지 **전부 ×10** — 저울 전체가 한 자릿수 커진다.

### 주사위
**2d6 을 굴려 ×10 으로 읽는다** (눈금 20~120 · 평균 70 · 표준편차 24.2).
분포의 꼴(쌍륙·뱀눈 포함)이 정확히 보존된다 — ×10 동형이다.

### 판정 공식 재환산
```
실행력 = 능력치(0~100+) + 기술×10 + 상황보정(캡 ±50) + 2d6×10
저항   = NPC능력치×10 + NPC기술×10 + (경계도+의심도+상태보정)×10 + 70
```
등급표: 대성공 ≥ +40 · 성공 ≥ +20 · 아슬 ≥ 0 · 부분 ≥ −30 · 실패 ≥ −50 · 치명 그 밑.
정적 난이도 100/120/140/160/180. auto_resolution ±80. 재시도 +20. 경지 격차 +20/단.

### 연쇄 환산

| 대상 | 처분 |
|---|---|
| 플레이어 능력치 | ×10 |
| **NPC 수치표 85항목** | **×10 전수 개서** (config/npcs/* 전 파일) |
| 장비 (애병 +1 · 캡 2) | ×10 → 애병 +10 · 캡 20 |
| 성별 ±1 | ×10 → **±10** — "느껴지되 결정하지 않는다" 계약상 ±10 이 옛 ±1 과 동일 무게이나, B-056 재승인 필요 |
| 경지 캡·생성 배분 | ×10 |
| 파생치 | 공식 재정박 필요 (내공(내공+1)/2 류의 비선형은 ÷10 보정항을 심어야 옛 값 보존) |

### 레벨 1~100 체감

확률은 **A안과 계단 단위로 동일**하다 (동형 확대). 다른 점 하나: 주사위 눈이 10 단위로
튀므로 마진의 1의 자리는 능력치 우열만이 정한다 — 10포인트 미만의 격차가 **동률
가르기**에서만 드러난다 (예: 원장 +3 우위는 승률을 못 바꾸고, 동점 상쇄만 가른다).

| 레벨차 | 성공권 | 비고 |
|---|---|---|
| 0 / 3 / 10 / 20 | 41.7% / 58.3% / 83.3% / ~100% | A안과 동일 계단 |

### 장단점

| 장점 | 단점 |
|---|---|
| 환산층이 없다 — 원장 = 판정 수치, 자리가 하나뿐 | **실효 확률이 A안과 같다** — 얻는 것 없이 비용만 낸다 |
| 마진 숫자가 커서 성장이 시각적으로 웅장하다 | NPC 85항목 + 등급표 + 난이도 + 보정 + 문서 주석의 수치 감각 전체를 개서 — 침묵하는 실패 표면적 최대 |
| | 2d6×10 이라는 읽기 규칙이 "2d6"이라는 등록부 언어와 어긋난다 (쌍륙=120?) |
| | 비선형 파생 공식(내력 풀)에 보정항을 지어 넣어야 한다 |

※ 주사위를 진짜로 넓히는 변형(예: 10d6, 평균 35·편차 7.9)도 검토했다 — 능력치 직결 시
레벨차 2 에 성공권이 78%, 5 에 97% 로 치솟아 **주사위가 죽는다** (등급표 전면 재설계 없이는
불가). 본선에 올리지 않고 기록만 남긴다.

## 3. C안 — 제곱 환산층 (원장 = 판정치² · 체감 곡선 내장)

**한 줄**: 판정치 = floor(√원장). 옛 값 X ↔ 원장 X². 한 눈금이 갈수록 비싸진다 —
**체감(遞減)이 환산식 자체에 산다.**

### 눈금 구조
- 원장 0~100+/축. 포인트 1점 = 원장 1. 판정치 = floor(√원장).
- 판정 +1 의 값: 3→4 는 7점, 5→6 은 11점, 8→9 는 17점, 9→10 은 19점 (≈6레벨 전액).
- 옛 캡 10 ↔ 원장 100 — **한 축 전액 특화(포인트 100)가 정확히 현경 캡에 닿는다.**

### 주사위
**2d6 유지.** A안과 같이 판정층 확률 구조 불변.

### 판정 공식 재환산
```
실행력 = floor(√능력치_원장) + 기술 + 상황보정(캡 ±5) + 2d6
저항   = 무변경 (NPC 표는 판정어 그대로)
```
등급표·난이도·auto_resolution·경지 격차 등 판정층 전부 무변경 (A안과 동일).

### 연쇄 환산

| 대상 | 처분 |
|---|---|
| 플레이어 능력치 원장 | **제곱** 마이그레이션 (옛 3 → 원장 9) |
| NPC 수치표·장비·성별 ±1 | **무환산** (A안과 동일 — 판정층 유지) |
| 경지 캡 | 제곱 (범인 9 · 삼류 16 · 이류 25 · 일류 36 · 절정 49 · 초절정 64 · 화경 81 · 현경 100) |
| 생성 배분 | 판정 눈금으로 배분 후 제곱 저장 (1→1 · 2→4) |
| 파생치 | 공식의 "실수치" = **√원장** (실수) — 기존 수치 보존 |

### 레벨 1~100 체감 — 초반은 A처럼, 후반은 눌린다

| 구간 | 레벨차 10 (30점 전액) | 성공권 변화 |
|---|---|---|
| 초반 (판정 4 · 원장 16 부근) | 16→46: 판정 +2 | 41.7% → 72.2% |
| 중반 (판정 5 · 원장 25 부근) | 25→55: 판정 +2 | 41.7% → 72.2% |
| 후반 (판정 8 · 원장 64 부근) | 64→94: 판정 +1 | 41.7% → 58.3% |

후반의 레벨차는 압축된다 — **최종장에서도 주사위가 산다** (대등 6단 등급표가 끝까지
굴러간다). 대신 전액 특화 없이는 판정 9~10 에 못 닿는다 (300점 분산 시 평균 원장 43 ≈
판정 6 — 옛 일류 고수의 전신).

### 장단점

| 장점 | 단점 |
|---|---|
| 판정층 무변경 + NPC·장비 무환산 (A안과 동급의 최소 표면적) | **비선형** — "포인트 1점의 값"이 현재치에 따라 다르다. 설명 부담, 찍는 맛 불균질 |
| 체감 곡선이 내장 — 소프트캡 표를 지어낼 필요가 없다 (√ 하나가 전부) | XP 곡선(후반 무겁게)과 겹쳐 **이중 감속** — 후반 판정 +1 에 6레벨 ≈ 130시간+, 정체감 위험 |
| 끝까지 주사위가 산다 — TRPG 저울의 감각 보존 | 옛 값 대응이 제곱이라 마이그레이션·감사가 A보다 한 눈금 어렵다 |
| 특화가 비싸져 빌드가 자연히 넓어진다 (지배 전략 억제) | 경지 캡의 격차 억제와 역할이 겹친다 (못이 둘) |

| 환산 작업량·위험 | **최소** | 최대 | 작음 (제곱 마이그레이션) |

## 5. 권고 — **A안** (승인 대상)

근거 넷:

1. **지어내는 층이 없다.** "적립은 실수, 판정은 정수부"는 이미 이 저장소의 법이다
   (player_creation.yml 화후 규칙). A안은 그 법의 자릿수를 하나 내린 것뿐이다 — v3 의
   *"판정 공식에 그대로, 새 공식 없음"* 과도 글자 그대로 정합한다.
2. **침묵하는 실패의 표면적이 가장 작다.** NPC 85항목·장비·성별·등급표·난이도·auto·재시도
   전부 무환산 — 건드리지 않은 등록부는 거짓말할 기회도 없다. B안은 수백 항목을 손으로
   개서하고도 확률이 A와 같다.
3. **격차 폭주는 새 수치가 아니라 기존 못(경지 캡 ×10)이 막는다.** C안의 √ 압축은 그 못과
   역할이 겹치고, XP 곡선의 후반 감속과 겹쳐 이중 감속이 된다 — 사용자가 고른 "찍어서
   올리는 맛"(B-135 원문)을 후반에 무디게 만든다.
4. **검증이 기계적이다.** 옛/새 동등 시나리오 대조 하네스(B-137 검증 조건)가 ×10 선형이라
   전수 자동 대조 가능 — 제곱·전면 개서보다 눈이 서기 쉽다.

C안은 차선이다 — "최종장에서도 주사위가 사는 TRPG 감각"을 캡보다 세게 지키고 싶다면 C.
B안은 권하지 않는다 (비용 최대 · 실효 이득 없음).

## 6. 사용자에게 묻는 것 (근거가 없어 지어내지 않은 자리)

1. **안의 선택** — A / B / C, 혹은 다른 방향.
2. **경지 캡의 존속과 값** — ×10(A·B) 또는 제곱(C) 환산으로 유지하는가. 특히 캡과 XP
   사다리의 교차: 범인 구간(삼류 자격 Lv10 이전)에 전액 특화 시 원장 47 > 범인 캡 30 —
   캡이 먼저 서서 분산을 강제한다. 의도대로인가.
3. **성별 ±1 의 자리** — 판정층 ±1 유지(A·C 권고)인가. B-056(값 자체의 승인)이 아직 열려
   있다 — 이번에 함께 닫는가.
4. **파생치 계약** — 내력 풀·이속·내구·경공이 "환산 실수치(원장/10 또는 √원장)"를 읽어
   기존 수치를 보존하는 방식의 승인.
5. **시트 표기** — `/혼천 정보` 에 원장(0~100)과 판정치를 병기하는가, 원장만 보이는가.
6. **NPC 표의 위쪽** — 현행 NPC 최고치는 판정 6~7 (취팔선보 거지·흑곰). 최종장 플레이어
   (특화 판정 9~10)와 맞설 상위 경지 NPC 수치는 **신규 등록**이 필요하다 — 값은 별도 승인.
7. **몬스터·야수 표** — NPC 와 같이 판정어 유지(무환산)로 두는가.
8. **생성 배분의 입력 눈금** — 생성 UI 는 옛 눈금(1~2 배분)으로 받고 저장만 새 원장으로
   할 것인가, 처음부터 원장 눈금으로 받을 것인가.
