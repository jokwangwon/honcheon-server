# 단전 시각화와 심법별 축기(蓄氣) 분리

> 요청: ① 단전을 시각화하라 ② 심법마다 내공을 쌓는 방법을 분리하라.
> 두 요청은 하나로 묶인다 — **단전 시각화의 실체를 '운기 경로(경락도)'로 만들면,
> 심법마다 다른 경로와 축기 방식이 곧 눈에 보이는 개성이 된다.**
> 기계 판독용: `config/simbeop.yml`

---

## 1. 단전 모델 — 그릇의 세 속성

```text
단전(丹田) = 후천진기의 그릇. 세 속성으로 정의한다:

용량(容量)  내공 능력치의 상한 — 심법 등급이 정한다 (기초 심법으로는 그릇이 안 커진다)
순도(純度)  내력 회복 효율 — 심법의 질. 탁한 기운은 많아도 둔하다
결(結)     심법이 그릇에 새긴 무늬 — 패시브 특성 (cultivation.yml technique_by_internal의 실체)
```

내공 능력치 = 그릇에 담긴 기운의 양. 개화(단전 개방) 전에는 그릇 자체가 닫혀 있다 (범인).

## 2. 단전 시각화

### 2.1 텍스트 RPG — 은유 사전 (수치 비노출 원칙)

GM은 내공 수치를 말하지 않는다. 대신 **크기·순도·색**의 은유로 말한다:

```text
크기 (내공):  1~2 이슬 → 3~4 호두알 → 5~6 주먹 → 7~8 소용돌이 → 9~10 깊은 못
순도:        탁하다 → 흐리다 → 맑다 → 투명하다 → 형체가 없다
결 (심법):    태극기공 = 흑백의 쌍환이 서로를 문다 / 자하신공 = 보랏빛 노을이 감돈다
             혈기심공 = 붉고 탁한 기운이 굶주린 듯 돈다

운기조식 장면 예: "가부좌를 틀자, 호두알만 한 맑은 기운이 단전에서 깨어나
                임맥을 타고 오른다 — 보랏빛이다. 새벽의 기운이 스며든 자하의 결."
진맥(의원/고수)은 이 은유를 읽는 행위다 — 심법의 정체가 여기서 탄로날 수 있다 (소문 연동).
```

### 2.2 MC — 경락도 GUI + 운기 파티클

```text
경락도 GUI (커스텀 인벤토리):
  중앙 = 단전 게이지 (내력 잔량 + 그릇 크기·순도의 시각 표현)
  주위 = 혈도 노드들 + 개방된 운기 경로 라인 — 심법마다 경로가 다르다
  심법 숙련이 오르면 경로의 노드가 하나씩 점등 (성장의 시각화)

운기조식 연출 (외부에서 보이는 것):
  운기 중 파티클이 몸 주위를 심법 고유의 경로·색으로 회전
  태극 = 흑백 쌍환 / 자하 = 보라 노을 / 정심 = 검 궤적의 잔광 / 혈기 = 탁한 적색
  → 보는 자는 심법을 추측할 수 있다 — 공개 사용 소문 시스템(무공 카탈로그)과 연결
  은밀 운기: 파티클 억제 선택 가능, 대가로 회복 -20% (숨는 것도 공력이 든다)
```

## 3. 축기 방식의 분리 — 심법마다 내공이 쌓이는 길이 다르다

훈련 시간의 계상 방식 자체를 분리한다 (training.yml의 "심법 등급이 연간 성장량을 정한다"의 구체화). 기본 단위: **전용 수련 1년 = 내공 +1** (능력치 성장 규칙과 동일)에 방식별 조건이 붙는다.

| 방식 | 축기 규칙 | 어울리는 삶 |
|------|-----------|--------------|
| **좌공(坐功)** | 정좌 운기 — 수련 선언 시간이 그대로 계상 (표준) | 문파 정규 수련, 폐관 |
| **동공(動功)** | 무공 수련·실전 시간의 50%가 축기로도 계상 (이중 성장) | 검수 — 검을 휘두르는 것이 곧 축기 |
| **시공(時功)** | 특정 시간대만 계상하되 2배율 (예: 새벽 자하 1구간) | 규칙적인 삶 — 느리지만 순도 최고 |
| **전공(戰功)** | 수련 무관 — 실전 전투마다 축기 점수 (생사의 경계가 그릇을 넓힌다) | 낭인, 실전파 |
| **식공(食功)** | 좌공 + 약재·독물·영초 복용 연계 가속 | 의가·독문 — 돈과 재료가 든다 |
| **흡성(吸星)** | 타인의 내력을 즉시 약탈 (30%) — **마공 분류 ①** | 금기 |

→ 같은 1년을 살아도 심법에 따라 내공이 쌓이는 삶의 형태가 다르다. **심법 선택 = 플레이스타일 선택.**

## 4. 심법 카탈로그 (초기 6종)

| 심법 | 계열 | 방식 | 용량 상한 | 순도 | 결 (패시브) |
|------|------|------|-----------|------|--------------|
| 현천토납법 | 개방(취걸개 기연) | 좌공 | 4 | 1.0 | 없음 — 대신 개화 실패 없음, 전환 부담 최소 (기초의 미덕) |
| 태극기공 | 무당 | 좌공+동공(권법 병행 30%) | 8 | 1.5 | 방어 시 반격, 내력 회복 강화 (cultivation.yml 정합) |
| 자하신공 | 화산 | **시공 (새벽 자하 구간, 2배)** | 9 | 1.3 | 회피·속도 계열 |
| 정심검결 | 화산 검문 | **동공 (검술 시간 50% 계상)** | 6 | 1.0 | 패링 강화 (skill_mechanics 정합) |
| 칠살음독경 | 독문 | 식공 (독물 복용 가속) | 8 | 1.1 | 중독 면역·독 증폭. 대가: 축기 중 원기 소모 |
| 혈기심공 | 혈교 금기 | 흡성 | 10 | 0.8 (탁함) | 재생. 대가: 심마 누적, 운기 색을 숨길 수 없다 |

- 자하신공+정심검결은 같은 화산 계보라 **겸수 공인** (검문의 낮과 자하의 새벽 — 하루가 꽉 찬다).
- 혈기심공은 용량 10에 축기가 가장 빠르다 — 마공이 유혹인 이유가 수치로 성립.

## 5. 기질(氣質) — 정순한 내공의 정화력

심법에는 계열(도가/불가/검문/독문/개방/마공)이 있고, **순도는 회복 배율이자 정화력이다.**
도가 계열 심법으로 쌓은 정순한 내공은 독조차 밀어낸다 — 무협의 그 장면을 규칙으로 만든다.

### 5.1 정화 공식

```text
정화력 = 내공 × 순도 (+ 도가·불가 계열 보정 +2)
독 등급 기준치: 하급 8 / 중급 12 / 상급 16 / 기독(奇毒) 20 (스토리 전용)
```

### 5.2 정화의 세 가지 사용

| 사용 | 조건 | 처리 |
|------|------|------|
| **배독(排毒)** — 자가 해독 | 심법 보유 | 운기조식 1구간 + 내력 절반 소모 → 정화력 vs 독 등급 판정. 성공 시 해독, 부분 성공 시 진행 정지만 |
| **도인도기(導引渡氣)** — 타인 해독 | 도가·불가 계열 + 순도 1.3 이상 | 손목을 잡고 진기를 흘린다 — 내력 대량 소모, **실패 시 시전자에게 독이 넘어올 위험** (판정 실패 = 중독 전이) |
| **해주(解呪)** — 사기 정화 | 도가·불가 계열 | 같은 공식으로 사술·사기(邪氣) 정화 — 폐사당의 괴이, 혈교 사술 대응. 정파가 혈교전에서 필요한 이유 |

부가: 도가·불가 계열은 **심마·주화입마 판정 +2** (정순함은 안에서도 지킨다).

### 5.3 독문과의 대비 — 정화가 아니라 동화

```text
칠살음독경(독문)의 중독 면역은 정화가 아니라 동화(同化)다 — 독을 먹어서 제 것으로 만든다.
따라서 독문은 자신은 면역이어도 남을 해독하지 못한다 (도인도기 불가).
오히려 복용한 독이 축기 재료가 된다 (식공).
→ 역할 분화: 무당 도사는 해독 지원, 당가 독인은 면역 딜러 — 파티 구성의 개성이 심법에서 나온다.
```

## 6. 겸수(兼修)와 전환 — 그릇은 하나다

```text
주(主) 심법 1개 원칙. 겸수는 상성표를 따른다:
  같은 계보(화산 검문+자하): 공인 — 충돌 없음
  중립 조합: 부(副) 심법의 축기 효율 50%
  상극 조합 (자하 ↔ 혈기 등): 겸수 시도 자체가 주화입마 판정 — 기운이 그릇 안에서 싸운다

심법 전환 (상승 심법으로 갈아타기):
  같은 계보: 기존 내공 90% 승계
  중립:     70% 승계 + 재축기 기간
  상극:     50% 승계 + 주화입마 위험 — '산공(散功) 후 재축기'라는 무협 서사의 규칙화
  → 기초 심법(현천토납법)의 존재 이유: 상한 4로 낮지만 어디로든 90% 승계
```

## 7. 기존 시스템 접합

```text
내력 회복:      internal_energy.yml의 회복률 [0.5~2]가 '순도'로 구체화됨 (심법별 수치)
개화:          심법 등급이 개화 성공률·기간 결정 (v2 유지) — 현천토납법 = 실패 없음
경지 게이트:    용량 상한이 낮은 심법은 상위 경지의 발목을 잡는다 (내공 요구치) —
               상승 심법을 찾는 여정이 성장 서사의 축이 된다 (비급 기연·문파 전승)
소문·세력:      운기 파티클 색 = 심법 노출 경로. 진맥 = 강제 감식.
               남의 문파 심법을 쓰는 자는 색으로 들킨다
주화입마:       겸수 상극·독학·은밀 운기 남용이 트리거 (internal_energy.yml qi_deviation)
시간 도약:      축기 방식이 도약 정산에 반영 — 시공 심법은 '규칙적인 삶' 선언 필요,
               전공 심법은 도약 중 실전이 없으면 정체 (방식이 삶을 규정한다)
```
