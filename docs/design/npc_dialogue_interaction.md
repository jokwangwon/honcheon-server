# NPC 대화 상호작용 — 대화 창과 말의 규칙

> 결정: 플레이어가 NPC와 어떻게 말하는가 — 대화 창의 형태(디스코드/MC), 자유
> 입력이 판정이 되는 길(의도 분류), 동시 대화의 중재.
> 기계 판독용: `config/npc_dialogue.yml`

---

## 1. 대화의 3층 — 모든 표면에 공통인 규칙 층

```text
[잡담층]  판정 없는 대화 (기존 auto_resolution '안전한 대화') — 시간 minor, 자유롭게
         LLM이 NPC 대사를 생성하되 지식 경계 안에서만 (7계 ④ — knowledge에 있는 것만)
[판정층]  말이 무기가 되는 순간 — 설득·위협·정보 캐기·흥정·거짓말
         자유 입력 → 의도 분류 → judgment action_pairs 매핑 → 엔진 판정 → 결과 렌더
[세계층]  대화도 세계에 남는다 — 단서 획득 = 이벤트 로그, 실언 = 의심도·소문 후보,
         NPC는 지난 대화를 기억한다 (state_json 대화 요지 누적 — 영속화)
```

### 의도 분류 — LLM 허용 범위의 경계선 (신설 규칙)

```text
자유 입력("주인장, 요즘 북쪽 길이 뒤숭숭하다던데…")을 누가 판정으로 바꾸나:
  LLM 분류기가 '어떤 행동인가'만 정한다 → {잡담 | 정보_캐기 | 설득 | 위협 | 흥정 | 거짓말}
  수치·성패는 전부 엔진 (7계 ① 불가침 — 분류는 라우팅이지 판정이 아니다)
  확신이 낮으면 플레이어에게 확인 버튼: "[정보 캐기로 판정] [그냥 잡담]"
  분류 실패의 안전망: 잡담으로 처리 (판정을 억지로 만들지 않는다)
```

## 2. 디스코드 — 대화 창의 형태

```text
시작    지역 채널에서 NPC가 '보인다' (장면 서술에 등장) → [말 걸기] 버튼 or /대화 <이름>
       일과가 위치를 정한다 — 밤의 한백은 카운터에 없다 (schedule 조회가 선행)
창     장면 스레드 안에서 진행. NPC 대사 = 웹훅 페르소나 (NPC 이름+초상 아바타로 발화)
       — 플레이어 눈에는 '그 사람이 말하는 것'으로 보인다 (몰입의 핵심 장치)
입력    혼합형: 자유 입력(메시지) 상시 + 상황 버튼 3~5개 (LLM 렌더 choices — 프리페치)
       버튼은 지름길일 뿐, 자유 입력이 항상 우선 시민이다
판정    embed 공개 (기존 원칙) — "설득 5+2d6=13 vs 12 │ 아슬아슬한 성공"
종료    [자리를 뜬다] 버튼 / 침묵 10분 자동 이탈 / NPC가 먼저 끊는다 (일과·태세 변화)
은밀    밀담은 개인 스레드로 분기 — 같은 채널 타인에게 안 보인다 (엿듣기 판정의 표적)
```

## 3. MC — 바닐라 입력 예산 안의 대화

```text
시작    NPC 우클릭 = 말 걸기 (바닐라 문법 그대로) — 대화 반경 5블록 (이탈 = 자연 종료)
창     채팅창이 대화창이다:
       NPC 대사   [한백] 어서 오게. 뭘 들려나? (이름 색 = 태세: 백=중립/녹=우호/적=적대)
       선택지     tellraw 클릭 텍스트 1~4번 (호버 = 부가 설명) — 클릭 = 선택
       자유 입력  대화 중 채팅 = NPC에게 하는 말 (주변 발화와 구분: 자동 라우팅)
판정    액션바 한 줄 ("설득 — 아슬아슬한 성공") + 채팅 embed풍 상세 (기존 즉시성 문법)
전투 중  기존 규칙 그대로 (npc_combat combat_dialogue — 외치기는 쿨다운 시전, 발화 중 가드 불가)
군중    같은 NPC에게 다른 플레이어가 우클릭 → "대화 중이다" (아래 4장)
```

## 4. 동시 대화 중재 — NPC의 입은 하나다

```text
원칙: NPC는 한 번에 한 장면 — 대화 = scenes 잠금 (G8 문법의 첫 적용례)
대기: 후발 플레이어는 '곁에서 기다린다' (같은 공간 — 대화가 보이는 건 아니다, 밀담 제외)
끼어들기: 명시 행동 — 진행 중 장면에 개입 선언 → 기존 참가자에게 통지 → 3자 장면으로 병합
        (무례함의 대가: NPC 심증 보정 -1, 상대 플레이어와의 긴장은 플레이의 몫)
군중 대화: 상인의 '접객'은 예외 — 거래·짧은 문답은 잠금 없이 병렬 (점소이는 바쁘다)
```

## 5. NPC 쪽의 규칙 — 말은 세계의 것

```text
지식 경계   NPC는 아는 것만 말한다 (knowledge/secrets — 해금 플래그 없인 LLM도 못 꺼낸다)
기억      대화 요지가 NPC 상태에 누적 — 다음 대화에서 이어진다 ("지난번 그 얘기 말인데")
         거짓말 들통의 재료: 전에 한 말과 어긋나면 의심도 +1 (이벤트 로그 대조)
태세 반영   같은 질문도 태세가 답을 바꾼다 — 경계 상태의 묵삼은 말을 아낀다 (컨텍스트 보정 기존)
시간      잡담 minor / 본격 문답·설득 = 구간 소모 (기존 action_costs — 대화도 시간을 쓴다)
먼저 말 걸기 NPC가 먼저 온다 — 의뢰 지명·세력 접촉·회수 이벤트는 NPC발 대화로 발화
```

## 6. 접합

기존 규칙의 재사용으로 성립: 태세 스펙트럼·전투 중 대화(npc_combat) / 일과·컨텍스트
보정(npc_lifecycle) / 판정 쌍(judgment action_pairs) / 지식·비밀(npcs/*.yml) /
장면 잠금(persistence scenes) / LLM 7계·npc_lines 스키마(llm.yml). **신설은 의도
분류와 웹훅 페르소나·동시 대화 중재뿐** — 나머지는 저장처와 화면을 정한 것이다.
