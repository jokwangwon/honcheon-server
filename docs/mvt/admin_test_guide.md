> 실행 환경: 로컬 PC (Java 21+). 원격 개발 환경은 Paper 저장소가 프록시 정책상 403이라

## 기동 (원커맨드)

```bash
./scripts/run_mvt_server.sh
# 콘솔에서: op <내닉네임>   →   MC 클라이언트(1.21.4)로 localhost:25565 접속
```

스크립트가 하는 일: `:server-mvt` 빌드 → `config/`(단일 진실 원천) 동기화 →
Paper 1.21.4 다운로드(최초 1회) → 기동. 월드는 기본 생성 월드를 쓴다 (M2b 이전 단계 —
청하현 맵 컴파일 결과 투입은 다음 단계).

## 관리자 체크리스트 (권장 순서)

```text
□ 1. 가축(돼지/소) 타격 — 기세 회색 확인, 처치 시 "배울 것이 없다" (적립 0)
□ 2. 늑대 스폰(/summon wolf) 후 사냥 — 기세 붉음, 처치 즉시 +N일 (체력 절반 미만이면 생사 = 2배)
□ 3. 늑대 연속 5마리 — 적립이 8→6→4.5→…로 주는지 (감쇠 -25%)
□ 4. 대량 사냥 — 합계 16일 도달 시 "오늘은 몸이 벅차다", /time add 24000 후 리셋 확인
□ 5. 숙련 돌파 — /혼천 원장에서 누적 확인, 90일 도달 시 타이틀 (테스트 가속: 늑대 다수 소환)
□ 6. 가죽 모아 /혼천 팔기 — 늑대 가죽 장당 50문 확인
□ 7. /혼천 물가 80 / 50 / 20 / 10 — 0.9/1.0/1.3/1.6배 확인
□ 8. /혼천 정산 0 → 마진 0(정체), /혼천 정산 1 → +1(상승), /혼천 정산 9 → 클램프 ±3 안내
□ 9. /혼천 판정 여러 번 — 등급 분포 체감 (PT 문서의 그 판정)
□ 10. 체감 메모: 적립 알림 속도(같은 틱인가), 문구 가독성, 소리 과다 여부
```

## 이 MVT가 아닌 것

- 청하현 맵·NPC 엔티티·스킬 파이프라인·소문망 인게임 표시는 다음 단계 (3막 이후 + M2b)
- 원장은 메모리 보관 — 서버 재시작 시 초기화 (영속화는 정식 서버 모듈의 몫)
- 플레이어 경지는 '범인' 고정 (기세 환산 단순화)

## 피드백 회수

체감 메모(10번)와 발견 버그를 그대로 전달해 주면 F 채번으로 처리한다 —
주사위 테스트(PT)가 잡지 못하는 것(속도감·가독성·손맛)이 이 테스트의 목적이다.
