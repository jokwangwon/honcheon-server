# 플레이 테스트 로그 PT-002 — 유년 시작 · 발단의 장 · 첫 시간 도약 (경량)

> 목적: v2 인생 시작 설계(전원 유년/소년 + 발단 사건 + 장 단위 시간 도약)의 경량 검증.
> 생성부터 운명 뽑기(무작위): 집안 d6, 발단 d7, 나이 구간 d2. 판정은 실난수 (tools/roll.py).

## 생성 (운명 뽑기 결과)

```text
집안: 몰락 무가의 자식 (d6) — 조부 대에 몰락해 청하현에 흘러든 무가. 벽에 낡은 검.
발단: 핏줄의 비밀 (d7) — 부모의 과거가 찾아온다
나이: 유년, 11세 / 기질: 협의형 (참고 롤)
능력치: 근1 민2 체2 내1 감2 화1 지2 (유년 기본 1 + 배분 4)  ※ F5 패치 적용
기술: 없음 (범인, 무공 백지) / 아버지: 장터 대서(代書)로 사는 조용한 사람
```

**⚠ 생성 단계에서 즉시 발견된 결함 (F5)**: 유년 기본치 2 = 상한 2라서 배분 4포인트를
쓸 곳이 없는 모순. 아이는 성인 평균(2)보다 약한 것이 맞으므로 **유년 기본치 1**로 패치
(소년은 기본 2/상한 3 유지). → config/player_creation.yml 반영 완료.

## 장 종결 — 첫 시간 도약

```text
도약: 2년 (플레이어 선언: 중상에서 회복한 아버지에게 검을 배운다)
압축 성장: 검법 0→2, 근력 1→2 / 사사(스승 有) → 범인 → 삼류 승급
나이: 11 → 13세 → 소년 구간 진입: 배분 +1 (체력 2→3), 상한 3
세계 진행: 청하현 상태 자연 회복 / 북쪽 산길에 도적 소문이 스멀거리기 시작
          (본편 청하현 사건들의 씨앗이 심기는 시점 — 기존 콘텐츠와 시간선 접속)
```

종료 상태: **13세 삼류 초입 소년.** 물려받은 것 = 구결 반쪽 + 아버지의 검법.
장기 훅 = 종남파, 파문의 누명, 왼발을 저는 사제, 검보의 나머지 반쪽.
초기 목표 갱신: "아버지의 누명을 벗긴다" — 유년의 발단이 일생의 목표가 됐다.

## 검증된 것

```text
1. 운명 뽑기가 즉시 서사를 만든다 — 몰락 무가 × 핏줄의 비밀 조합이 자동으로
   "벽의 낡은 검"과 이어졌다 (집안의 world_link가 발단의 재료로 기능).
2. 아이 취급 보정이 유년 플레이를 성립시킨다 — 감각 2짜리 아이가 엿듣기/미행에서
   3연속 유효 결과. '눈과 귀, 발'이라는 유년 플레이 스타일이 수치로 실현됨.
3. 부수 리스크의 서사 가치 재확인 — '아버지가 알았다', '아버지가 아들을 봤다'가
   전부 주사위에서 나온 드라마.
4. 장 종결 → 시간 도약 → 구간 상승(유년→소년) → 세계 동시 진행의 흐름이 자연스럽고,
   도약이 본편 콘텐츠(청하현 사건)와 시간선을 접속시키는 도구로 작동.
```
