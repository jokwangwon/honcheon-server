# 플레이 테스트 로그 PT-005 — 첫 인터랙티브 세션 (사용자 플레이어)

> 최초의 실사용자 세션. GM = LLM(본 세션), 플레이어 = 사용자. 실난수 판정 9회.
> 생성(성향 테스트)부터 제2장 중반까지 — 규칙 통합 검증 + UX 발견.

## 세션 요약

```text
캐릭터: 이름 없는 아이 — 12세 유년, 객잔집 자식, 발단 '습격' (전부 운명 뽑기)
       성향 테스트 B,B,C,A,C → 5중 동점 = "아직 정해지지 않은 아이"
제1장 「불타는 주막」: 이리 낙인 무리의 습격 — 틈새 관찰(성공) → 장독대 선취(성공)
       → 겨울밤 관도 주파(실패 → 곽진의 상단이 구조: 실패의 루트 전환) → 한백이 거둠
       → 시간 도약 (겨울~봄 5개월, 점소이 생활 정산)
제2장 「객잔의 아이」: 절름발이 서생 투숙 — 떠보기(실패: 경계 상승) → 엿듣기(성공:
       한백이 아이를 지켜줌) → 새벽 미행(부분 성공: 늦게 도착) → 잿더미 대치 —
       돌팔매 교란(쌍육 대성공: 헛간 붕괴, '어른들의 매복'으로 오인) → 추궁(부분:
       장부 사본·구출 우선 원칙·관원 연루) → 곽진 설득(아슬: 정찰 합류 + 소문 반 토막
       유출) → 글 배우기(화후 반 성) → 북행 소금 수레에서 중단
세계 스레드: 이리 낙인(미상 세력, 상단 화압 배후 의혹), 문 서생, 늙은 포교(정체 불명),
       유출 소문 1건, 북쪽 소굴(하루 반 거리 추정)
```

## 검증된 것

```text
✓ 운명 생성 + 발단 사건이 즉시 플레이 가능한 서사를 만든다 (습격 × 객잔집 = 청하현 정착 동선)
✓ 실패의 루트 전환이 실전에서 자연스럽다 — 관도 주파 실패가 곽진 인연을 만들었다
✓ 아이 보정의 양면 — 정보(+1)는 강하고 설득(-1)은 아프다: 유년 플레이 정체성 뚜렷
✓ 부수 리스크·대성공 보너스가 서사 동력 (쌍육 헛간 붕괴, 소문 반 토막 유출)
✓ 시간 도약 정산 + 세계 진행이 장 사이에서 매끄러움
✓ NPC 성향 기반 반응 — 한백의 '팔지 않음'(위험 회피+객잔 보호), 곽진의 3조건(실용주의)
```
