# PT-006 — 1막 「생존과 첫 실전」 실주사위 테스트

> 검증 질문: **무공 백지 소년이 사냥과 품팔이로 살아남으며 자라는가?**
> 대상 규칙: 실전의 경험치화 v2.1 (combat_hwahu) · 경제(생계 루프·매입가·물가) ·
> 기세 격차 · 마크. 주사위: `tools/roll.py` 실난수. 엔진: ProgressionEngine·EconomyEngine.

## 캐릭터

```text
단이(段伊) — 14세 소년, 농가의 자식 (청하현 외곽), 범인 (무공 백지)
능력치 [근력3 민첩3 체력3 내공3 감각2 화술2 지혜3] (소년: 기본2+자유5, 상한3)

```

## 정산 — 엔진 수치 검증

```text
성장 원장 (수련 일치): 덫·사냥 +14.25일 (2→3 필요 360일의 4.0%)
                     도주 +8일 / 민첩 +30일 (360일의 8.3%) — 사선의 값어치가 보인다
                     일일 상한(16일) 미접촉 — 소년 사냥 페이스에서 상한은 문제 아님 ✓
마크: 사선 2 (늑대·도적), 실전 1 (도주) — 이류 승급 요건(숙련2+실전1)에 실전 마크 기여 ✓
경제 원장: 20 → 40 → 60 → 30 → 40 → 60문. 닷새 순익 +40문
          수입 = 가죽 50×2 + 품팔이 40 / 지출 = 국밥+봉놋방 30/일 / 손실 = 가죽 1장
감쇠 체감: 같은 늑대가 8 → 3 → 2.25일치 — "더 강한 상대나 새 사냥터"압력이 실제로 생긴다 ✓
기세 확인: 범인에게 들짐승(삼류 상당)은 늘 상수 — 소년기 사냥 = 진짜 성장 루트 성립 ✓
```

**판정: 산다, 그리고 자란다 — 단 빠듯하게.** 허탕(T5)과 강탈(T6)이 이틀 치 순익을 지웠다. 이 빠듯함은 의도(생존 서사)로 판단하되, 아래 F19 처럼 문턱 하나는 손봤다.

```text

    → 패치: 집안 grants에 '생활 기술 선택 1종 (2레벨)' 추가 (농가·표국·객잔 등)

```
