## 종료 시점 세계 상태 (D2 밤)

```text
지역(청하현): 치안 53 / 경제 49 / 민심 57   (습격 저지 반영)
플레이어: 경상(판정 −1, 치료 필요), 공적 1건, 곽진 신뢰 +1
묵삼: 생존, 플레이어 얼굴 인지 (의심도 5), 접선 장소 변경
하오문: 점수 3 [1단계 소문 인지] — 대상 "얼굴 아는 낭인" (이름 미확인, 병합 대기)
녹림(갈호): 습격 실패 + 부하 피해 → 보복/재습격 떡밥
소문: R-a "낭인이 밤에 객잔 주변을 얼쩡거린다" (강도 1, 객잔망)
      R-b "상단이 도적을 격퇴했다. 낭인 하나가 활약" (강도 3, 상단망 발원 확산 중)
미획득 정보: 묵삼의 이름, 하오문 연결, 창고, 정보 유출 구조 전부 — 사건의 진상은 그대로 잠복
```

흥미로운 종료 구도: 플레이어는 습격을 저지한 공로자이면서, 동시에 하오문 장부에 "얼굴 아는 낭인"으로 올라 있다. R-b 소문이 하오문 망에 닿으면 두 기록이 **병합될 수 있다** — 다음 세션의 자연 훅.

## 검증된 것

```text
1. 실패 분기의 실전 작동 — 3연속 실패(T3·T5·T6)에도 진행 불능이 없었다.
   특히 T7: 플레이어가 잃은 루트(묵삼 조사)를 세계가 만든 사건(도적 소문→호위 공모)이
   대체했다. "실패는 루트 전환" 원칙이 GM 임기응변이 아니라 세계 상태에서 자연 유도됨.
2. 정보 경제 — 단서 부족(이름·시각 미확보)이 T8 면접을 어렵게 만들었고(단서 +1뿐),
   부분 성공의 결과가 '후미 배치'라는 서사로 자연 번역됨.
3. 세계 타이머 — 플레이어가 습격 시각을 끝내 모른 채로도 습격은 예정대로 발생.
   "세계는 기다리지 않는다" 검증. (이번엔 우연히 현장에 있었다 — 몰랐다면 D+3 습격 성공 루트)
4. 소문/세력/지역 규칙은 표 참조만으로 즉시 적용 가능 — GM 부담 낮음.
5. 아슬아슬한 성공의 부수 리스크가 서사 재료로 잘 작동 (취객 목격 → 소문 후보).
```

## 발견된 문제 (설계 보완 과제)

```text
F1. [밸런스] 협의형+'무공형'인데 낭인 지망생 신분은 무공 기술이 0 —
    전투에서 검술 0으로 판정. 시작 신분에 무기 기술 선택지 1개가 필요하거나
    '무공형' 세부 성향이 기술 1을 부여해야 함. (player_creation.yml 보완)

    다수 대 다수, 라운드 순서, 아군 NPC(곽진) 처리, 부상 적용 시점을 GM 재량으로 메꿈.
    combat_system.md가 다음 최우선 과제.
F3. [신규] 세력 반응 점수는 위협/주목 축뿐 — '우호' 축이 없다.
    상단 공적이 곽진 개인 신뢰로만 남고 상단이라는 세력 차원에는 기록되지 않음.
    세력 우호/관계 수치(또는 공적 장부) 설계 필요.

    재량이었음 — 행동-판정 대응표에 '기만 저항' 기본 규칙 추가 필요.
```
