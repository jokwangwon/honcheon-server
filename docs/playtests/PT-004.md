# 플레이 테스트 로그 PT-004 — 고경지 통합 검증 (도인도기 · 독 3층 · 오의)

> 목적: 최신 규칙 통합 시험 — 도인도기, 독 등급, 오의 개안/발동권(흐름)/격돌,
> 태극 연비, 자원 스택, 선천진기(회생). 판정: 실난수 (tools/roll.py).
> 후기 게임 비네트 — 규칙 검증용 1회성 캐릭터.

## 캐릭터

```text
청현자(淸玄子), 45세, 무당 초절정 검수. 근4 민5 체4 내8.0 감5 화3 지4 / 검법 6
심법: 태극기공 (도가, 순도 1.5, 연비: 검기·강기 -1, 반격 결)
오의: 태극혜검 — 개안 상태 (초절정: 불완전 시전, 위력 절반+대가)
내력 24 / 내구 18 / 원기 90 / 수명 잔여 55년
상대: '혈수라' — 혈교 초절정 마인 (근5 도법6, 혈기심공: 발력+1, 내구 20)
```

## 종료 정산

```text
청현자: 빈사(치료 필요), 내력 0(고갈), 원기 75(피로), 수명 잔여 45년 — 살아남은 대가의 총합
세계:   오의 소문 2건 동시 발생 (강도 3, 억제 불가) —
        "무당의 검이 관도에서 오의를 폈다" / "혈교의 마공이 목격됐다"
세력:   무당(자파 오의 사용 보고 — 청현자 소환 예상), 정파 연합(혈교 경보 — 대사건 입력),
        관군(초절정 둘 관찰 대상), 혈교(은신 파탄 — 혈수라 문책 예상)
서사 훅: 혈수라의 목적(왜 정파 무인에게 혈독을?), 무당의 추궁, 수명 10년의 무게
```

## 검증된 것

```text
✓ 도인도기 — 도가+순도 1.3↑ 조건, 판정 생략 경계(기대 +5 → 판정 필요) 정상.
  대성공의 보너스(증언 획득)가 다음 사건의 단서가 됨.
✓ 독 3층 — 상급 독은 도인도기 자격자에게도 굴려야 하는 벽 (하급처럼 자동이 아님).
✓ 태극 연비 — 검기 2→1: 기운 프로파일이 고경지 자원전에서 실질 이득.
✓ 흐름 발동권 — 패링 성공이 오의를 열었다: '잘 싸운 순간이 오의를 연다' 루프 실증.
✓ 개안의 대가 — 불완전 오의(−2)가 완전 오의에 패배: 경지 서열이 서사적으로 옳게 작동.
✓ 자원 스택의 서사 — 빈사+고갈+피로가 '더 싸울 수 없음'을 만들고, 오의 노출(소문 억제
  불가)이 마인의 이탈 이유를 시스템에서 제공: 전투 종결이 재량이 아니라 규칙에서 나옴.
✓ 회생 — 선천진기 지출 확인 대화("수명을 태우시겠습니까") → 수명 −10년.
  초절정전은 오의 한 방이 아니라 자원전이며, 마지막 자원은 수명이다.
```
